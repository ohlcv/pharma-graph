# 朗读粒度 → 组合多选

## Context（为什么改）

`漫游设置` 里的「朗读粒度」目前是**单选分段控件**，4 个固定预设互斥：

- 仅标题 / 标题和关联 / 标题和关联和标签 / 标题和摘要

用户无法自由组合朗读内容。目标：改成 **4 个独立开关**（标题 / 关联 / 标签 / 摘要），任意组合多选；朗读文本按**固定顺序**拼接，结果与勾选先后无关；刷新后记忆；老用户的既有偏好平滑迁移。

涉及朗读内容映射（均为既有字段）：

| 开关 | 取自 `SpeakableNode` |
| --- | --- |
| 标题 | `label` |
| 关联 | `edges_out[*].reason`（中文语义说明，非 target id） |
| 标签 | `tags` |
| 摘要 | `fullSummary`（保持现状，**不接入 `shortSummary`**） |

## 设计决策

1. **数据结构**：`SpeechGranularity` 枚举 → 字段集 `SpeechField = 'label' | 'edges' | 'tags' | 'summary'`，配套 `SpeechFields = readonly SpeechField[]`。
2. **持久化**：沿用同一个 key 字面量 `pg:speech:granularity`（**不改**，否则老用户偏好丢失）；值改为按固定顺序 `join('+')`，如 `label+edges+tags`。
3. **迁移**：读取时——含 `+` → 新格式（逐 token 校验，任一非法即整体回落默认，不做半信任拼接）；不含 `+` → legacy 映射：
   - `label` → `[label]`、`label-edges` → `[label, edges]`、`label-edges-tags` → `[label, edges, tags]`、`label-full-summary` → `[label, summary]`
   - 缺失 / 非法 → `[label, edges, tags]`（沿用旧默认）
   - 拆出**纯函数 `parseSpeechFields(raw)`**（不碰 localStorage），便于 node 环境单测。
4. **至少保留一项**：四项自由切换；空集时 controller 拒绝写入并返回 `false`；UI 点击后**无条件回读 controller 重新同步**（自动弹回），不加 toast、不新增 import。
5. **顺序恒定**：按常量 `SPEECH_FIELD_ORDER = ['label','edges','tags','summary']` 遍历拼接，与勾选顺序无关。
6. **属性改名**：`data-speech-granularity` → `data-speech-field`（值变为单字段 token）；容器 `role="radiogroup"` → `role="group"`；`aria-pressed` 表示各项开关。
7. **命名同步**：`SpeechGranularity`/`SpeechGranularityOptions` → `SpeechField`/`SpeechFieldOptions`；`currentGranularity`/`setGranularity` → `currentSpeechFields`/`setSpeechFields`；删除已无引用的 `SpeechGranularityLabels`。

- 类型 / 常量重命名（见决策 1、7），新增 `SPEECH_FIELD_ORDER`、`SpeechFieldLabels = { label:'标题', edges:'关联', tags:'标签', summary:'摘要' }`。

## 验证

- `npx vitest run tests/unit/ui/speech-granularity.test.ts`
- `npm run lint`
- `npm run dev` 手测：
  - 桌面侧栏与移动抽屉**各自**可多选，且互相同步（两棵树共用 `[data-speech-field]` 选择器，点一侧另一侧应同步）。
  - 刷新后偏好记忆；勾选顺序不同但朗读文本顺序恒定。
  - 取消最后一项被拒绝（自动弹回）。
  - 旧 localStorage 值（如 `label-edges-tags`）迁移后朗读结果与原预设逐字一致。

## 风险

- 测试是 node 纯函数测试，**签名一变先编译失败**，必须同步改测试。
- 同步函数必须遍历**全部** `[data-speech-field]` 按钮，否则移动端与桌面不同步。
- 不新建第二个 localStorage key，不新增文档。
