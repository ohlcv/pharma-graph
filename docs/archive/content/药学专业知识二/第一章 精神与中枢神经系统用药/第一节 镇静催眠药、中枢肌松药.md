# 镇静催眠药、中枢肌松药


## 这一节在讲什么？

这一节讲的是用于镇静、催眠和缓解肌肉痉挛的药物。镇静催眠药主要通过增强GABA能神经抑制发挥作用：苯二氮卓类（如地西泮、氯硝西泮）效果全面但有成瘾风险；非苯二氮卓类Z药（如唑吡坦）入睡效果强而依赖性相对较低；褪黑素受体激动剂（如雷美替胺）模拟生理节律，适合昼夜节律失调性失眠。中枢肌松药（如巴氯芬）则通过抑制脊髓反射弧中的中间神经元来缓解肌肉痉挛。

## 为什么要理解它？

因为失眠是门诊最常见的睡眠主诉，镇静催眠药的使用非常普遍。但成瘾风险、宿醉效应、跌倒风险（老年人）、撤药反应和长期用药管理，都是临床用药安全必须高度关注的领域。掌握各类药物的特点，是在CNS用药中做好用药监护的基础。

## 它主要和什么有关？

它最容易和抗癫痫发作药物连起来理解——苯二氮卓类本身就是癫痫持续状态的首选急救药物，作用机制（增强GABA抑制）完全相通。同时，苯二氮卓类与阿片类联用时的呼吸抑制风险，也是围手术期镇痛和急救用药中需要特别警惕的药物相互作用。

## 它通常在什么阶段出现？

它出现在CNS用药学习的起点，是临床最常用的CNS药物类别之一。学到这里，已经开始接触到"增强神经递质抑制"这一核心药理学机制，以及"CNS药物都有成瘾风险"这条贯穿始终的安全主线。

## 它在整套框架里放在哪里？

它位于《药学专业知识二》第一章第一节，是整章中临床应用最广的入门节点。往上承接CNS用药总框架，往下可通向失眠管理、焦虑治疗和癫痫持续状态的急救处理。

## 镇静催眠药药理作用横向对比

| 药物类别 | 抗焦虑 | 镇静催眠 | 抗惊厥 | 抗癫痫 | 麻醉作用 | 肌肉松弛 |
|---|---|---|---|---|---|---|
| 巴比妥类 | 有 | 有 | 有 | 有 | 有 | 有 |
| 苯二氮䓬类 | 有 | 有 | 有 | 有 | 无 | 有 |
| 佐匹克隆 | 无 | 有 | 无 | 无 | 无 | 弱 |
| 唑吡坦 | 无 | 有 | 无 | 无 | 无 | 无 |

**剂量-效应核心规律**：镇静催眠药随剂量递增效应依次为——**镇静 → 催眠 → 抗惊厥 → 麻醉 → 呼吸麻痹死亡**；其中肌肉松弛作用与剂量无正相关。

## 镇静催眠药临床用药评价

### 巴比妥类

**作用特点**

- 起效速度由脂溶性决定：短效/超短效脂溶性高、起效快；长效类脂溶性低、起效慢
- 肝药酶诱导作用：加速自身及合用药物的代谢，降低其他药物药效
- 剂量依赖性效应：随剂量升高，依次呈现"镇静→催眠→抗惊厥→麻醉→呼吸麻痹死亡"
- 记忆口诀：**全心全意**

**典型不良反应**

- 宿醉效应：嗜睡、精神依赖、步履蹒跚、共济失调、肌无力
- 过敏反应：严重可诱发史蒂文斯-约翰逊综合征（SJS），一旦出现需立即停药
- 依赖与戒断：长期用药产生耐受性、依赖性；突然停药会出现失眠、焦虑、震颤、惊厥等戒断症状
- 心血管风险：大剂量抑制心肌收缩力、降低血压；与延长 Q-T 间期的药物合用，心脏毒性风险升高
- 呼吸风险：静脉快速给药易引发呼吸暂停、支气管痉挛
- 记忆口诀：**笨蛋儿子找不到妈妈**

**禁忌与注意**

- 禁用人群：严重肺功能不全、肝硬化、血卟啉病、未控制的糖尿病、严重贫血患者
- 特殊人群：肝功能不全者常规剂量即可诱发反常兴奋，老年患者必须减量

### 苯二氮䓬类

**作用特点**

- 起效速度由脂溶性决定：地西泮、氟西泮脂溶性高、起效快；氯氮䓬起效慢
- 肝脏代谢：多数经肝脏代谢，代谢产物仍有药理活性，半衰期会延长
- 药理谱广：同时具备抗焦虑、镇静催眠、抗惊厥、抗癫痫、中枢性肌松作用
- 药物相互作用：与其他中枢抑制药合用，中枢抑制效应叠加；与对乙酰氨基酚合用，会降低退热效果
- 记忆口诀：**爸比不焦急**

**典型不良反应**

- 宿醉效应：嗜睡、步履蹒跚、共济失调
- 依赖与戒断：长期用药产生依赖；突然停药出现反跳性失眠、焦虑、多汗、震颤、惊厥
- 静脉给药风险：低血压、心动过缓、呼吸抑制
- 老年风险：易诱发跌倒、认知功能障碍
- 可透过胎盘屏障、分泌入乳汁，妊娠期、哺乳期慎用

### 非苯二氮䓬类（新型催眠药）

**作用特点**

- 作用专一：镇静催眠作用强，抗焦虑、肌松、抗惊厥作用极弱
- 安全性高：起效快、半衰期短，次日宿醉效应轻，依赖性、戒断反应远低于苯二氮䓬类，无明显呼吸抑制
- 代表药特性：**唑吡坦仅具有镇静催眠作用**，无抗焦虑、肌松、抗惊厥功效
- 记忆口诀：
  - **克隆羊没有爹妈**（佐匹克隆无额外广谱药理作用）
  - **唑吡坦是孤儿，只能一个人睡**（唑吡坦仅单一催眠作用）

**典型不良反应**

- 常见嗜睡、头晕、乏力、记忆障碍
- 罕见睡眠相关异常行为（梦游、睡眠进食、睡眠驾驶）
- 长期用药突然停药，可出现轻度反跳性失眠

## 中枢肌松药临床用药评价

### 乙哌立松

**作用特点**

- 抑制 γ-运动神经元自发冲动
- 降低肌梭敏感性
- 兼具镇痛、改善局部循环作用
- 不影响神经肌肉接头传递

**临床应用**：缓解多种疾病导致的肌紧张、痉挛性麻痹。

**典型不良反应**：嗜睡、头晕、头痛；胃肠道不适；肝功能异常；血压下降。

### 巴氯芬

**作用特点**：选择性激动 GABA-B 受体；抑制脊髓突触反射。

**临床应用**：多发性硬化所致的骨骼肌痉挛；脊髓外伤、退行性病变、肿瘤引发的肌肉痉挛。

**典型不良反应**：嗜睡、头晕、乏力、恶心；突然停药可诱发幻觉、惊厥。

### 氯唑沙宗

**作用特点**：抑制脊髓和皮层下的多突触反射；发挥肌松效果。

**临床应用**：急慢性软组织扭伤；运动后肌肉酸痛；中枢病变导致的肌肉痉挛。

**典型不良反应**：以恶心等消化道症状为主；其次为头晕、嗜睡。

## 镇静催眠总论是什么？

镇静与催眠是中枢神经系统的两种不同抑制程度，本质是剂量差异：小剂量/弱作用→镇静效果→镇静药；中剂量/强作用→诱导睡眠→催眠药。剂量继续升高：部分药物可产生抗惊厥、麻醉作用，过量会导致呼吸麻痹甚至死亡。

核心要点：

- 镇静与催眠是中枢神经系统两种不同抑制程度
- 本质是剂量差异：小剂量弱→镇静；中剂量强→催眠
- 剂量继续升高：部分药物产生抗惊厥、麻醉作用
- 过量会导致呼吸麻痹甚至死亡

## 镇静催眠药分类是什么？

按化学结构与作用靶点把镇静催眠药归类为四大类。

### 1. 巴比妥类

- 作用机制：增强 GABA 介导的氯离子内流，非特异性广泛抑制中枢神经系统

### 2. 苯二氮䓬类

- 作用机制：选择性激动 GABA-A 受体，促进氯离子通道开放，增强中枢抑制

### 3. 非苯二氮䓬类（新型催眠药）

- 非苯二氮䓬类 GABA 受体激动剂：唑吡坦、佐匹克隆、右佐匹克隆、扎来普隆
- 褪黑素/食欲素受体调节剂：雷美替胺（褪黑素受体激动剂）、食欲素受体拮抗剂

### 4. 其他类

- 水合氯醛

## 失眠临床选药原则是什么？

失眠按主诉分型选择镇静催眠药的临床用药原则。严格按三层结构的「药物画像 → 场景」对齐：

| 主诉分型 | 首选药物 | 类别归属 |
|---|---|---|
| **入睡困难** | 扎来普隆 | 非苯二氮䓬 Z 药 |
| **入睡 + 睡眠维持** | 唑吡坦、佐匹克隆 | 非苯二氮䓬 Z 药 |
| **焦虑 + 夜间觉醒过多/早间觉醒过早** | 氟西泮 | 苯二氮䓬类（长效） |

记忆口诀：**入扎｜焦氟｜双唑佐**

> 说明：三唑仑不作为睡眠维持/夜醒早醒适应症（仅短效标签）。原发性失眠为类别层级原则，见下方"特殊知识点"。

## 中枢肌松药总论是什么？

中枢肌松药作用于脊髓、大脑皮层下中枢，抑制多突触反射，阻断神经冲动传导，从而产生骨骼肌松弛效应。

核心要点：

- 作用于脊髓、大脑皮层下中枢
- 抑制多突触反射
- 阻断神经冲动传导
- 产生骨骼肌松弛效应

## 中枢肌松药分类是什么？

中枢肌松药分为两大类。

### 苯二氮䓬类中枢肌松药

- 代表：地西泮（兼具肌松作用）

### 非苯二氮䓬类中枢肌松药（本节重点）

- 乙哌立松
- 巴氯芬
- 氯唑沙宗

## 特殊知识点｜不归属单药画像

（类别层级原则、家族共性、跨药场景。这些考点不能硬塞进某一个药的画像卡。）

### 1. 【原发性失眠｜类别层级原则】

> **原发性失眠 → 首选「非苯二氮䓬类 Z 药」**

这是类别选择原则，不是某一个具体药物的适应症。不要把这个原则下放到扎来普隆或唑吡坦的画像里。

### 2. 【苯二氮䓬类｜共同药理作用】

> **抗焦虑 ｜ 镇静催眠 ｜ 抗惊厥 ｜ 抗癫痫 ｜ 肌松**
>
> **无麻醉作用**

记忆口诀：**抗焦镇惊癫，肌松不麻醉**

### 3. 【苯二氮䓬类｜按时长分类】

| 时长分类 | 代表药物 | 备注 |
|---|---|---|
| **短效** | 三唑仑 | 正式考点原文短效仅明确 **三唑仑** 一个 |
| **长效** | 氟西泮、夸西泮、地西泮 | 必须包含 **夸西泮** |

记忆口诀：**三咪短，氟夸地长**

> ※ 咪达唑仑虽然属于短效苯二氮䓬类，但本考点原文只把"三唑仑"列为短效。口诀可以保留"三咪短"助记，但正式分类短效 = 三唑仑。

### 4. 【苯二氮䓬类｜老年人】

> 老年人敏感性增加 → **更容易出现宿醉效应**（嗜睡、步履蹒跚、共济失调、跌倒）

### 5. 【特殊药物｜跨场景连接】

> **咪达唑仑** → 外科手术 / 诊断检查 → **诱导睡眠**（跨第二节抗癫痫节复用）
>
> **水合氯醛** → **近似生理性睡眠**
>
> **水合氯醛** → **小儿高热 ｜ 破伤风 ｜ 子痫** 引起的惊厥

### 6. 【仅用于治疗失眠】两药共性

> **唑吡坦、佐匹克隆** —— 两药均仅具镇静催眠作用，无抗焦虑、肌松、抗惊厥等额外药理谱。

### 7. 【巴比妥类｜起效速度】

> **脂溶性越高 → 起效越快**

四药起效速度从快到慢排序：**硫喷妥钠 ＞ 司可巴比妥 ＞ 异戊巴比妥 ＞ 巴比妥**

记忆口诀：**硫 ＞ 司 ＞ 异 ＞ 苯**
