# 非苯二氮䓬类按靶点分类

## 它在讲什么？

按作用靶点对非苯二氮䓬类进行亚类细分。

## 靶点分类

### GABA 受体激动剂

- 唑吡坦
- 佐匹克隆
- 右佐匹克隆
- 扎来普隆

### 褪黑素/食欲素受体调节剂

- 雷美替胺（褪黑素受体激动剂）
- 食欲素受体拮抗剂

## 它和节的关系？

它属于非苯二氮䓬类分类下的靶点亚类细分节点，向上承接非苯二氮䓬类 module 节点。
