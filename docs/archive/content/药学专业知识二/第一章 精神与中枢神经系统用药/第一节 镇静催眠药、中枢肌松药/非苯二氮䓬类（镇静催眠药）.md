# 非苯二氮䓬类（镇静催眠药）


## 它是什么分类？

按化学结构分类的镇静催眠药类别，也称新型催眠药（Z 药 + 褪黑素/食欲素调节剂）。

## 分类下有哪些代表药物？

按靶点细分：

- 非苯二氮䓬类 GABA 受体激动剂（Z 药）：唑吡坦、佐匹克隆、右佐匹克隆、扎来普隆
- 褪黑素/食欲素受体调节剂：雷美替胺（褪黑素受体激动剂）、食欲素受体拮抗剂

## 记忆口诀

- **非非睡鼻**——非苯二氮䓬类，主打睡眠改善
- **克隆羊没有爹妈**——佐匹克隆无额外广谱药理作用
- **唑吡坦是孤儿，只能一个人睡**——唑吡坦仅单一催眠作用

## 它和节的关系？

它属于镇静催眠药、中枢肌松药节下的化学分类分支，与巴比妥类、苯二氮䓬类、其他类分类并列。
