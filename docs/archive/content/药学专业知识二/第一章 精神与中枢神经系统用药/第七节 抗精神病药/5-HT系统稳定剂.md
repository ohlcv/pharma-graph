# 5-HT 系统稳定剂

## 它是什么分类？

SGAs 按作用靶点的子分类。

## 代表药物

- 阿立哌唑

## 它和节的关系？

它属于抗精神病药节下第二代抗精神病药按作用靶点的子分类，与 5-HT₂A/D₂ 受体拮抗剂并列。
