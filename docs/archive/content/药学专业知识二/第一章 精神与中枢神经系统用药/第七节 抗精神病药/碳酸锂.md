# 碳酸锂

## 它是什么药？

心境稳定剂（治疗躁狂症、双相情感障碍）。

## 它的核心特点是什么？

- 躁狂症的首选治疗药物
- 对双相情感障碍（躁狂抑郁交替发作）有良好的治疗与预防复发作用
- 也可预防反复发作的抑郁症

## 关键提示

- 治疗窗极窄，治疗剂量与中毒剂量接近
- 用药期间必须常规监测血锂浓度

## 典型不良反应

**常见（用药初期更明显）**：

- 恶心、呕吐、腹泻
- 多尿、烦渴
- 手抖、乏力
- 体重增加

**长期用药**：

- 甲状腺功能减退
- 肾浓缩功能下降
- 需定期监测甲状腺功能与肾功能

## 锂中毒

血药浓度过高引发，表现为意识模糊、共济失调、高热、惊厥、昏迷，严重可致死亡。

**诱发/加重因素**：腹泻、大量出汗、低盐饮食会加重锂蓄积。

## 用药注意（钠盐摄入）

- 钠可促进锂的肾脏排泄
- 低钠饮食易诱发锂中毒
- 服药期间需保持正常盐量摄入，不可低盐饮食
