# 选择性去甲肾上腺素再摄取抑制剂（NRI）

## 它是什么分类？

选择性抑制突触前膜对NE再摄取的抗抑郁药分类。

## 分类下有哪些代表药物？

- 瑞波西汀

## 记忆口诀

去瑞士买波西尼（去甲肾上腺素再摄取抑制剂 → 瑞波西汀）。

## 它和节的关系？

它属于抗抑郁药节下的分类，与其他 7 类（SSRI、SARI、四环类、SNRI、三环类、NaSSA、MAOI）并列。
