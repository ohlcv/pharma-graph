# 丙戊酸钠

## 【药物画像】

### 药物特点

> **广谱、全能抗癫痫药**

### 药物相互作用

> **碳青霉烯类 → 丙戊酸钠血药浓度↓ → 癫痫失控风险↑**

### 不良反应

> **肝毒性｜体重增加｜脱发**

### 最小映射

```text
丙戊酸钠
├─ 广谱、全能
├─ 碳青霉烯类 → 血药浓度↓ → 癫痫失控↑
└─ 肝毒性 / 体重↑ / 脱发
```

### 🧠 记忆钩子

> **"丙戊酸钠：广谱全能，肝毒、增重、脱发；碰碳青霉烯，浓度往下掉。"**

## 它是什么药？

脂肪酸类抗癫痫药，作用机制为增强GABA介导的抑制，具有多重作用机制。

## 它的作用特点是什么？

- 肝酶抑制剂
- **广谱、全能抗癫痫药，全面性强直-阵挛发作首选**
- 3岁以下儿童慎用，肝损伤风险高；**肝病患者禁用**

## 它的典型不良反应和禁忌是什么？

- 典型不良反应：**肝毒性、体重增加、脱发**、胰腺炎、致畸
- 禁忌：肝功能损害（妊期）

## 它的用药注意事项是什么？

- 关注肝毒性
- 避免与抗凝药联用
- **避免与碳青霉烯类合用——血药浓度骤降，癫痫失控风险显著升高**
- 对胎儿有致畸性，影响胎儿认知发育
- 备孕、孕期尽量避免
- 妊娠期同样增加先天畸形风险

## 按发作类型选药中的位置

- 失神发作：乙琥胺、丙戊酸、拉莫三嗪
- 肌阵挛发作：乙琥胺、丙戊酸、拉莫三嗪
- 全面性强直-阵挛发作：丙戊酸、左乙拉西坦、托吡酯、拉莫三嗪
- 全面性癫痫综合征：丙戊酸（最有效）

## 它和节的关系？

它属于抗癫痫发作药物节下的脂肪酸类分支，并通过GABA增强机制与苯巴比妥共享机制。在跨药特殊知识点集合中，它是"丙戊酸钠×碳青霉烯类"独立药物相互作用考点的唯一主角。
