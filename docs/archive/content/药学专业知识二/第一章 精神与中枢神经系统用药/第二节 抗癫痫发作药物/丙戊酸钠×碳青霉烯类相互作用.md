# 【特殊知识点⑤｜丙戊酸钠 × 碳青霉烯类】

> **合用 → 丙戊酸钠血药浓度↓ → 癫痫失控风险↑**

## 🧠 口诀

> **"碳青霉烯压丙戊，浓度下降癫痫控不住。"**

## 这个信息块的存在意义？

它属于"药×药→临床后果"这一类典型的独立考点。从出题视角，它常以单选或配伍题形式出现：

- 给出药名（丙戊酸钠 + 碳青霉烯类）→ 问会出现什么后果
- 给出后果（抗癫痫药血药浓度骤降、癫痫失控）→ 问合用了什么抗菌药

- 药物视角复习（丙戊酸钠画像内）：丙戊酸钠有哪些考点？→ 可以找到"碳青霉烯类浓度下降"
- 考点视角复习（本信息块）：单独强化"药×药→后果"的连锁，便于配伍/案例训练

允许知识在两个视角下出现。这不是重复，而是**药物视角 + 药物相互作用考点视角**两张地图叠加。

## 临床处理要点

1. 丙戊酸钠治疗期间应**避免合用碳青霉烯类**（亚胺培南/美罗培南/厄他培南等）
2. 若感染必须使用碳青霉烯类，应考虑**换用其他抗癫痫药**，或在密切监测血药浓度与临床症状的前提下调整方案
3. 合用期间一旦出现癫痫发作频率升高/失控，应优先排查该相互作用并立即处理
