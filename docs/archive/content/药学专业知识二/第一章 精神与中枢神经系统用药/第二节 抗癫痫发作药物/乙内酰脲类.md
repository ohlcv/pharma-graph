# 乙内酰脲类

## 它是什么分类？

按化学结构分类的抗癫痫药类别，母核为乙内酰脲环结构。

## 分类下有哪些代表药物？

- 苯妥英钠

## 它和节的关系？

它属于抗癫痫发作药物下的化学分类分支，与巴比妥类、苯二氮䓬类等分类并列。

## 在整套知识框架里放在哪里？

它位于抗癫痫发作药物节内，是化学结构分类维度下的一个分类支点，向下承接苯妥英钠节点。
