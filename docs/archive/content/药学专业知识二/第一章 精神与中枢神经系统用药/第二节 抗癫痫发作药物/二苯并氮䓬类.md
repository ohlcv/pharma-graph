# 二苯并氮䓬类

## 它是什么分类？

按化学结构分类的抗癫痫药类别，母核为二苯并氮䓬环结构。

## 分类下有哪些代表药物？

- 卡马西平
- 奥卡西平

## 它和节的关系？

它属于抗癫痫发作药物下的化学分类分支，与巴比妥类、乙内酰脲类等分类并列。

## 在整套知识框架里放在哪里？

它位于抗癫痫发作药物节内，是化学结构分类维度下的一个分类支点，向下承接卡马西平、奥卡西平节点。艾司利卡西平属于钠通道阻滞机制但化学分类不归于二苯并氮䓬类，归属其他抗癫痫药。
