# 磺胺类

## 它是什么分类？

按化学结构分类的抗癫痫药类别，母核为琥珀酰亚胺结构。

## 分类下有哪些代表药物？

- 乙琥胺

## 它和节的关系？

它属于抗癫痫发作药物下的化学分类分支，与巴比妥类、苯二氮䓬类等分类并列。

## 在整套知识框架里放在哪里？

它位于抗癫痫发作药物节内，是化学结构分类维度下的一个分类支点，向下承接乙琥胺节点。
