# 艾司利卡西平

## 它是什么药？

抗癫痫药，作用机制为钠通道阻滞。

## 它的作用特点是什么？

与卡马西平、奥卡西平同属抑制兴奋性通路下的钠通道阻滞机制药物。

## 它和节的关系？

它属于抗癫痫发作药物节下的其他抗癫痫药分支，并通过钠通道阻滞机制与卡马西平、奥卡西平共享机制。
