# 丁丙诺啡

## 它是什么药？

半合成吗啡样镇痛药（μ 受体部分激动剂）。

## 它的核心特点是什么？

- 半合成来源
- μ 受体部分激动剂
- 具较强镇痛作用

## 它和节的关系？

它属于中枢镇痛药节下半合成吗啡样镇痛药分类的代表药物。
