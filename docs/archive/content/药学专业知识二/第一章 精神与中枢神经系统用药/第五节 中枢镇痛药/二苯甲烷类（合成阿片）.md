# 二苯甲烷类（合成阿片）

## 它是什么分类？

合成阿片类下的化学结构子类（二苯甲烷母核）。

## 分类下有哪些代表药物？

- 美沙酮

## 它和节的关系？

它属于合成阿片类下的化学结构子类，与苯哌啶类、吗啡烷类、苯并吗啡烷类并列。
