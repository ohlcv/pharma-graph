# 半合成吗啡样镇痛药

## 它是什么分类？

阿片类中按来源划分的半合成产物子类。

## 分类下有哪些代表药物？

- 双氢可待因
- 丁丙诺啡
- 氢吗啡酮
- 羟吗啡酮
- 羟考酮

## 它和节的关系？

它属于麻醉性镇痛药（阿片类）下的半合成子类，与阿片生物碱类、合成阿片类并列。
