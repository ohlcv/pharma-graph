# 羟考酮

## 它是什么药？

半合成吗啡样镇痛药。

## 它的核心特点是什么？

- 半合成来源（蒂巴因衍生物）
- 强效中枢镇痛
- 临床用于中重度疼痛

## 它和节的关系？

它属于中枢镇痛药节下半合成吗啡样镇痛药分类的代表药物。
