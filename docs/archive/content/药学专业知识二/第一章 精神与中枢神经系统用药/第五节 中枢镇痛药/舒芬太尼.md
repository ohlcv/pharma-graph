# 舒芬太尼

## 它是什么药？

苯哌啶类合成阿片。

## 它的核心特点是什么？

- 苯哌啶类合成阿片
- 镇痛效力强于芬太尼
- 常用于麻醉诱导与维持

## 它和节的关系？

它属于中枢镇痛药节下苯哌啶类（合成阿片）分类的代表药物。
