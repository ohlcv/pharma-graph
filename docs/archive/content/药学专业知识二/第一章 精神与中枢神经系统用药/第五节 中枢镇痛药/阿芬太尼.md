# 阿芬太尼

## 它是什么药？

苯哌啶类合成阿片。

## 它的核心特点是什么？

- 苯哌啶类合成阿片
- 起效快、作用时间短
- 常用于短时麻醉操作

## 它和节的关系？

它属于中枢镇痛药节下苯哌啶类（合成阿片）分类的代表药物。
