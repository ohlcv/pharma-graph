# 中枢抗胆碱药


## 它是什么分类？

抗帕金森病药下与拟多巴胺类药并列的机制大类——拮抗相对亢进的乙酰胆碱功能，恢复递质平衡。

## 代表药

- 苯海索

## 它和节的关系？

它属于抗帕金森病药节下两大机制分类之一，与拟多巴胺类药并列。
