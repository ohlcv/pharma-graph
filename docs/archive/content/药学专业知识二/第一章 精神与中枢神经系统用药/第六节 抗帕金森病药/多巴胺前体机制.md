# 多巴胺前体机制（左旋多巴→DA）

## 它是什么机制？

通过补充多巴胺前体（自身无活性）+ 抑制外周脱羧增加脑内药量。

## 关键环节

| 环节 | 说明 |
|---|---|
| 前体 | 左旋多巴——多巴胺前体，本身无药理活性 |
| 透过 BBB | 可透过血脑屏障进入中枢 |
| 转化 | 在中枢经多巴脱羧酶转化为多巴胺 |
| 外周脱羧 | 99% 在外周脱羧生成多巴胺（这是常规与 DDCI 组成复方的原因） |
| DDCI 作用 | 卡比多巴/苄丝肼抑制外周脱羧，既减少外周不良反应又增加脑内药量 |

## 它在节里处于什么位置？

它属于抗帕金森病药节内多巴胺前体+DDCI 亚类的机制节点。
