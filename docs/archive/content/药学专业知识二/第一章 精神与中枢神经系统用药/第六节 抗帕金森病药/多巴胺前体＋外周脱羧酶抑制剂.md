# 多巴胺前体+外周脱羧酶抑制剂

## 它是什么分类？

拟多巴胺类药的核心亚类——补充多巴胺前体 + 抑制外周脱羧。

## 代表药

- 多巴胺前体：左旋多巴
- 外周脱羧酶抑制剂：卡比多巴、苄丝肼

## 临床常用复方制剂

| 复方 | 组成 |
|---|---|
| 多巴丝肼 | 左旋多巴 + 苄丝肼 |
| 卡左双多巴 | 左旋多巴 + 卡比多巴 |

## 典型不良反应与相互作用

左旋多巴复方制剂的典型不良反应与关键药物相互作用。

### 典型不良反应

| 类别 | 具体表现 |
|---|---|
| 胃肠道反应 | 恶心、呕吐、食欲减退 |
| 心血管反应 | 体位性低血压、心律失常 |
| 长期用药运动并发症 | 异动症（不自主的舞蹈样、手足徐动样动作）、开关现象（症状在突然缓解"开期"与加重"关期"之间波动） |
| 精神症状 | 失眠、焦虑、幻觉、妄想、抑郁等 |

### 关键药物相互作用

**维生素 B₆**

- 是多巴脱羧酶的辅酶
- 单用左旋多巴时禁用——会加速外周脱羧降低疗效
- 与卡比多巴合用时不受影响

**抗精神病药**

- 吩噻嗪类、丁酰苯类可阻断中枢多巴胺受体
- 拮抗左旋多巴疗效，甚至诱发药源性帕金森综合征
- 禁用

**单胺氧化酶抑制剂**

- 非选择性 MAOI 可引发高血压危象
- 禁止合用

## 它和节的关系？

它属于抗帕金森病药节下拟多巴胺类药的核心亚类。
