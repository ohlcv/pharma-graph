# 乙酰唑胺

## 它是什么药？

乙酰唑胺是碳酸酐酶抑制药的经典代表，通过抑制近曲小管碳酸酐酶减少H⁺-Na⁺交换。

## 适应证

| 适应证 | 备注 |
|---|---|
| **各型青光眼** | 减少房水生成、降眼压（核心用途） |
| **脑水肿** | 减少脑脊液生成 |
| **代谢性碱中毒** | 排出碳酸氢根 |
| **急性高山病** | 经典预防用途 |
| **癫痫小发作辅助** | 较少用 |
| **促进酸性药物排泄** | **碱化尿液**，如水杨酸、尿酸 |

## 碱化尿液的作用

**乙酰唑胺可碱化尿液，促进酸性药物（如水杨酸、尿酸）排泄**——是临床上用于酸性药物中毒解救的特殊价值。

## 典型不良反应

- **中枢抑制**：嗜睡、头晕、疲乏（较其他利尿药更明显）
- **代谢性酸中毒**（碳酸氢根丢失）
- **低钾血症**
- **尿路结石**（尿钙升高，易形成**磷酸钙结石**）
- **磺胺样过敏反应**
- 骨髓抑制

## 禁忌

- 对磺胺类药物过敏者
- 严重肝肾功能不全
- 代谢性酸中毒
- 肾结石病史患者

## 它和节的关系？

乙酰唑胺是碳酸酐酶抑制药的核心代表，是青光眼降眼压治疗的传统一线药物。
