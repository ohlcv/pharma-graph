# 吲达帕胺

## 它是什么药？

吲达帕胺是**类噻嗪样利尿药**的代表，商品名"钠催离"。相比氢氯噻嗪，吲达帕胺具有**利尿作用更强、对糖脂代谢影响更小**的优势。

## 核心优势

| 维度 | 氢氯噻嗪 | 吲达帕胺 |
|---|---|---|
| 利尿强度 | 中等 | **更强、持续更久** |
| 对血糖影响 | 升高 | 影响较小 |
| 对血脂影响 | 升高 | 影响较小 |
| 对尿酸影响 | 升高 | 影响较小 |
| 适用人群 | 一般人群 | 高血压伴代谢综合征、老年单纯收缩期高血压 |

## 适应证

- 原发性高血压
- 心力衰竭
- **老年单纯收缩期高血压**

## 典型不良反应

- 与噻嗪类相似但较轻：低钾、低钠
- 头痛、眩晕、乏力
- 光敏反应

## 它和节的关系？

吲达帕胺是类噻嗪样利尿药的代表，相比氢氯噻嗪更适合高血压伴代谢综合征患者使用。
