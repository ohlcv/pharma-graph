# 山梨醇

## 它是什么药？

山梨醇是甘露醇的类似物（六元醇），属于渗透性利尿药。临床应用较甘露醇少。

## 与甘露醇的区别

| 维度 | 甘露醇 | 山梨醇 |
|---|---|---|
| 代谢 | 基本不被代谢 | 部分代谢为果糖 |
| 能量供应 | 无 | 提供少量能量 |
| 临床应用 | 常用 | 较少用 |

## 适应证

- 脑水肿
- 青光眼降眼压

## 典型不良反应

- 与甘露醇类似：脱水、高钠血症
- 渗透性肾病

## 它和节的关系？

山梨醇是渗透性利尿药中的"备选"，临床应用不如甘露醇广泛。
