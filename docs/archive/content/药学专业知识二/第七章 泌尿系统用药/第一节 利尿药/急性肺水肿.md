# 急性肺水肿

## 它是什么病？

急性肺水肿是指液体快速积聚于肺组织间隙和肺泡内，导致呼吸困难、低氧血症的危急重症。

## 病因

- 急性左心衰竭（最常见原因）
- 高血压急症
- 急性心肌梗死
- 严重心律失常
- 液体过负荷

## 临床特点

- 严重呼吸困难、端坐呼吸
- 咳粉红色泡沫样痰
- 双肺湿啰音
- 低氧血症
- 强迫坐位

## 治疗

| 药物 | 作用 |
|---|---|
| **呋塞米** | 快速强效利尿 + 扩张静脉，首选 |
| 吗啡 | 镇静、扩张静脉 |
| 血管扩张药 | 硝普钠、硝酸甘油 |
| 强心苷 | 地高辛（合并心衰时）|

## 它在知识体系里的位置？

急性肺水肿是袢利尿药（呋塞米）最紧急的临床应用，是急性心衰的核心治疗之一。
