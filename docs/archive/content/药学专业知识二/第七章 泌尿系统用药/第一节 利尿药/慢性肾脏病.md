# 慢性肾脏病

## 它是什么病？

慢性肾脏病（CKD）是指各种原因引起的肾脏结构和功能障碍≥3个月的疾病。根据GFR分为5期。

## CKD分期（KDIGO）

| 分期 | GFR (ml/min/1.73m²) | 特点 |
|---|---|---|
| G1 | ≥90 | 正常或轻度升高 |
| G2 | 60-89 | 轻度下降 |
| G3a | 45-59 | 轻中度下降 |
| G3b | 30-44 | 中重度下降 |
| G4 | 15-29 | 重度下降 |
| G5 | <15 | 肾衰竭 |

## SGLT2抑制药的重要临床证据

| 研究 | 关键结果 |
|---|---|
| **DAPA-CKD** | 达格列净显著降低CKD患者肾衰和心血管死亡风险 |
| **EMPA-KIDNEY** | 恩格列净显著延缓CKD进展 |

## 治疗策略

- 控制基础疾病（糖尿病、高血压等）
- SGLT2抑制药（核心保护）
- ACEI/ARB（基础降压、降低蛋白尿）
- 非奈利酮（合并糖尿病时）
- 避免肾毒性药物
- 终末期准备肾脏替代治疗

## 它在知识体系里的位置？

慢性肾脏病是SGLT2抑制药的核心适应证之一（无论是否合并糖尿病）。
