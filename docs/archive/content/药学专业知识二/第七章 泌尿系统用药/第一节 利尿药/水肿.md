# 水肿

水肿是指组织间液过多积聚导致组织肿胀，是利尿药最常见的适应证。

## 病因分类

| 类型 | 常见病因 | 首选利尿药 |
|---|---|---|
| **心性水肿** | 心力衰竭 | 袢利尿药（呋塞米）、噻嗪类、螺内酯 |
| **肝性水肿** | 肝硬化腹水 | 螺内酯（首选）+ 袢利尿药 |
| **肾性水肿** | 肾病综合征、肾衰竭 | 呋塞米（肾病综合征首选） |
| 特发性水肿 | 不明原因 | 噻嗪类、螺内酯 |

## 治疗原则

- 心性水肿：袢利尿药快速缓解症状 + 螺内酯改善长期预后
- 肝性水肿：螺内酯单独或联合袢利尿药（避免电解质紊乱诱发的肝性脑病）
- 肾性水肿：袢利尿药为首选（特别是肾病综合征）

## 它在知识体系里的位置？

水肿是利尿药最核心的适应证，几乎所有利尿药都以治疗水肿为主要临床用途。
