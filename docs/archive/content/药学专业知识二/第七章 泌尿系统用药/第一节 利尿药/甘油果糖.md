# 甘油果糖

## 它是什么药？

甘油果糖是渗透性利尿药之一，由甘油与果糖组成，相比甘露醇具有**作用温和持久、反跳轻**的特点。

## 与甘露醇的比较

| 维度 | 甘露醇 | 甘油果糖 |
|---|---|---|
| 作用强度 | 强 | 温和 |
| 持续时间 | 短 | 持久 |
| 反跳现象 | 较明显 | 较轻 |
| 适用情况 | 急性颅内压升高 | **慢性颅内压升高** |
| 肾功能影响 | 较大 | 较小 |
| 代谢 | 不被代谢 | 提供能量 |

## 适应证

- **慢性颅内压升高**（优于甘露醇）
- 脑水肿
- 青光眼降眼压
- 脑外科手术前后

## 典型不良反应

- 头痛、恶心
- 口渴
- 大量输注可致电解质紊乱

## 它和节的关系？

甘油果糖是渗透性利尿药中"温和持久"分支的代表，是慢性颅内压升高的优选。
