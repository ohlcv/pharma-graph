# 碳酸酐酶抑制药

## 这类药是什么？

碳酸酐酶抑制药通过抑制**近曲小管上皮细胞的碳酸酐酶**，减少H⁺-Na⁺交换，增加钠、碳酸氢根排泄。**利尿作用弱，现已不作为常规利尿剂使用**。

**口诀：清官探案，走近看**

## 分类代表药

| 药物 | 特点 |
|---|---|
| 乙酰唑胺 | 经典代表药 |
| 醋甲唑胺 | 类似乙酰唑胺 |

## 作用特点

- 抑制近曲小管碳酸酐酶
- 减少H⁺-Na⁺交换
- 增加钠、碳酸氢根排泄
- **可碱化尿液，促进酸性药物排泄**（如水杨酸、尿酸）
- 利尿作用弱

## 核心适应证

| 适应证 | 备注 |
|---|---|
| **各型青光眼** | 减少房水生成、降眼压（核心用途） |
| **脑水肿** | 减少脑脊液生成 |
| **代谢性碱中毒** | 排出碳酸氢根 |
| **急性高山病** | 经典预防用途 |
| **癫痫小发作辅助** | 较少用 |
| **促进酸性药物排泄** | 如水杨酸、尿酸 |

## 典型不良反应

- **中枢抑制**：嗜睡、头晕、疲乏
- **电解质紊乱**：代谢性酸中毒、低钾血症（区别于其他利尿剂的"碱中毒"倾向）
- **尿路结石**：尿钙升高，易形成**磷酸钙结石**
- 磺胺样过敏反应
- 骨髓抑制

## 禁忌

- 对磺胺类药物过敏者
- 严重肝肾功能不全
- 代谢性酸中毒
- 肾结石病史患者

## 它和节的关系？

碳酸酐酶抑制药是利尿药中"利尿作用较弱、不作常规使用"的分类，但其青光眼降眼压、碱化尿液等作用是核心临床价值。
