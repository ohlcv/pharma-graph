# 糖尿病肾病

## 它是什么病？

糖尿病肾病是糖尿病的微血管并发症之一，主要病理特征为肾小球硬化、蛋白尿、肾功能进行性下降。

## 临床分期（Mogensen分期）

| 分期 | 特点 |
|---|---|
| I期 | 肾小球高滤过 |
| II期 | 微量白蛋白尿 |
| III期 | 持续微量白蛋白尿 |
| IV期 | 显性蛋白尿 |
| V期 | 肾衰竭 |

## 核心治疗药物

| 药物 | 类别 | 关键证据 |
|---|---|---|
| **SGLT2抑制药** | 新型口服降糖药 | CREDENCE、DAPA-CKD、EMPA-KIDNEY |
| **非奈利酮** | 高选择性醛固酮受体拮抗药 | FIDELIO-DKD、FIGARO-DKD |
| **ACEI/ARB** | 基础降压药 | IDNT、RENAAL |
| **GLP-1受体激动剂** | 部分研究显示获益 | 多项心血管获益试验 |

## 治疗目标

- 控制血糖、血压、血脂
- 减少蛋白尿
- 延缓肾功能恶化
- 降低心血管事件

## 它在知识体系里的位置？

糖尿病肾病是SGLT2抑制药和非奈利酮的核心适应证，是利尿药在肾脏保护领域的重要应用。
