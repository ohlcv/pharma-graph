# 袢利尿药

## 这类药是什么？

袢利尿药通过抑制**髓袢升支粗段上皮细胞Na⁺-K⁺-2Cl⁻共转运体（NKCC2）**发挥强效利尿作用。

**特点**：利尿作用迅速、强大、短暂，是目前作用最强的利尿药类别。

**口诀：强效他不服**

## 分类代表药

| 药物 | 特点 |
|---|---|
| 呋塞米 | 临床最常用，口服生物利用度个体差异大 |
| 布美他尼 | 效价强度最高，耳毒性最小 |
| 托拉塞米 | 生物利用度高、作用时间长，肝肾双通道代谢 |
| 依他尼酸 | 不含磺胺结构，磺胺过敏患者可选用，耳毒性最大 |

## 效价强度排序

**布美他尼 > 托拉塞米 > 呋塞米 > 依他尼酸**

## 作用特点

- 利尿作用快速而强大，不易导致酸中毒
- 改善利尿剂抵抗（扩张肾血管、增加肾血流量）
- 肾病综合征和肾衰竭的首选治疗药物
- 是改善其他利尿药无效的肾病综合征水肿的唯一药物
- 心力衰竭：扩张静脉，降低左心室充盈压，是症状性心衰治疗的基石
- 急重症高血压、合并心衰的高血压患者首选
- 用于轻中度高钙血症、高钾血症、稀释性低钠血症
- 加速毒物排泄（配合输液）
- 抢救急性肺水肿与脑水肿

## 天花板效应

呋塞米用于水肿性疾病，最大剂量可达600mg/d，常规控制在100mg/d以内。

## 典型不良反应

- **水电解质紊乱**：低血容量（低血压）、低血钾、低血钠、低血镁、低氯性代谢性碱中毒
- **耳毒性**：剂量依赖性，表现为耳鸣、听力下降、暂时性耳聋（**依他尼酸风险最高**、**布美他尼风险最低**）
- **高尿酸血症**：诱发或加重痛风
- **代谢影响**：升高血糖、血脂
- **过敏反应**：除依他尼酸外均含磺胺结构，可出现磺胺交叉过敏

口诀："那位假美女脸蛋黄，小心高糖高脂高尿酸；一只耳朵不过敏"

## 禁忌

- 严重低钠血症
- 对磺胺类药物过敏者（依他尼酸除外）
- 痛风急性期
- 严重电解质紊乱未纠正者

## 它和节的关系？

袢利尿药是利尿药中作用最强的分类，是急性心衰、严重水肿的首选治疗药物。
