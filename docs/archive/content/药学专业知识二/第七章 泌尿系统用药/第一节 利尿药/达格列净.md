# 达格列净

## 它是什么药？

达格列净是SGLT2抑制药，相比恩格列净具有更广泛的"非糖尿病人群"获益证据。

## 关键临床证据

- **DAPA-HF研究**：达格列净在HFrEF患者中，无论是否合并糖尿病均降低心血管死亡和心衰恶化风险
- **DELIVER研究**：扩展到HFpEF患者同样获益
- **DAPA-CKD研究**：在CKD患者中显著降低肾衰风险

## 多重作用

- 降糖（合并糖尿病时）
- 心衰治疗（HFrEF、HFpEF）
- 慢性肾病保护
- 降压、减重

## 适应证

- 2型糖尿病
- 射血分数降低的心力衰竭（HFrEF）
- 射血分数保留的心力衰竭（HFpEF）
- 慢性肾脏病

## 典型不良反应

- 泌尿生殖系统感染
- 酮症酸中毒
- 低血压

## 它和节的关系？

达格列净是SGLT2抑制药中"心衰证据最广"的代表，涵盖HFrEF和HFpEF两大类型。
