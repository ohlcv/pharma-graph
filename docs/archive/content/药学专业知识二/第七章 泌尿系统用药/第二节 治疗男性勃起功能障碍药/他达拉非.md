# 他达拉非

## 它是什么药？

他达拉非（商品名"希爱力"）是PDE-5抑制剂中的**长效代表**，特别适合需要长时效的患者。

## 关键特点

| 维度 | 他达拉非特点 |
|---|---|
| 作用维持时间 | **36小时**（最长） |
| 高脂饮食影响 | **不受影响** |
| "蓝视"风险 | **少见**（独特优势） |
| 背痛、肌痛 | **相对多见** |
| ED合并BPH | **可同时改善BPH下尿路症状** |

## 适应证

| 适应证 | 备注 |
|---|---|
| **勃起功能障碍** | 核心适应证 |
| **ED合并良性前列腺增生** | **独特适应证**——改善尿频、尿急、夜尿多 |
| **肺动脉高压** | 获批适应证 |

## 临床价值

- 36小时长时效，减少服药与性活动的时间关联压力
- 不受高脂饮食影响，使用方便
- 视觉不良反应少，安全性较高
- ED合并BPH患者首选（"一举两得"）

## 典型不良反应

- **背痛、肌痛**（相对多见）
- 颜面潮红、头痛（发生率低于西地那非、伐地那非）
- 鼻塞、消化不良
- **蓝视现象少见**

## 它和节的关系？

他达拉非是PDE-5抑制剂中的"长效全能选手"，兼具ED治疗、肺动脉高压、BPH下尿路症状三重适应证。
