# 勃起功能障碍（ED）

## 这是什么病？

勃起功能障碍（Erectile Dysfunction, ED）是指阴茎不能达到或维持足够勃起以完成满意性生活。

**病理生理本质**：**阴茎海绵体平滑肌松弛障碍，血液无法充盈**。

## 病因分类

| 病因类型 | 常见原因 | 占比 |
|---|---|---|
| **血管性（最常见）** | 动脉粥样硬化、糖尿病、高血压、高血脂 | >50% |
| 内分泌性 | 性腺功能减退、甲状腺疾病、库欣综合征 | 较多 |
| 神经性 | 脊髓损伤、糖尿病神经病变、盆腔手术 | 部分 |
| 药物性 | 抗高血压药（噻嗪类、β阻滞剂）、抗抑郁药、抗雄激素药 | 可观 |
| 心理性 | 焦虑、抑郁、压力 | 与器质性常共存 |

## 心血管早期信号

**关键提示**：ED是心血管疾病的早期信号！
- 阴茎血管细（直径1-2mm），血管病变最早在此显现
- 高血压、高血脂、糖尿病患者，ED发生率显著升高
- ED出现后3-5年内，心血管事件风险显著升高

## 危险因素

- 年龄增长
- 心血管疾病（高血压、动脉粥样硬化）
- 糖尿病
- 代谢综合征
- 吸烟、肥胖
- 心理压力

## 治疗原则

| 严重程度 | 首选治疗 |
|---|---|
| 轻度-中度 | **PDE-5抑制剂口服**（一线） |
| 中度-重度 | PDE-5 + 真空负压装置 |
| 重度/口服无效 | **局部注射**（前列地尔、罂粟碱+酚妥拉明）、假体植入 |

## 它在知识体系里的位置？

勃起功能障碍是泌尿系统用药中"功能性疾病"的代表，前连心血管疾病，后接慢病管理和老年医学。
