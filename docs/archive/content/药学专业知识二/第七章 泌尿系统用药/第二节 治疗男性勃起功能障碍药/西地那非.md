# 西地那非

## 它是什么药？

西地那非（商品名"万艾可"，俗称"伟哥"）是第一个上市的PDE-5抑制剂，是ED治疗的**经典代表药**。

## 用法用量

- 18岁以上成人**起始剂量50mg**
- 性活动前约**1小时**按需服用
- 根据疗效与耐受度，剂量可在25~100mg范围内调整
- **24小时内最多服用1次，单次最大剂量不超过100mg**
- 65岁以上老年患者、肝功能损伤、重度肾功能不全患者，起始剂量降至25mg为宜

## 用药注意

- **高脂餐延缓吸收，建议餐前至少2小时服用**以获得最快起效
- 起效必须有性刺激

## 适应证

| 适应证 | 备注 |
|---|---|
| **勃起功能障碍** | 核心适应证 |
| **肺动脉高压** | 获批适应证 |
| **儿童重症肺动脉高压** | 获批适应证 |

## 典型不良反应

- **"蓝视"现象**（特征性）——视物呈蓝绿色调、光敏感增强，大剂量/高血药浓度时更明显
- 颜面潮红、头痛
- 鼻塞、头晕
- 体位性低血压
- 消化不良

## 它和节的关系？

西地那非是PDE-5抑制剂中最经典的代表药，是"伟哥"这一名称的来源，也是临床应用最广泛的ED药物。
