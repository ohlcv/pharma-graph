# 二羟丙茶碱

## 它是什么？

属于**黄嘌呤类**，是茶碱的羟丙基衍生物。支气管扩张作用弱于茶碱，但**对心脏和血压的影响较小**，对合并心功能不全的患者更为适用。

## 临床应用是什么？

- 哮喘和COPD维持治疗
- **合并心功能不全的哮喘患者**（心血管副作用较茶碱轻）

## 用法用量是什么？

- **口服**：每次0.1~0.2 g，每日3次
- **静脉**：每次0.25~0.5 g

## 典型不良反应是什么？

- 胃肠道不适
- 头痛
- 心悸（较茶碱轻）

## 它和章的关系？

它是黄嘌呤类代表药之一，定位"茶碱衍生物，作用较弱但心血管副作用轻，适合心功能不全患者"。
