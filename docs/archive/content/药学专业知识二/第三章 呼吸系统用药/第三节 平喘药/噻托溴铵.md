# 噻托溴铵

## 它是什么？

属于**长效M受体拮抗剂**（LAMA），经典LAMA代表药。通过选择性阻断气道M胆碱受体（尤其是M₃受体），松弛支气管平滑肌，作用维持24 h，每日1次吸入，使用方便。

## 临床应用是什么？

- **COPD长期维持治疗一线用药**（单用LAMA为COPD稳定期一线治疗选择之一）
- **哮喘联合治疗**：与ICS+LABA组成三联制剂（如布地奈德/福莫特罗/噻托溴铵）
- **支气管痉挛预防**

## 用法用量是什么？

- **吸入给药**：每日1次，每次18 μg（噻托溴铵粉吸入剂）
- 一次/日，依从性好

## 典型不良反应是什么？

- 口干（最常见）
- 视物模糊
- 尿潴留（前列腺肥大者禁用）
- 便秘

## 它和章的关系？

它是LAMA的代表药，定位"LAMA经典，一日1次，COPD一线，LAMA三联成员"，是"拮抗胆碱带有托"口诀的成员。
