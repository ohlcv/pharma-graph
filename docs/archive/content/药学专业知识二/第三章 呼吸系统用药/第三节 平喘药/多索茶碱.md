# 多索茶碱

## 它是什么？

属于**黄嘌呤类**，新型茶碱衍生物。支气管扩张作用强于茶碱，不良反应（尤其是心脏毒性）较茶碱轻。

## 临床应用是什么？

- 哮喘和COPD的维持治疗
- 可作为茶碱的替代品（不良反应较轻）

## 用法用量是什么？

- **口服**：每次200~400 mg，每日2次
- **静脉**：每次300 mg，每日1次

## 典型不良反应是什么？

- 胃肠道不适
- 心悸（较茶碱轻）
- 头痛

## 它和章的关系？

它是黄嘌呤类代表药，定位"新型茶碱类，作用强于茶碱，不良反应较轻"。
