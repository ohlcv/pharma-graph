# 异丙托溴铵

## 它是什么？

属于**短效M受体拮抗剂**（SAMA），是急性发作联合雾化的经典搭档。通过阻断气道M胆碱受体松弛支气管，同时减少气道黏液分泌。与SABA联合雾化效果优于单用SABA。

## 临床应用是什么？

- **急性发作联合雾化首选**：与沙丁胺醇联合雾化，用于轻至中度哮喘急性发作和COPD急性加重
- **COPD维持治疗**（作为SAMA每日3~4次吸入）

## 用法用量是什么？

- **雾化溶液**：成人每次0.5 mg，与沙丁胺醇联合雾化效果更佳
- **定量气雾剂**：每次2喷（42 μg），每日3~4次

## 典型不良反应是什么？

- 口干（最常见）
- 视物模糊（睫状肌麻痹）
- 尿潴留（老年男性慎用，前列腺肥大者禁用）

## 它和章的关系？

它是M胆碱受体拮抗剂SAMA的代表药，定位"SAMA，急性发作联合雾化，与SABA协同"，是"拮抗胆碱带有托"口诀的成员。
