# 西替利嗪

## 它是什么？

属于**第二代H₁受体拮抗剂**，选择性阻断组胺H₁受体，减轻过敏症状。中枢镇静作用弱，嗜睡不良反应较第一代明显减少。

## 临床应用是什么？

- **过敏性鼻炎**（鼻塞、流涕、喷嚏、眼痒）
- **过敏性鼻炎合并哮喘**（同时改善上下气道症状）
- **慢性荨麻疹**

## 用法用量是什么？

- **口服**：每次10 mg，每日1次；或每次5 mg，每日2次

## 典型不良反应是什么？

- 嗜睡（较第一代轻）
- 口干
- 头痛

## 它和章的关系？

它是H₁受体拮抗剂的代表药，定位"第二代H₁拮抗剂，嗜睡轻，用于过敏性鼻炎合并哮喘"，是"替他考一分"口诀的成员。
