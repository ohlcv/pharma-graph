# 酮替芬

## 它是什么？

属于**第一代H₁受体拮抗剂**，兼有**肥大细胞膜稳定作用**，因此比普通H₁拮抗剂更适合哮喘的预防性治疗。价格便宜，但中枢镇静作用明显。

## 临床应用是什么？

- **哮喘预防和长期控制**（具有预防价值）
- **过敏性鼻炎**
- 慢性荨麻疹

## 用法用量是什么？

- **口服**：每次1 mg，每日2次
- 起效较慢，通常需要连续使用2~4周才能看到明显效果

## 典型不良反应是什么？

- **嗜睡**（第一代H₁拮抗剂的特点，用药初期明显）
- 口干
- 体重增加（长期使用时可见）

## 它和章的关系？

它是H₁受体拮抗剂代表药之一，定位"第一代H₁拮抗剂，兼有肥大细胞膜稳定作用，用于哮喘预防，嗜睡明显"，是"替他考一分"口诀的成员。
