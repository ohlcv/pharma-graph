# 氨溴索

## 它是什么？

属于**黏痰溶解剂**，是临床应用最广泛的祛痰药。通过促进肺表面活性物质分泌和纤毛运动，并裂解黏痰酸性糖蛋白中的二硫键，使痰液黏度降低。

## 核心作用特点是什么？

1. **祛痰作用强于溴己新**，临床应用最广泛
2. **可增强抗菌药疗效**：与阿莫西林、头孢呋辛、红霉素、多西环素等同服，可**升高抗菌药在肺组织中的浓度**，增强局部抗菌效果（这是它区别于其他祛痰药的独特优点）
3. **配伍注意**：与pH>6.3的溶液混合会导致药物游离析出沉淀，配液时需注意溶液酸碱度

## 临床应用是什么？

- 急慢性支气管炎、肺炎痰多
- COPD痰黏不易咳出
- 支气管造影术后促进造影剂排出

## 用法用量是什么？

- **口服**：每次30 mg，每日3次
- **雾化吸入**：每次15~30 mg，每日2~3次
- **静脉**：重症可静脉给药

## 典型不良反应是什么？

- 胃肠道不适
- 皮疹（罕见）
