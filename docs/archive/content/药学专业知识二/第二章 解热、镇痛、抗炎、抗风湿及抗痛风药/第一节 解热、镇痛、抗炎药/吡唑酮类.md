# 吡唑酮类

## 它是什么药？

属于**非选择性COX抑制剂**，以**保泰松**为代表。抗炎抗风湿作用较强，但**不良反应较多**，临床已少用。

## 代表药是什么？

**保泰松**——吡唑酮类代表药。

## 典型不良反应是什么？

- 胃肠道刺激：恶心、腹痛、腹泻
- **血液系统损害**：粒细胞减少、再生障碍性贫血（需警惕）
- **水钠潴留**：加重高血压、心力衰竭
- 肝损伤

## 临床应用是什么？

- 主要用于其他NSAIDs无效的风湿性疾病
- 临床已少用

## 它和章的关系？

它是NSAIDs非选择性COX抑制剂的化学分类，定位"保泰松，抗炎作用较强，但不良反应多，临床少用"。
