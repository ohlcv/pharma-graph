# 秋水仙碱

## 它是什么？

是痛风急性发作的**特异性抗炎药**，通过抑制中性粒细胞趋化、黏附和吞噬作用，减少炎症因子释放，产生强效抗炎止痛作用。**无降尿酸作用**。

## 临床应用是什么？

- **痛风急性发作首选特效药**（发病24小时内疗效最佳，超过48小时疗效显著下降）
- **降尿酸治疗初期的预防用药**（小剂量联用，防止血尿酸波动诱发急性发作）

## 用法用量是什么？

- **急性发作**：首剂1 mg，之后按需补充，**24小时最大剂量不超过6 mg**
- **预防剂量**：每日0.5~1 mg（小剂量用于降尿酸治疗前3~6个月）

## 典型不良反应是什么？

- **胃肠道反应**：最常见的**早期中毒信号**——恶心、呕吐、腹痛、水样腹泻；出现腹泻需**立即停药**
- 长期/大剂量：肌炎、周围神经病变、骨髓抑制（粒细胞、血小板减少）、肝肾功能损伤
- 静脉给药全身毒性风险高，**优先选择口服给药**

## 禁忌人群是什么？

- 骨髓增生低下者禁用
- 严重肝肾功能不全者禁用
- 妊娠期、哺乳期女性禁用

## 它和章的关系？

它是急性发作期抗痛风药的代表药，定位"急性发作首选特效药，无降尿酸作用，治疗窗窄，胃肠道是中毒信号，24h最大6mg"。

## 记忆口诀是什么？

**"秋水治疗窗很窄，胃肠道是中毒信号，24h不过6"**

| 口诀 | 含义 |
|---|---|
| **治疗窗很窄** | 安全剂量与中毒剂量接近，不良反应呈剂量依赖性 |
| **胃肠道是中毒信号** | 恶心、呕吐、腹泻是**最早出现的**中毒信号，出现腹泻需立即停药 |
| **24h不过6** | 急性发作24小时内最大剂量不超过6 mg |
