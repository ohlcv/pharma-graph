# 阿那白滞素

## 它是什么药？

白细胞介素‑1（IL‑1）受体拮抗剂，属于bDMARDs，通过竞争性阻断IL‑1受体，抑制IL‑1介导的炎症反应。

## 临床定位是什么？

- 类风湿关节炎（传统DMARDs疗效不佳时）
- 自身炎症性疾病（如Still病）

## 典型不良反应是什么？

1. **注射部位反应**：红肿、疼痛（最常见）
2. 感染风险升高
3. 头痛

## 用药注意是什么？

- 每日皮下注射给药
- 用药前筛查感染

## 它和章的关系？

是bDMARDs中IL‑1通路的代表，定位"IL‑1受体拮抗剂，注射部位反应最常见，每日给药"。
