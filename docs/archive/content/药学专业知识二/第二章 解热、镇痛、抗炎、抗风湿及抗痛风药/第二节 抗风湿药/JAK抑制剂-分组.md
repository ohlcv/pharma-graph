# JAK抑制剂

## 它们是什么药？

Janus激酶（JAK）抑制剂，属于**小分子靶向合成DMARDs（tsDMARDs）**，通过抑制JAK信号通路，阻断多种炎症因子表达。口服给药是其突出优势。

## 代表药有哪些？

- **枸橼酸托法替布**
- **巴瑞替尼**

## 临床定位是什么？

- 类风湿关节炎（csDMARDs疗效不佳时）
- 活动性强直性脊柱炎

## 典型不良反应是什么？

1. **感染风险升高**：带状疱疹发病率高于其他bDMARDs
2. **心血管事件**：血栓风险（FDA黑框警告）
3. 胃肠道不适
4. 肝功能异常

## 用药注意是什么？

- 用药前需筛查结核、乙肝
- 有血栓史者慎用

## 它和章的关系？

是tsDMARDs的代表，定位"口服JAK抑制剂，带状疱疹和血栓风险需关注，FDA黑框警告"。
