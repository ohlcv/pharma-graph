# 传统合成改善病情的抗风湿药

## 它是什么？

传统合成改善病情的抗风湿药（csDMARDs），又称慢作用抗风湿药，是风湿免疫病的一线基础治疗。**起效慢**（3~6个月），但能延缓关节骨破坏。

## 分哪几类？

| 类别 | 代表药 |
|---|---|
| **抗疟药** | 羟氯喹、氯喹 |
| **免疫抑制剂** | 来氟米特、甲氨蝶呤、环磷酰胺、吗替麦考酚酯、硫唑嘌呤、环孢素 |
| **金制剂** | 金诺芬 |
| **其他** | 柳氮磺吡啶 |

## 记忆口诀是什么？

**"甲乙丙丁戊，红金双"**——csDMARDs 六大代表药：天干"甲乙丙"对应甲氨蝶呤、来氟米特、柳氮磺吡啶；"红"对应羟氯喹（抗疟药颜色）；"金"对应金诺芬；"双"对应双醋瑞因。

## 它和章的关系？

是DMARDs的两大分支之一，定位"传统合成，起效慢，一线基础，延缓骨破坏"。
