# 依奇珠单抗

## 它是什么？

属于**IL-17抑制剂**，是**人源化抗IL-17A单克隆抗体**，选择性阻断IL-17A。

## 临床应用是什么？

- 银屑病关节炎
- 强直性脊柱炎
- 斑块型银屑病

## 典型不良反应是什么？

- 感染风险升高（用药前需筛查结核/乙肝）
- 过敏反应
- 注射部位反应

## 它和章的关系？

它是IL-17抑制剂代表药，定位"人源化抗IL-17A，用于银屑病关节炎和强直性脊柱炎"。
