# 免疫抑制剂（DMARDs）

## 它们是什么药？

属于**csDMARDs**中的**免疫抑制剂**，通过抑制免疫细胞增殖或功能，减少自身免疫炎症反应，对风湿免疫病起改善病情作用。

## 代表药及特点是什么？

| 药物 | 临床定位 | 典型不良反应 |
|---|---|---|
| **甲氨蝶呤** | 类风湿关节炎**锚定药、首选药**，每周1次，需补充叶酸 | 骨髓抑制、肝损伤、致畸 |
| **来氟米特** | 类风湿关节炎、狼疮性肾炎 | 强致畸性、肝损伤 |
| **环磷酰胺** | 重症系统性红斑狼疮、血管炎 | 出血性膀胱炎、骨髓抑制 |
| **吗替麦考酚酯** | 狼疮肾炎、器官移植排斥 | 胃肠道反应、感染风险 |
| **硫唑嘌呤** | 系统性红斑狼疮维持治疗 | 骨髓抑制、肝损伤 |
| **环孢素** | 类风湿关节炎、狼疮肾炎 | 牙龈增生、多毛、高血压 |

## 记忆口诀是什么？

**"甲乙环吗硫环"**——按谐音串联六大免疫抑制剂。

## 它和章的关系？

是csDMARDs中最重要的一类，定位"免疫抑制，锚定药首选，多药可选，各有特色不良反应"。
