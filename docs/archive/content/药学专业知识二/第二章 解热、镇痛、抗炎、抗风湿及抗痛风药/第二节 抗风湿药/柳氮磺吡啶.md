# 柳氮磺吡啶

## 它是什么药？

属于**csDMARDs**中的**磺胺类**药物，具有抗炎和免疫抑制作用。

## 临床定位是什么？

- **强直性脊柱炎**（常用药之一）
- 类风湿关节炎
- 溃疡性结肠炎

## 典型不良反应是什么？

1. **磺胺过敏**：皮疹、光敏反应，严重者可致Stevens‑Johnson综合征
2. **罕见引起DRESS综合征**（严重全身性过敏反应）
3. **男性可逆性不育**：精子计数减少，停药可逆
4. 胃肠道反应：恶心、腹泻
5. 肝功能异常

## 代谢特点是什么？

- 口服难吸收，在肠道内被细菌分解为**5‑氨基水杨酸**和**磺胺吡啶**
- 5‑氨基水杨酸发挥抗炎作用，磺胺吡啶发挥抗菌作用

## 它和章的关系？

是csDMARDs中磺胺类代表，定位"磺胺类，强直性脊柱炎常用，男性可逆不育需关注"。

## 记忆口诀是什么？

**"柳氮磺吡啶，炎症肠病磺胺类，罕见DRESS不育男"**

| 口诀 | 含义 |
|---|---|
| **柳氮磺吡啶** | 药名 |
| **炎症肠病** | 溃疡性结肠炎 |
| **磺胺类** | 药物类别 |
| **罕见DRESS** | 罕见引起DRESS综合征 |
| **不育男** | 男性可逆性不育 |

**为什么要记？** 柳氮磺吡啶的三大考点：磺胺类、罕见DRESS综合征、男性可逆不育。
