# 蛋白质类药（重组XX、XX单抗）特点总结

## 共同特点是什么？

生物制剂（重组蛋白药物、单克隆抗体类药物）具有以下共同特征：

## 给药途径是什么？

| 给药方式 | 说明 |
|---|---|
| **皮下注射** | 常用，可自行注射（如阿达木单抗、依那西普） |
| **静脉注射/输注** | 用于需要缓慢给药的药物（如英夫利昔单抗） |

## 共性不良反应有哪些？

1. **过敏反应**：皮疹、荨麻疹，严重者可能发生过敏性休克
2. **注射部位局部反应**：红肿、疼痛（皮下注射常见）
3. **输液反应**：发热、寒战、胸闷（静脉输注时）
4. **类流感样症状**：发热、乏力、肌肉酸痛
5. **产生中和抗体**：长期用药后可能产生抗药物抗体，导致疗效下降

## 贮存条件是什么？

**2～10℃，冷藏保存**——蛋白质药物稳定性差，温度过高会导致蛋白变性失效。

## 临床使用注意是什么？

1. 用药前需**皮试或密切监测**过敏反应
2. 静脉给药时**缓慢输注**，并监测生命体征
3. 每次用药前检查**药物有效期和外观**
4. 居家存放需放置**冰箱冷藏层**，避免冷冻和高温
5. 用药期间若出现发热、严重皮疹需及时就医
