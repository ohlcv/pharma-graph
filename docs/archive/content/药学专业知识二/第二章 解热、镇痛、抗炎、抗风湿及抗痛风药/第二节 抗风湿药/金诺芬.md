# 金诺芬

## 它是什么药？

属于**csDMARDs**中的**金制剂**，通过抑制免疫细胞功能和炎症因子发挥抗风湿作用，历史悠久，现已少用。

## 临床定位是什么？

- 活动性类风湿关节炎（主要用于其他药无效时）
- 曾是经典抗风湿药，现已被csDMARDs其他药物取代

## 典型不良反应是什么？

1. **黏膜损害**：口腔炎、舌炎、皮炎
2. **血液系统损害**：白细胞减少、血小板减少
3. 蛋白尿（肾脏损害）
4. 腹泻

## 记忆口诀是什么？

**"金钱（金诺芬）没了，要检查"**

| 口诀 | 含义 |
|---|---|
| **金钱（金诺芬）** | 药名 |
| **没了** | 半衰期长，体内蓄积 |
| **要检查** | 定期检查肝肾功能、血常规 |

**为什么要记？** 金诺芬起效慢（3个月）、需长期监测，口诀帮助记住不良反应检查要点。
