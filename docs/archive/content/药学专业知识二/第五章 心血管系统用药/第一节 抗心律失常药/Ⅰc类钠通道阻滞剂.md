# Ⅰc类钠通道阻滞剂

## 这一组在讲什么？

这一组讲的是钠通道阻滞剂中**阻滞强度最强、对复极影响最小**的亚类。它们明显减慢心肌细胞动作电位0相除极速率和传导速度，但基本不延长动作电位时程。

## 为什么要理解它？

因为Ⅰc类虽然抗心律失常效力强，但CAST试验（心律失常抑制试验）发现其在**心肌梗死后室性心律失常患者中反而增加死亡率**。这直接改写了Ⅰc类药物的临床定位——禁用于缺血性心脏病、结构性心脏病和心衰患者，仅用于无器质性心脏病的室上性或室性心律失常。这是"机制强≠临床获益"的经典反例。

## 它主要和什么有关？

它和钠通道阻滞剂Ⅰ类的关系是"亚类细分"——Ⅰa延长复极、Ⅰb缩短复极、Ⅰc对复极几乎无影响。它和普罗帕酮的关系是"细分类型 → 代表药"。它和心律失常死亡风险的关系是"CAST试验 → 禁忌证"。

## 它通常在什么阶段出现？

它出现在理解Ⅰa类、Ⅰb类特征之后，是钠通道阻滞剂的第三种亚类。学到这里，重点建立"药物的体外抗心律失常效力不能直接等同于临床获益甚至可能反向"这一重要用药观念。

## 它在整套框架里放在哪里？

它位于《药学专业知识二》第五章第一节抗心律失常药节下属、钠通道阻滞剂（Ⅰ类）亚类下的Ⅰc类细分模块，往上承接钠通道阻滞剂的Ⅰ类框架，往下通过普罗帕酮落地到临床用药。
