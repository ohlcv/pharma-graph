# 二十碳五烯酸（EPA）

## 它是什么药？

它是高纯度 ω-3 多不饱和脂肪酸，通过抑制肝脏 TG 合成、促进 TG 分解降低血清 TG 水平。

## 它有什么独特之处？

它的"独特"在于**EPA 纯品具有独立的抗炎和心血管保护作用**——它已被开发为处方药（Vascepa），用于高 TG 血症和降低心血管事件风险，同时具有改善血管内皮功能的作用。

## 临床应用是什么？

- **高 TG 血症**
- **心血管保护**

## 它和节的关系？

它是**高纯度 ω-3 脂肪酸的代表药**，同 DHA 共同构成 ω-3 脂肪酸家族。
