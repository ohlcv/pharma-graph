# 匹伐他汀

## 它是什么药？

它是脂溶性他汀，经 CYP2C9 代谢。

## 它有什么独特之处？

它的"独特"在于**经 CYP2C9 代谢**——与经 CYP3A4 代谢的他汀（洛伐他汀、辛伐他汀、阿托伐他汀）相比，药物相互作用相对较少。

## 临床应用是什么？

- **高胆固醇血症**

## 它和节的关系？

它是**他汀类的代表药**，脂溶性、CYP2C9 代谢。同节与其他他汀形成代谢差异对比。
