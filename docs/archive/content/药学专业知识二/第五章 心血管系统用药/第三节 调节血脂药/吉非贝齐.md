# 吉非贝齐

## 它是什么药？

它是贝丁酸类的代表药之一，通过激活 PPARα 受体，增强 LPL 活性，促进 TG 降解及 VLDL 清除。

## 它有什么独特之处？

它的"独特"在于**与他汀类药物相互作用**——吉非贝齐抑制 OATP1B1 转运体，可显著升高他汀类的血药浓度，增加肌病风险，是临床上最需要注意他汀相互作用的贝特类药物。

## 临床应用是什么？

- **高 TG 血症**

## 它和节的关系？

它是**贝丁酸类的代表药**之一。同节与非诺贝特、苯扎贝特共同构成贝特类。
