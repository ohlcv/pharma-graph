# 抗氧化剂

## 这一组在讲什么？

这一组讲的是通过强抗氧化作用抑制LDL氧化修饰的药物。代表药为普罗布考。

## 为什么要单独理解它？

因为抗氧化剂是通过"抑制LDL氧化→减少泡沫细胞形成→延缓动脉粥样硬化"机制起效的药物，区别于所有其他降胆固醇药。它的"降低HDL-C"不良反应是它与其他调脂药最大的区别。

## 典型不良反应是什么？

- **Q-T间期延长**
- **室性心律失常**
- **胃肠道反应**

## 禁忌是什么？

- **严重室性心律失常**
- **Q-T间期延长**

## 它和节的关系？

它位于调脂药分类总览下属、其他调血脂药类。定位"抗氧化机制、降低HDL、Q-T延长"。
