# 普伐他汀

## 它是什么药？

它是水溶性他汀，**不经细胞色素P450酶代谢**，药物相互作用少。

## 它有什么独特之处？

它的"独特"在于**不经CYP450代谢**——这是他汀中药物相互作用最少的药物，与经CYP3A4代谢的他汀（洛伐他汀、辛伐他汀、阿托伐他汀）形成鲜明对比，是需要多药联合治疗患者（老年人、合并多种疾病者）的理想选择。

## 临床应用是什么？

- **高胆固醇血症**
- **混合型高脂血症**

## 它和节的关系？

它是**他汀类的水溶性代表药**，不经CYP代谢。同节与洛伐他汀/辛伐他汀（CYP3A4）形成代谢差异对比。
