# 瑞舒伐他汀

## 它是什么药？

它是水溶性他汀，经 CYP2C9 代谢。是**高强度他汀的代表药之一**。

## 它有什么独特之处？

它的"独特"在于**高强度 + 水溶性 + CYP2C9代谢**——和水溶性普伐他汀一样不经 CYP3A4，但降脂强度远高于普伐他汀。可逆性肾毒性（蛋白尿、血肌酐升高）是其特殊关注点，需定期监测肾功能。

## 临床应用是什么？

- **高胆固醇血症**
- **ASCVD 防治**

## 它和节的关系？

它是**他汀类的高强度代表药**，水溶性、CYP2C9 代谢。同节与阿托伐他汀（CYP3A4）形成代谢差异对比。
