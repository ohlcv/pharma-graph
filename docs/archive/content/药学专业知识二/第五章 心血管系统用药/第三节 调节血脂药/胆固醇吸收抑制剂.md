# 胆固醇吸收抑制剂

## 这一组在讲什么？

这一组讲的是通过抑制肠道胆固醇吸收来降低血胆固醇的药物。代表药为依折麦布。

## 为什么要单独理解它？

因为胆固醇吸收抑制剂是主降胆固醇类中唯一针对肠道吸收环节的药物——和他汀（抑制肝脏合成）是完全不同的作用靶点，二者联用有协同效应。它不抑制CYP450，是他汀+依折麦布联合的理论基础。

## 典型不良反应是什么？

- **胃肠道反应**：轻微（便秘、腹胀、恶心）
- **头痛**
- **肌痛**
- 耐受性良好

## 它和节的关系？

它位于调脂药分类总览下属、主降胆固醇第二类。与他汀类联用是抑制合成+抑制吸收双重阻断的经典联合方案。
