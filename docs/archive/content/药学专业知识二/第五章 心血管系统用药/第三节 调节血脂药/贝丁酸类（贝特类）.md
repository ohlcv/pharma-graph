# 贝丁酸类（贝特类）

## 这一组在讲什么？

这一组讲的是通过激活PPARα受体、增强脂蛋白脂酶活性来降低TG的药物。代表药为非诺贝特、苯扎贝特、吉非贝齐。

## 为什么要单独理解它？

因为贝丁酸类是以降低TG为首要目标的调脂药——这是它与所有降胆固醇类药物最大的区别，它的PPARα激活机制是理解其降TG特效的核心。

## 典型不良反应是什么？

- **胃肠道不适**
- **肌痛**
- **肝酶升高**
- **胆石症**
- **血尿酸升高**

## 药物相互作用是什么？

- **与他汀类联用**：肌病和横纹肌溶解风险增加
- **与口服抗凝药联用**：增强抗凝作用，需减少抗凝药剂量

## 它和节的关系？

它位于调脂药分类总览下属、主降TG第二类。定位"降TG首选、PPARα激动机制"。
