# 高纯度ω-3脂肪酸

## 这一组在讲什么？

这一组讲的是通过抑制肝脏TG合成、促进TG分解来降低TG的高纯度ω-3多不饱和脂肪酸制剂。代表药为EPA和DHA。

## 为什么要单独理解它？

因为ω-3脂肪酸是降TG类中安全性最好、不良反应最少的药物——胃肠道反应轻微、无严重代谢不良反应、还有抗炎和改善内皮功能的作用。

## 典型不良反应是什么？

- **胃肠道反应**：轻微（恶心，腹泻）
- **鱼腥味**
- **出血风险轻度增加**

## 它和节的关系？

它位于调脂药分类总览下属、主降TG第三类。定位"降TG安全性好、抗炎附加"。
