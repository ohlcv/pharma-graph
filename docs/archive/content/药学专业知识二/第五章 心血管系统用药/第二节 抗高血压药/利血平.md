# 利血平

## 它是什么药？

它是去甲肾上腺素能神经末梢阻滞药，通过抑制交感神经末梢囊泡对去甲肾上腺素（及5-HT、多巴胺）的再摄取，使其被单胺氧化酶降解，从而耗竭神经递质而降压。

## 它有什么独特之处？

它的"独特"在于**递质耗竭 + 多系统作用**——它不仅耗竭去甲肾上腺素，还耗竭5-HT、多巴胺，因此具有中枢抑制作用（嗜睡、抑郁）。它是降压药中**抑郁症禁忌**的标志性药物。同时它的"诱发消化性溃疡"特征使溃疡病患者禁用。

## 临床应用是什么？

- **高血压**：温和降压（现已较少使用）
- **躁狂症**：作为辅助药
- **某些精神病状态**

## 典型不良反应是什么？

- **鼻塞**
- **胃酸分泌增多**：可诱发消化性溃疡
- **腹泻**
- **中枢抑制**：嗜睡、抑郁（严重者致自杀倾向）
- **帕金森样症状**
- **乳房胀痛、泌乳**

## 禁忌是什么？

- **溃疡病**
- **抑郁症**
- **帕金森病**
- **妊娠期**

## 它和节的关系？

它是去甲肾上腺素能神经末梢阻滞药亚类的**唯一代表药**，定位"递质耗竭、溃疡/抑郁/帕金森禁用"。同节属交感神经抑制药大类。
