# 厄贝沙坦

## 它是什么药？

它是ARB沙坦类的代表药，选择性阻断 AT₁ 受体降压，作用持久。

## 它有什么独特之处？

它的"独特"在于**对糖尿病肾病的明确靶器官保护作用**——IRMA-2和IDNT研究证实厄贝沙坦可显著延缓2型糖尿病肾病的进展、减少蛋白尿，是ARB中糖尿病肾病证据最充分的药物之一。

## 临床应用是什么？

- **高血压**：单独或联合治疗
- **糖尿病肾病**：靶器官保护

## 典型不良反应是什么？

- 腹泻、血钾升高、头晕、疲乏、血管神经性水肿（罕见）

## 禁忌是什么？

- 与其他ARB相同：双侧肾动脉狭窄、高钾血症、妊娠期

## 它和节的关系？

它是ARB亚类的**代表药**，定位"糖尿病肾病靶器官保护"。同节与氯沙坦、缬沙坦等共同构成ARB家族。
