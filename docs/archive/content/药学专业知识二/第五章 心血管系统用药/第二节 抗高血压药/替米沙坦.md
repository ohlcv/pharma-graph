# 替米沙坦

## 它是什么药？

它是ARB沙坦类的代表药，半衰期最长（24小时），超长效。

## 它有什么独特之处？

它的"独特"在于**超长效（24小时半衰期）+ PPARγ激动双重作用**——是ARB中半衰期最长的成员，每日给药1次即可24小时平稳降压；同时具有PPARγ激动作用，可改善胰岛素抵抗，适合伴代谢综合征、胰岛素抵抗的高血压患者。

## 临床应用是什么？

- **高血压**：单独或联合治疗
- **伴代谢综合征、胰岛素抵抗的高血压**：因PPARγ激动
- **心血管事件预防**

## 典型不良反应是什么？

- 腹泻、血钾升高、头晕、疲乏、血管神经性水肿（罕见）

## 禁忌是什么？

- 与其他ARB相同：双侧肾动脉狭窄、高钾血症、妊娠期

## 它和节的关系？

它是ARB亚类的**代表药**，定位"超长效、PPARγ激动、代谢综合征友好"。同节与氯沙坦、缬沙坦等共同构成ARB家族。
