# 硝苯地平

## 它是什么药？

它是第一代二氢吡啶类CCB的代表药，作用于L型钙通道，扩张血管降压。短效、生物利用度低、血药浓度波动大，降压快但作用时间短。

## 它有什么独特之处？

它的"独特"在于**第一代CCB的"短效 + 波动大"**特征——降压快但作用时间短、易引起反射性心动过速。同时它也是**剂型改造的经典案例**——第二代硝苯地平控释片通过缓释/控释工艺实现24小时均匀释放，是CCB剂型演进的标志。它的**舌下含服快速降压**曾用于高血压急症，但因反射性心动过速风险已不推荐。

## 临床应用是什么？

- **高血压**：第一代片剂 + 第二代控释片
- **心绞痛**：稳定型心绞痛、变异型心绞痛
- **雷诺综合征**

## 典型不良反应是什么？

- **颜面潮红、头痛**：因血管扩张
- **脚踝部水肿**：因毛细血管前小动脉扩张、毛细血管静水压升高
- **牙龈增生**：长期使用常见
- **反射性心率加快**：因短效降压快速触发压力反射
- **便秘**

## 禁忌是什么？

- **低血压**
- **严重主动脉瓣狭窄**
- **心动过速患者禁用第一代**：因反射性心率加快

## 它和节的关系？

它是二氢吡啶类CCB亚类的**第一代代表药**，定位"短效、波动大、剂型改造典范"。同节第二代（硝苯地平控释片）和第三代（氨氯地平等长效药）形成CCB三代演进。
