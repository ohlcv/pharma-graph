# 米诺地尔

## 它是什么药？

它是钾通道开放药，通过开放血管平滑肌细胞钾通道、促使K⁺外流、细胞膜超极化，从而舒张血管平滑肌、降低血压。

## 它有什么独特之处？

它的"独特"在于**降压药 + 脱发的跨领域应用**——内服是难治性高血压的口服选择；外用（溶液剂）可治疗脱发（因皮肤血管扩张作用促进毛发生长）。这一"双跨应用"使它在药学专业知识二中具有特殊地位。

## 临床应用是什么？

- **难治性高血压**：口服
- **脱发**（斑秃、雄激素性脱发）：外用溶液剂

## 典型不良反应是什么？

- **多毛症**：最显著的内服不良反应
- **反射性心动过速**
- **水钠潴留**
- **心包积液**：罕见但严重
- **体位性低血压**

## 禁忌是什么？

- **嗜铬细胞瘤**
- **严重肝肾功能不全**

## 它和节的关系？

它是钾通道开放药亚类的**代表药**，定位"钾通道开放、难治性高血压、外用治脱发"。同节与吡那地尔同属钾通道开放药。
