# 缬沙坦

## 它是什么药？

它是ARB沙坦类的代表药，选择性阻断 AT₁ 受体降压，半衰期长，长效平稳。

## 它有什么独特之处？

它的"独特"在于**长效 + VALIANT研究证据**——VALIANT研究证实缬沙坦对心肌梗死后心衰患者具有心血管保护作用。同时它也是**ARNI（沙库巴曲缬沙坦）的关键组分**——和沙库巴曲组成复方后产生ARB+脑啡肽酶抑制的双重机制。

## 临床应用是什么？

- **高血压**：单独或联合治疗
- **心力衰竭**：ACEI不耐受的替代
- **心肌梗死后**：VALIANT研究证实

## 典型不良反应是什么？

- 腹泻、血钾升高、头晕、疲乏、血管神经性水肿（罕见）

## 禁忌是什么？

- 与其他ARB相同：双侧肾动脉狭窄、高钾血症、妊娠期

## 它和节的关系？

它是ARB亚类的**代表药**，定位"长效、VALIANT研究、ARNI组分"。同节与氯沙坦形成"促尿酸排泄 vs 心血管事件预防"的不同定位。
