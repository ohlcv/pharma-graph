# 血管紧张素受体脑啡肽酶抑制剂（ARNI）

## 这一组在讲什么？

这一组讲的是兼具 ARB（缬沙坦）与脑啡肽酶抑制剂（沙库巴曲）双重作用的药物。代表药为沙库巴曲缬沙坦。

## 为什么要单独理解它？

因为 ARNI 是 RAS 抑制药中**机制最新、临床地位上升最快**的一类——作为心衰治疗新基石（PARADIGM-HF 试验显示优于依那普利）。它的"双重机制"（ARB + 脑啡肽酶抑制）是 RAS 抑制药亚类演进的标志性突破。

## 它主要和什么有关？

它和 RAS 系统的 AT₁ 受体节点 + 利钠肽系统（脑啡肽酶降解通路）双重相关。它和缬沙坦（ARB）的关系是"组分复用"，但因机制叠加，临床地位与单纯 ARB 不同。

## 它通常在什么阶段出现？

它出现在理解 ACEI、ARB、肾素抑制剂之后，是 RAS 抑制药"从单机制到双机制"演进的关键节点。

## 它在整套框架里放在哪里？

它位于《药学专业知识二》第五章第二节抗高血压药节下属、RAS 抑制药大类下的第四亚类。横跨第五章第五节抗心力衰竭药节（ARNI 是心衰新基石）。
