# 西氯他宁

## 它是什么药？

它是前列环素合成促进药，通过促进血管内皮前列环素（PGI₂）合成、发挥扩血管作用而降压。

## 它有什么独特之处？

它的"独特"在于**前列环素合成促进**——是降压药中少数通过促进PGI₂合成起效的药物之一。它临床应用较少，多作为难治性高血压的联合选择。

## 临床应用是什么？

- **高血压**：多作为联合选择
- **难治性高血压**

## 典型不良反应是什么？

- **头痛、颜面潮红**
- **胃肠道反应**
- **过敏反应**

## 禁忌是什么？

- **妊娠期**
- **严重肝肾功能不全**
- **对本品过敏**

## 它和节的关系？

它是前列环素合成促进药亚类的**唯一代表药**。同节属其他类降压药大类。
