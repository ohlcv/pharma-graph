# 伊伐布雷定

## 它是什么？

**单纯降低心率药**，选择性、特异性抑制心脏起搏If电流。

## 作用机制

| 特点 | 说明 |
|---|---|
| **靶点** | 心脏起搏If电流 |
| **作用部位** | 仅作用于窦房结 |
| **心内传导** | 无影响 |
| **心肌收缩力** | 无影响 |
| **心室复极** | 无影响 |

## 适应证

窦性心律且心率≥75次/分钟、伴有心脏收缩功能障碍的**NYHA Ⅱ~Ⅳ级慢性心力衰竭**患者

## 临床定位

- 可与β受体拮抗剂联合使用
- 用于**β受体拮抗剂禁忌或不能耐受**的患者

## 典型不良反应

| 不良反应 | 说明 |
|---|---|
| **光幻视**（闪光幻觉） | 通常轻中度，剂量依赖性，多在开始治疗2个月内出现，多为一过性 |
| **心动过缓** | 过量风险 |
| **房室传导阻滞** | 过量风险 |
| **心房颤动** | 新发或加重 |

## 禁忌

病窦综合征、严重心动过缓、传导阻滞、低血压患者禁用

## 药物相互作用

| 药物 | 效应 |
|---|---|
| **强效CYP3A4抑制剂**（酮康唑、伊曲康唑、克拉霉素、口服红霉素、奈法唑酮、利托那韦） | 禁止合用 |
| **CYP3A4诱导剂**（利福平、巴比妥类、苯妥英钠） | 降低暴露量，合用时需调整剂量 |

## 它和章的关系？

伊伐布雷定是控制心率药的代表，定位"单纯降低心率，选择性抑制If电流，对传导/收缩力/复极无影响，光幻视为特征性不良反应，CYP3A4代谢强抑制剂禁用"。
