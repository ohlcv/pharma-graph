# 去乙酰毛花苷（西地兰D）

## 它是什么？

**速效强心苷**，起效速度介于毒毛花苷K与地高辛之间，在体内可转化为地高辛。

## 核心作用特点

| 特点 | 说明 |
|---|---|
| **效价** | 速效 |
| **给药途径** | 静脉给药 |
| **起效速度** | 介于毒毛花苷K与地高辛之间 |
| **代谢** | 在体内可转化为地高辛 |

## 临床应用

- **急性心力衰竭**的紧急处理

## 它和章的关系？

去乙酰毛花苷（西地兰D）是强心苷类的速效代表，定位"速效强心苷，起效介于毒K与地高辛之间，体内转化为地高辛，用于急性心衰"。
