# 抗心力衰竭药临床用药评价与总结

## 一、强心苷类临床评价

### 作用特点

| 药物 | 效价 | 起效 | 达峰 | 持续/消除 | 特点 |
|---|---|---|---|---|---|
| **地高辛** | 中效 | 口服1~2h；静注5~30min | 口服4~6h；静注1~4h | 口服36h；静注6h | 生物利用度80%，原型经肾排泄 |
| **洋地黄毒苷** | 长效 | 1~4h | 8~14h | 半衰期7天以上 | 肝脏代谢，肾功能不全者可用 |
| **毒毛花苷K** | 速效 | 静注10~15min | — | 蓄积性低 | 起效最快 |
| **去乙酰毛花苷** | 速效 | 介于毒毛花苷K与地高辛之间 | — | 体内转化为地高辛 | 急性心衰 |

### 临床定位

适用于已使用**利尿剂 + ACEI/ARB + β受体拮抗剂**治疗仍持续有症状的**HFrEF**，或合并房颤心室率快者。

### 中毒表现与救治

| 表现 | 救治 |
|---|---|
| **胃肠道**（恶心呕吐） | 早期，停药 |
| **心脏毒性**（心律失常） | 停药+补钾；快速型：苯妥英钠；缓慢型：阿托品 |

### 药物相互作用

| 升高地高辛浓度 | 低钾增加中毒风险 |
|---|---|
| 胺碘酮、维拉帕米、普罗帕酮、螺内酯、环孢素、克拉霉素、四环素（抑制肠道细菌代谢） | 排钾利尿剂（噻嗪类、袢利尿剂） |

**禁忌**：含钙注射液

## 二、伊伐布雷定临床评价

| 项目 | 内容 |
|---|---|
| **作用** | 单纯降低心率，选择性抑制If电流，仅减慢窦性心率 |
| **适应证** | 窦性心律+心率≥75次/分+NYHA Ⅱ~Ⅳ级心衰；β受体拮抗剂禁忌/不耐受者 |
| **不良反应** | 光幻视（特征性）、心动过缓、房室传导阻滞、房颤 |
| **禁忌** | 病窦综合征、严重心动过缓、传导阻滞、低血压 |
| **相互作用** | 禁止与强效CYP3A4抑制剂合用（酮康唑、克拉霉素等） |

## 三、沙库巴曲缬沙坦（ARNI）临床评价

| 项目 | 内容 |
|---|---|
| **组成** | 沙库巴曲（脑啡肽酶抑制剂）+ 缬沙坦（AT₁拮抗剂） |
| **机制** | 减少利钠肽降解 + 抑制RAAS |
| **适应证** | HFrEF（NYHA Ⅱ~Ⅳ级，LVEF≤40%）；原发性高血压 |
| **起始剂量** | 常规100mg bid；未用过ACEI/ARB者50mg bid |
| **不良反应** | 低血压、高钾血症、咳嗽、头晕、血管性水肿 |
| **禁忌** | 禁与ACEI合用（停36h再换）；血管性水肿史；血钾>5.4mmol/L；重度肝损害；妊娠 |

## 四、八类心衰药物核心定位

| 药物 | 核心定位 |
|---|---|
| **利尿剂** | 缓解水钠潴留，改善呼吸困难和水肿 |
| **ACEI/ARB** | 抑制RAAS，延缓心室重构，改善预后（基石） |
| **ARNI** | ACEI/ARB不能控制症状时的替代选择 |
| **β受体拮抗剂** | 抑制交感，改善预后（基石） |
| **醛固酮受体拮抗剂** | 金三角成员，抗纤维化 |
| **SGLT-2抑制剂** | 排糖排钠，改善预后（新基石） |
| **伊伐布雷定** | β受体拮抗剂已达目标剂量，心率仍≥70次/分 |
| **地高辛** | 减轻症状，改善心功能，用于持续有症状者 |

## 五、核心定位对比

| 药物 | 定位 |
|---|---|
| **伊伐布雷定** | 已用ACEI/ARB/ARNI+β受体拮抗剂+醛固酮受体拮抗剂后，心率仍≥70次/分者；或β受体拮抗剂禁忌/不耐受者 |
| **地高辛** | 减轻心衰症状，改善心功能，用于HFrEF持续有症状者 |

## 记忆口诀是什么？

**"心衰治疗八罗汉：利尿普利和洛尔，醛固酮拮抗排糖王，维立西呱伊伐布雷定，地高辛来把症状清"**

**为什么要记？** 八类药物构成心衰治疗全景框架，伊伐布雷定与地高辛的定位区分是高频考点。
