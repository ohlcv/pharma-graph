# 毒毛花苷K

## 它是什么？

**速效强心苷**，所有强心苷中**起效最快**者。

## 核心作用特点

| 特点 | 说明 |
|---|---|
| **效价** | 速效 |
| **给药途径** | **静脉给药** |
| **起效时间** | **10~15分钟** |
| **特点** | 起效最快 |
| **排泄** | 以原型经肾脏排泄 |
| **蓄积性** | 低 |

## 临床应用

- **急性心力衰竭**的紧急处理（起效快，首选）

## 典型不良反应

- 胃肠道反应（恶心、呕吐）
- 心脏毒性（心律失常）

## 它和章的关系？

毒毛花苷K是强心苷类的速效代表，定位"速效强心苷，静脉10~15min起效，起效最快，蓄积性低，用于急性心衰"。
