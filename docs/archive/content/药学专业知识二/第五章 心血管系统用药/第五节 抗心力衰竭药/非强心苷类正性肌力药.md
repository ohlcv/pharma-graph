# 非强心苷类正性肌力药

## 它是什么药？

通过非强心苷类机制增强心肌收缩力，用于**急性心力衰竭短期支持治疗**的代表药。

## 代表药

| 药物 | 机制 |
|---|---|
| **米力农** | 磷酸二酯酶III抑制剂，提高cAMP，增强心肌收缩力 |
| **多巴酚丁胺** | β₁受体激动剂，增强心肌收缩力 |
| **氨力农** | 磷酸二酯酶III抑制剂（老药，已少用） |

## 与强心苷类的区别

| 对比 | 非强心苷类 | 强心苷类 |
|---|---|---|
| **机制** | PDE III抑制 / β₁激动 | 抑制Na⁺/K⁺-ATP酶 |
| **应用** | 急性心衰短期支持 | 慢性HFrEF长期治疗 |
| **心律失常风险** | 相对较低 | 相对较高 |

## 临床应用

- **急性心力衰竭**的短期血流动力学支持
- 不作为慢性心衰的长期治疗

## 它和章的关系？

非强心苷类正性肌力药是正性肌力药的一类，定位"急性心衰短期支持，不宜长期使用，与强心苷类互补"。
