# β受体拮抗剂（抗心绞痛）

## 它是什么药？

通过阻断β受体（β₁、β₂），产生以下效应：
- **减慢心率**（负性频率）
- **降低心肌收缩力**（负性肌力）
- **降低血压**
- → **降低心肌耗氧量**，缓解心绞痛

## 为什么它是抗心绞痛的核心药物？

**唯一兼具双重作用的药物类别**：

| 作用层面 | 具体效应 |
|---|---|
| **缓解症状** | 降低心肌耗氧量，与硝酸酯类/CCB联用效果更好 |
| **改善预后** | 预防心肌梗死后心室重构、改善心功能、降低心血管事件风险 |

## 代表药有哪些？

| 药物 | 特点 |
|---|---|
| **美托洛尔** | β₁选择性，临床最常用 |
| **比索洛尔** | β₁选择性，作用持续时间较长 |
| **卡维地洛** | α₁+β₁+β₂非选择性，兼具α₁阻断的扩血管作用 |
| **阿罗洛尔** | α₁+β非选择性，适用于高血压伴心绞痛 |

## 典型不良反应是什么？

- **心动过缓**
- **低血压**
- **支气管痉挛**（β₂阻断，哮喘患者慎用）
- **外周血管收缩**（四肢发凉）
- **性功能障碍**

## 禁忌人群是什么？

- **支气管哮喘**或严重COPD患者禁用（β₂阻断诱发支气管痉挛）
- **重度心动过缓**（病态窦房结综合征、Ⅱ~Ⅲ度房室传导阻滞）
- **急性心力衰竭**发作期禁用
- **心源性休克**禁用

## 它和章的关系？

β受体拮抗剂是抗心绞痛的核心药物，定位"唯一兼具缓解症状与改善预后双重作用的药物类别，降低心肌耗氧量，支气管哮喘者禁用"。

## 记忆口诀是什么？

**"美托洛尔和比索洛尔，β₁选择最常用；卡维地洛和阿罗洛尔，α₁加β非选择扩血管"**

| 口诀 | 代表药 | 特点 |
|---|---|---|
| **美托洛尔** | β₁选择性 | 临床最常用 |
| **比索洛尔** | β₁高选择性 | 作用持续时间较长，每日1次 |
| **卡维地洛** | α₁+β₁+β₂非选择性 | 扩血管，适合高血压伴心绞痛 |
| **阿罗洛尔** | α₁+β非选择性 | 扩血管，适用于高血压伴心绞痛 |

**为什么要记？** 快速区分四类β受体拮抗剂代表药：美托洛尔/比索洛尔（β₁选择性，临床最常用）vs 卡维地洛/阿罗洛尔（α₁+β非选择性，兼具扩血管作用）。
