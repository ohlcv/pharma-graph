# 心绞痛

## 它是什么病？

心绞痛是冠状动脉粥样硬化或痉挛导致心肌急剧、短暂的缺血缺氧所引起的临床综合征，表现为发作性胸痛、胸闷或胸部压迫感。

## 它分几种类型？

- **稳定型心绞痛**：因冠脉固定狭窄，多在劳累、情绪激动时发作，休息或硝酸甘油可缓解
- **不稳定型心绞痛**：斑块破裂、冠脉痉挛所致，休息时也可发作，是急性冠脉综合征的一种
- **变异型心绞痛**：冠脉痉挛引起，多在静息时发作

## 它怎么治疗？核心药物是哪几类？

- **硝酸酯类**（硝酸甘油、硝酸异山梨酯）—— 急性发作首选；硝酸甘油舌下含服 0.5mg 起效迅速
- **β受体阻滞剂**（美托洛尔、比索洛尔）—— 降低心肌耗氧，长期预防一线
- **钙通道阻滞剂**（地尔硫䓬、维拉帕米、氨氯地平）—— 变异型或 β 阻滞剂禁忌时
- **抗血小板药**（阿司匹林、氯吡格雷）—— 预防血栓

## 它在知识体系里放在哪里？

它位于药学专业知识二第五章第四节抗心绞痛药节下属，是该节所治疗的核心疾病。向上承接抗心绞痛药模块，向下与硝酸甘油（硝酸酯类代表药）形成"疾病 ↔ 治疗药"的关联。
