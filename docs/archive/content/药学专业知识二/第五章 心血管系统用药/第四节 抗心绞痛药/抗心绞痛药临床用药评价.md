# 抗心绞痛药临床用药评价

## 三类缓解症状药物对比

| 药物类别 | 核心机制 | 优点 | 局限 |
|---|---|---|---|
| **硝酸酯类** | NO供体，降低心肌耗氧 | 急性发作首选，剂型多样 | 连续使用产生耐药 |
| **β受体拮抗剂** | 降低心肌耗氧 | **唯一兼具改善预后**，降低心血管事件 | 支气管哮喘禁用，心动过缓慎用 |
| **钙通道阻滞剂** | 扩张血管，降低心脏负荷 | 尤其适合高血压/冠状动脉痉挛患者 | 非二氢吡啶类与β受体拮抗剂合用需谨慎 |

## 联合用药原则

### 缓解症状的联合

- **β受体拮抗剂+硝酸酯类**：经典联合，协同降低心肌耗氧量（首选联合方案）
- **β受体拮抗剂+CCB（二氢吡啶类）**：适用于伴高血压的患者
- **硝酸酯类+CCB（非二氢吡啶类）**：需谨慎，可能过度抑制心脏

### 改善预后的联合（ABCDE方案）

| 字母 | 代表药物 | 作用 |
|---|---|---|
| **A** | Aspirin + ACEI/ARB | 抗血小板 + 抑制RAAS |
| **B** | β受体拮抗剂 | 降低心肌耗氧，改善重构 |
| **C** | Cholesterol（他汀类） | 降脂，稳定斑块 |
| **D** | Diabetes（降糖药） + Diet（饮食控制） | 控制血糖 |
| **E** | Exercise（运动） + Education（健康教育） | 生活方式管理 |

## 用药评价要点

### 硝酸酯类

- **首选急性发作**：舌下含服硝酸甘油，2~3 min起效
- **避免耐药**：偏心给药，每日8~12 h无药期
- **禁忌**：青光眼、严重低血压、PDE-5抑制剂（西地那非）

### β受体拮抗剂

- **唯一双重作用**：既缓解症状，又改善预后（降低猝死风险）
- **首选**：美托洛尔、比索洛尔
- **禁忌**：支气管哮喘、重度心动过缓、急性心衰发作期

### 钙通道阻滞剂

- **二氢吡啶类**：扩张血管为主，踝部水肿常见
- **非二氢吡啶类**：减慢心率，与β受体拮抗剂合用需谨慎
- **变异型心绞痛首选**：地尔硫卓

### 改善预后药物

- **抗血小板**：阿司匹林是基础，DAPT用于ACS
- **他汀类**：所有心绞痛患者均应使用，基石治疗
- **ACEI/ARB**：心绞痛伴高血压/糖尿病/心功能不全者优选

## 记忆口诀是什么？

**"ABCDE方案：阿司匹林ACEI、Beta受体、C胆固醇、D糖尿病饮食、E运动教育"**

| 字母 | 内容 | 具体措施 |
|---|---|---|
| **A** | Aspirin + ACEI/ARB | **阿司匹林**（抗血小板首选）+ **ACEI/ARB**（改善心肌重构） |
| **B** | Beta-blocker | **β受体拮抗剂**（降低心肌耗氧，预防猝死） |
| **C** | Cholesterol | **他汀类药物**（降脂+稳定斑块） |
| **D** | Diabetes + Diet | **控制血糖**（降糖药）+ **饮食控制** |
| **E** | Exercise + Education | **运动康复** + **健康教育** |

**为什么要记？** ABCDE方案是心绞痛综合管理的核心框架，将改善预后的全部措施系统化，一网打尽。
