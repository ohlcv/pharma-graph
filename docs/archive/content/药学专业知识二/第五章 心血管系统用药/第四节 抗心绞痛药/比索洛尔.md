# 比索洛尔

## 它是什么药？

**高选择性β₁受体拮抗剂**，对β₂受体几乎无阻断作用。与美托洛尔相比，它选择性更高、半衰期更长（约10-12小时），因此每日一次给药即可实现24小时平稳降压和心率控制。临床用于高血压、冠心病和慢性心力衰竭，因选择性高，在合并轻中度 COPD 或外周血管病的患者中相对安全。

## 它有什么独特之处？

它的"独特"在于四点：
- **极高的β₁选择性**——对β₂受体的亲和力极低，在合并轻中度 COPD、外周血管病、糖尿病等"边界患者"中相对安全
- **半衰期长（10-12小时）**——血药浓度平稳，每日一次给药依从性好
- **慢性心衰三大基石之一**——与美托洛尔、卡维地洛并称"心衰三巨头"，可显著降低心衰患者死亡率
- **跨章节归属**——同时归属抗心律失常药章节（Ⅱ类代表药）

## 核心作用特点是什么？

| 特点 | 说明 |
|---|---|
| **受体选择性** | **高选择性β₁**（对β₂几乎无影响） |
| **作用持续** | 半衰期长（10-12小时），作用持续时间较长 |
| **给药频率** | **每日1次** |
| **临床优势** | 支气管痉挛风险低于非选择性β受体拮抗剂 |

## 临床应用是什么？

- **高血压**：尤其适用于伴冠心病或心衰的患者
- **冠心病**：心绞痛长期预防和心肌梗死二级预防
- **慢性心力衰竭**：β受体阻滞剂心衰治疗的基石，需从极小剂量起始、逐渐滴定
- **心律失常**：窦性心动过速、房颤心室率控制

## 典型不良反应是什么？

- **心动过缓、房室传导阻滞**
- **低血压、头晕、疲乏**
- **心力衰竭加重**：起始剂量过大或加量过快可诱发
- **肢端发冷**
- **撤药综合征**：长期使用后突然停药可诱发心绞痛或心梗
- **支气管痉挛**：高选择性不等于零风险，严重哮喘仍禁用

## 禁忌人群是什么？

- 重度心动过缓禁用
- 急性心力衰竭发作期禁用
- 心源性休克禁用

## 它和节/章的关系？

- **抗心绞痛药节**（第五章第四节)：β受体拮抗剂代表药，定位"高选择性β₁，每日1次，支气管痉挛风险低"
- **抗心律失常药节**（第五章第一节)：Ⅱ类β受体拮抗剂亚类代表药，与美托洛尔（高选择性β₁）、普萘洛尔（非选择性）、卡维地洛（α₁+β联合）形成选择性—受体组合多层对比
- **抗心力衰竭药节**（第五章第五节)：心衰三大基石之一，与美托洛尔、卡维地洛并列
