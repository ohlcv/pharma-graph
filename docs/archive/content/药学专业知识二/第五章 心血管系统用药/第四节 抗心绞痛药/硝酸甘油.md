# 硝酸甘油

## 它是什么？

**硝酸酯类**的代表药，也是**心绞痛急性发作的首选**缓解措施。

## 核心作用特点是什么？

| 特点 | 说明 |
|---|---|
| **剂型多样** | 舌下含服片、甘油溶液、口腔喷雾剂、透皮贴剂等 |
| **舌下含化** | 吸收迅速完全，生物利用度可达**80%** |
| **起效极快** | **2~3分钟**起效，**5分钟**达最大效应 |
| **持续时间短** | 约**20~30分钟** |
| **避免耐药** | 长期用药者不应突然停药 |

## 用法用量是什么？

- 心绞痛发作时**舌下含服**
- 疼痛未缓解，**每5分钟可重复1片**
- **15分钟内总量达3片仍不缓解，应立即就医**

## 典型不良反应是什么？

- **扩血管反应**：体位性低血压（搏动性头痛）、面部潮红、烧灼感
- **反射性心率加快**
- **耐受性**：连续使用可产生耐药

## 禁忌人群是什么？

- 青光眼患者禁用
- 严重低血压患者禁用
- 正在使用5型磷酸二酯酶抑制剂（如西地那非）者禁用
