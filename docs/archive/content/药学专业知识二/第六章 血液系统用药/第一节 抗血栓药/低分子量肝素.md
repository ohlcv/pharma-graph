# 低分子量肝素

## 它是什么？

低分子量（4000~6000Da）肝素，皮下注射使用方便的改良版肝素。

## 代表药

| 药物 |
|---|
| **达肝素钠** |
| **那屈肝素钙** |
| **依诺肝素钠** |
| **贝米肝素钠** |

## 核心特性

| 特性 | 说明 |
|---|---|
| **分子量** | 4000~6000Da |
| **作用** | 抑制Ⅱa和Ⅹa |
| **生物利用度** | **90%** |
| **给药** | 皮下注射，一日1~2次 |
| **抗凝持续** | 持续时间长 |

## 优势 vs 普通肝素

| 对比 | 低分子量肝素 | 普通肝素 |
|---|---|---|
| **HIT发生率** | **远低于**肝素 | 可诱导HIT |
| **治疗窗** | 较宽 | 窄 |
| **实验室监测** | **一般无需** | 需监测APTT |

## 监测

抗Ⅹa活性监测（仅在特殊情况下使用）

## 代谢

主要经**肾脏清除**——肾功能不全需调整剂量或避免使用

## 逆转

**鱼精蛋白部分中和**

## 它和章的关系？

低分子量肝素是肝素类常用改良版，定位"皮下注射90%生物利用度，一日1~2次，HIT风险低无须监测APTT，肾功能不全需调整"。
