# 抗凝药

## 它是什么药？

通过减弱**纤维蛋白形成**来防止血栓形成的药物。

## 四大类

| 类别 | 代表药 |
|---|---|
| **维生素K拮抗剂** | 华法林 |
| **肝素类** | 肝素（钠/钙）、低分子量肝素（达肝素钠、那屈肝素钙、依诺肝素钠、贝米肝素钠）、磺达肝癸钠 |
| **直接抗凝药** | 达比加群酯、比伐芦定、阿加曲班、水蛭素、利伐沙班、阿哌沙班、艾多沙班 |
| **丝氨酸蛋白酶抑制剂** | 萘莫司他（仅体外循环抗凝） |

## 记忆口诀是什么？

**"抗凝四大家：华法林、肝素、DOAC、萘莫司他"**

**为什么要记？** 抗凝药按机制分四大类，每类代表药与临床定位差异大，是高频考点。

## 它和节的关系？

抗凝药是抗血栓药的第一大类，定位"减弱纤维蛋白形成，四大类——华法林（口服，监测INR）、肝素类（注射，急诊）、DOAC（口服，无须监测）、萘莫司他（仅体外）"。
