# 抗血小板药

## 它是什么药？

通过**抑制血小板活化、聚集**阻止动脉血栓形成的药物。

## 六大类

| 类别 | 代表药 |
|---|---|
| **血栓素A₂合成酶抑制剂** | 阿司匹林、吲哚布芬、奥扎格雷钠 |
| **P2Y₁₂受体拮抗剂** | 噻氯匹定、氯吡格雷、替格瑞洛 |
| **GPⅡb/Ⅲa受体拮抗剂** | 阿昔单抗（不可逆）、依替巴肽、替罗非班（可逆） |
| **磷酸二酯酶抑制剂** | 西洛他唑、双嘧达莫 |
| **5-羟色胺受体拮抗剂** | 沙格雷酯 |
| **前列环素受体激动剂** | 贝前列素钠 |

## 记忆口诀是什么？

**"抗板六大类：TXA₂、P2Y₁₂、GPⅡb/Ⅲa、PDE、5-HT、前列环素"**

**为什么要记？** 抗血小板药分六大类，每类代表药与临床场景各异，是高频考点。

## 它和节的关系？

抗血小板药是抗血栓药第二大类，定位"抑制血小板活化聚集，六大类——TXA₂合成酶抑制剂（阿司匹林）、P2Y₁₂受体拮抗剂（氯吡格雷等）、GPⅡb/Ⅲa受体拮抗剂（替罗非班等）"。
