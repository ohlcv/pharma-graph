# 替奈普酶（TNK-tPA）

## 它是什么？

**新一代特异性纤溶酶原激活剂**，单次注射即可，使用最方便。

## 核心特性

| 特性 | 说明 |
|---|---|
| **纤维蛋白特异性** | 有 |
| **纤维蛋白原消耗** | **极小** |
| **半衰期** | **20~24min（更长）** |
| **给药** | **单次注射** |

## 适应证与时间窗

**急性心肌梗死**：发病**6小时内**

## 与阿替普酶、瑞替普酶对比

| 对比 | 阿替普酶 | 瑞替普酶 | 替奈普酶 |
|---|---|---|---|
| 半衰期 | 4~5min（短） | 14~16min（略长） | **20~24min（更长）** |
| 给药 | 持续静滴 | 分2次注射 | **单次注射** |
| 操作便利性 | 复杂 | 中等 | **最简便** |

## 它和章的关系？

替奈普酶是新一代特异性溶栓药，定位"单次注射即可，半衰期20~24min更长，纤维蛋白原消耗极小，急性心梗6h内最优"。
