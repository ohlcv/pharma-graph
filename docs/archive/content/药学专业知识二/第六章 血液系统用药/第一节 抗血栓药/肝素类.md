# 肝素类

## 它是什么药？

通过增强**抗凝血酶Ⅲ（AT-Ⅲ）**活性发挥抗凝作用的注射用抗凝药。

## 三者对比

| 项目 | 肝素 | 低分子量肝素 | 磺达肝癸钠 |
|---|---|---|---|
| **平均分子量** | 约15000Da（3000~30000） | 4000~6000Da | 1728.08 |
| **结合位点** | 抗凝血酶Ⅲ（AT-Ⅲ） | 抗凝血酶Ⅲ（AT-Ⅲ） | **只抑制Ⅹa** |
| **作用特点** | 抑制Ⅱa、Ⅸa、Ⅹa、Ⅺa、Ⅻa | 抑制Ⅱa和Ⅹa | 仅抑制Ⅹa |
| **皮下注射生物利用度** | 15%~30% | **90%** | **100%** |

## 给药与临床特性

| 项目 | 肝素 | 低分子量肝素 |
|---|---|---|
| **给药方式** | 静脉或皮下，起效快、清除快 | 皮下为主，一日1~2次 |
| **安全性** | 可诱导血小板减少症（HIT），治疗窗窄 | HIT发生率远低于肝素，治疗窗较宽，**一般无需实验室监测** |
| **逆转** | **鱼精蛋白完全逆转** | **鱼精蛋白部分中和** |
| **代谢** | 主要肝脏清除、网状内皮系统代谢 | 主要经**肾脏清除**，肾功能不全需调整 |
| **监测指标** | **APTT**（活化部分凝血活酶时间） | 抗Ⅹa活性监测 |

## 与华法林对比

| 项目 | 华法林 | 肝素类 |
|---|---|---|
| **给药** | 口服 | 注射 |
| **机制** | 抑制VKORC1，减少凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ合成 | 增强AT-Ⅲ活性，抑制Ⅱa、Ⅸa、Ⅹa、Ⅺa、Ⅻa |
| **起效** | 起效慢，维持时间长 | **起效快**，体内、体外均抗凝 |
| **监测** | **INR** | **APTT**（低分子肝素通常无需） |
| **妊娠期** | **禁用** | 肝素、低分子量肝素**可用** |
| **肾功能不全** | 无需调整 | 肝素无需调整；低分子肝素**需调整或避免** |
| **解救** | 维生素K | 鱼精蛋白 |

## 它和节的关系？

肝素类是抗凝药的注射类代表，定位"普通肝素起效快监测APTT、低分子量肝素使用方便HIT风险低、磺达肝癸钠仅抑制Ⅹa，鱼精蛋白可逆转"。
