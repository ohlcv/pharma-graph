# 阿司匹林（血栓章节）

## 它是什么？

通过小剂量**不可逆抑制血小板COX-1**，减少TXA₂合成，抑制血小板聚集。

## 核心特性

| 特性 | 说明 |
|---|---|
| **机制** | 小剂量不可逆抑制COX-1 |
| **效应** | 减少TXA₂合成 |
| **术前停用** | 需停用 **7~10天** |

## 用法用量

| 适应证 | 剂量 |
|---|---|
| **急性心肌梗死** | 首剂**300mg嚼服**，之后75~100mg/d维持 |
| **心肌梗死二级预防** | 75~300mg/d |
| **脑卒中二级预防** | 75~300mg/d |
| **短暂性脑缺血发作（TIA）二级预防** | 75~300mg/d |

## 它和章的关系？

阿司匹林是TXA₂合成酶抑制剂代表，定位"小剂量不可逆抑制COX-1，心血管事件一级/二级预防基础药，术前停7~10天"。
