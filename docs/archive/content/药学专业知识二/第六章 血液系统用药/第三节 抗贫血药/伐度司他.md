# 伐度司他

## 它是什么药？

**低氧诱导因子脯氨酰羟化酶抑制剂**（HIF-PHI）。

## 临床应用是什么？

- **慢性肾病所致贫血**（透析及非透析患者）

## 用法用量是什么？

- **口服**，每周 2~3 次
- 按体重和血红蛋白水平调整剂量

## 典型不良反应是什么？

- 血栓形成
- 高血压
- 胃肠道反应

## 记忆口诀是什么？

**"伐度司他，进口 HIF；口服稳定内源"**——与罗沙司他同类不同药。

**为什么要记？** 罗沙司他（国产）、伐度司他（进口）、恩那司他（进口）是同类三种药，区分国产/进口。

## 它和章的关系？

属于抗贫血药下 ESAs 第三亚类（HIF-PHI）的"进口"代表药。
