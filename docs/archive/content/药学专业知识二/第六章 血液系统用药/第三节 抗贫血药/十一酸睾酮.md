# 十一酸睾酮

## 它是什么药？

**蛋白同化激素**，通过刺激骨髓造血治疗贫血。

## 临床应用是什么？

- **再生障碍性贫血**辅助治疗
- 慢性贫血辅助治疗
- 男性性腺功能减退症（睾酮替代治疗）

## 用法用量是什么？

- 口服：分早晚 2 次，餐后口服
- 按贫血程度调整剂量

## 典型不良反应是什么？

- **肝毒性**（黄疸、肝酶升高）
- **男性化**（女性患者出现声音变粗、多毛）
- 水钠潴留
- 前列腺增生

## 记忆口诀是什么？

**"十一酸睾酮，再障辅助；男性化、肝毒要注意"**——**肝毒性**和**男性化**是核心副作用。

**为什么要记？** 同化激素副作用使临床应用受限，女性患者用药需特别交代。

## 它和章的关系？

属于抗贫血药下 ESAs 第五亚类（蛋白同化激素）的代表药。
