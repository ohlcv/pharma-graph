# 右旋糖酐铁（口服）

## 它是什么药？

**右旋糖酐铁口服剂型**，三价铁与右旋糖酐复合物形式的有机铁。

## 临床应用是什么？

- 缺铁性贫血治疗
- 不能耐受其他口服铁剂的患者

## 用法用量是什么？

- 口服：成人每次 25~50 mg（以铁计），每日 1~3 次
- **餐后服用**减少胃肠道刺激

## 典型不良反应是什么？

- 胃肠道反应
- 便秘
- **黑便**（正常现象）
- 牙齿染色

## 记忆口诀是什么？

**"右旋糖酐铁，口服和注射两剂型；过敏风险注射高"**——**口服剂型过敏风险低**，**注射剂型过敏风险高**。

**为什么要记？** 右旋糖酐铁注射剂型是铁剂中过敏风险最高的药物之一，临床应用时需要试敏。

## 它和章的关系？

属于抗贫血药下铁剂子伞形（口服铁剂）的"多糖复合有机铁"代表药。
