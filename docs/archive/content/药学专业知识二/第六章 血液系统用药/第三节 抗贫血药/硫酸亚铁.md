# 硫酸亚铁

## 它是什么药？

经典**无机铁**口服剂，二价铁（亚铁）形式，吸收率高。

## 临床应用是什么？

- 缺铁性贫血治疗
- 妊娠期、哺乳期铁需求增加

## 用法用量是什么？

- 口服：成人每次 0.3 g，每日 3 次；儿童按体重计算
- **餐后服用**减少胃肠道刺激

## 典型不良反应是什么？

- 恶心、呕吐、上腹疼痛
- 便秘（减少肠蠕动）
- **黑便**（正常现象）
- 牙齿染色（液体制剂）

## 记忆口诀是什么？

**"硫酸亚铁，二价易吸；便宜经典，胃肠反应大"**——**便宜经典**是特点，**胃肠反应大**是限制。

**为什么要记？** 硫酸亚铁虽经典但胃肠道反应限制了患者依从性，是临床处方时需要交代清楚的点。

## 它和章的关系？

属于抗贫血药下铁剂子伞形（口服铁剂）的"经典无机铁"代表药。
