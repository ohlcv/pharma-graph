# 重组人促红素

## 它是什么药？

基因重组的**人促红素**，模拟内源性 EPO 作用，刺激红细胞生成。

## 临床应用是什么？

- **肾功能不全所致贫血**（包括透析及非透析患者）
- **外科围手术期的红细胞动员**（术前血红蛋白 100~130 g/L）
- 化疗后贫血

## 用法用量是什么？

- 皮下注射或静脉注射
- 每周 2~3 次
- 目标血红蛋白：100~120 g/L（不应超过 130 g/L，避免血栓风险）

## 典型不良反应是什么？

- **血压升高**，可诱发高血压性脑病
- **血栓形成风险升高**
- 过敏反应
- 长期使用可诱发**纯红细胞再生障碍性贫血**

## 临床应用注意

1. 用药期间定期检查红细胞比容，避免红细胞过度生成
2. 治疗有效后造血增强，需**每日补充铁剂**
3. 叶酸或维生素B₁₂不足会降低本品疗效
4. 体内铝蓄积过多也会影响疗效

## 禁忌

- 未控制的重度高血压
- 对本品过敏者

## 记忆口诀是什么？

**"rhEPO 三次周，肾性贫血首选；高血压禁，警惕纯红再障"**——**每周 2~3 次**是经典频次，**纯红再障**是长期使用的罕见但严重风险。

**为什么要记？** 重组人促红素是 ESAs 的"经典"，临床应用最广。

## 它和章的关系？

属于抗贫血药下 ESAs 第一亚类（人促红素类）的"第一代"代表药。
