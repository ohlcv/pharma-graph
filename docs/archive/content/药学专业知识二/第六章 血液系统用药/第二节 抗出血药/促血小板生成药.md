# 促血小板生成药

## 它是什么药？

通过**激活血小板生成素（TPO）受体**或模拟 TPO 作用，促进巨核细胞增殖、分化与成熟，提升血小板计数的药物。

## 作用特点

1. **特异性作用于 TPO 受体**：调节巨核细胞增殖、分化与成熟，促进血小板生成。
2. **仅用于血小板减少症患者**：不用于无出血风险的人群。
3. **过量或错误使用可导致血小板计数异常升高，诱发血栓形成**：用药目标不是使血小板计数达到正常值；用药期间及停药后至少 2 周需定期监测血常规。

## 两大类代表药

| 类别 | 代表药 | 给药频次 |
|---|---|---|
| **注射用 TPO 类** | 重组人血小板生成素 | 每日或隔日皮下注射 1 次 |
| **白介素类** | 人白介素-11 | 每日皮下注射 1 次 |
| **口服 TPO 受体激动剂** | 艾曲泊帕、海曲泊帕、阿伐曲泊帕、芦曲泊帕 | 口服，每日 1 次 |

## 记忆口诀是什么？

**"11个老板谱小曲"**——**11**（人白介素-11）+ **老**（重组人血小板生成素）+ **板**（艾曲泊帕）+ **谱**（海曲泊帕）+ **小**（阿伐曲泊帕）+ **曲**（芦曲泊帕）。

| 口诀 | 含义 |
|---|---|
| **11** | 人白介素-11 |
| **个老** | 重组人血小板生成素（"老"代指经典注射用） |
| **板** | 艾曲泊帕（艾**板**谐音） |
| **谱** | 海曲泊帕（海**谱**） |
| **小** | 阿伐曲泊帕（"小"代指"阿伐"） |
| **曲** | 芦曲泊帕（**曲**） |

**为什么要记？** 促血小板生成药种类多但名称都以"-泊帕"结尾（除 11 和 rhTPO），口诀串联 6 个代表药与分类。

## 临床应用是什么？

- 免疫性血小板减少症（ITP）
- 再生障碍性贫血
- 化疗后血小板减少
- 慢性肝病相关血小板减少

## 它和节的关系？

属于抗出血药下促凝血药的第一大类，定位"促血小板生成，TPO 受体激活，仅用于血小板减少症，警惕血栓风险"。
