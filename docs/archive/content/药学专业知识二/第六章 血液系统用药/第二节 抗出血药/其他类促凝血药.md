# 其他类促凝血药

## 四类亚药物

### 1. 蛇毒血凝酶

- **机制**：类凝血酶样作用，促进纤维蛋白原转化为纤维蛋白，加速止血。
- **特点**：仅在血管破损处促进凝血，正常血管内不诱发血栓形成，不影响凝血因子数量。
- **代表药**：矛头蝮蛇血凝酶、尖吻蝮蛇血凝酶、白眉蛇毒血凝酶。

### 2. 毛细血管止血药

- **卡络磺钠**：增强毛细血管对损伤的抵抗力，降低毛细血管通透性，增强受损毛细血管端的回缩作用，缩短出血时间。
- **酚磺乙胺**：降低毛细血管通透性，收缩毛细血管，促进血小板释放凝血活性物质，缩短凝血时间。

### 3. 收缩血管药

- **垂体后叶注射液**：主要成分为缩宫素和血管加压素；降低内脏血流量，收缩血管平滑肌，压迫食管静脉曲张破裂出血的出血部位止血。
- **特利加压素**：人工合成的血管加压素类似物，作用更持久，不良反应相对更少。

### 4. 血管硬化剂（聚桂醇）

- 使曲张静脉周围纤维化，压迫曲张静脉达到止血目的；静脉内注射后可损伤血管内皮、促进血栓形成、阻塞血管，从而止血。

## 记忆口诀是什么？

**"蛇毛收硬"**——四类各取首字：**蛇**毒血凝酶、**毛**细血管止血药、**收**缩血管药、**硬**化剂（聚桂醇）。

**为什么要记？** 其他类药物机制差异大（蛇毒→促凝、毛细→止血、收缩→压迫、硬化→阻塞），口诀按机制串联四种"杂类"促凝血药。

## 临床应用是什么？

- 蛇毒血凝酶：手术前后出血预防
- 毛细血管止血药：鼻出血、牙龈出血、眼底出血
- 收缩血管药：食管静脉曲张破裂出血、肺咯血
- 血管硬化剂：下肢静脉曲张、食管静脉曲张硬化治疗

## 它和节的关系？

属于抗出血药下促凝血药的第五大类，定位"蛇毒、毛细、收缩、硬化四种杂类，各有适应证"。
