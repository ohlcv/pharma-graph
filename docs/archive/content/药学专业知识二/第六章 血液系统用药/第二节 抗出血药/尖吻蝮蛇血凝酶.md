# 尖吻蝮蛇血凝酶

## 它是什么药？

从中国尖吻蝮蛇（五步蛇）毒中提取的**类凝血酶样物质**。

## 临床应用是什么？

- 手术前后出血预防
- 消化道出血
- 创伤性出血

## 用法用量是什么？

- 静脉注射、肌内注射
- 通常每次 1~2 单位

## 典型不良反应是什么？

- 偶见过敏反应
- 大剂量可能引起血栓形成（罕见）

## 记忆口诀是什么？

**"尖吻蝮蛇，五步蛇；国产蛇毒血凝酶"**——**"尖"**指尖吻蝮，**"五步"**形容其毒性。

**为什么要记？** 区分三种蛇毒血凝酶的来源蛇种。

## 它和章的关系？

属于抗出血药下促凝血药第五大类（其他类）蛇毒血凝酶亚类的"国产"代表药。
