# 白眉蛇毒血凝酶

## 它是什么药？

从中国白眉蛇（Agkistrodon blomhoffii brevicaudus）毒中提取的**类凝血酶样物质**。

## 临床应用是什么？

- 手术前后出血预防
- 咯血
- 消化道出血
- 创伤性出血

## 用法用量是什么？

- 静脉注射、肌内注射
- 通常每次 1~2 单位

## 典型不良反应是什么？

- 偶见过敏反应
- 大剂量可能引起血栓形成（罕见）

## 记忆口诀是什么？

**"白眉蛇毒血凝酶，国产蛇毒；'白'是蛇种颜色"**——区别于"矛头蝮蛇"（南美）、"尖吻蝮蛇"（中国五步蛇）。

**为什么要记？** 三种蛇毒血凝酶来源蛇种不同，"白眉"是国产蛇种之一。

## 它和章的关系？

属于抗出血药下促凝血药第五大类（其他类）蛇毒血凝酶亚类的"国产"代表药。
