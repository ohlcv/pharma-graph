# 重组人凝血因子Ⅷ

## 它是什么药？

**基因工程合成的凝血因子Ⅷ**，相比人血浆提取的凝血因子Ⅷ，**病毒感染风险为零**。

## 临床应用是什么？

- **甲型血友病**（先天性凝血因子Ⅷ缺乏）的出血治疗与预防
- 重组制剂是欧美甲型血友病治疗的首选

## 优势对比

| 维度 | 人凝血因子Ⅷ | 重组人凝血因子Ⅷ |
|---|---|---|
| 来源 | 健康人血浆 | 基因工程合成 |
| 病毒感染风险 | 有（已大幅降低） | **零** |
| 免疫原性 | 较高 | 较低 |
| 成本 | 低 | 高 |
| 临床地位 | 二线 | 一线首选 |

## 注意事项

- 仍可能产生凝血因子抑制物（抗体）
- 用药期间需监测凝血因子Ⅷ 活性

## 用法用量是什么？

- 静脉滴注，按凝血因子Ⅷ 缺乏的程度和体重计算
- 与人凝血因子Ⅷ 用法相同

## 典型不良反应是什么？

- 凝血因子抑制物产生（抗体）
- 过敏反应
- 血栓形成（过大剂量）

## 记忆口诀是什么？

**"重组人凝血因子Ⅷ，病毒风险为零；甲型血友病首选"**——**"重组"= 更安全**。

**为什么要记？** 重组制剂是现代生物技术优势，明确记忆"病毒风险为零"是高频考点。

## 它和章的关系？

属于抗出血药下促凝血药第三大类（凝血因子）的"甲型血友病"代表药（重组制剂）。
