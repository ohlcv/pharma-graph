# 瑞波西利

## 它是什么药？

瑞波西利是**CDK4/6抑制剂**，作用机制与哌柏西利相同——通过阻滞肿瘤细胞从G1期进入S期来抑制癌细胞增殖。定位也是**抗肿瘤治疗**，主要用于乳腺癌。

## 作用机制

阻滞肿瘤细胞从G1期进入S期，减少HR+/HER2-乳腺癌细胞的增殖。

## 适应证

**激素受体阳性（HR+）、人表皮生长因子受体2阴性（HER2-）**的局部晚期或转移性乳腺癌的治疗。

## 临床地位

- CDK4/6抑制剂的代表药物之一
- 常与内分泌治疗药物联用
- 是HR+/HER2-乳腺癌的一线治疗选择

## 它和节的关系？

瑞波西利与哌柏西利同为CDK4/6抑制剂的乳腺癌适应证药物，两者可视为同类竞品，作用机制和适应证基本一致。
