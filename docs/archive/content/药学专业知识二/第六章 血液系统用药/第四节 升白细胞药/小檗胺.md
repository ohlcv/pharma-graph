# 小檗胺

## 它是什么药？

小檗胺是**双苄基异喹啉类生物碱**，具有促进白细胞增生的作用。它的一大特点是"一药多效"——除了升白，还兼有多种药理作用。

## 药理作用

1. **促进白细胞增生**——用于升白
2. **抗炎**——兼具抗炎作用
3. **降血压**——可用于高血压辅助治疗
4. **抗肿瘤**——研究发现有抗肿瘤活性
5. **抗心肌缺血**——保护心肌
6. **抗心律失常**——稳定心律

## 适应证

防治肿瘤患者化疗、放疗及苯中毒等引起的白细胞减少症。

## 用药注意

- 兼有降压作用，高血压患者使用需注意监测血压

## 它和节的关系？

小檗胺是其他升白细胞药中作用最广泛的一个，"一药多效"是其最大特点。
