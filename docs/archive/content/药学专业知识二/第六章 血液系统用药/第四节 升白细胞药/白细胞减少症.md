# 白细胞减少症

## 它是什么病？

白细胞减少症是指外周血白细胞数**持续低于3.5×10⁹/L**的病理状态。白细胞是人体对抗感染的"士兵"，数量减少后，患者容易出现发热、感染，严重时可发生败血症。

## 病因

- 化疗（最常见原因）
- 放疗
- 苯中毒
- 骨髓疾病（再生障碍性贫血、骨髓增生异常综合征）
- 先天性/特发性因素

## 临床意义

白细胞减少症是化疗患者最常见的并发症之一。严重白细胞减少会导致：
- 粒细胞缺乏性发热（FN）
- 感染
- 败血症
- 化疗剂量减少或化疗周期延迟

## 与相邻概念的关系

| 疾病 | 诊断标准 |
|---|---|
| 白细胞减少症 | 外周血白细胞数持续低于3.5×10⁹/L |
| 中性粒细胞减少症 | 外周血中性粒细胞绝对值低于1.5×10⁹/L |
| 粒细胞缺乏症 | 中性粒细胞低于0.5×10⁹/L |

## 它在知识体系里的位置？

白细胞减少症是第四节升白细胞药的适应证，各种升白药都以此为目标疾病。
