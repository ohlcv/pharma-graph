# 脱氧核苷酸钠

## 它是什么药？

脱氧核苷酸钠是**复方制剂**，主要成分为脱氧核苷酸。它的作用是促进细胞活力、改善机体代谢。

## 适应证

作为辅助治疗药物，用于：
- 急、慢性肝炎
- 白细胞减少症
- 血小板减少症
- 再生障碍性贫血

## 作用特点

- 促进细胞活力
- 改善机体代谢
- 定位为辅助治疗药物（非首选升白药）

## 它和节的关系？

脱氧核苷酸钠是其他升白细胞药中定位最"宽泛"的一个——主要用于辅助治疗，不属于化疗后升白的首选药。
