# 腺嘌呤

## 它是什么药？

腺嘌呤又名**维生素B4**，是生物体内**辅酶与核酸的组成和活性成分**。作为核酸前体物质，它可以刺激骨髓白细胞增生。

## 适应证

防治各种原因引起的白细胞减少症。

## 重要注意事项

- **腺嘌呤属于核酸前体**，与化疗药合用有可能促进肿瘤发展
- 化疗期间患者使用需谨慎，权衡利弊

## 它和节的关系？

腺嘌呤是其他升白细胞药中机制最"质朴"的一个——直接补充核酸原料。需要特别注意与化疗药的相互作用。
