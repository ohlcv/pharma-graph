# 重组人粒细胞刺激因子

## 它是什么药？

它是调节骨髓粒系造血的主要细胞因子之一，化学名叫**重组人粒细胞刺激因子（G-CSF）**。作用于粒系造血祖细胞，促进增殖分化，把白细胞数量拉回来。

## 适应证

1. 癌症化疗等原因导致的中性粒细胞减少症
2. 急性白血病化疗所致的中性粒细胞减少症
3. 骨髓增生异常综合征伴发的中性粒细胞减少症
4. 再生障碍性贫血伴发的中性粒细胞减少症
5. 先天性、特发性中性粒细胞减少症
6. 促进骨髓移植后的中性粒细胞数升高

## 典型不良反应

- **肌肉骨骼系统**：骨痛、腰痛、胸痛、肌肉酸痛（骨髓增生的表现）
- **过敏反应**：皮疹、荨麻疹、颜面浮肿
- 其他：发热、头痛、乏力、肝功能异常

## 用药注意

- 化疗药物给药前后24小时内避免使用
- 应在化疗结束后24~48小时使用

## 它和节的关系？

G-CSF是刺激因子类的代表药，是化疗后中性粒细胞减少症的首选治疗药物。
