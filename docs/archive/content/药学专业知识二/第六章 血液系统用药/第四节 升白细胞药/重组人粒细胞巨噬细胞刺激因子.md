# 重组人粒细胞巨噬细胞刺激因子

## 它是什么药？

它是调节骨髓造血的另一类细胞因子，化学名叫**重组人粒细胞巨噬细胞刺激因子（GM-CSF）**。作用于造血祖细胞，促进粒系和单核巨噬细胞成熟，并把成熟细胞释放到外周血。

## 适应证

1. 预防和治疗肿瘤放疗或化疗后引起的白细胞减少症
2. 治疗骨髓造血功能障碍及骨髓增生异常综合征
3. 预防白细胞减少时可能潜在的感染并发症
4. 加快感染引起的中性粒细胞减少的恢复速度

## 不良反应与注意事项

- 常见发热、寒战、恶心、呼吸困难、腹泻，常规对症处理可缓解
- 与化疗药物同时使用可加重骨髓毒性，应于化疗结束后24~48小时使用
- **自身免疫性血小板减少性紫癜患者禁用**

## 它和节的关系？

GM-CSF与G-CSF同属刺激因子类，GM-CSF的作用范围更广（涵盖粒系和单核巨噬细胞两系）。
