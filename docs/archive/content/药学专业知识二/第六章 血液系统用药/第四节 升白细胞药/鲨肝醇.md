# 鲨肝醇

## 它是什么药？

鲨肝醇是存在于鲨鱼肝油中的一种成分，具有**促进白细胞增生**及**抗放射线**的作用。

## 适应证

防治因化疗、放疗及苯中毒等引起的白细胞减少症。

## 作用特点

- 促进白细胞增生
- 抗放射线（对放射线损伤有保护作用）
- 常用于放射治疗患者的辅助用药

## 它和节的关系？

鲨肝醇是其他升白细胞药中"抗放射线"作用最突出的一个，特别适合放射治疗患者使用。
