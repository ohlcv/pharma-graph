# 法莫替丁

## 它是什么药？

第三代 H₂ 受体拮抗剂，化学结构含噻唑环，抑酸作用为 H₂RA 中**最强**。

## 它有什么独特之处？

- **抑酸强度高**：约为西咪替丁的 30~100 倍，作用时间长（10~12 h）
- **无抗雄激素作用**（区别于西咪替丁）
- **无多酶 P450 抑制**（区别于西咪替丁）
- 药物相互作用少
- 不透过血脑屏障，中枢副作用少
- 可用于肾功能不全者（剂量调整）

## 临床应用是什么？

- 消化性溃疡（DU/GU）
- GERD 维持治疗
- 应激性溃疡预防
- 上消化道出血辅助
- **OTC**：治疗消化不良、胃灼热
- 卓-艾综合征辅助

## 典型不良反应是什么？

- 总体耐受性好
- 偶见头痛、头晕、便秘、腹泻
- 罕见：过敏反应、肝功能异常

## 它和节的关系？

它是 H₂RA **第三代**临床首选；**考点**：**抑酸最强、无抗雄、无 CYP 抑制**三大特点，临床已基本取代西咪替丁。
