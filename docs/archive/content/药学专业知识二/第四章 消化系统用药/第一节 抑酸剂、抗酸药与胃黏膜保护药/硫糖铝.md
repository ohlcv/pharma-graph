# 硫糖铝

## 它是什么药？

蔗糖硫酸酯的铝盐（Sucralfate），黏膜保护药代表。

## 它有什么独特之处？

- **酸性环境（pH < 4）中解离**形成带负电的胶体
- 与溃疡面**带正电的蛋白**（白蛋白、纤维蛋白）结合 → **形成牢固的保护膜**
- 保护膜覆盖溃疡基底**6~8 h**
- 同时：
  - **促进内源性前列腺素合成**
  - **吸附表皮生长因子（EGF）**于溃疡面
  - 加速黏膜修复

## 临床应用是什么？

- **胃/十二指肠溃疡**黏膜修复
- 急慢性胃炎
- NSAIDs 致黏膜损伤辅助

## 服药注意是什么？

- **需酸性环境起效，餐前 1 小时服用**
- **不宜与抑酸剂、抗酸药、H₂ 拮抗剂同服**（间隔至少 30 min）

## 典型不良反应是什么？

- **便秘**（最常见，与铝离子相关）
- 偶见口干、恶心、皮疹、头晕
- **严重肾功能不全者慎用**（铝蓄积）

## 它和节的关系？

它是黏膜保护药代表；与铋剂同属黏膜保护但**不含铋**；考点集中在"**负电胶体+正电蛋白+保护膜 6~8 h**"。
