# 碳酸钙

## 它是什么药？

难吸收性抗酸药之一，中和反应：

$$\text{CaCO}_3 + 2\text{HCl} \rightarrow \text{CaCl}_2 + \text{H}_2\text{O} + \text{CO}_2\uparrow$$

## 它有什么独特之处？

- **中和作用强、起效快**
- 同时释放**大量 CO₂** → 腹胀、嗳气
- **反跳性胃酸分泌**（CO₂ 刺激胃泌素释放）
- 长期/大剂量服用 → **乳碱综合征**（高钙血症、代谢性碱中毒、肾钙质沉着）
- 短期按需使用相对安全

## 临床应用是什么？

- 急性反酸、烧心的快速缓解
- 补钙（兼有钙补充作用）

## 典型不良反应是什么？

- 腹胀、嗳气（CO₂ 释放）
- **高钙血症**（长期/大剂量）
- 肾结石风险
- 反跳性胃酸分泌

## 相互作用是什么？

- 不可与四环素、喹诺酮、铁剂同服（钙离子络合）
- 与 Vit D 同服增加钙吸收（高钙血症风险）

## 它和节的关系？

它是难吸收性抗酸药代表；考点集中在"**释 CO₂ + 乳碱综合征**"特征。短期对症安全、长期不可。
