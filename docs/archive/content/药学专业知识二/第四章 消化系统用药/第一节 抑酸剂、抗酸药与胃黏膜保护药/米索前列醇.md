# 米索前列醇

## 它是什么药？

前列腺素 E₁（PGE₁）甲基类似物，抑酸剂第四亚类的唯一临床代表药。

## 它有什么独特之处？

- **激动胃壁细胞 EP 受体**：抑制腺苷酸环化酶 → 减少 cAMP → 抑酸
- **促进胃黏液分泌**
- **促进碳酸氢盐分泌**
- **增加胃黏膜血流**
- **抑制胃黏膜损伤**
- → **抑酸 + 黏膜保护双重作用**

## 临床应用是什么？

- **NSAIDs 引起的消化性溃疡预防**（核心适应症，对抗 NSAIDs 抑制内源 PG）
- NSAIDs 治疗者高危人群的溃疡预防（>65 岁、既往溃疡史、合并抗凝/糖皮质激素）
- 消化性溃疡辅助治疗
- 药物流产（与米非司酮联用终止早期妊娠）

## 典型不良反应是什么？

- **腹痛、腹泻**（最常见，肠蠕动增加所致）
- **子宫平滑肌兴奋**（**孕妇绝对禁用**——可致流产、子宫破裂）
- 过敏反应

## 它和节的关系？

它是 PG 类抑酸剂**唯一代表药**；考点集中在"**NSAIDs 溃疡预防 + 孕妇禁用**"。也是药物流产核心药物，与米非司酮联用。
