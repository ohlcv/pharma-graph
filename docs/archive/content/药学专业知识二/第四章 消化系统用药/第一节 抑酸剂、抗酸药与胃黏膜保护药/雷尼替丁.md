# 雷尼替丁

## 它是什么药？

第二代 H₂ 受体拮抗剂，化学结构含**呋喃环**，抑酸作用较西咪替丁更强、不良反应更少。

## 它有什么历史背景？

- 曾是世界上最常用的 H₂RA 之一，年销售数十亿美元
- **2019 年检出 N-亚硝基二甲胺（NDMA）**致癌杂质（NDMA 是已知致癌物，可诱发消化道肿瘤）
- 美国 FDA、欧盟 EMA、中国 NMPA 多国要求**撤市或暂停销售**
- 目前仅作为**药学历史/撤市案例**被考点提及

## 临床应用是什么？

- 曾用于消化性溃疡、GERD、应激性溃疡预防
- 目前**临床已基本不用**，由法莫替丁、罗沙替丁等替代

## 典型不良反应是什么？

- CYP 抑制较西咪替丁弱，但仍存在
- 肝毒性报告（转氨酶升高）
- 心律失常报告
- 长期使用 Vit B₁₂ 缺乏

## 它和节的关系？

它是 H₂RA **第二代**代表药；考点集中在"**呋喃环 + NDMA 杂质撤市**"。临床上**推荐第三代法莫替丁或第四代罗沙替丁**等更安全 H₂RA。
