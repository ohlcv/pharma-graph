# 乳酶生(Lactasin / Biofermin)

## 它是什么药？

活肠球菌的干燥制剂助消化药，在肠内分解糖类生成乳酸，使肠内酸度增高，抑制腐败菌生长繁殖，减少肠内发酵与产气，**兼具促进消化和止泻的作用**。

## 它有什么独特之处？

- 活肠球菌的干燥制剂
- 肠内分解糖类生成乳酸
- 肠内酸度增高、抑制腐败菌生长繁殖
- 减少肠内发酵与产气
- **兼具促进消化和止泻的作用**
- **用药注意**：与抗菌药、抗酸药合用时需**间隔 3 小时**；**铋剂、鞣酸、活性炭、酊剂等可抑制、吸附或杀灭活肠球菌**，不能与本品合用

## 临床应用是什么？

- 消化不良
- 腹胀
- 小儿饮食失调引起的腹泻、绿便

## 典型不良反应是什么？

总体少；偶见腹胀；过浓/过量可致便秘。
