# 止吐药

## 这是什么？

止吐药是预防和治疗恶心呕吐的药物，按作用机制分 7 大类：抗胆碱能药、多巴胺 D₂ 受体拮抗剂、5-HT₃ 受体拮抗剂、NK-1 受体拮抗剂、抗组胺药（H₁）、糖皮质激素、其他类（苯二氮䓬、沙利度胺）。

## 为什么要学它？

因为化疗相关恶心呕吐（CINV）是化疗最影响患者生活质量的副作用，按催吐风险分级的联合方案是临床核心；术后恶心呕吐（PONV）、晕动病呕吐、妊娠呕吐也是高频场景。

## 它和什么有关？

- 和化疗方案有关：高度致吐方案（HEC）需三联预防（5-HT₃ + NK-1 + 地塞米松）
- 和帕金森病有关：多巴胺受体拮抗剂可加重 PD 症状（甲氧氯普胺、氟哌利多）
- 和胃轻瘫有关：甲氧氯普胺、多潘立酮兼具外周促动力作用

## 一般在什么时候用？

- 化疗前 30 min 给药预防（CINV 预防 > 治疗）
- 麻醉前给药预防（氟哌利多）
- 晕车/晕船前 30 min 给药（东莨菪碱贴、抗组胺药）
- 妊娠剧吐：维生素 B₆ → 异丙嗪 → 短期甲氧氯普胺

## 在知识体系里算什么？

它是消化系统用药的"支持治疗"模块，与第 1 节（抑酸）、第 2 节（胃肠动力）形成"治胃 + 治动力 + 治呕吐"的完整消化用药体系。

## 速记口诀是什么？

- **7 大类**："多虑了，三祖穷死啦，阿姨"
- **4 级化疗催吐**："高中低，321，轻微致吐可不需"

## 化疗止吐分级用药方案（CINV 分级）是什么？

化疗相关恶心呕吐（CINV）的预防用药方案，按化疗药物的催吐风险（呕吐发生概率）分 4 级，对应不同的联合用药方案。记忆口诀："**高中低，321，轻微致吐可不需**"。

| 催吐风险分级 | 呕吐发生概率 | 推荐止吐方案 |
|---|---|---|
| **高度催吐风险** | >90% | 三联方案：5-HT₃ + NK-1 + 地塞米松；第 2~5 天维持治疗 |
| **中度催吐风险** | 30%~90% | 二联方案：第 1 天 5-HT₃ + 地塞米松；后续按需维持 |
| **低度催吐风险** | 10%~30% | 单药方案：任选 5-HT₃ / 糖皮质激素 / 多巴胺 D₂ 拮抗剂 |
| **轻微催吐风险** | <10% | 无需常规预防性给药，出现症状后对症处理 |

### 核心特点

- **预防 > 治疗**：化疗用药前 30 min 给药，预防效果远优于治疗
- 高度致吐方案以三联固定组合为主；含蒽环 + 环磷酰胺的中度致吐方案也需三联
- 多日连续化疗方案：推荐全程使用三联方案覆盖急性 + 延迟性呕吐期
- **急性呕吐**（0~24 h）：主要由 5-HT₃ 通路介导，首选 5-HT₃ 拮抗剂
- **延迟性呕吐**（24~120 h）：主要由 P 物质通路介导，首选 NK-1 拮抗剂
- 地塞米松在急/延迟两期均有效

### 临床应用

- **高度催吐（HEC）**：顺铂、AC 方案（多柔比星/表柔比星 + 环磷酰胺）、卡铂 AUC≥4、大剂量环磷酰胺、大剂量阿霉素
  - 方案：阿瑞匹坦（或福沙匹坦）+ 昂丹司琼/帕洛诺司琼 + 地塞米松；第 2~3 天继续口服阿瑞匹坦 + 地塞米松维持
- **中度催吐（MEC）**：卡铂 AUC<4、伊立替康、奥沙利铂、阿糖胞苷、紫杉醇
  - 方案：5-HT₃（昂丹司琼/帕洛诺司琼）+ 地塞米松；若合并 AC 升级为三联
- **低度催吐**：氟尿嘧啶/亚叶酸钙、吉西他滨、丝裂霉素
  - 方案：地塞米松或多潘立酮或昂丹司琼单药
- **轻微催吐**：博来霉素、长春碱、门冬酰胺酶
  - 方案：无需常规预防；症状出现后对症

### 联合方案的安全性

- 联合方案常见 ADR：5-HT₃ 类（便秘、头痛、轻度 QT 延长）、NK-1 类（疲乏、便秘、嗳气）、地塞米松（短程使用失眠、血糖波动、兴奋）
- **地塞米松剂量过大、时间过长**会引发血糖显著升高、应激性溃疡、肾上腺抑制
- NK-1 类抑制 CYP3A4，与地塞米松合用时地塞米松剂量需减半（约 50%）
- 联合方案的总 ADR 谱是各药 ADR 的叠加，需密切关注
