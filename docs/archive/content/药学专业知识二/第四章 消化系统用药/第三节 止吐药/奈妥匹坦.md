# 奈妥匹坦(Netupitant)

## 它是什么药？

NK-1 受体拮抗剂，与帕洛诺司琼制成口服固定复方制剂 NEPA。

## 它有什么独特之处？

- 半衰期约 90 h，是同类最长之一
- 与帕洛诺司琼（长效 5-HT₃）联合制成 NEPA 单剂复方片
- 单剂 NEPA 可替代传统多药三联方案
- 与口服地塞米松联合（剂量可因相互作用调整）

## 临床应用是什么？

- 高度、中度催吐化疗方案预防
- 与地塞米松联合的简化两联方案

## 典型不良反应是什么？

头痛、疲乏、便秘；与同类 NK-1 拮抗剂类似。

## 它和节的关系？

NK-1 拮抗剂代表；NEPA 复方简化了高度催吐方案的给药。
