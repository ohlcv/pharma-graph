# 氟哌啶醇

## 它是什么药？

丁酰苯类多巴胺 D₂ 受体拮抗剂，**强效中枢镇吐**，用于化疗相关性恶心呕吐、术后恶心呕吐和难治性呕吐。也是第一代抗精神病药（FGAs）丁酰苯类的代表药，主要阻断中枢多巴胺 D₂ 受体。

## 它有什么独特之处？

- 丁酰苯类**强效中枢镇吐**（与氯丙嗪同为镇吐药中的强效药）
- 丁酰苯类**强效抗精神病**（与氟哌利多同属一类，作用相近）
- 大剂量锥体外系反应明显
- 与氟哌利多同属丁酰苯类，作用相近

## 核心作用特点是什么？

| 特点 | 说明 |
|---|---|
| **受体阻断** | 丁酰苯类中枢 D₂ 强效拮抗 |
| **镇吐效力** | 强于多数其他止吐药 |
| **抗精神病效力** | 第一代强效 FGAs |
| **锥体外系** | EPS 突出（急性肌张力障碍、帕金森样症状、静坐不能）|

## 临床应用是什么？

**止吐用途（第四章第三节）：**
- 化疗相关性恶心呕吐（CINV）
- 术后恶心呕吐（PONV）
- 难治性呕吐

**抗精神病用途（第一章第七节）：**
- 精神分裂症（丁酰苯类 FGAs 代表药）

## 典型不良反应是什么？

- **锥体外系反应**（急性肌张力障碍、帕金森样症状、静坐不能）
- **QT 间期延长**风险
- 嗜睡、体位性低血压
- 禁忌：帕金森病、嗜铬细胞瘤

## 它和节/章的关系？

- **止吐药章节**（第四章第三节）：丁酰苯类强效中枢镇吐；与氟哌利多同属一类，是难治性呕吐的保留方案
- **抗精神病药章节**（第一章第七节）：丁酰苯类 FGAs 代表药，与氟哌利多并列
