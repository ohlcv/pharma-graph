# 沙利度胺(Thalidomide)

## 它是什么药？

谷氨酰亚胺类（酰亚胺类），具有止吐、抗炎、免疫调节多重作用，无经典止吐靶点但临床上用于免疫相关疾病伴随的呕吐。

## 它有什么独特之处？

- 谷氨酰亚胺结构（"反应停"事件著名致畸原）
- 兼具止吐+抗炎+免疫调节三重机制
- 用于多发性骨髓瘤、骨髓异常增生综合征
- 强致畸性，孕妇绝对禁用

## 临床应用是什么？

- 多发性骨髓瘤等免疫相关疾病
- 化疗相关呕吐辅助
- 强直性脊柱炎、白塞病等免疫病伴呕吐

## 典型不良反应是什么？

**强致畸性**（孕妇绝对禁用；计划妊娠的育龄女性亦禁用；男性服药期间需采取避孕）；嗜睡、便秘、周围神经病变、深静脉血栓（联合地塞米松时风险增加）。

## 它和节的关系？

其他类止吐药；兼具免疫调节的多用途药，是化疗辅助止吐的"配角"。
