# 福沙匹坦(Fosaprepitant)

## 它是什么药？

阿瑞匹坦的磷酰化前药，静脉注射后迅速在体内转换为阿瑞匹坦。

## 它有什么独特之处？

- 静脉给药，适用于不能口服的患者
- 单次给药后活性与口服阿瑞匹坦相当
- 注射部位反应（血栓性静脉炎）需关注

## 临床应用是什么？

- 高度致吐性化疗方案 HEC 静脉预防
- 与静脉 5-HT₃+地塞米松联合

## 典型不良反应是什么？

注射部位反应、疲乏、便秘、腹泻、呃逆；与口服阿瑞匹坦类似。

## 它和节的关系？

NK-1 拮抗剂静脉给药代表；口服阿瑞匹坦的静脉等效选择。
