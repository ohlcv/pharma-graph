# 糖皮质激素止吐

## 它属于什么分类？

糖皮质激素在止吐药中按机制序号归属于第六大类，本质是联合方案的基础组分而非独立止吐药。它通过抗炎、抑制前列腺素合成、稳定细胞膜等多重机制起效，单用时止吐作用中等，但与其他止吐药联用时可显著增强疗效。临床上以地塞米松最为常用，其次为甲泼尼龙。

## 分类依据是什么？

- **按代表药**：
  - **地塞米松**：长效糖皮质激素，临床最常用，几乎所有化疗止吐联合方案的基础组分
  - **甲泼尼龙**：中效糖皮质激素，部分方案中可替代地塞米松
- **按给药途径**：以静脉、口服为主，单次或短程给药

## 它有什么特点？

- 单用时止吐作用中等，机制与 5-HT₃、NK-1 通路不同
- 与其他止吐药联用可显著增强疗效，是各级化疗止吐联合方案的基础组分
- 对化疗急性期、延迟期呕吐均有效，覆盖范围广
- 短程用药耐受性良好、性价比高，是联合方案的"廉价增效剂"

## 临床应用是什么？

- 各级化疗相关性恶心呕吐（CINV）联合方案的固定组分
  - 高度催吐化疗三联方案：5-HT₃ + NK-1 + 地塞米松
  - 中度催吐化疗二联方案：5-HT₃ + 地塞米松
  - 低度催吐化疗：地塞米松单药或联合
- 放疗相关呕吐的辅助治疗
- 术后恶心呕吐（PONV）联合方案中的辅助用药

## 典型不良反应是什么？

短期使用不良反应少，多为短暂可耐受的血糖轻度波动、失眠、兴奋、呃逆、胃部不适。长期或反复使用需关注全身性激素不良反应：血糖升高（糖尿病患者须监测血糖）、骨质疏松、感染风险升高、肾上腺皮质功能抑制、应激性溃疡。因此化疗止吐方案中通常仅短程使用 1~5 天。

## 它和节的关系？

它是止吐药第六大类（按机制序号），化疗止吐联合方案的基础组分。地塞米松属糖皮质激素统属，在其他章节已建节点（如内分泌章节），4.3 节通过 `relates` 边直接引用，不重复建节点。本节点与 CINV 分级用药方案（cinv-staging-regimens）强关联，构成完整的化疗止吐联合方案框架。
