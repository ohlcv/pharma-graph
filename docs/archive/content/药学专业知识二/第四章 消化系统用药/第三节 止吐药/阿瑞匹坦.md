# 阿瑞匹坦(Aprepitant)

## 它是什么药？

神经激肽-1（NK-1）受体拮抗剂，口服制剂，阻断中枢 P 物质介导的呕吐反射。

## 它有什么独特之处？

- 首个上市的 NK-1 受体拮抗剂（2003 年）
- **对化疗后延迟性呕吐（24~120 h）效果突出**
- 半衰期约 9-13 h
- 对 CYP3A4 有中度抑制作用
- 高度催吐方案三联方案的固定组分

## 临床应用是什么？

- 高度致吐性化疗（HEC）方案全程预防（顺铂等）
- 与 5-HT₃+地塞米松组成三联方案
- 中度催吐含蒽环类+环磷酰胺方案

## 典型不良反应是什么？

疲乏、便秘、嗳气、呃逆；CYP3A4 抑制可升高地塞米松、紫杉醇等血药浓度；与华法林合用需监测 INR。

## 它和节的关系？

NK-1 拮抗剂口服经典代表；高度催吐三联方案的延迟期核心。
