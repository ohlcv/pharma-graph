# 肠易激综合征（IBS）

## 它是什么病？

**肠易激综合征**（Irritable Bowel Syndrome, IBS）—— 罗马 IV 定义：**反复腹痛**，过去 3 个月内每周至少发作 1 次，伴以下 2 项或以上：

- 腹痛与**排便相关**
- 伴排便**频率**改变
- 伴粪便**性状**改变

## 4 个亚型是什么？

按 Bristol 粪便性状分类：

| 亚型 | 主要表现 |
|---|---|
| **IBS-C**（便秘型）| 便秘为主 |
| **IBS-D**（腹泻型）| 腹泻为主 |
| **IBS-M**（混合型）| 腹泻与便秘交替 |
| **IBS-U**（不确定型）| 不符合上述 |

## 病理生理基础是什么？

- 内脏高敏感
- 脑-肠轴失调
- 肠道微生态紊乱
- 肠道动力异常
- 肠道低度炎症

## 治疗策略是什么？

| 类型 | 治疗 |
|---|---|
| **腹痛** | **解痉药**（匹维溴铵、间苯三酚）|
| **IBS-D** | **止泻药**（洛哌丁胺）+ 解痉 |
| **IBS-C** | 渗透性泻药（聚乙二醇、乳果糖）+ **5-HT₄ 激动**（莫沙必利）|
| 辅助 | 益生菌、心理治疗（认知行为治疗、低剂量三环抗抑郁）|

## 它和节的关系？

它是第二节解痉药 + 促动力药的核心适应症；分亚型治疗是关键。
