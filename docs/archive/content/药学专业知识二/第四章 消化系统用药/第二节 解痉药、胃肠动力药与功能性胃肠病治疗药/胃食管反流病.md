# 胃食管反流病（GERD）

## 它是什么病？

**胃食管反流病**（GERD）是胃十二指肠内容物反流入食管引发的：

- **食管症状**：烧心、反酸、胸骨后疼痛
- **食管外症状**：慢性咳嗽、哮喘、声嘶
- **食管黏膜损伤**：反流性食管炎

## 3 种分型是什么？

1. **非糜烂性 GERD（NERD）**（最常见，约 60%~70%）
2. **糜烂性食管炎（EE）**（LA 分类：A~D 级）
3. **Barrett 食管**（食管下段鳞状上皮被柱状上皮替代 → **癌前病变**）

## 病理机制是什么？

**抗反流屏障功能减弱**：

- 食管下括约肌（LES）一过性松弛
- 膈肌脚功能低下

**反流物攻击**：胃酸、胃蛋白酶、胆汁

**食管黏膜防御减弱**

## 治疗策略是什么？

1. **抑酸**：**首选 PPI 8 周**（奥美/雷贝/埃索等）或 P-CAB
2. **促动力**：辅助（莫沙必利、多潘立酮）
3. **生活方式**：
   - 抬床头
   - 避免饱餐、睡前 2 h 禁食
   - 避免高脂、巧克力、咖啡、酒精、吸烟
   - 减重
4. **手术**：内镜下腹腔镜胃底折叠术（Nissen）

## 它和节的关系？

它是第二节促动力药 + 第一节抑酸剂的交叉节点；与 PPI/P-CAB 抑酸联合治疗是核心。
