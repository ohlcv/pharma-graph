# 普芦卡必利(Prucalopride)

## 它是什么药？

选择性 5-HT₄ 受体激动剂促动力药，通过激活肠神经丛 5-HT₄ 受体促进乙酰胆碱释放、增强肠动力。

## 它有什么独特之处？

- 作用机制：**选择性 5-HT₄ 受体激动剂**
- 具有促肠动力的作用
- 适用于成人慢性便秘症状的改善
- 强选择性（心血管安全性优于其他 5-HT₄ 激动剂）

## 临床应用是什么？

- **成人慢性便秘症状的改善**
- 慢性特发性便秘
- 阿片类顽固性便秘可尝试
- 妊娠期、糖尿病便秘可尝试

## 典型不良反应是什么？

最常见的不良反应为**头痛及胃肠道症状**（腹痛、恶心、腹泻）。

## 它和节的关系？

4.5 节 7 大类第五类（促动力药）唯一代表；用于成人慢性便秘；与机制互补的渗透性泻药、促分泌药合用可增效。
