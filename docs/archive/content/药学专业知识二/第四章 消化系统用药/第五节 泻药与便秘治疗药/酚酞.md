# 酚酞(Phenolphthalein)

## 它是什么药？
酚酞类刺激性泻药，通过刺激肠壁神经丛作用，增加肠道蠕动。

## 它有什么独特之处？
- 酚酞类化学药
- 刺激肠壁神经丛
- 起效快、作用强
- 一度广泛使用，安全性争议较大

## 临床应用是什么？
- 急性便秘的短期补救
- 肠道准备

## 典型不良反应是什么？
长期服用易出现药物依赖、电解质紊乱；可能导致结肠黑变病。不建议慢性便秘或老年患者长期使用。

## 它和节的关系？
4.5 节 7 大类第一类（刺激性泻药）化学药代表；与蒽醌类、比沙可啶同属应急补泻药。
