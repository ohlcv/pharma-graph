# 乌帕替尼(Upadacitinib)

## 它是什么药？

JAK1 选择性抑制剂口服小分子靶向药，IBD 顽固病例治疗。

## 它有什么独特之处？

- **JAK1 选择性抑制剂**
- 顽固性 UC 治疗
- 口服给药（便利性突出）
- 用于生物制剂失败或不耐受患者

## 临床应用是什么？

- 中重度 UC 诱导缓解与维持
- 对生物制剂失败患者
- 类风湿关节炎等（其他章节用途）

## 典型不良反应是什么？

感染（带状疱疹）；血栓风险；脂质异常；中性粒细胞减少。

## 它和节的关系？

4.6 节第三亚类第五大类（JAK 抑制剂与整合素拮抗剂）JAK 代表；与托法替尼（泛 JAK）同属 JAK 抑制剂但选择性不同。
