# 利福昔明(Rifaximin)

## 它是什么药？

利福霉素类衍生物非吸收肠道抗菌药，口服后仅 < 1% 的剂量经胃肠吸收。

## 它有什么独特之处？

- 属于非吸收肠道抗菌药
- **口服后仅 < 1% 的剂量经胃肠吸收**（系统暴露极低）
- 抗菌谱广——对多数革兰阳性菌、革兰阴性菌（包括需氧菌和厌氧菌）均有杀菌作用
- 主要用于敏感病原菌引起的肠道感染
- **可有效治疗大肠埃希菌菌株引起的旅行者腹泻**
- **但弯曲杆菌通常对其耐药**
- **连续服用不能超过 7 日**

## 临床应用是什么？

- 旅行者腹泻
- 敏感菌引起的肠道感染
- 急慢性小肠结肠炎
- 肠道菌群失调辅助

## 典型不良反应是什么？

总体耐受好（吸收少）；偶见腹胀、恶心、皮疹；罕见肠道菌群失衡。

## 它和节的关系？

4.6 节第二亚类核心药物；与喹诺酮类（全身抗菌，需感染重时用）和小檗碱（OTC 植物抗菌）并列。
