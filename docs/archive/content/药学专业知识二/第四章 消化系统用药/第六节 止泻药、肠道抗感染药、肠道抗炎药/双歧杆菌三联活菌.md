# 双歧杆菌三联活菌(Bifidobacterium Triple Live Bacteria)

## 它是什么药？

复方活菌制剂，组分为长型双歧杆菌、嗜酸乳杆菌和粪肠球菌，调节肠道菌群、维持菌群平衡。

## 它有什么独特之处？

- **复方制剂**——长型双歧杆菌 + 嗜酸乳杆菌 + 粪肠球菌
- 调节肠道菌群，维持菌群平衡
- 主治肠道菌群失调引起的急慢性腹泻、便秘

## 临床应用是什么？

- 肠道菌群失调引起的腹泻、腹胀等
- 轻中型急性腹泻、慢性腹泻的辅助治疗

## 典型不良反应是什么？

总体少；偶见腹胀、排气增加；**注意**：切勿置于高温处，溶解时水温不超过 40℃；**避免与抗菌药同服**，若合用需间隔 2~3 小时；**铋剂、鞣酸、药用炭、酊剂等能抑制/吸附活菌**，不能并用。

## 它和节的关系？

4.6 节第一亚类第五大类（止泻微生态）复方代表；与地衣芽孢单菌制剂并行；与 4.5 节微生态剂（治疗便秘）互为镜像。
