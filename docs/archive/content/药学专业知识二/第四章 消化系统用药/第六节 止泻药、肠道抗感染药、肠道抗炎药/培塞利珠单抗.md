# 培塞利珠单抗(Certolizumab Pegol)

## 它是什么药？

PEG 化 Fab 片段的 TNF-α 抑制剂生物制剂，**妊娠期可用 IBD 治疗药**。

## 它有什么独特之处？

- PEG 化 Fab 片段的 TNF-α 抑制剂
- CD 治疗用药
- **妊娠期/哺乳期可用**（不通过胎盘/乳汁）
- 无 Fc 片段——抗体依赖细胞毒性低

## 临床应用是什么？

- CD 诱导缓解与维持
- **妊娠期 IBD 维持**
- 哺乳期 IBD 维持

## 典型不良反应是什么？

注射部位反应；感染易感；总体耐受好。

## 它和节的关系？

4.6 节第三亚类第四大类（生物制剂）TNF-α 代表；妊娠期 IBD 维持首选。
