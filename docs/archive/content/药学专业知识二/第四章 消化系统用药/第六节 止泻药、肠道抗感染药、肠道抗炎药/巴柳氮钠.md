# 巴柳氮钠(Balsalazide Sodium)

## 它是什么药？

5-ASA 偶氮前药，化学结构由 5-ASA 通过偶氮键与无活性的惰性载体相连。

## 它有什么独特之处？

- 5-ASA 偶氮前药
- **在结肠细菌作用下释放出美沙拉嗪**
- 载体为无活性的惰性成分（4-氨基苯甲酰-β-丙氨酸）
- 上消化道吸收少、结肠药物浓度高

## 临床应用是什么？

- 轻中度溃疡性结肠炎急性发作
- UC 维持治疗

## 典型不良反应是什么？

水杨酸样反应；少见粒细胞减少、肝肾毒性；与磺胺吡啶无关（载体不同）。

## 它和节的关系？

4.6 节第三亚类第一大类（5-ASA）前药变体；与柳氮磺吡啶同属前药但载体不同。
