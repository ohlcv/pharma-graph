# 戈利木单抗(Golimumab)

## 它是什么药？

TNF-α 抑制剂生物制剂，UC 治疗用药。

## 它有什么独特之处？

- TNF-α 单克隆抗体
- UC 治疗用药
- 皮下给药

## 临床应用是什么？

- 中重度 UC 诱导缓解与维持

## 典型不良反应是什么？

注射部位反应；感染易感；罕见肿瘤风险。

## 它和节的关系？

4.6 节第三亚类第四大类（生物制剂）TNF-α 代表。
