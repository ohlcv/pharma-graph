# 托法替尼(IBD 用途, Tofacitinib)

## 它是什么药？

泛 JAK 抑制剂口服小分子靶向药，IBD 顽固性 UC 治疗。

## 它有什么独特之处？

- **泛 JAK 抑制剂**（JAK1/JAK3）
- 顽固性 UC 治疗
- 口服给药
- 与 2.2 节抗风湿用途（托法替布）同药

## 临床应用是什么？

- UC 诱导缓解与维持
- 类风湿关节炎等（2.2 节用途）

## 典型不良反应是什么？

感染（带状疱疹、肺部感染）；血栓；脂质异常；中性粒细胞减少；罕见肿瘤。

## 它和节的关系？

4.6 节第三亚类第五大类（JAK 抑制剂与整合素拮抗剂）泛 JAK 代表；与乌帕替尼（JAK1 选择性）同属 JAK 抑制剂。
