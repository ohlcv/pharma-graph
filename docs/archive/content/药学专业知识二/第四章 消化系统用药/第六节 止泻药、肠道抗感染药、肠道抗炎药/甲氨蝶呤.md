# 甲氨蝶呤(IBD 用途, Methotrexate)

## 它是什么药？

二氢叶酸还原酶抑制剂免疫调节药，IBD 维持治疗常用（特别是 CD 合并关节炎）。

## 它有什么独特之处？

- 二氢叶酸还原酶抑制剂
- 抑制嘌呤合成与免疫细胞增殖
- **CD 维持治疗常用**
- 合并关节炎患者尤其适合
- 与 2.2 节抗风湿用途同药

## 临床应用是什么？

- CD 维持治疗（合并关节炎者尤适）
- 类风湿关节炎（2.2 节用途）

## 典型不良反应是什么？

肝毒性（需定期监测）；骨髓抑制；肺纤维化（罕见）；肾清除为主。

## 它和节的关系？

4.6 节第三亚类第三大类（免疫调节药）抗代谢代表；跨章节用药（同时为 2.2 节抗风湿药）。
