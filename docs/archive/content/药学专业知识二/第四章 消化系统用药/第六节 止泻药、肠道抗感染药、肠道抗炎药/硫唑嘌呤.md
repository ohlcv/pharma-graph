# 硫唑嘌呤(Azathioprine)

## 它是什么药？

嘌呤类似物免疫调节药，IBD 维持治疗一线药物。

## 它有什么独特之处？

- 嘌呤类似物免疫抑制
- 抑制核酸合成 → 抑制 T 细胞增殖
- **IBD 维持治疗一线**
- 起效慢（数周至数月）
- **需监测 TPMT 活性**（硫代嘌呤甲基转移酶）以避免骨髓抑制

## 临床应用是什么？

- UC 维持治疗
- CD 维持治疗
- 减少激素依赖

## 典型不良反应是什么？

**骨髓抑制**（TPMT 缺乏者风险高）；肝毒性；感染易感；罕见淋巴瘤风险。

## 它和节的关系？

4.6 节第三亚类第三大类（免疫调节药）嘌呤类似物代表；与巯嘌呤（活性代谢物）配对。
