# 粪肠球菌(Enterococcus Faecalis / Faecium)

## 它是什么药？

肠道益生菌之一，常作为双歧杆菌三联活菌复方制剂的组分之一，通过定植肠道调节菌群。

## 它有什么独特之处？

- 肠道益生菌（活肠球菌类）
- 常作为双歧杆菌三联活菌复方制剂的组分
- 与双歧杆菌、嗜酸乳杆菌协同调节菌群
- 主治肠道菌群失调引起的急慢性腹泻

## 临床应用是什么？

- 双歧三联复方组分使用
- 直接菌群失调辅助

## 典型不良反应是什么？

总体少；同双歧三联复方禁忌；免疫缺陷者慎用活菌。

## 它和节的关系？

4.6 节第一亚类第五大类（止泻微生态）组分之一；与双歧杆菌、嗜酸乳杆菌构成三联复方。
