# 美沙拉嗪(Mesalazine / 5-ASA)

## 它是什么药？

5-氨基水杨酸类（5-ASA）IBD 抗炎药的核心活性分子，多种抗炎和免疫抑制特性。

## 它有什么独特之处？

- 5-ASA 的活性分子形式
- 多种抗炎和免疫抑制特性
- **药物在空肠迅速吸收，仅 20% 到达回肠末端或结肠**
- 常制成缓释剂型或前药使更多药物到达结肠

## 临床应用是什么？

- 溃疡性结肠炎急性发作期（诱导缓解）
- 溃疡性结肠炎维持治疗
- 克罗恩病急性发作（活动期）

## 典型不良反应是什么？

水杨酸反应（头痛、腹痛、恶心）；少见粒细胞减少、肝肾毒性、过敏。

## 它和节的关系？

4.6 节第三亚类第一大类（5-ASA）核心；前药/缓释剂型为实现"结肠定向"的工程化方案。
