# 蒙脱石(Montmorillonite)

## 它是什么药？

吸附剂类止泻药（硅酸盐类矿物药），对消化道内的病毒、病菌及其产生的毒素有固定和抑制作用，对消化道黏膜有覆盖能力，并通过与黏液糖蛋白相互结合，提高黏膜屏障对攻击因子的防御功能。

## 它有什么独特之处？

- 固定病毒、病菌及其毒素
- 覆盖消化道黏膜
- 与黏液糖蛋白结合提高黏膜屏障
- 可用于**成人及儿童急、慢性腹泻**
- **不溶于水**——需与一定量水形成混悬液才能更好散布于胃肠道黏膜表面
- 通常建议每个包装（3g）至少需要 50 ml 水稀释

## 临床应用是什么？

- 成人急慢性腹泻
- 儿童急性腹泻
- 食物/药物相关腹泻

## 典型不良反应是什么？

偶见轻度便秘；少数患者腹胀；**与其他药服用时建议与蒙脱石间隔一段时间**。

## 它和节的关系？

4.6 节第一亚类第一大类（吸附剂）代表药；与抗动力药、抗分泌药形成"吸附-抑制-减少分泌"的止泻三联机制。
