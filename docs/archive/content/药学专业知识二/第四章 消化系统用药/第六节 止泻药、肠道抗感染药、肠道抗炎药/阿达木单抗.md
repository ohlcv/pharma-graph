# 阿达木单抗(IBD 用途, Adalimumab)

## 它是什么药？

全人源 TNF-α 抑制剂生物制剂，IBD 治疗皮下维持用药。

## 它有什么独特之处？

- 全人源 TNF-α 单克隆抗体
- 皮下注射——可家庭给药
- IBD 治疗（UC、CD）
- 与 2.2 节抗风湿用途同药

## 临床应用是什么？

- 中重度 UC 维持治疗
- CD 诱导缓解与维持
- 类风湿关节炎等（2.2 节用途）

## 典型不良反应是什么？

注射部位反应；感染易感（结核、乙肝）；罕见神经脱髓鞘、肿瘤风险。

## 它和节的关系？

4.6 节第三亚类第四大类（生物制剂）TNF-α 代表；与英夫利昔（静脉）、戈利木、培塞利珠同属 TNF-α 抑制剂。
