# 异甘草酸镁(Magnesium Isoglycyrrhizinate)

## 它是什么药？

异甘草酸镁是 18α-异甘草酸镁单铵盐，类糖皮质激素样抗炎保肝药。

## 它有什么独特之处？

- 18α-异甘草酸镁单铵盐
- 类糖皮质激素样抗炎作用
- 与甘草酸二铵同属甘草酸类但结构优化
- 副作用相对较轻

## 临床应用是什么？

- 急慢性病毒性肝炎
- 药物性肝损伤
- 肝硬化辅助治疗

## 典型不良反应是什么？

低血钾、水钠潴留、血压升高（较甘草酸二铵略轻）；严重低钾血症、高钠血症、高血压、心衰、肾衰患者禁用。

## 它和节的关系？

4.4 节第一亚类第三大类（甘草酸类抗炎药）代表药；与甘草酸二铵同属甘草酸类。
