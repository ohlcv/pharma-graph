# 联苯双酯(Bifendate)

## 它是什么药？

联苯双酯是合成的降转氨酶药，降低谷丙转氨酶（ALT）作用强、起效快。

## 它有什么独特之处？

- 降低 ALT 作用强
- 起效快
- 停药后转氨酶易反跳
- 需逐步减量停药

## 临床应用是什么？

- 慢性肝炎 ALT 显著升高
- 药物性肝损伤转氨酶升高
- 脂肪肝伴转氨酶升高

## 典型不良反应是什么？

总体耐受良好；关键注意：停药后转氨酶易反跳，需逐步减量停药，不可骤然停用。

## 它和节的关系？

4.4 节第一亚类第四大类（降酶药）代表药；与双环醇同属降酶药，“双双降酶”。
