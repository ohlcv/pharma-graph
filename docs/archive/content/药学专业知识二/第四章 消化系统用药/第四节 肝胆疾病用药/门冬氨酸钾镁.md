# 门冬氨酸钾镁(Potassium Magnesium Aspartate)

## 它是什么药？

含门冬氨酸、钾离子、镁离子的复方制剂，提供氨基酸与电解质双重补充，促进肝细胞代谢。

## 它有什么独特之处？

- 提供 K⁺ 与 Mg²⁺ 电解质
- 提供门冬氨酸（氨基酸）
- 促进物质代谢与能量代谢
- 保持代谢所需酶的活性
- 兼用于心肌代谢

## 临床应用是什么？

- 重症肝炎、肝硬化辅助
- 病毒性肝炎伴低钾低镁
- 肝性脑病辅助
- 心律失常伴低钾低镁（兼用）

## 典型不良反应是什么？

滴注过快可致恶心、呕吐、血管刺激；高钾血症、高镁血症、肾功能不全者慎用或禁用。

## 它和节的关系？

4.4 节第一亚类第五大类（促代谢药）代表药；从代谢支持角度辅助护肝。
