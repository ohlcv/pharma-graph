# 布局设置重构 — 修改位置说明

## 整体结构

桌面端：
  - topbar 的布局 dropdown 保留不动（桌面切换布局的唯一入口）

## src/ui/layout/layout-engine.ts

### 修改 `runLayout`

透传 localStorage 中保存的参数，让 cytoscape 使用用户滑杆值而不是默认值：

```ts
const overrides = loadStoredParams(name) ?? {};
renderer.runLayout(name, overrides);
```

### 不再新增 `switchLayoutAndRefresh`

桌面切换入口留在 topbar（`pick-layout`），`action-handlers.ts` 里已有的 `switchLayout()`（runLayout + 刷新两个参数面板）已经覆盖，无需在 layout-engine 里再加 dropdown 同步。

---

## src/ui/layout/layout-params.ts

### 修改 `renderLayoutParams`

去掉对「应用参数」按钮的隐藏逻辑（始终显示按钮）。

### 手机端

- 删除 `toggleBsLayout` / `toggleBsParams`（旧的两个折叠块已合并）。
- 新增 `toggleBsLayoutSetting`：切换「布局设置」子折叠，首次展开时调用 `renderBsLayoutParams` 刷新。
- 新增 `restoreBsLayoutSettingPrefs` / `resetBsLayoutSettingPrefs`：从 localStorage 恢复/重置子折叠状态。
- `restoreBsAdvancedPrefs` / `resetBsAdvancedPrefs` 同步恢复/重置「布局设置」子折叠。
