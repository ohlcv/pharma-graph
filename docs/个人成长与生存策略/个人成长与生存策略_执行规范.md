# 《个人成长与生存策略》执行规范

> **文件定位：** 本文件规定全书的思想建构原则、内容编辑标准、论证边界、Frontmatter 与知识图谱规范，以及重构过程的执行和验收要求。
>
> **配套文件：**《个人成长与生存策略》重构方案。前者规定“如何做”，后者规定“这本书要表达什么、如何组织”。

---

## 一、项目定位

### 1.1 本书要回答的根本问题

《个人成长与生存策略》不是对旧节点进行分类汇总，也不是把原有文章装进新的文件夹。它要从作者迄今形成的认知、观察、模型、原则和实践中，建构一套完整的个人思想体系。

全书围绕以下问题展开：

> **一个具有特定先天条件、处于特定社会环境中的有限个体，如何在一个复杂、动态、充满不确定性的世界中，认识现实、选择方向、配置资源，并建立一套能够长期运行的个人生存系统？**

这个问题包含四个基本现实：

1. **世界具有复杂性。** 世界不是静态事物的简单集合，而是由关系、因果、约束和变化构成的复杂系统。
2. **个体具有有限性。** 人受到先天条件、认知能力、时间、精力、资源和环境的限制。
3. **未来具有不确定性。** 即使世界存在因果关系，也不意味着个体能够完整掌握因果链或准确预测未来。
4. **行动无法等待完全认知。** 人必须在有限信息下作出选择，并通过实践反馈持续修正认识与行动。

### 1.2 本书最终要建立什么

本书不是一套解释一切的理论，也不承诺消除不确定性或让个体控制所有结果。

它要建立的是一套个人生存与行动系统，帮助个体：

- 理解外部现实及其约束；
- 认识自身条件和成长空间；
- 建立价值排序与取舍原则；
- 判断知识、模型和推理的可靠程度；
- 管理有限的时间、精力、认知资源和现实资源；
- 在不确定环境中持续行动、适应和迭代；
- 提高生存质量，并尽可能保留长期选择权。

### 1.3 本书的性质与边界

本书可以包含哲学思考、跨学科理论、个人观察、思想实验、价值原则和实践方法，但不等同于任何单一学科教材。

本书不是：

- 纯粹的哲学理论专著；
- 命理学教材或命理预测手册；
- 心理学、神经科学或医学诊断手册；
- 只讲习惯、效率和自律的工具书；
- 把所有跨学科相似性都解释成同一底层规律的统一理论。

纳入材料必须服务于全书的核心问题与论证主线。不能为了追求概念数量、学科跨度或理论气势而堆砌内容。

## 二、全书顶层结构

### 2.1 五章顺序固定

全书固定采用以下五章，顺序由作者明确确定，不得擅自调整：

1. **世界观**
2. **价值观**
3. **人生观**
4. **认识论**
5. **方法论**

五章分别承担以下职责：

| 章节   | 核心问题                         | 讨论对象                                             |
| ------ | -------------------------------- | ---------------------------------------------------- |
| 世界观 | 世界究竟如何运行？               | 世界本身的结构、关系、因果、变化、秩序、演化与可能性 |
| 价值观 | 什么值得追求，什么必须放弃？     | 价值排序、资源投入、机会成本、取舍原则与行为边界     |
| 人生观 | 我是谁？从哪里出发？能改变什么？ | 个体先天条件、后天变量、人生轨迹与时代处境           |
| 认识论 | 有限的人如何认识复杂世界？       | 观察、抽象、压缩、模型、证据、概率与认知边界         |
| 方法论 | 如何把认知转化为行动？           | 知识发现、算力管理、任务执行、环境工程与社交决策     |

### 2.2 目录顺序是讲述顺序，不是认知发生顺序

五章顺序用于组织读者的理解路径，不意味着人的认知在现实中严格依次发生。

尤其要区分世界观与认识论：

- **世界观讨论世界本身：** 现实由什么构成，关系如何组织，世界如何变化。
- **认识论讨论人如何认识世界：** 人如何观察、抽象、建模、推理，以及知识的可靠性和边界。

五章之间的讲述关系可以概括为：

```text
理解世界
  ↓
确立取舍
  ↓
理解自身
  ↓
审查认知
  ↓
组织行动
  ↺
实践反馈修正认识、价值判断与行动方式
```

这是一条叙述主线，不是五个彼此隔绝的知识容器。五章之间可以互相引用，但每个思想必须有明确的主要论述位置。

### 2.3 全书总纲命题

> 人无法选择自己的全部初始条件，也无法控制外部世界的全部变化。但人可以逐步认识自己的条件，理解现实的约束，建立合理的价值排序，改善自己的认知与行动系统，从而提高自己在复杂世界中的生存质量和人生选择权。

## 三、思想重构原则

### 3.1 原始节点是思想材料，不是最终目录

原始 Markdown 节点可能是：

- 一个完整论点；
- 一个概念定义；
- 一种解释模型；
- 一个思想实验；
- 一段个人经验；
- 一条价值原则；
- 一套操作流程；
- 一个案例或外部参考；
- 一个尚未完成、等待补充的假设。

不能因为某个节点原来是独立文件，就默认它在新书中必须继续作为独立章节或独立节点。

### 3.2 先建构思想，再安排材料

重构必须遵循以下顺序：

1. 提炼一组材料共同回答的核心问题。
2. 确定它在全书中承担的论证任务。
3. 设计读者理解它所需的前置概念与论证顺序。
4. 再决定原始节点如何拆分、合并、重写、引用或归档。
5. 建立跨章节联系。
6. 检查是否保留了原材料中有价值的思想。

不得从旧文件夹结构反推新书目录。

### 3.3 允许非一对一迁移

一个旧节点可以：

- 被吸收进一个更大的新论述；
- 被拆成定义、论证、案例或方法；
- 与多个节点共同构成新章节；
- 保留为独立模型，但不再承担章节标题；
- 仅作为案例、注释或交叉引用；
- 在有记录的前提下归档。

一个新章节也可以由多个旧节点、作者后来明确形成的观点和必要的新论证共同构成。

### 3.4 一个思想只设一个主要论述位置

原则上，一项完整思想只在一个位置展开。其他章节可以简要调用、交叉引用或从不同角度讨论其另一层问题，不复制整篇正文。

典型边界：

- 动态关系网络在世界观中解释现实结构；认识论中讨论人如何把复杂网络提取为可理解的结构。
- 先天与后天在人生观中系统论述；认识论中只讨论先验、证据与认知更新。
- 社交边界的价值理由放在价值观；社交分级和具体执行流程放在方法论。
- 命理内容全部集中在人生观的一个小节。
- 光的路径与困光思想实验集中在世界观的相关小节；其他章节只交叉引用其认识论启示。

### 3.5 保留作者声音与思想边界

- 优先保留作者原有核心措辞、隐喻和独特表达。
- 可以重排论证、调整句序和段落，但不得偷换观点。
- AI 补写的解释不得伪装成作者原话或历史上已经形成的观点。
- 作者尚未明确的模型定义必须标记待确认，不代替作者做最终解释。
- 不把探索性表达润色成貌似确定的科学结论。
- 不把外部参考观点改写成作者原创。

## 四、五章的编辑边界

### 4.1 世界观

讨论外部现实本身：

- 动态关系网络与本体结构；
- 因果链、关系链、时间与变化；
- 网络与树形结构作为世界结构的表达；
- 秩序、混沌、吸引子、稳定结构与选择压力；
- 演化、趋同、路径与可能性；
- 光的路径模型及相关思想实验。

要求：

- 先说明概念在原学科或原语境中的含义，再说明作者如何借用。
- 不把不同学科中名称相似的概念直接视为同一概念。
- 不把物理学隐喻当作人生规律的实验性证明。
- 不将世界的客观结构与人对该结构的认知表达混为一谈。

### 4.2 价值观

讨论什么值得追求、什么应该放弃，以及个人资源如何分配：

- 人生主线优先；
- 核心事项使用最好的资源；
- 不贪小便宜、算大账；
- 实事求是，考虑隐性成本；
- 细枝末节不较真；
- 真诚但不自我献祭；
- 双向尊重、边界、自我保护与平衡；
- 风险、代价和长期机会成本。

要求：

- 区分价值判断与事实判断。
- 保留原则形成的背景和适用条件。
- 本章主要回答“为什么这样取舍”；具体执行流程放在方法论。

### 4.3 人生观

讨论个体如何理解自身，以及个人与环境、命运轨迹和成长空间之间的关系：

- 先天底色与后天变量；
- 不可轻易改变的倾向与可训练能力；
- 个人资源底盘、认知、决策与抗风险能力；
- 家庭、社会、教育、资源与时代环境；
- 命运轨迹与作者从命理观察中形成的认识。

要求：

- 不把接纳先天条件写成放弃行动。
- 不把后天可训练写成“只要努力就能改变一切”。
- 说明个体行动、环境条件和系统约束之间的关系。

#### 命理内容的唯一归属

**所有命理相关内容统一放在《人生观》的一个独立小节，不得拆散到其他章节。**

命理在本书中的定位是：作者借助传统命理符号体系观察、拆解和思考命运轨迹，并由此讨论先天条件、后天变量、环境约束与人生选择。作者并非以系统研究命理模型本身为全书主线。

编辑要求：

1. 五行、天干地支、十神、四柱、称骨等符号与规则说明集中呈现。
2. 八字交互、称骨模型、四同八字、模型矛盾、适用边界、现代社会有效性变化等内容，在同一小节内按论证关系组织。
3. 合并重复解释，保留确有不同分析对象或论证功能的内容。
4. 重点呈现作者借此观察命运轨迹的认识，不扩张成全面命理学教材。
5. 区分传统体系内部规则、作者观察、结构类比、工作假设和可验证事实。
6. 不将命理预测能力表述为已经获得现代科学验证的结论，也不擅自否定作者个人观察的价值。

### 4.4 认识论

讨论人如何认识、抽象和表达世界：

- 本体与认知的区别；
- 复杂网络与认知中的树形骨架；
- 抽象、压缩、截断、粗粒化与模型简化；
- 分形、自相似、结构类比与同构；
- 频率派、贝叶斯更新、先验与证据；
- 知识、证据、解释力、认知边界与模型失效。

要求：

- 区分现实对象、观察结果、模型表达和对模型的解释。
- 明确证据强度与不确定性。
- 类比只能帮助理解，不能代替论证。
- 模型不能覆盖现实全部细节；其价值必须结合用途与边界判断。
- 不把认知局限等同于世界本身没有规律。

### 4.5 方法论

讨论如何发现答案、管理资源、组织任务、保护执行环境并处理人际互动：

- 知识发现与问题求解；
- 算力预算、消耗识别、常态管控、维护、预警、熔断与复盘；
- 任务启动、上下文保护与感官 I/O 管理；
- 社交关系分级、模式路由、帮助判定、边界执行与事后冷却。

要求：

- 方法说明目标、适用条件、执行步骤和停止条件。
- 区分原则、流程、工具、模板与案例。
- 不把个人实践中有效的策略宣称为普遍定律。
- 方法必须接受反馈，允许根据结果迭代。
- 本章是个人行动系统，不是技巧清单。

## 五、关键思想材料的特殊要求

### 5.1 光的模型与彭罗斯镜室

光的相关模型安排在世界观中有关路径、可能性与规则约束的部分。

作者明确要求加入**彭罗斯镜室**。在作者尚未提供具体解释或资料前，只登记为待补充的模型条目，不擅自编写其物理结构、数学性质或与其他理论的关系。

不得将彭罗斯镜室与困光思想实验视为同一个模型，除非作者明确确认二者关系。

### 5.2 困光思想实验

标题必须使用：

**《困光思想实验：一层层的规则墙无法改变的结局》**

其核心内容：

- 思想实验来自一个短视频提出的问题：能否把光永久困在一个绝对光滑的镜面盒子里，让它无限反射？
- 作者的理解是：解决一层物理规则带来的限制后，可能出现更深一层规则；一层层解决局部约束，仍无法保证最终结局改变，最终似乎仍有更深层规律导致光消散。
- 它带来一种“结局似乎早已写定”的感受。
- 作者将其映射到量化研究：解决未来函数后遇到过拟合；解决过拟合后遇到样本外失效；解决回测问题后遇到模拟实盘与真实实盘差异；解决模拟实盘差异后，又遇到交易者自身操作可能反过来影响市场。

映射链：

```text
解决未来函数
    ↓
遇到过拟合
    ↓
解决过拟合
    ↓
遇到过去不代表未来／样本外失效
    ↓
解决回测问题
    ↓
遇到模拟实盘与真实实盘的差异
    ↓
解决模拟实盘差异
    ↓
遇到真实交易中，交易者自身操作可能反过来影响市场
```

编辑必须保留：

- 从表面简单的问题到深度未知的问题的认知落差；
- 一层问题解决后，下一层问题才显现的递进结构；
- 量化研究案例中的具体层级；
- “多阶函数”是作者用来描述问题深度和递归性的表达，不擅自将其定义为数学函数；
- “结局似乎早已写定”是思想体验与哲学感受，不写成已证明的宿命论结论。

不得恢复旧标题《困光思想实验：改不了光的本性，就重排法则之墙》，不得将其改写成“改变边界条件即可改变结局”。

### 5.3 “答案已经存在”

“答案已经存在”是作者用于指导知识发现的工作公理与搜索立场。

编辑时区分：

- 搜索空间中可能已有可复用的答案或组件；
- 找到一个逻辑完整、值得验证的候选方案；
- 通过实验、实现或证据证明候选方案有效。

前两者不能自动推出第三者。不得把工作公理写成“任何问题的答案都必然已经被找到”的客观定理。

## 六、论证等级与内容性质

全书必须区分以下内容性质：

1. **可核验事实**：有明确来源或可重复核查。
2. **学科理论**：在相应学科中有清晰定义与适用范围的理论。
3. **作者观点**：作者基于经验、观察与推理形成的判断。
4. **工作假设**：暂时用于解释或指导探索，仍需检验。
5. **结构类比**：借用不同领域的相似关系帮助理解，不等于两者本质相同。
6. **个人经验**：作者自身处境中观察到的现象，不自动推广为普遍规律。
7. **价值判断**：关于重要性、应然、取舍和行动原则的判断。
8. **思想实验**：通过设定条件推演问题的思维工具，不等于现实实验或已证明定理。

特别注意：

- 路径积分、退相干、重整化、混沌吸引子等概念，先说明原学科含义，再说明作者的借用方式。
- 困光思想实验作为作者的哲学类比呈现，不伪装成物理学或数学定理。
- 彭罗斯镜室在定义未核实前，只保留名称和待补资料状态。
- 命理内容区分传统符号体系、作者观察与可验证事实。
- 对神经科学、心理学和生理机制的陈述，不根据个人体验擅自推断脑区、神经递质或诊断。
- “算力”“电量”“熔断”等可以作为工程隐喻使用，但不能直接当成可测量的生理量。

## 七、目录、正文与知识图谱的分工

### 7.1 三套结构

| 结构     | 回答的问题                 | 职责                                               |
| -------- | -------------------------- | -------------------------------------------------- |
| 思想体系 | 作者究竟想表达什么？       | 决定核心命题、论证层次和概念关系                   |
| 书籍目录 | 读者应该怎样理解？         | 决定章节顺序、阅读路径和内容展开                   |
| 知识图谱 | 各思想之间实际是什么关系？ | 表达严格的概念层级、实例归属、组成、互斥与等价关系 |

三者应当协调，但不要求一一对应。

### 7.2 目录不是图谱边的翻译

节点处于同一章节，不代表它们必然存在 `part_of` 关系；两个节点在图谱中存在关系，也不代表它们必须在书中相邻。

章节归属属于编辑结构，图谱边属于严格语义关系。不能为了目录层级而滥用图谱边，也不能为了图谱丰富而创造语义。

### 7.3 跨章节关联

跨章概念应：

- 选择一个主要位置完整论述；
- 在其他章节简要说明其关联或交叉引用；
- 不复制整篇正文；
- 只有符合既定五种语义关系时才建立图谱边。

## 八、Frontmatter 与知识图谱协议

### 8.1 权威依据

`frontmatter.md` 是字段、格式、边类型和语义方向的唯一规范依据。原始 ZIP 是原始内容底稿；作者在对话中明确确认的要求优先于旧文档；`v5.md` 仅为候选建议，必须核验，不能作为规范来源。

### 8.2 既有字段

保留 `frontmatter.md` 中已经定义的字段与结构，包括：

- `id`
- `label`
- `shape`
- `fill`
- `stroke`
- `location.book`
- `location.chapter`
- `location.section`
- `location.item`（已废弃，默认不再使用）
- `published`
- `tags`
- `summary.short`
- `summary.full`
- `edges_out`

不得擅自修改既有字段语义。实际执行时以 `frontmatter.md` 原文为准。

### 8.3 仅允许新增的五个字段

作者仅授权增加：

- `created_at`
- `status`
- `version`
- `authors`
- `sequence_in_book`

除此之外，不得增加任何新的 Frontmatter 字段，包括但不限于 `kind`、`collaboration`、`evolution_phase`、`updated`、`sources`、`claims` 等。

建议 `status` 受控值为 `draft`、`review`、`approved`、`archived`；如需变更，先由作者确认。

### 8.4 时间字段

- `created_at`：内容最初形成的日期，不得直接用迁移日期代替。
- `published`：保持原规范中的发布或更新时间含义。
- `sequence_in_book`：新书中的阅读顺序，不代表创作时间。

无法确认日期时不得编造。应按原规范留空或处理，并在迁移台账说明。

### 8.5 五种合法边关系

只允许以下五种 `edges_out.type`：

| 类型            | 语义                 | 方向        |
| --------------- | -------------------- | ----------- |
| `subclass_of`   | 子类属于更一般的父类 | 子类 → 父类 |
| `instance_of`   | 个体属于某个类       | 个体 → 类   |
| `part_of`       | 局部组成整体         | 局部 → 整体 |
| `disjoint_with` | 两个类互斥           | 对称        |
| `equivalent_to` | 两个类定义等价       | 对称        |

不得新增其他关系类型，包括 `supports`、`derived_from`、`applies_to`、`implements`、`contrasts_with`、`mitigates`、`related_to` 等。

每条边必须包含 `target`、`type`、`reason`。关系方向和语义必须符合 `frontmatter.md`。因果影响、论据支持、类比、引用和普通关联不能伪装成上述五种边。

### 8.6 Frontmatter 与正文格式

严格遵循 `frontmatter.md`：

- 文件第一行必须为 `---`，Frontmatter 以第二条 `---` 结束。
- 文件名与 `label` 对应；`id` 唯一。
- `location.book`、`location.chapter` 等按规范填写。
- `location.item` 已废弃，默认不再使用。
- `summary.short` 不超过 200 字；`summary.full` 不超过 500 字，并按原规范使用 `【标签】` 分段。
- 有 Markdown 正文时必须有且仅有一个 H1，且为正文第一个标题。
- H1 后使用 H2 分节，H2 下可用 H3，不得跳级。
- 摘要与正文分工明确，不把长正文塞入摘要。

如本文件对字段长度或格式的概括与 `frontmatter.md` 原文有差异，以 `frontmatter.md` 为准。

### 8.7 合法 `fill` 值清单

`fill` 只能取 [`src/core/config.ts`](../../src/core/config.ts) 中 `FILL_CONFIG` 已注册的键。当前合法值共 **10 个**：

| `fill` 值            | 显示名              | 适用对象                           | 默认形状                           |
| :------------------- | :------------------ | :--------------------------------- | :--------------------------------- |
| `cls-structure`      | 组织结构            | 书 / 篇 / 章 / 节入口              | round-pentagon（圆角五边形）       |
| `cls-classification` | 药物分类            | 粗分类 / 细分类 / 亚类             | octagon（八边形）                  |
| `cls-drug`           | 药物                | 具体药物（重点 + 普通）            | ellipse（椭圆）                    |
| `cls-disease`        | 疾病                | 疾病 / 症状 / 综合征               | diamond（菱形）                    |
| `cls-biomolecule`    | 生物实体            | 靶点 / 受体 / 酶 / 转运体 / 基因   | round-triangle（圆角三角）         |
| `cls-feature`        | 作用特点 / 临床评价 | 作用特点 / 临床用药评价 / 选药原则 | star（星形）                       |
| `cls-adverse`        | 不良反应 / 禁忌     | 典型不良反应 / 禁忌 / 毒性         | round-hexagon（圆角六边形）        |
| `cls-concept`        | 抽象概念 / 总论     | 定义性概念 / 总论 / 术语           | round-rectangle（圆角矩形）        |
| `cls-summary`        | 总结                | 节内总结 / 跨节大总结 / 表格       | bottom-round-rectangle（下圆矩形） |
| `cls-mnemonic`       | 口诀                | 记忆口诀 / 顺口溜                  | tag（标签形）                      |

要求：

1. **不得使用清单外的值**（如已废弃的 `cls-collection`）。非法 `fill` 会被 `npm run validate` 记为警告，并在渲染层回落到默认样式，节点的语义色与形状全部丢失。
2. **结构节点统一用 `cls-structure`**：全书根节点、五章章节点、各节节入口都用该值；且**不要**再显式写 `shape`，否则会覆盖 `round-pentagon` 的入口形状。
3. **语义节点按论证性质选值**：概念/模型用 `cls-concept`，方法/论点/操作要点用 `cls-feature`，总结卡与对照表用 `cls-summary`，口诀用 `cls-mnemonic`；预警信号、陷阱、误区与风险拦截类节点沿用 `cls-adverse`（取其"警示"语义），生理/神经机制类节点沿用 `cls-biomolecule`。`cls-drug`、`cls-disease`、`cls-classification` 不在本书范围内使用。
4. **权威来源**：字段语义与形状映射以 [`docs/RULES.md`](../RULES.md) §二 与 `FILL_CONFIG` 为准。若确需新增 `fill` 类型，必须先在 `src/core/config.ts` 注册并同步 `RULES.md`，再回填本表，不得在内容中先行使用。

## 九、编辑动作与节点质量

### 9.1 可采用的编辑动作

| 动作 | 含义                                                   |
| ---- | ------------------------------------------------------ |
| 保留 | 节点有独立价值，保留并按新书定位修订                   |
| 合并 | 多个节点重复或互补，整合成更完整的论述                 |
| 拆分 | 一个节点包含多个定义对象或论证任务                     |
| 重写 | 保留思想，重新组织论证和表达                           |
| 引用 | 不重复原文，在其他位置调用其结论或模型                 |
| 归档 | 内容被替代、过时或不再有独立用途；保留记录，不无痕删除 |

### 9.2 合并与拆分标准

合并前确认：

- 是否表达同一核心定义或机制；
- 是否只是同一主题的不同层次；
- 合并后是否仍能区分必要概念；
- 是否会破坏独立引用或使用场景。

拆分前确认：

- 是否包含多个独立问题；
- 是否有不同定义对象、论证链或操作流程；
- 是否能在不重复大段内容的前提下独立理解。

不得仅凭标题相似合并，也不得仅凭篇幅较长拆分。

### 9.3 作者贡献与 AI 参与记录

- 只有在某个节点的实质内容由作者和 AI 共同形成时，才在 `authors` 中记录双方。
- AI 名称必须使用实际模型名称，不得虚构模型或版本。
- 本项目当前对话中的模型身份为 **ChatGPT（GPT-6）**；只有当 GPT-6 对该节点有实质贡献时才记录，不得自动标注到所有节点。
- 不得把 AI 的补充解释伪装成作者原有内容。

## 十、执行流程与验收

### 10.1 固定执行流程

1. 将原始 ZIP 作为只读基线。
2. 盘点全部有效 Markdown 节点、目录、链接、Frontmatter 与正文。
3. 按全书核心命题和五章职责制定迁移矩阵。
4. 对每组材料确定论证任务，而非只指定文件去向。
5. 设计各章总纲、各节任务和论证顺序。
6. 执行保留、合并、拆分、重写、引用或归档。
7. 修订 Frontmatter、目录、阅读指南、链接与图谱关系。
8. 分章审校，再进行全书交叉审校。
9. 输出迁移台账、校验报告与完整项目包。

### 10.2 单节点检查清单

- [ ] 内容来自原始材料，或明确标记为后续新增观点。
- [ ] 节点在新书中承担明确的论证任务。
- [ ] 主要章节归属合理，不是机械沿用旧位置。
- [ ] 没有与其他节点重复论述。
- [ ] `id` 唯一，`label` 与文件名对应。
- [ ] `location` 指向实际章节和小节。
- [ ] 新增字段仅限五个获准字段。
- [ ] 日期有依据，没有把迁移日期误记为创作日期。
- [ ] 摘要和正文标题层级符合 `frontmatter.md`。
- [ ] 边类型只使用五种合法关系，方向和理由正确。
- [ ] 正文区分事实、理论、类比、假设、经验、思想实验与价值判断。
- [ ] 跨章引用正确，没有重复复制整篇内容。

### 10.3 全书验收标准

- 五章顺序严格为世界观、价值观、人生观、认识论、方法论。
- 全书围绕“有限个体如何在复杂、不确定的世界中建立可持续的生存与行动系统”展开。
- 目录体现思想论证顺序，而非旧节点的机械归类。
- 世界观与认识论明确区分“世界本身”与“人对世界的认识”。
- 命理内容全部集中在人生观的唯一一个小节。
- 光的模型包含“彭罗斯镜室”；未确认定义不擅自补造。
- 困光思想实验使用最新标题和准确含义。
- 原始材料中有价值的思想得到保留、重组或有记录地归档。
- 图谱协议未被擅自扩展。
- 目录、正文位置、Frontmatter 与图谱引用一致。
- 编辑过程可追溯、可复核。
