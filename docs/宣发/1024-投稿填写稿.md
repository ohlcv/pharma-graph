## 05 作品介绍

```
「药学家族关系星图」是一个把执业药师考试教材变成可交互知识网络的网页应用。免注册、免安装，浏览器打开即用。

【给谁用】执业药师考生（尤其二战与冲刺阶段）、药学专业学生、授课教师。

【解决什么问题】三大本教材、上千个知识点，背了忘、忘了背；更麻烦的是药名高度相似，背串了自己都不知道。课本上其实画着分类树，但真正背书的时候，知识还是散的——结构从来没有被"看见"。

【怎么做】把药学专业知识一、二、药学综合知识与技能三科的 2,700+ 个知识点拆成十类节点，每个节点就是一份完整讲义（定义、分类、用法、不良反应）；再用属种、包含、实例、互斥、等价五种关系、3,100+ 条边把它们连成一张网。形状定身份，颜色定门类，线型定关系——看一眼轮廓和连线，就知道谁是谁、谁和谁容易搞混。点开任意节点即见讲义，顺着关系线走，易混药自然并排出现，混淆无处藏身。

【核心玩法】

1. 漫游学习——一键自动串讲整本书。两种策略：教材顺序（深度优先，和翻书顺序一模一样）、先修依赖（拓扑序，先学地基再学楼，前置没懂绝不提前讲后面）；间隔 1–10 秒连续可调，顺序 / 倒序 / 随机，可暂停、可手动步进，5 档深度（结构 · 概览 · 重点 · 全面 · 全部）。适合通勤、睡前、考前查漏补缺。

2. 语音朗读——粒度自由组合：标题、关联、标签、摘要、正文；语速 0.5–2.0 可调，等读完再自动跳下一站。通勤路上、闭眼躺着都能过一遍考点。

3. 关系推理——五种关系任意追查，把"背串"从记忆问题还原成结构问题。

4. 七种布局 + 大屏投屏——Euler / COSE / 同心圆 / 环形 / 网格 / Dagre / 广度优先，一键变换形态；课堂演示按 Esc 进大屏，图谱铺满全屏。

【一个更进一步的尝试】《药事管理与法规 2026 速成通关手册》：传统教学是一节课讲知识、一节课讲题，两件事分开。这本手册把它们焊在一起——245 条考点逐条写全，每条考点下面直接挂真题，2023–2025 三套真题加三套压轴卷逐题挂靠，题干、选项、答案、解析一字不少；🟢送分 / 🟡技巧 / 🔴放弃三色分级，考前一小时只看书尾的「保命清单」。边学边见题，学完就会做题。

【审美】三层视差的星空，液态玻璃的面板——学习可以不苦，复习随时启动；教材可以很美，知识浪漫灵动。星图从奇点爆散、在引力与斥力里自然排布成知识拓扑的那一刻，教材第一次显得浪漫。

【彩蛋】这张星图不止是考点。它由几个互不连通的空间组成，空间之间没有一条边相连，唯一的旅行方式是穿过一扇门——门后是什么，自己去发现。

【怎么体验】打开链接，等星图成形；顶部搜索框输入任意药名定位，或直接点工具栏「漫游」交给它自己讲。主站：pharma.ac.cn

⚠️ 备考学习工具，非用药指导。
```

## 正文

```
我药学出身，太知道备考的苦了。

执业药师考试一上来就是三大本，上千个知识点。背了忘、忘了背，最要命的是——药名长得都一样，背串了都不知道。课本上明明画着分类树，可你背的时候，知识还是散的。

所以我给自己做了这个：药学家族关系星图 pharma.ac.cn。

把整本书拆成上千个节点，用属种、包含、实例、互斥这些关系连成一张网。每个点开就是完整讲义，顺着线走，易混药直接对比着看。

我最得意的功能是「漫游」：像开了自动挡，按教材顺序或者先修依赖，把整本书自动串讲一遍。顺序、策略、深度都你定，还带语音朗读，粒度随便组合——闭着眼也能复习。

还有个我自己很骄傲的尝试：法规这门课，我把 245 个考点和 6 套卷的真题焊在一起了。传统是学一节课、再做一节课的题；我让每个考点下面直接挂真题，边学边见题。这是我和 AI 一起写的书——我觉得这才是 AI 时代该有的学习方式。

星空主题、玻璃质感——教材可以很美，知识浪漫灵动。学习可以不苦，复习随时启动：通勤路上开漫游，睡前闭眼听朗读。

图里还藏着彩蛋。整张星图其实是好几个宇宙：药学宇宙之外还有别的宇宙，它们之间没有一条边相连，全靠一扇门飞过去。空间之间还漂着几个奇观，都是实时画出来的——奇观不只是知识，具体是什么我不剧透。背书背累了，自己去别的宇宙逛一圈。

免注册免安装，浏览器打开 pharma.ac.cn 就能用。
备考的、学药的、当老师的，都欢迎来踩一脚。

⚠️ 备考工具分享，非用药指导。

#WorkBuddy #1024程序员节 #执业药师 #执业药师考试 #药学 #知识图谱 #学习工具 #备考
```
