## 二、节点视觉规范（个人成长领域语义映射）

| fill 值 | 本书语义 | 典型节点 |
|---|---|---|
| cls-structure | 章、节等结构节点 | 各章入口、各节入口 |
| cls-concept | 模型、原理、认知框架 | 八字交互系统、先天底色、恢复型资源认知 |
| cls-biomolecule | 神经/生理实体与机制 | 杏仁核-前额叶、前额叶有限算力 |
| cls-feature | 原则、方法、流程、模板、操作卡 | 管控四步、决策四问、Class0-4、熔断流程 |
| cls-adverse | 误区、陷阱、预警信号 | 六大坑、反扑信号、L1-L3 预警、红色预警 |
| cls-summary | 总纲、总览、清单类 | 总纲、管控闭环总览、差距六变量、决策表 |
| cls-mnemonic | 口诀、类比卡 | 警报响不等于着火、车型/司机、化学方程式 |

- **stroke: glow（高亮描边）= 高频核心操作卡**，全书 4 张：
  总纲、管控闭环总览（第二章第二节）、应急熔断五步（第二章第五节）、感官与任务管理系统（第三章总论）。
- **edges_out 六类边**：part_of（子→父，主干）、instance_of、subclass_of、disjoint_with（互斥，如 case1/case2）、
  equivalent_to、same_individual。reason 字段写明具体关系。
- 跨章的"内外呼应"（如环境减触发 ↔ 感官IO过滤器）不硬连边，统一写在节点正文【跨章呼应】段，
  保持本体边类型干净。

## 三、本次重构（v3）相对原书做了什么

**原则：原书 100 个节点全部保留、正文忠实迁移，不删改任何原始内容；只做结构重排、编号修正与新增。**

1. **章级重排（四章依赖链）**
   - 原《第一章 社交推理框架》整体迁移为**第四章**（69 个节点，八节编号与归属原样保留）
   - 原《第二章 感官与任务调度》第一、二、三节迁移为**第三章 任务与感官工程**（19 个节点）
   - 原第二章第四节《倦怠预警与熔断机制》11 个节点上移，并入**第二章 算力管理**第四、五节
   - 新增**第一章 认知底色**（24 节点）与**第二章 算力管理**主体（21 节点），内容来自 2026-09-19 的深度讨论
2. **熔断体系内外合流**：原书熔断偏外部行为侧（三级信号、配额、恢复时长、触发流程），
   新增内容偏内部心智侧（反扑信号、生理重置、念头接纳、应急五步）；二者在第二章第四、五节按
   "监测 → 配额 → 熔断 → 恢复"链路整合，两套执行卡互相引用、不重复合并。
3. **修正原书四处瑕疵**
   - 原第四节子节点 id 后缀误写为 p1-02-03、location 误标"第三节" → 统一修正为实际章/节坐标
   - 道⑤正文引用"第二章第三节倦怠熔断"与目录"第四节"自相矛盾 → 统一指向新第二章第五节
   - case1 中【红色预警】为悬空引用（语境是情绪失控无法自停）→ 指向第二章第五节【L3 三级临界熔断】
   - L1/L2/L3 预警、帮助判定红色预警、对话红线预警三类信号卡 fill 规范为 cls-adverse
4. **id 规则**：`前缀-英文名-p1-章号-节号`；章入口统一 ch- 前缀；迁移节点只改坐标后缀，主体名不变。
5. **目录结构**：章入口 md 置于书根；章同名目录下放章级节点（道层/总论）与各节；
   节入口 md 与节同名目录并列，子节点入节目录（与原书两级半结构一致）。

## 五、隐私与脱敏说明（公开使用前必读）

- 本书为**通用化生存策略手册**，可公开传播。全库不含任何个人八字、出生日期、生辰信息；
  命理章节仅讨论模型机制，唯一具体命例为清代史贻直与铁匠之子的公开历史典故。
- **命理示例已全部抽象化**：正文不使用任何具体干支（天干/地支）组合作为示例，
  一律以"某对地支相冲""同一组地支冲克"等抽象表述替代，避免任何示例与读者真实命局发生巧合对应。
- 全库无可定位到作者本人的独特信息：不含地域、职业考试、宠物、亲属、工作单位等个人背景；
  正文中的"你/我"均为泛指使用者，非指代作者本人。
- 引用外部观点（如第八节"杰哥三要三不要"）均已标注来源与使用警示，不构成个人隐私。
- 若进一步引用本书内容，建议保留【使用警示】【适用边界】等限制性段落，避免框架被误用。

## 六、日常使用方法

- **急症**：直接翻第二章第五节 glow 卡《应急熔断五步》。
- **日常运行**：第二章第二节《管控闭环总览》（glow）是每日操作系统；配合第四节配额与信号自检。
- **做事启动不了/怕打断/感官过载**：第三章对应三节，拿外部工具直接用。
- **社交场景**：先走第四章第七节关系分级（前置过滤 8 步），再按第六节决策表选模式 A/B，
  涉及帮忙走第二节决策四问与帮助分级；亲密关系冲突可参考第八节外部参考（注意其使用警示）。
- **想懂"为什么"**：读第一章；口诀卡（cls-mnemonic）用于快速回忆，适合贴在显眼处。
