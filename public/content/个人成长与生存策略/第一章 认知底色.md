  full: |-
    【章定位】全书认知层，回答四个问题：八字这套符号到底在描述什么、它的边界在哪、模型与世界本身是什么关系、先天的东西能不能改。
    【章脉络】
      - 第一节 命运模型的符号系统：因果链坐标 → 五行生克 → 天干地支 → 十神关系 → 四柱四环 → 出生时间与先天生理 → 称骨法速查表，先正面还原"八字在描述什么"，不辨对错
      - 第二节 命运模型的认知拆解：称骨/八字机制差异 → 四同八字 → 适用边界 → 改命逻辑 → 趋同进化佐证 → 内在矛盾与现代视角，完成认知祛魅，收口到行动信条
      - 第三节 本体与认知：动态块宇宙、网与生成树、分形自相似同构、路径积分与光的命运、困光思想实验、退相干与粗粒化、频率派与贝叶斯派 —— 一切模型都是无限全连图在某个尺度上的粗粒化骨架，宿命论的错误是把骨架当全图；本体本身也在被持续改写
      - 第四节 先天底色与后天变量：神经气质、不可根除原理、可训练能力清单、现代差距六变量、先天/后天判断标准
    【章结论】先天是倾向、不是定数；模型是骨架、不是全图；不可改的加装防火墙，可训练的直接立项。
    【承上启下】既然本能只能管控、不能根除，而管控消耗有限的生理算力，第二章进入操作层：算力管理。
