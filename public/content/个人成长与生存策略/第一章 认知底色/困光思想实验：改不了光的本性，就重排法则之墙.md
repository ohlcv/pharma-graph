full: |-
  【思想实验】假设要困住一束永远沿最快路径前进的光，你怎么办？
    - 你不能下令"光，你停下、你转弯"——那要违背光的本性，做不到
    - 你只能一层层利用物理法则本身去布置边界：每加一道墙，光的轨迹就被引导一步，但**光的本性分毫未改**
  【光的本性·严格表述·费马原理（1662）】光从 A 到 B，实际走的路径让"光程"取驻值（一阶变分为零）：
      δ∫ n·ds = 0， 其中 n 是介质折射率，ds 是路径微元
    - 严格说不是"最短时间"，而是"平稳时间"——可能是极小、极大、鞍点（光在玻璃球内反射路径上甚至取极大）
    - 是哈密顿平稳作用量原理在几何光学中的化身：把"光学长度"当 Lagrangian，做变分即得欧拉-拉格朗日光线方程
    - 与费曼路径积分互补：所有路径都走，相位一致的驻相路径相长凸显为经典光线
  【要困住一束光，必须依次跨过的五层物理法则】
    以下每一层都"利用法则、不违反法则"——这就是"墙"的真实含义：**法则本身就是墙的材料**，你只是把它按特定几何堆叠

    **第一层·反射定律（θᵢ = θᵣ）**
      - 适用条件：介质折射率不连续界面，最简单形式是平面镜
      - 光的行为：入射角等于反射角（光线方向反转、法线分量不变）
      - 边界条件：用一块反射面，光就会乖乖转 90°
      - 局限：单面镜只能转一次方向，必须多面配合才能拐弯或封闭

    **第二层·折射定律（斯涅尔定律，n₁sinθ₁ = n₂sinθ₂）**
      - 适用条件：两种折射率不同的介质之间的界面
      - 光的行为：从低折射率射向高折射率时，光线向法线偏折；反之远离法线
      - 边界条件：用棱镜（不同折射率玻璃组合）或渐变折射率介质（GRIN lens），光路被连续弯成所需曲线
      - 物理直觉：费马原理要求"驻相路径"，所以光在介质中变慢会补偿几何长度，自动找到时间最短的折中
      - 局限：折射率比有限，光偏折角度有限；不像镜面那样可以 100% 反射，部分光会透过

    **第三层·全反射（Total Internal Reflection, TIR）**
      - 适用条件：光从高折射率 n₁ 进入低折射率 n₂，入射角大于临界角 θ_c = arcsin(n₂/n₁)
      - 关键数学：当入射角大于 θ_c，斯涅尔公式给出 sinθ₂ > 1，无实数解——意味着**没有透射光、100% 反射**
      - 边界条件：纤芯 n₁ > 包层 n₂ 时，光在界面上反复全反射，光被"困"在细丝里沿光纤传播数千公里
      - 真实参数：典型光纤 n₁=1.52、n₂=1.49，临界角约 78.8°，数值孔径 NA=√(n₁²−n₂²)≈0.30
      - 隐形细节：全反射不是光真的"碰壁反弹"——界面外侧还有一层**倏逝波**（evanescent wave），沿界面平行传播几个波长后衰减回纤芯；这就是包层存在的第二个原因（容纳倏逝波，避免外物干扰）
      - 极限：弯曲半径太小时，入射角会跌破 θ_c，光瞬间漏光——光纤弯折的物理上限

    **第四层·光子禁带（Photonic Band Gap）**
      - 适用条件：周期性介质（如一维 Bragg 镜 = 多层高低折射率薄膜；或三维光子晶体）
      - 光的行为：在某些频率范围内、某些传播方向上，光的色散关系**完全无实数解**——电磁波无法在该结构中传播
      - 边界条件：周期性带来相干散射，每层反射波相干叠加产生构造性干涉→反射率 99.999% 以上（窄带）或全可见光（宽带 omnidirectional 镜）
      - 物理直觉：从波动光学看，这是**多重反射波的相干相长**；从费马原理看，这是"所有走法都被结构本身禁止"
      - 应用：法布里-珀罗腔、激光腔镜、高反膜、单光子源腔、拓扑光子绝缘体
      - 隐形细节：禁带只对特定频率、特定方向、特定偏振有效；要全频段全方向困光，需要 chirped 结构或多维光子晶体

    **第五层·几何视界（Event Horizon）**
      - 适用条件：引力场足够强，使史瓦西半径 r_s = 2GM/c² 内的逃逸速度 > c
      - 光的行为：在视界内部，所有未来类光锥都指向奇点 r=0——**没有任何方向能让光远离引力源**
      - 边界条件：质量足够大、足够集中；黑洞本身就是"墙"，因为时空本身的因果结构已经不允许光出界
      - 物理直觉：不再需要任何物质界面——**时空几何本身就是不可逃逸的边界条件**
      - 隐形细节：r_s 处不是物质密度无穷大，而是**时空曲率让所有因果未来都被截断**；光在视界外仍可绕黑洞飞行（光子球 r=1.5 r_s 处有圆轨道），但任何低于光子球的光都会螺旋落入
  【同一束光，五层墙的累加】工程上的实际困光装置往往同时用多层：
    - 单模光纤=第二层（折射率差导引）+ 第三层（全反射困束）
    - 高反镜 = 第四层（Bragg 多层禁带）
    - 激光腔 = 第四层（高反镜）+ 第二层（腔内增益介质折射率）
    - 黑洞 = 第五层（几何视界）—— 黑洞不是物质墙，是因果结构墙
  【困光的统一规律】无论哪一层，光的"本性"——沿光程平稳路径走——从未改变。墙之所以能困住光，是因为：
    (1) 每道墙都"利用法则而非违反法则"——墙本身就是法则的产物
    (2) 多层墙叠加 = 多重边界条件联合作用，让原本"开阔"的所有路径被逐层筛掉
    (3) 墙改变的不是光，而是光**能走的路径清单**——把开放路径剪成闭合路径，把可能路径剪成唯一路径
    这正好是"骨架不是全图"的物理版：墙体从全连路径中剪出主干，剩下的主干就是被观测到的轨迹
  【映射：困住本能这束光】
    - 先天本能 = 光，它的"本性"（遇触发即反应、沿最小阻力路径走）不可删除、不可被命令停止
    - 意志力硬压 = 用手去挡光，徒劳且耗能（光会绕开，手一松就恢复）
    - 真正可行 = 布置边界条件之墙：环境减触发（撤掉光源/反射面）、强制冷却规则（延时介质）、默认选项设计（让最好走的路恰好是对的路）、规则防火墙（反射壁）
    - 五层对应：反射 = 行为提示（穿衣镜）、折射 = 重新标定诱惑梯度、全反射 = 物理/规则边界（手机锁进抽屉）、禁带 = 多重规则叠加的不可越界结构、视界 = 长期身份认同（"我是不能做这种事的人"—— 因果结构级的不可越界）
    - 本能仍在走它的最快路径，但你重排了墙，它"自愿"走进你设计的轨道——这就是"只能管控、不能根除"的物理版
  【轮回的机制与打破】
    - 重复模式轮回（总栽进同一类关系、同一类冲动、同一个坑）= 同一束光在同一间从没动过的腔体里，必然走出同一条轨迹
    - 轮回不靠"想通"打破：对着光喊话不改变光路
    - 打破轮回 = 重新布置墙：换环境（移除反射镜）、改默认流程（调整腔体几何）、在触发与反应之间插入物理间隔（增加光学厚度、改变色散）。边界条件一变，同样的光立刻走出不同的路
    - 这也是为什么"想通"无效——思想相当于告诉光"请走另一条路"，但光只会沿费马原理走；除非你改变了腔体本身（环境/规则/默认/物理墙），光不会改路径
  【跨章呼应】墙的具体材料 = 第二章管控闭环第四步"环境减触发"、第二章第四/五节配额与熔断、第三章外部脚手架（把开销卸载给工具与环境，就是把墙外包出去）；长期身份认同（视界级墙）的建设见第四章社交推理框架中关于"稳定框架"与"边界即自我保护"的口诀。
  【口诀（演化版）】
    改不了光的本性，就重排墙的位置。
    反射·折射·全反射·禁带·视界——五层法则之墙，墙是法则的产物，不是法则的对立。
    突破轮回不靠喊话，靠换腔体。
