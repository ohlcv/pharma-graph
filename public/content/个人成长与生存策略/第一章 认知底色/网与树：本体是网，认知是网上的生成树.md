full: |-
  【两种结构·动态版】
    - 网（网络）：节点多对多相连、可有环、可被作者**随时添加/删除节点、改写边权重、合并或拆分节点**。代表：因陀罗网、神经网络、生态系统、社会关系、互联网、本图谱的底层全图
    - 树（生成树）：每次作者按下"提交"按钮那一刻，按当前 part_of 规则剪出来的无环骨架。**注意：生成树不是唯一的**——同一个网在不同作者、不同时刻、不同时的工作流里，可以剪出不同的生成树
  【数学关系：生成树的多样性】任意一张连通的网，都能通过保留部分边、逻辑上断开其余边，得到一棵覆盖全部节点的"生成树"。一棵网通常包含指数级别的可能生成树（Kirchhoff 定理给出计数）；树不是网的对立面，而是网在选定一套方向规则后保留下来的某个可导航骨架。
  【关键修正·作者与作品不分离】
    原版论证：物理世界允许环，可遍历的逻辑骨架必须无环。
    演化版补刀：物理世界不仅允许环，作者**还能主动剪枝、重排、改写骨架**。这就是本项目真实的工作流——
      - 程序员写新节点：等价于"在网里增加节点"
      - 程序员改 part_of：等价于"重剪生成树"
      - 程序员删除旧节点：等价于"在网里剪掉一片"
      - git 合并冲突：等价于"两棵生成树在同一个边上意见不一致，需要走协议重剪"
    STP 不只是"无环兜底"，还隐含"可重新协商边"——这才是活图谱。
  【认识论分工·双层】
    - 网承载完备性+演化能力：一切关联真实存在，弱联系、意外、黑天鹅都住在网里；作者能改写这一切
    - 树承载瞬时可导航性：每次提交后，必须有一棵可遍历的生成树，否则读图人就迷路
    - 成熟认知 = "树为此刻可见的骨、网为作者工作流的全量上下文"：知道任何一棵生成树只是无数可能之一，别把它误当成唯一正确
  【对命运的映射·动态版】人生因果是一张无限网，命理的四柱十神是在网上某个时点人为选出的一棵生成树（主干关系链）；而**人生也是一本被持续改写的书**——
    - 宿命论 = 把某一棵生成树误当成整张网和整本书，以为因果只有主干一条路、全书已写完
    - 觉醒 = 看见树之外还有网（任意两节点间还有大量没画出的弱边）+ 看见书还在改写（作者身份在自己手里）
    - 改命 = 同时意识到两条：你不是只读那一支的主干；你也能在自己的工作流里剪出新枝、重排部分章节
  【对本图谱的规定·动态版】
    - part_of 树负责"某一刻讲得清、走得通"：当下可读
    - 【跨章呼应】段负责留住"网感"：被弱联系的池子
    - git 历史负责"作者改写的全部轨迹"：以前剪过哪条枝、删过哪个节点，都在那里
    - 三者缺一不可：读图谱的人看到当前的树，读 git log 的人看到作者剪枝的全过程
