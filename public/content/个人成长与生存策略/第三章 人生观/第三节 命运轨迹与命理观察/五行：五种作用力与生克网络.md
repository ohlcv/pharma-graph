# 五行：五种作用力与生克网络

## 一、符号本义：五种动态作用态势，而非五种化学元素

在拆解传统命理模型时，最常见的望文生义是把“金、木、水、火、土”当成金属、木头、水、火焰和泥土五种具体物质。
事实上，在传统符号体系内部，五行编码的是**五种基本的作用力方向与状态特征**：

* **木（生发）**：向外舒展、生长、启动与破土的态势；
* **火（炎上）**：向上升腾、发散、显露与高热度的态势；
* **土（承载）**：居中受纳、缓冲、过渡与化育的态势；
* **金（从革）**：向内收敛、裁断、肃杀与边界规则的态势；
* **水（润下）**：向下沉潜、流动、蓄藏与寒凉的态势。

## 二、生克双环：五节点有向反馈网络

如果用现代图论的语言来翻译，五行系统实质上是一个**包含 5 个节点、10 条有向边的对称反馈图**，由“相生环”与“相克环”叠加而成：

1. **相生环（相邻递推的正反馈供给）**：`木 → 火 → 土 → 金 → 水 → 木`。前一行滋养、促发后一行。
2. **相克环（隔位制约的负反馈约束）**：`木 → 土 → 水 → 火 → 金 → 木`。隔一位施加限制与消耗，防止某一方无限制膨胀。

因此，在传统模型内部，“相克”并不天然等同于坏事，而是维持系统不失控的**负反馈调节器**——没有相生则系统缺乏动力，没有相克则单一态势过度亢进而失衡。

## 三、模型分析逻辑：看动态权重与流通，而非数个数

在八字模型的内部规则中，判断五行状态从来不是简单地数八个字里有几个金、几个木（那是外行常见的误解），而是看**以出生季节（月令）为最大权重的力量对比与生克流通路径**。这一“看非线性交互与流通”的特征，正是后文（3.2）区分八字交互模型与称骨线性加法模型的关键所在。
