# 传统命运模型的符号系统

## 一、为什么要先客观交代传统模型的内部符号？

面对一套流传已久的传统体系，如果连它的基本符号和组合规则都没搞清楚，要么容易陷入盲目崇拜，要么只能停留在笼统的表面批判。
因此，本模块（3.1）的任务是**像阅读一份古人留下的建模说明书一样，客观还原传统四柱八字体系内部的符号定义与运行语法**——同时明确：还原其内部规则，只是为了看清它是如何编码世界的，绝不等于承认其内部假设就是现代科学事实。

## 二、传统命理符号系统的五层架构表

| 符号层级 | 传统概念名称 | 体系内部定义与组合规则 | 对应下属节点 |
| :--- | :--- | :--- | :--- |
| **1. 基础作用力** | **五行（木火土金水）** | 非指五种具体化学元素，而是指五种动态态势（生发、炎上、承载、收敛、润下）及其相生（供给）、相克（制衡）构成的五节点反馈网络 | 《五行：五种作用力与生克网络》及生克口诀 |
| **2. 显隐状态编码** | **十天干 × 十二地支** | 天干表外显流动之气，地支表内藏沉淀之根（内含藏干），月支（月令）为季节权重提纲；干支相配构成六十甲子 | 《天干地支：显性与隐性两套符号》 |
| **3. 自我中心关系网** | **十神系统** | 以日干代表“我”，其余干支按与“我”的五类生克（生我、我生、克我、我克、同我）× 阴阳异同，映射为十种社会关系与心性模式 | 《十神：以我为中心的十种关系》 |
| **4. 时空四环坐标** | **年月日时四柱与大运** | 年柱（祖辈/童年）、月柱（父母/青年）、日柱（自身配偶/中年）、时柱（子女/晚年），辅以十年一步的大运滚动时间窗 | 《四柱：时间链与关系链重合的四环》 |
| **5. 出生条件假说** | **禀气说与围产期转译** | 古人假设出生时刻天地气机烙印于体质；现代视角下仅能对应出生季节与围产期环境的极弱统计相关 | 《出生时间与先天生理：禀气说与现代转译》 |
