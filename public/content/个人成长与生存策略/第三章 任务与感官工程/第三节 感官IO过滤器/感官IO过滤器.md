# 感官IO过滤器

## 【工程原理：替没有“自动丢包芯片”的大脑加装物理前置滤波器】

神经典型者的丘脑自带强悍的“感官门控（Sensory Gating）”功能，会自动把背景里的空调声、邻座说话声、衣服标签摩擦感当成垃圾数据包直接丢弃（Drop）。
而你的大脑默认开启了**“混杂抓包模式（Promiscuous Mode）”**——外界每一分贝的突发声响、每一流明的眩光都在强制触发你的前额叶中断。因此，你必须在物理信号接触感官之前，用外部硬件把它滤掉。

## 【声、光、触三通道滤波与声学工程配置表】

| 感官通道 | 主要漏电刺激源 | 外部硬件滤波方案（SOP） |
| :--- | :--- | :--- |
| **听觉（Audio I/O）** | 突发交谈人声、咀嚼声、施工/风扇低频轰鸣 | **ANC 主动降噪耳机 + 粉红噪音（Pink Noise）声学掩蔽**：ANC 负责抵消稳态低频；同时以 40–50 dB 播放每倍频程衰减 3dB 的粉红噪音或自然雨声，抬高听觉掩蔽阈值，削平突发人声的信噪比尖峰 |
| **视觉（Visual I/O）** | 惨白荧光顶灯、屏幕频闪眩光、杂乱桌面视觉噪点 | **关顶灯 + 侧后方暖白漫射照明（3500K）**；显示器降亮度并锁定深色主题（如本星图的 `#020617` 深空底色）；桌面视野内清空无关杂物 |
| **触觉（Tactile I/O）** | 刺痒领标、紧勒腰带/袖口、化纤闷汗材质 | 入库新衣第一步剪平所有硬标签；工作与居家服同款复购纯棉宽松款，消除皮肤表面持续微中断 |
| **事后散热（Cool-down）** | 被迫外出办事、参加聚会、医院/车站高密度暴露 | 回家第一步不看手机、不说话，直接进入暗光卧室平躺 **15–30 分钟**，排空感官缓冲区积压电荷 |
