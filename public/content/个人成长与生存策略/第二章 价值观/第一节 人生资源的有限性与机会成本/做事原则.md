# 做事原则

## 一、原则的形成背景：为什么取舍必须算总账？

在时间、精力、前额叶算力与物质资源全部有限的现实条件下，一个人最大的资源流失，往往不是因为不够努力，而是因为**在错误的层级上用错了取舍标准**——在不值当的小事上精打细算、死磕完美，却在真正决定长期生存质量的核心骨架上凑合将就、心存侥幸。

本节点的七条做事原则，并非道德说教，而是从长期机会成本与隐性成本核算中提炼出的**价值优先级法则**。

## 二、“要算大账，要考虑看不见的东西”：防损耗三戒

| 原则条目 | 价值判断依据（为什么这样取舍） | 隐性成本与风险敞口剖析 |
| :--- | :--- | :--- |
| **1. 不要贪小便宜** | 眼前账面收益不等于整体净收益；注意力带宽、时间完整性与信用底盘远比蝇头小利昂贵 | 为省小钱或占琐碎便宜而耗费数小时比价、扯皮或背负模糊人情债，实则是用高价值的整块主线时间去交换低劣回报 |
| **2. 不要耍小聪明** | 核心能力壁垒与复杂系统稳定性不存在“跳过地基”的投机捷径 | 靠取巧绕过底层基本功，短期看似省力，但在深层规则墙（见第一章第四节《困光思想实验》）面前必然暴露结构性脆弱，返工代价数倍于初建 |
| **3. 不要幻想** | 主观愿望不等于客观条件；把决策建立在“万一运气好”的幻想上等于主动放大风险敞口 | 在信息不足或趋势不利时靠脑补“奇迹”拖延止损，会错失调整结构的最佳窗口，侵蚀长期选择权 |

## 三、“分清主次，抓住主线”：非对称配置四律

承认资源有限，就意味着绝不能平均用力，而必须采取**极度非对称的资源配置**：

1. **核心要用最好的**
   凡是直接决定人生主线产出、长期健康底盘（如睡眠、高频生产力工具、核心专业学习）与抗风险安全垫的事项，在能力范围内配置最好的资源与最充沛的满电时段。因为在核心节点上省下的小成本，都会在下游被放大为系统性的效率折损。
2. **细枝末节不较真**
   凡是不改变主线方向、不影响核心交付质量与安全底线的次要枝节（如非核心文档的过度修饰、日常琐碎分歧、无关痛痒的外部评价），主动降低标准、快速放过。不在细枝末节上纠缠，是保护核心算力不被完美主义抽干的必要放弃。
3. **下笨功夫**
   越是核心的底层认知与硬核技能，越没有速成秘籍。放弃对“一招制胜”的浮躁搜寻，耐下心来在基础概念、真实数据与基本功上做日复一日的扎实投入，用前期看似缓慢的“笨功夫”换取后期的结构复利。
4. **实事求是**
   承认客观规律与自身当前的真实边界：知道就是知道，不知道就是不知道；能承受就是能承受，过载就是过载。一切计划与复盘都从已核实的事实出发（与本章第二节《现实主义与个人行动信条》直接咬合）。
