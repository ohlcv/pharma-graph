# case2｜对方期待落空（不是侵害）

## 一、核心辨析：为什么“他很失望”不等于“我伤害了他”？

在人际互动中，最容易瓦解个人边界的心理机制，是把**“对方的负面情绪（失望、不悦、抱怨）”**直接当成了**“我做错了事 / 我伤害了对方”**的证据。

**`case2｜对方期待落空（不是侵害）`** 从价值与责任逻辑上拆开了这一错误等号：
* 当一个人未经你同意，单方面在脑海里把你的时间、注意力、技能或金钱提前写进他的计划表时，这张“预期支票”是他自己签发的，而不是你欠他的债务；
* 当你因为看护自身主线或精力不足而拒绝兑现这张单方支票时，他的“账面预期”确实落空了，但**他原本合法拥有的存量权益没有受到一丝一毫的减损**。

因此，**未给予对方未经约定的免费增量（`case2`），绝不等于夺走对方的既有存量（`case1`）。**

## 二、常见 case2 场景的价值重校准

| 常见人际场景 | 容易产生的内疚误判 | 基于 case2 的客观责任校准 |
| :--- | :--- | :--- |
| **拒绝长时间充当单向情绪垃圾桶** | “我现在结束对话去休息，他今晚难受是不是我的错？” | 每个成年人是自身情绪的第一责任人；温和告知自身精力上限以保证睡眠，不侵害对方任何既有权益 |
| **拒绝替熟人包办耗时的个人事务** | “我明明懂这个领域却不帮他做完，是不是太冷漠？” | 你的专业能力是你长期投入下笨功夫积累的核心资产，不是任何人可以免费征用的公共品 |
| **过去曾主动帮过忙，此次拒绝继续包办** | “以前都帮了，这次拒绝是不是不够朋友？” | 过去的单次善意是馈赠而非终身契约；每一次新请求都独立适用边界判断 |

## 三、面对期待落空后的价值定力

一旦按规则核实当前情境属于 `case2`，在价值观上就应当做到**“态度温和，内心零负罪感”**：
* 如果对方虽感失落但能尊重你的决定，说明双方边界健康；
* 如果对方因为单方期待落空而开始对你进行道德绑架、指责谩骂或散布恶言，则意味着对方正在试图通过情绪施压越界，此时更不应退让（具体关系降级与应对流程见第五章第四节）。
