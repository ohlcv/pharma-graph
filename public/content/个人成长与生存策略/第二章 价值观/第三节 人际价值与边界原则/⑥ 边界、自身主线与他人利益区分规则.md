# ⑥ 边界、自身主线与他人利益区分规则

## 一、核心问题：拒绝他人时，“他不开心”究竟是不是“我害了他”？

在践行《① 你的人生主线优先级最高》与《② 真诚，但绝不自我献祭》时，最具迷惑性的道德困境是：**当我为了保护自己的主线而拒绝某个请求时，对方表现出了明显的失望、不满甚至指责——这是否意味着我的边界侵害了他的利益？**

如果不把“利益侵害”与“期待落空”从概念根基上切开，任何有道德感的人都会在对方的负面情绪面前败下阵来。因此，本规则通过下属的 **`case1｜真正侵害他人利益`**、**`case2｜对方期待落空（不是侵害）`** 以及 **《平衡原则》**，建立一套客观的责任分界线。

## 二、存量与增量的分界：侵害 vs 期待落空

判断一项行为是否构成对他人利益的侵害，基准线不在于“对方主观上高不高兴”，而在于**“对方的既有合法存量权益是否因为你的主动行为而受损”**：

```text
[准备设立边界 / 拒绝请求 / 收缩投入]
        │
        ▼
  1. 是否主动实施了欺诈、侵占财物、造谣中伤或恶意毁约？
        ├─ 是 ──► 【case1｜真正侵害他人利益】（使他人合法存量受损，绝对禁止）
        └─ 否
           │
           ▼
  2. 此前是否已明确作出承诺、签署约定或收受对方对价？
        ├─ 是 ──► 【平衡原则·履约义务】（须按约完成，或提前坦诚协商变更/退还对价）
        └─ 否
           │
           ▼
  3. 对方的不满是否仅因“单方面预设你会免费付出，而你未提供该增量”？
        └─ 是 ──► 【case2｜对方期待落空（不是侵害）】（对方既有存量毫发无损，属正当边界）
```

## 三、本规则在全书中的双重职责

* **在第二章《价值观》中的职责**：厘清是非与责任归属，让你在严守“不害人、重契约”底线的前提下，彻底卸下因拒绝无理索取而产生的虚假道德负罪感。
* **在第五章《方法论》中的职责**：作为《第四节 社交推理与关系管理系统》中“社交判断的输入与底层约束”，直接为后续的《决策四问》与拒绝执行提供前置判据。
