# 平衡原则

## 一、为什么需要“平衡原则”？

在建立人际边界的过程中，如果只讲“守住底线、不亏欠别人”，容易滑回不敢拒绝的老好人状态；如果只讲“我的人生主线优先、随时可以拒绝”，又容易误把“已经答应别人的承诺”也当成随时可以丢弃的包袱，从而损害个人信誉。

**《平衡原则》**的作用，就是在**“重诺守信的契约责任”**与**“拒绝无理索取的自主边界”**之间，建立一套权责对等、先后有序的平衡准则。

## 二、三层优先级结构与适用条件

| 优先级 | 核心准则 | 适用条件与边界说明 |
| :--- | :--- | :--- |
| **第一层：不主动侵害（底线）** | 绝不主动损害他人既有合法权益（严禁 `case1`） | 适用于一切人际关系与任何情绪状态；哪怕面对他人的不当对待，也只做止损隔离，不做违规暗算 |
| **第二层：有约必履（契约）** | 已明确承诺或收受对价之事，必须履约或提前协商 | 适用于已亲口答应、已签协议或已接受对等交换的事项；若因不可抗力或严重过载无法按原计划完成，必须第一时间坦诚沟通改期或退还对价，严禁不告而别 |
| **第三层：无约可拒（边界）** | 未事先约定的无偿请求，完全自主决定去留（`case2`） | 适用于一切临时加塞、未承诺过的求助与情感消耗；既往的单次善意不构成永久义务 |

## 三、源头减负：要想少背履约债，关键在于“慎诺”

《平衡原则》揭示了一个至关重要的现实推论：
**既然一旦开口承诺（进入第二层），就必须耗费资源去履约；那么保护自身主线最有效的防线，就在于“在第三层尚未承诺时把好关”**——在没有核算清楚自身算力余量与隐性成本之前，绝不因为抹不开面子而随口许诺（具体承诺前的四步核查流程，详见《第五章 · 第四节 社交推理与关系管理系统》中的《决策四问》）。
