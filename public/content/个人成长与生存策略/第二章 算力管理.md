# 第二章 算力管理

## 【为什么“管电”是一切生存策略的命门】

第一章已经确立了一条冷酷的生理事实：你的先天高敏感底色（杏仁核低阈值唤醒）无法被物理删除，只能靠前额叶皮层（PFC）建立新回路去抑制和引导。但前额叶是一个**高能耗、低续航、极易受睡眠与血糖波动影响**的硬件模块。

每当你在纠结中反复拉扯、在琐事上强行克制、在多任务间频繁切换，或者在社交摩擦里试图自证清白时，你都在剧烈燃烧同一个前额叶算力池。一旦电量跌破临界线，前额叶就会强制下线，控制权瞬间交还给杏仁核与旧神经回路——这时你会体验到莫名的心慌、思维死循环、全面自我否定，甚至做出冲动毁约或情绪决堤的举动。

因此，神经多样性生存的核心不是“磨炼更强的意志力”，而是**把意志力当作极度稀缺的电力来精打细算**。

## 【本章六节的工程化闭环】

本章按照电源管理系统的标准架构，将原本分散的“内部心智调节”与“外部倦怠防护”彻底合流为一套严密的六步闭环：

| 环节 | 对应章节 | 核心目标与关键操作卡 |
| :--- | :--- | :--- |
| **0. 预算总纲** | 《做事原则》 | 确立算力分配最高法则：核心要最好，次要细节不较真；不贪小便宜、不耍小聪明、不要幻想，把极品算力留给主线。 |
| **1. 识漏记账** | 第一节 算力账本 | 认清前额叶算力的生理上限，锁死头号漏电黑洞——**持续的内心冲突与自我批判**，先砍内耗再谈开源。 |
| **2. 常态节流** | 第二节 常态管控闭环 | 日常运行 **★《管控闭环总览》**：遇触发先打标签（“警报响不等于着火”）→ 重大决定强制冷却 24–72h → 套用三问客观框架 → 改造物理环境减少触发。 |
| **3. 日常充电** | 第三节 算力维护 | 树立“恢复型资源观”：靠睡眠地基、日常琐事自动化、平稳血糖与微运动、定时停机留白来维持基线，每次只改一个习惯。 |
| **4. 负载预警** | 第四节 负载监测与配额 | 将外显指标（躯体紧绷/专注下降/情绪易怒）与内源指标（思绪循环/脑补最坏结局）合流为 **L1（早期）→ L2（过载）→ L3（临界）** 三级预警，并设定高消耗事件配额。 |
| **5. 过载熔断** | 第五节 熔断与恢复 | 一旦出现反扑信号或达到 L3，立即放弃任何“分析与硬扛”，无脑执行 **★《应急熔断五步》** 与《分级恢复协议》（L1 休 30 分钟 / L2 休半天 / L3 静默 1–3 天）。 |
| **6. 事后调优** | 第六节 复盘迭代 | 严禁在过载期复盘！待电量完全恢复后，用《复盘四问》像排查服务器故障一样修正触发阈值与环境护栏。 |
