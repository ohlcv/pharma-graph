# 复盘四问

## 【四格无责故障排查表（Blameless Postmortem Form）】

每次从过载或人际摩擦中完全恢复后，花 10 分钟填写下表，产出一行具体的**系统参数补丁**，随后立即翻篇：

| 排查序号 | 工程排查问题 | 填写示范（只写参数，不写道德自责） |
| :--- | :--- | :--- |
| **一问触发场景** | 具体是什么外部输入击穿了防线？ | `周三晚 21:00 在嘈杂餐厅被 Class 1 熟人连续追问个人规划` |
| **二问储备状态** | 事发前底层生理算力处于什么水位？ | `前晚仅睡 5.5 小时 + 连续工作 8 小时未冷却，进场前已处 L2 边缘` |
| **三问机制得失** | 哪步做对了？哪个环节漏防了？ | `做对：未当场发火；漏防：在 L2 低电量下违背决策表，未及时用模式 A 刹车离场` |
| **四问参数调整** | 下次往系统里打入哪条硬补丁？ | `新增补丁：凡睡眠 <6.5h 当日，晚间一律拒接任何非 Class 4 聚餐邀约` |
