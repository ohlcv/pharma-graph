# 第五章 方法论

## 【核心问题：在有限算力和不确定现实中，如何持续行动、管理风险并改善结果？】

前四章依次回答了世界如何运行（世界观）、什么值得追求（价值观）、我处于什么位置（人生观）以及如何审视知识的可靠性（认识论）。第五章的任务，是把这些认知与价值判断转化为一套**日常可调用、过载可兜底、事后可迭代的个人行动系统**。

本章不是零散技巧的堆砌，而是由四个紧密咬合的子系统组成的工程体系：

## 【四大行动子系统架构与分工】

| 子系统 | 对应小节 | 解决的核心实操问题 |
| :--- | :--- | :--- |
| **1. 知识发现系统** | **第一节 知识发现与问题求解：从诗云到黑暗森林** | **当不知道答案在哪时怎么找？** 以“答案已经存在”为搜索工作公理，结合人机协作、自下而上组件搜索与自上而下原理搜索，从庞大知识空间中提炼可验证的候选方案。 |
| **2. 内核资源调度系统** | **第二节 个人算力管理系统** | **有限的认知精力怎么省、怎么充、过载了怎么救？** 建立算力账本、四步常态管控闭环、五法日常维护、L1–L3 负载预警与配额，以及过载时的五步应急熔断、分级恢复与无责复盘。 |
| **3. 外部对事脚手架** | **第三节 任务执行与感官环境工程** | **任务启动难、怕打断、感官易过载怎么破？** 用最小启动原则、硬指令清单与固定启动脚本破除冷启动阻力；用时段隔离、中断快照与消息批处理保护上下文；用声光触 I/O 过滤器与系统冷却降低环境损耗。 |
| **4. 外部对人路由系统** | **第四节 社交推理与关系管理系统** | **如何在人际互动中护住主线不被抽干？** 严格按实际调用流运行：`4.1 判断输入与底线约束 → 4.2 人际关系分级（Class 0–4）前置过滤 → 4.3 决策判断表与切换规则路由 → 4.4 模式 A 轻量模板 / 4.5 模式 B 深度推理与帮助四问 → 4.6 外部参考、风险拦截与事后冷却`。 |
