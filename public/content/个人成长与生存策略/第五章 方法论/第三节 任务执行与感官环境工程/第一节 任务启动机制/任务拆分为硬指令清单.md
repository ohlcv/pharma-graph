# 任务拆分为硬指令清单

## 【软指令 vs 硬指令编译对照表】

为什么你的待办清单（To-Do List）常常写满了却一动不想动？因为你写下的是未经编译的“高级抽象愿景”，每次看一眼都要耗费大量前额叶算力去实时编译。
任何任务进入执行队列前，必须先按以下标准编译为**无需动脑即可机械执行的“硬指令（Hard Instructions）”**：

| ❌ 阻塞启动的“软指令”（禁写） | ✅ 零阻力直出的“硬指令”（标准格式） |
| :--- | :--- |
| `复习执业药师药二` | `打开《药二·镇静催眠药》目录，朗读并核对地西泮、佐匹克隆 2 张卡片` |
| `优化图谱前端性能` | `运行 profile 脚本，记录 euler 布局前 100 帧耗时到便签` |
| `重构个人生存策略书` | `打开第一章 6 个缺失 summary.full 的 md 文件，补齐 3 条要点` |
| `准备周末出行` | `打开备忘录打包清单，将身份证、充电器、降噪耳机装入双肩包` |
