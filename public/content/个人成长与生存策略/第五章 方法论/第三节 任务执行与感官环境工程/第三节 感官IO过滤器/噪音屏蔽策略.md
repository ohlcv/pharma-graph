# 噪音屏蔽策略

## 【声学工程方案：为什么只戴降噪耳机还不够，必须叠“粉红噪音”？】

主动降噪耳机（ANC）擅长通过反向声波抵消空调、飞机引擎等**低频稳态噪音**，但对人类语言频段（300–3000 Hz）的**突发瞬态声音（如旁边突然有人说话、笑声、关门声）**几乎无法完全消除；而在绝对安静的背景下，突然漏进来的一句人声反而具有极高的信噪比（SNR），会瞬间抓走你的注意力。

## 【三级声学护栏标准配置】

1. **第一级：ANC 主动降噪打底**——消除环境中的低频嗡鸣，降低听觉皮层底噪负载。
2. **第二级：粉红噪音（Pink Noise）或自然雨声掩蔽**——白噪音在高频段过于尖锐刺耳（听久易累），而**粉红噪音（功率谱密度与频率成反比 $1/f$，每倍频程衰减 3 dB）**贴合人耳等响曲线。以 40–45 dB 铺底播放，就像给耳朵盖上一层柔和的声学毛毯，能把外部突发人声的信噪比尖峰彻底抹平。
3. **第三级：时段与物理错峰**——把必须与人沟通的杂事集中压在午后環境嘈杂期，把清晨与深夜的零噪音黄金窗 100% 留给核心主线。
