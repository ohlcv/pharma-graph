# 感官过载识别

## 【核心认知：很多时候你以为的“发脾气/厌世”，其实只是“感官吃撑了”】

神经多样性者常常把**纯粹的物理感官过载（Sensory Overload）**误判为情绪或人际问题——比如在灯火通明、人声鼎沸的商场或饭局待了两个小时后，突然看伴侣或朋友哪儿都不顺眼，想原地爆炸。
其实那一刻你根本不是对人有意见，而是你的视觉、听觉与触觉通道已经塞满了未处理的原始信号，前额叶被彻底挤爆了。

## 【四通道过载自检与一秒急救表】

| 过载通道 | 早期报警体感 | 现场 10 秒急救动作 |
| :--- | :--- | :--- |
| **视觉通道** | 眼眶发酸、觉得灯光白得刺眼、看屏幕字迹发飘 | 调低屏幕亮度至 40%、戴遮阳帽/防蓝光镜，或借故去洗手间闭眼 3 分钟 |
| **听觉通道** | 多人同时说话时脑子嗡嗡响、对高频餐具声/笑声产生生理性愤怒 | 立刻戴上入耳式降噪耳塞/耳机，或离席走到室外安静走廊透气 |
| **触觉通道** | 突然觉得衣服领口勒脖子、袜子缝线硌脚、周围人靠得太近令人窒息 | 解开领扣/换宽松衣物，拉开与他人 1 米以上的物理社交距离 |
| **语言与认知** | 别人问话需要反应 3 秒才能听懂、不想开口说任何一个字 | 立即停止硬撑聊天，发出标准口令：`“我有点头晕，先去安静处坐会儿”` |
