# 第二步·强制冷却规则

## 【核心逻辑：用“时间物理隔离”熬死杏仁核洪峰】

你的本能最擅长制造一种虚假的紧迫感：**“我现在必须立刻想通！我必须马上回这条消息把话说清楚！我现在就要决定退不退出！”**
一旦你顺从了这种紧迫感，你就等于在血液皮质醇浓度最高、前额叶抑制力最低的时刻签下了合同。

## 【分级冷却时长与封存指令】

| 事项量级 | 强制冷却时长 | 冷却期操作纪律 |
| :--- | :--- | :--- |
| **日常琐事**（吃什么/买日用品） | **0 分钟（10 秒直觉拍板）** | 严禁在鸡毛蒜皮上调用深度分析框架，直接按默认习惯过 |
| **中度摩擦**（想发长文争辩/想买非刚需大件） | **24 小时（睡醒一觉再看）** | 把写好的草稿存进备忘录，设 24 小时后提醒；次日重看时 80% 会直接删掉 |
| **重大决策**（辞职/绝交/重大合作/大额投资） | **48 ～ 72 小时（睡醒两到三觉）** | 冷却期内只允许用《中断快照》记录客观事实，严禁向外界发出任何终局表态 |
