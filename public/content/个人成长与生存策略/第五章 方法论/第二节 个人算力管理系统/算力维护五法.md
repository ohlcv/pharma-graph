# 算力维护五法

## 【前额叶硬件保养 SOP】

如果把前额叶比作高精密光刻机，那么《算力维护五法》就是它的恒温、恒湿、稳压电源保障系统：

| 维护维度 | 生理机制依据 | 每日可执行硬标准 |
| :--- | :--- | :--- |
| **1. 睡眠地基** | 慢波睡眠期胶质淋巴系统清理代谢毒素，修复前额叶-杏仁核连接 | 把睡眠当作不可侵占的 P0 级主线任务；只要昨晚没睡好，今日自动下调 40% 算力预算 |
| **2. 琐事自动化** | 每次“选哪个”的微决策都会同等消耗前额叶令牌（Token） | 早晨起床动作、常备餐饮清单、工作台布局 100% 标准化固定 |
| **3. 血糖稳压** | 神经元无糖原储备，低血糖或胰岛素骤升骤降会直接导致前额叶掉线 | 攻坚期常备坚果/鸡蛋等慢碳蛋白补给，严禁空腹喝浓咖啡硬顶 |
| **4. 主动停机窗口** | 连续高专注会导致突触间隙腺苷堆积，强制休息可防跌入 L2 过载 | 计时器每满 50 分钟，强制闭眼或起身接水 5 分钟（期间禁刷手机） |
| **5. 单习惯串行训练** | 建立一条新神经回路需要持续消耗额外算力，多线并改必致全线溃败 | 每个月只挑 **1 个** 最小习惯固化，旧习惯完全成自然后再开下一个 |
