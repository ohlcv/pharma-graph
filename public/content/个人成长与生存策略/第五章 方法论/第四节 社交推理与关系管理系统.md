# 第四节 社交推理与关系管理系统

## 一、系统定位：原则在第二章定好，流程在本节跑通

在人际互动中，个体之所以容易耗尽算力，往往是因为缺少一套清晰的**前端过滤与分流机制**——无论面对谁、无论对方抛出什么话题，大脑都默认启动全功率深度推演，并在事后陷入漫长的反刍。

按照全书“价值判断与操作方法分离”的架构原则：
* **“为什么人生主线优先、为什么真诚不等于自我献祭、为什么对方期待落空（`case2`）不等于侵害他人利益（`case1`）”**的价值论证，已经在 **《第二章 价值观 · 第三节 人际价值与边界原则》** 中完整确立；
* 本节（第五章第四节）不再重复价值说理，而是把第二章的原则作为输入约束， strictly 按照**实际处理一次人际事件的先后调用顺序（4.1 → 4.6）**，组装成一套低功耗、可检索、有熔断的社交推理操作系统。

## 二、社交推理六步调用流水线（4.1 → 4.6）

```text
[收到外部人际输入 / 求助请求 / 沟通议题]
        │
        ▼
【4.1 社交判断的输入与底层约束】
  核对第二章底线：是否触及主线安全？是否已诺需履约（平衡原则）？属 case1 侵害还是 case2 期待落空？
        │
        ▼
【4.2 人际关系分级与策略适配（Class 0 ～ Class 4）】
  按客观共同经历与互惠记录定级（Class0 弱连接 / Class1 普通熟人 / Class2 挚友 / Class3 父母直系 / Class4 亲密伴侣）
  ※ 重要声明：关系分级仅用于确定互动策略与算力配额，绝不代表对他人高低贵贱的价值审判
        │
        ▼
【4.3 模式选择与切换路由】
  对照《模式选择决策判断表》四条件（核心利益？环境允许？精力在线？需预判冲突？）
        ├─ 任一为“否”（默认 90% 日常场景） ──► 【4.4 模式 A：轻量化快速调用】
        │                                        调用《闲聊 / 共情 / 委婉拒绝模板》+《模式A强制刹车规则》
        └─ 四项全“是”（仅极少数关键场景） ──► 【4.5 模式 B：高精度深度推理与帮助判定】
                                                 ├─ 一般重要沟通：按《模式B推理步骤》限时推演
                                                 └─ 他人求助判定：过《红色预警信号》→ 过《决策四问 Q1–Q4》
                                                                 → 匹配《帮助三级 L1 共情 / L2 指引 / L3 实操》
        │
        ▼
【4.6 外部参考、风险拦截与事后冷却】
  • 事中防拉扯：调用外部参考《杰哥三要三不要原则》（含使用警示、场景 1–3 自证拦截与红线预警）
  • 事后防反刍：执行《社交后冷却机制》+《限制复盘时长（≤15min）》，拦截《伪装过载 / 完美主义 / 自动越界分析陷阱》
```
