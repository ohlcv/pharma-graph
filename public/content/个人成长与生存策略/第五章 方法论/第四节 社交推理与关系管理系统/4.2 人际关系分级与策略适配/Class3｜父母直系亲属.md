# Class3｜父母直系亲属

## 【核心策略定位：为什么对父母不能照搬 Class 1 的刚性防御？】

在人际关系分级中，**Class 3（父母、直系亲属）**是最特殊的一档：你既不能像对待 Class 0/1 那样轻易断联降级，又极易因为代际观念鸿沟、暗示性抱怨与“孝顺”道德压力而瞬间烧光算力。
因此，Class 3 的工程策略不是“筑高墙正面对抗”，而是**“外层铺设柔性减震垫（模式 A 顺毛），内层焊死配额与主线钢板”**。

## 【Class 3 四大高频消耗场景与标准应答 SOP】

| 高频触发场景 | 错误反应（高损耗踩坑） | 标准工程响应（低功耗 SOP） |
| :--- | :--- | :--- |
| **长篇抱怨但无具体诉求** | 启动模式 B 认真帮父母分析利弊，结果反被指责“不体谅他们” | **纯模式 A 共情模板**：只顺着情绪说“确实不容易，您多注意休息”，绝不帮出主意，满 15 分钟借故挂电话 |
| **暗示式施压**（“你看邻居家谁谁都……”） | 自动接茬自证、争辩两代人环境不同，引发大吵 | **装傻丢包策略**：只回表面字义（“那他确实挺厉害的”），绝不把话题往自己身上引 |
| **要求包办复杂事务（L3 陷阱）** | 怕父母嫌烦大包大揽，事后出一点小问题被埋怨半年 | **降级为 L2 + 丑话说前头**：提供筛选好的 2 个选项让父母自己拍板，并提前声明客观风险 |
| **道德绑架**（“白养你了/这点事都指望不上”） | 陷入内疚献祭，或暴怒掀桌对骂 | **卖惨哭穷挡箭牌**：不顶嘴，直接陈述自身客观极限（“我最近项目/备考压力极大，实在腾不出手”） |
