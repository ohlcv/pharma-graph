# 决策四问

## 【核心机制：防止“好心办坏事、惹一身腥”的四道串联保险丝】

高算力、具备强专业能力的人，在人际交往中极易成为别人眼里的“免费外包工具人”——从帮亲戚修电脑、配药咨询，到帮同事改方案、帮朋友做人生决定。
为了彻底杜绝“耗尽自己的算力帮了忙，最后还因为一点小瑕疵被对方埋怨”的悲剧，凡涉及需要你付出实质算力的求助，必须严格串联通过以下 **Q1–Q4 决策四问**：

## 【Q1–Q4 串联校验与降级输出矩阵】

| 校验维度 | 自检核心问题 | 判定为 `No` 时的特征信号 | 判定为 `No` 时的标准降级动作 |
| :--- | :--- | :--- | :--- |
| **Q1 动机校验** | 我是发自内心愿意且毫无怨言地想帮这一下吗？ | 心里叹气、觉得是个负担、只是因为“抹不开面子”或怕对方生气 | **一票否决**：直接调用《委婉拒绝模板》，绝不带着委屈硬帮 |
| **Q2 代价校验** | 投入的时间、精力与风险，是否完全在我的闲置配额内？ | 当前正处备考/项目攻坚期，或自己已处于 L1/L2 疲劳状态 | **一票否决或限死 L1**：`“最近手头实在太紧，只能精神上支持你，没法上手帮啦”` |
| **Q3 主动性校验** | 对方在找我之前，是否已经自己查过基础资料、尽了本分努力？ | 连百度/说明书都没看，直接甩来一句“你帮我弄一下/你直接告诉我买哪个” | **降级为 L2 指路**：只扔一个公开链接或关键词，让对方自己去读，绝不代劳 |
| **Q4 责任边界校验** | 辅助边界是否清晰？万一结果不理想，对方会自己担责而不赖我吗？ | 对方习惯把决定权推给你（“我都听你的，你说行就行”），隐含出事找你背锅的倾向 | **锁死免责声明或拒接 L3**：仅提供客观利弊清单，明确声明“最终得你自己拍板，我不替你做决定” |
