# 场景3｜双方情绪平稳，共同商量安排

## 【场景定位：如何把握真正值得投入模式 B 算力的协商窗口】

在《自证｜说服触发判定规则》的三个分支中：
* **场景 1（对方指控你的动机、人品、态度）** → 严禁自证，直接退出；
* **场景 2（对方单纯询问客观事实，无指责）** → 一句话给干货事实，不加戏；
* **场景 3（双方情绪平稳，共同商量具体安排）** → **这是唯一允许你开启模式 B 进行建设性沟通的绿灯窗口。**

## 【场景 3 标准三段式沟通模板】

1. **第一句：亮明硬边界（对应《三要②建立自身稳定框架》）**
   先把你的不可让步条件（时间、精力、预算上限）作为客观物理约束摆在桌面上：
   * `“这件事我的底线是 X（例如：周日我必须留出半天独处恢复算力），在这个前提下我们看怎么排最顺。”`
2. **第二句：抛出具体选项（对应《三要③清晰给出预期》）**
   不让对方猜，直接给可执行路径：
   * `“我初步想了两个方案：要么我们周六上午集中弄完（方案 A），要么拆成下周二、四晚上各一小时（方案 B），你倾向哪个？”`
3. **第三句：开放微调并设超时保护**
   * 若对方提出合理修改 → 只要不击穿第一句的硬底线，痛快采纳；
   * **熔断监控**：若商量过程中对方突然变脸翻旧账（滑向场景 1），或连续来回拉扯超过 3 轮仍无进展 → 立即停止协商，切换《红线预警》挂起对话。
