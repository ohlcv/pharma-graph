# 第四章 社交推理框架

## 【核心痛点：为什么社交会瞬间抽干你的算力】

神经多样性大脑在社交中最致命的默认习惯，是**“无论面对谁、无论什么话题，一律默认开启全功率深度推理模式（模式 B）”**：
别人随口一句客套或抱怨，你的大脑会自动调动全部算力去推演对方的潜台词、心理动机与未来十步风险；对方一旦露出失望或指责，你立刻陷入“我是不是做错了 / 我必须解释清楚让他理解我”的自证死循环。

第四章的核心工程改造，就是在你与外界人际输入之间，加装一套**“前置分级过滤 + A/B 双模路由流水线”**——把 90% 的浅层社交降维成零算力消耗的模板调用，把深度推理与情绪带宽严格保留给极少数通过校验的核心关系与关键议题。

## 【社交推理标准四步执行流水线】

> **阅读与调用提示**：本章各节保留了历史编号（第一至八节），但在实际应对任何社交事件时，请严格按照以下 **Step 0 → Step 4** 的真实流水线顺序调用：

```text
[收到外部社交输入 / 请求 / 冲突]
       │
       ▼
【Step 0 顶层公理校验】《社交体系底层之道》（①主线优先 ②真诚不献祭 ③不主动博弈 ④放弃求理解 ⑤边界即自保）
       │  └─ 若触发拒绝内疚 → 调《⑥ case1 真正侵害 vs case2 期待落空》校验阀
       ▼
【Step 1 关系分级前置过滤】《第七节 人际关系分级与策略适配》（Class 0 弱连接 ～ Class 4 亲密伴侣）
       │  └─ 锁定该对象允许的最大算力配额、边界硬度与默认模式
       ▼
【Step 2 模式路由分流】《第六节 模式选择决策判断表》 & 《第三节 切换规则》
       │  ├─ Q: 关乎核心利益？环境充足？当前精力在线？需预判冲突？
       │  ├─ 任一为“否”（默认 90% 场景） ──► 进入【Step 3A 轻量化快速调用模式（第一节 模式 A）】
       │  │                                    └─ 调取《闲聊/共情/委婉拒绝模板》，超时触发《强制刹车规则》
       │  └─ 四项全“是”（手动开启）      ──► 进入【Step 3B 高精度深度推理模式（第二节 模式 B）】
       │                                       ├─ 涉及帮忙请求 → 过《决策四问 Q1–Q4》+《红色预警一票否决》
       │                                       ├─ 通过后定级输出 → 《帮助三级 L1 共情 / L2 信息指引 / L3 实操》
       │                                       └─ 涉及指控/拉扯 → 调《第八节 场景 1–3 判定》与《红线预警刹车》
       ▼
【Step 4 事后冷却与防反刍】《第四节 外部辅助工具》 & 《第五节 高频踩坑预警》
       └─ 执行《社交后冷却机制》+《限制复盘时长（≤15min）》，拦截“伪装过载 / 完美主义 / 自动越界分析”
```
