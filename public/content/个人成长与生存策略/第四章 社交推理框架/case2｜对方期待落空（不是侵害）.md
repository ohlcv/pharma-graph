# case2｜对方期待落空（不是侵害）

## 【核心定性：对方的“失望”不等于你的“加害”】

高敏感大脑在拒绝别人时最容易触发的认知错觉，是把**“我拒绝了他 → 他很不开心/很失望”**自动等价于**“我伤害了他”**。
本节点是专门为你解除这种虚假负罪感的逻辑校验卡：**当对方未经你同意，单方面在脑海里把你的时间、算力和金钱划入他的预期账户时，你拒绝兑现这张空头支票，只是让他回到了原本的零点，绝没有侵害他分毫。**

## 【典型 case2 场景与去内疚对照表】

| 高频触发场景 | 你脑内易冒出的内疚误判 | 客观事实重校准（SOP 定性） |
| :--- | :--- | :--- |
| 拒绝陪对方熬夜倾诉/随时秒回消息 | “我不陪他，他今晚情绪崩溃是不是我害的？” | 你不是对方的 24 小时急诊心理医生；守住睡眠地基是主线刚需 |
| 拒绝帮熟人无偿处理耗时极长的麻烦事 | “这点忙都不帮，是不是显得我太冷血？” | 你从未承诺包办其个人事务；提供 L2 公开信息指引已尽仁义 |
| 过去帮过三次，第四次拒绝继续免费兜底 | “以前都帮了，现在不帮是不是背信弃义？” | 既往的善意馈赠是单次事实，绝不自动生成终生无偿服务的卖身契 |

## 【后续响应联动规则】

* **正常反应**：对方虽略显失落但表示理解 → 维持原关系等级。
* **越界升级反应**：对方因期待落空而开始道德绑架（“你变了 / 你怎么这么自私”）或情绪勒索 → 对方已触发《红色预警信号》，立即中止解释，按第七节《动态调整规则》下调其关系等级。
