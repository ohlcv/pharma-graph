  full: |
    【定义】对方对你有**预期**（无偿付出、兜底、牺牲时间、无限陪伴等），你**不满足这个预期**——对方失望，但**他的固有权益没有被你损害**。

    【典型场景】
      - 对方预设你会无条件陪他聊到半夜 → 你说"我需要先睡" → 对方失望
      - 对方预设你会帮他做某件麻烦事 → 你说"这件事我帮不了" → 对方失望
      - 对方预设你会借钱/借车/借资源 → 你拒绝 → 对方失望
      - 对方预设你能保持某个时间段的回应 → 你未做到 → 对方失望
      - 对方预设你们关系是"永远的谁照顾谁" → 你开始要求对等 → 对方失望
      - 对方预设你情绪稳定 → 你表达了不满 → 对方失望

    【共同特征】
      - **对方有未明确表达的预期**（"我以为你会......"）
      - **你没有承诺过**满足这个预期
      - **对方没有付出对应代价**（对方未付费、未互惠、未签订任何契约）
      - 你只是**没有给出额外资源**，**没有主动施加伤害**

    【这不是侵害】
      - 对方"预设你会" ≠ "你承诺过会"
      - 对方失望 ≠ 你造成了损失
      - 对方的"期待"不是"固有权益"
      - 你有权拒绝任何**未明确承诺的请求**

    【常见误判】
      - "我拒绝帮他，他可能会很痛苦，我是不是在伤害他？" → 不是，他的痛苦源于他自己的预设，不是你的行为
      - "如果我拒绝，他以后不跟我做朋友了，是不是我害的？" → 不是，他主动结束关系是他自己的选择
      - "我拒绝他显得我很冷漠，我是不是太无情了？" → 不是冷漠，是合理边界
      - "他以前帮过我，我现在不帮他，显得我不讲义气？" → 过去的帮助不是"现在必须回馈的义务"

    【执行规则】
      - 任何时候拒绝/设立边界后对方失望 → **正常反应，无需内疚**
      - 不必为对方的失望负责（除非你的拒绝本身构成了 case1）
      - 如果对方的反应升级（PUA、道德绑架、散布谣言）→ 那是对方在做 case1，不是你的责任
      - 如果对方持续失望 → 这正是【关系分级→动态调整规则】评估降级的信号

    【与"道"的关系】
      - 符合【道之①主线优先】——你没有牺牲主线
      - 符合【道之②真诚但不献祭】——你表达了真实边界
      - 符合【道之⑤边界即自保】——边界即停止额外付出
