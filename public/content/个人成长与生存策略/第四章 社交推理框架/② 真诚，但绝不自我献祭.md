# ② 真诚，但绝不自我献祭

## 【核心解绑：为什么“温和地拒绝”才是最高级的真诚？】

高敏感者往往有强烈的道德洁癖，认为既然要对人“真诚”，就应该有求必应、倾尽所有；一旦拒绝别人，就会觉得自己虚伪或亏欠。
这其实把**“态度上的真诚（Sincerity）”**与**“资源上的无底线献祭（Self-Sacrifice）”**混为一谈了。

真正的真诚，恰恰要求你**对自己的电量和边界诚实**：当你只有 10% 的电量时，坦诚温和地告诉对方“我今天确实没精力帮你看这个”，这叫**真真诚**；明明累得要命却强颜欢笑说“没问题包在我身上”，一边做一边在心里暗骂对方没眼力见，这叫**伪装与献祭**。

## 【“真真诚”与“伪善献祭”话术对照卡】

| 场景 | ❌ 自我献祭式伪装（高内耗、埋怨雷区） | ✅ 有边界的真诚表达（低功耗、长期可持续） |
| :--- | :--- | :--- |
| **自己正忙主线时被请求帮忙** | `“没事没事，我手头的不急，我先帮你弄吧！”`（结果熬夜赶工自己崩盘） | `“这段时间我正好在赶一个核心死线，实在抽不出整块精力帮你做；你可以先看下 X 资料。”` |
| **朋友长时间倒苦水致你过载** | 硬撑着听两小时，脑子已被轰炸成浆糊还在附和 | `“我特别理解你现在很难受，但我今天脑子实在转不动了，怕没法给你好的回应，我先去睡一觉，明天再听你说好吗？”` |
| **被借钱或要求超出能力的担保** | 怕伤感情硬着头皮借出生活费，事后每天提心吊胆 | `“我的资金目前都在固定规划里，原则上不对外拆借，这方面帮不上你，希望你能理解。”` |
