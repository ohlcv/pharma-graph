  full: |
    【核心】所有社交策略的定位都是**被动防御**——只有当对方开始索取、施压、道德绑架时，防御机制才启动。

    【防御 vs 进攻】
      - **防御**：识别对方的索取 → 守住自己的边界
      - **进攻**：主动测试对方 → 试图拿捏对方 → **绝对禁止**

    【为什么不能主动开启博弈】
      - 主动博弈需要持续算力投入 → 与【①主线优先】冲突
      - 主动博弈会把对方推到对立面 → 关系损耗加剧
      - 主动博弈会让你"享受"赢的感觉 → 容易上瘾、失控
      - 主动博弈会让你失去"受害者"地位 → 反而陷入纠缠

    【常见的"伪防御"陷阱】
      - "我要测试他一下，看他是不是真的在乎" → **这是进攻，不是防御**
      - "我要故意冷淡，看他会不会主动" → **这是拿捏，不是边界**
      - "我要让他知道我不是好惹的" → **这是示威，不是保护**
      - "我先发制人，让他闭嘴" → **这是攻击，不是防御**

    【真正的防御场景】
      - 对方提出不合理要求 → 你拒绝
      - 对方开始道德绑架 → 你退出对话
      - 对方反复试探你的底线 → 你强化声明
      - 对方开始消耗你的资源 → 你主动收缩

    【触发条件】防御机制启动的唯一条件：**对方先发起**。
      - 你不必主动识别"对方动机"——只在你感觉到压力/不适时启动防御
      - 你不必主动"识别索取"——只在对方做出明确索取动作时拒绝

    【与其他道的关系】
      - 是【杰哥三要三不要】的使用前提——博弈工具只在被动场景使用
      - 与【①主线优先】协同——主动博弈消耗主线算力
      - 与【⑤边界即自保】协同——边界的目的是停止伤害，不是反击

    【验证方法】
      - 每次启动"防御机制"前问自己："对方真的做了什么，还是我在预判？"
      - 如果对方没做任何事 → 不要启动防御
