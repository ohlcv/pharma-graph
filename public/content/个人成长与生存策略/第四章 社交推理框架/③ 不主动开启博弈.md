# ③ 不主动开启博弈

## 【核心界限：盾牌只用来挡刀，绝不用来主动砸人】

当你掌握了人际关系分级、帮助判定四问以及第八节的博弈拆解工具后，必须时刻警惕一种隐蔽的诱惑——把防御盾牌当成进攻长矛，去主动测试、拿捏身边的人。

本系统的《道之③》明确锁定：**全书所有社交策略均为“事件驱动型（Event-Driven）被动防御程序”。对方不发包越界，你的防御进程保持零功耗休眠。**

## 【“伪防御（实为主动博弈）”与“真防御”对照表】

| 行为表现 | 系统定性 | 为什么必须禁止 / 允许 |
| :--- | :--- | :--- |
| “我故意三天不回消息，看他会不会慌张找我” | ❌ **主动拿捏（严禁）** | 破坏稳定预期，把关系拖入猜忌与零和博弈，反噬自身算力 |
| “我先假装提一个过分要求，测试他是不是真心对我” | ❌ **人性测试（严禁）** | 属于主动制造摩擦的进攻行为，违背《②真诚但绝不献祭》 |
| “对方还没开口，我先脑补他想占便宜并冷脸防备” | ❌ **预判过载（严禁）** | 典型《自动越界分析陷阱》，对方未出招你已自损三千算力 |
| 对方明确提出越界索取 → 平静调用模板拒绝并设限 | ✅ **标准被动防御** | 事实清晰、动作干净，零额外算力损耗 |

## 【一秒自检口令】

在准备对某人使用防备或博弈策略前，先问自己一句：**“对方此时此刻已经做出了具体的越界行为，还是我自己在脑内预演？”** 如果是后者，立即挂起防御进程，切回主线。
