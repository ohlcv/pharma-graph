# ⑥ 边界、自身主线与他人利益区分规则

## 【核心功能：给“主线优先”装上精准的伦理校准器】

既要坚持《①你的人生主线优先级最高》，又要守住《②真诚，但绝不自我献祭》，在实际操作中最容易遇到的卡点就是：**“我这次拒绝他，到底是正当的自我保护，还是自私冷漠地害了别人？”**

本节点通过下挂两枚互斥分支卡（`case1 真正侵害他人利益` vs `case2 对方期待落空`）与一枚《平衡原则》，为你提供一套零模糊度的三步判定树。

## 【三步边界定性决策树】

```text
[准备做出拒绝 / 设限 / 退出动作]
       │
       ▼
  Q1: 我是否正在主动撒谎、造谣、侵占财物或故意破坏对方计划？
       ├─ 是 ──► 命中【case1 真正侵害】──► ❌ 系统严禁，立即停止！
       └─ 否
          │
          ▼
  Q2: 我此前是否已对该事项做出明确承诺，或已收受对方对价/利益交换？
       ├─ 是 ──► 命中【平衡原则·履约义务】──► ⚠️ 须按约完成，或提前坦诚协商改期/退还对价（禁直接消失）
       └─ 否
          │
          ▼
  Q3: 对方的不快，是否仅仅源于“他预设我会免费付出/兜底，而我未满足”？
       └─ 是 ──► 命中【case2 期待落空】──► ✅ 100% 合理边界！清空内疚，直接调用《委婉拒绝模板》
```
