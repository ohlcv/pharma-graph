  full: |
    【核心原则】三句话总结 case1 + case2 + 履约义务：

    【原则一：不主动伤人】
      - 不做 case1 行为（撒谎、毁约、造谣、攻击）
      - 即使对方让你失望、难受、愤怒，你也不主动伤害对方
      - 这是【道】的硬底线——任何情况下不突破

    【原则二：已有承诺、契约要履约】
      - 你**明确答应**过的事（口头、书面、合同）→ 必须完成
      - 你**收了对方代价**（定金、礼物、薪酬）→ 必须完成对应义务
      - 你**主动发起**的事（你说他帮你做、做了一半）→ 必须给个交代
      - 履约不是"自我献祭"，是**你的承诺对应的责任**

    【原则三：没有预先约定的无偿付出，你有权拒绝】
      - 对方希望你做某事，你**从未明确答应过** → 你有权拒绝
      - 对方希望你无偿做某事，你**没有承诺过免费** → 你有权拒绝
      - 对方期待你兜底，你**没有签过兜底合同** → 你有权拒绝
      - 你之前做过同样的事 → 这是**既往事实**，不是**未来义务**

    【三原则的优先级】
      - 原则一（不主动伤人）→ **最高优先级**
      - 原则二（履约）→ **高优先级**——但触发【道之①主线优先】时可以重新协商履约方式
      - 原则三（拒绝权）→ **常态权限**——随时可用

    【履约的特殊情况】
      - 履约成本超出你能力时 → 提前沟通重新协商（不消失、不毁约）
      - 履约会严重伤害主线 → 提前说明，重新协商履约时间/方式
      - 履约内容本身不道德/违法 → 你有权**解除承诺**（不构成毁约）
      - 履约前提（对方付费/提供资源）对方未兑现 → 履约义务相应降低

    【与"道"的整体关系】
      - 三原则不是孤立的——必须放在【道】的整体框架下理解：
        - 原则一呼应【道之④双向尊重】
        - 原则二呼应【道之②真诚】（答应了就要做到）
        - 原则三呼应【道之⑤边界即自保】（不献祭）
      - 三原则之间冲突时（如"履约会伤害主线"）→ 重新协商，而非单方毁约

    【常见误区】
      - "履约就等于献祭" → 错，履约是合理承诺的执行，不是无底线牺牲
      - "拒绝就等于冷漠" → 错，拒绝未承诺的事是合理边界
      - "对方期待就是我的义务" → 错，未明确承诺的期待不是义务

    【执行小工具】
      - 面对对方的请求，先问："我承诺过吗？"——承诺过→ 履约；没承诺过→ 重新决定
      - 面对自己的拒绝，先问："我在主动伤害吗？"——是→ 停止；不是→ 正常执行
      - 面对履约困境，先问："可以重新协商吗？"——可以→ 协商；不可以→ 履约或承担违约后果
