# 社交体系底层之道

## 【公理定位：社交推理流水线的总宪法（Step 0）】

在第四章整套社交推理引擎中，《社交体系底层之道》是位于一切具体技巧之上的**顶层公理（Step 0）**。
它的唯一核心使命是：**把你的前额叶算力死死护在人生主线之内**。社交只是生活的附属接口，绝不是你的人生主战场；任何脱离“保护主线算力”这一目标的社交技巧，在本系统中一律禁用。

## 【六条派生公理速查表】

| 公理编号 | 核心指令 | 拦截的高频内耗场景 |
| :--- | :--- | :--- |
| **① 主线优先级最高** | 社交请求与主线任务/休息冲突时，无条件保主线 | 拦截“为了合群或不好意思拒绝而熬夜陪聊、打乱核心计划” |
| **② 真诚但绝不献祭** | 给真诚的态度，但不给无底线的免费兜底 | 拦截“要么彻底掏空自己讨好，要么彻底冷漠翻脸”的二极管模式 |
| **③ 不主动开启博弈** | 防御盾牌仅在对方先发起索取/越界时被动激活 | 拦截“故意冷落试探对方、提前预判恶意先发制人”的算力空转 |
| **④ 放弃求被理解** | 接受神经典型者无法感同身受你的感官与认知体验 | 拦截“写千字长文试图向所有人解释清楚自己为什么这样”的徒劳自证 |
| **⑤ 边界即自我保护** | 设限的唯一动机是“我没电了”，而非“我要给你点颜色看看” | 拦截因报复性设限引发的对抗升级与二次情绪内耗 |
| **⑥ 侵害 vs 落空区分** | 主动毁约伤人（case1）严禁；收回未承诺的免费资源（case2）零内疚 | 拦截拒绝他人无理期待后产生的道德负罪感 |
