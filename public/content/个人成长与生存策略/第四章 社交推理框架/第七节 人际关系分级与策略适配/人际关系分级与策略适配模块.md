# 人际关系分级与策略适配模块

## 【核心机制：为什么关系分级永远是社交的第一步（Step 1）？】

如果把你的大脑算力比作服务器带宽，那么最严重的系统漏洞就是**“不对请求方做权限鉴权（Authentication & Authorization）”**——不管是路人随口一句评价、远房亲戚让你帮忙选电脑，还是伴侣的核心沟通，全都分配同等的最高算力去深度推演。
本模块的作用，就是在你的社交入口处建立一张**五级访问控制表（ACL，Class 0–Class 4）**。任何对话进入大脑的第一秒，先查对方属于哪一档，直接按档位锁死算力上限。

## 【Class 0–Class 4 五级权限与策略总表】

| 等级 | 覆盖对象 | 算力配额上限 | 默认运行模式 | 边界形态 | 允许最高帮助等级 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Class 0 弱连接** | 陌生人、临时店员、群聊网友 | **零配额（即走即清）** | 100% 模式 A | 硬物理隔离（禁透露个人背景/特质） | 不提供个人帮助 |
| **Class 1 普通熟人** | 一般同事、邻居、远亲、点头之交 | **极低（≤5 分钟/次）** | 默认模式 A | 礼貌刚性防线（防甩锅、防修电脑式沾染） | L1 浅层共情 / L2 公开链接 |
| **Class 2 挚友** | 经长期双向检验的知己好友 | **中等（按需调用）** | 日常 A / 深聊 B | 双向尊重防线（有来有往，不秋后算账） | 四问全过可给 L2 / 有限 L3 |
| **Class 3 父母亲属** | 父母、直系血亲（无法物理切割） | **定时定额窗口化** | 日常 A / 重大医疗财务 B | **柔性缓冲防线**（嘴甜心硬，降冲突保配额） | L1 安抚 + L2 信息，严控包办 L3 |
| **Class 4 亲密伴侣** | 配偶、长期深度承诺伴侣 | **最高专属带宽** | 可高频开启模式 B | **双向协商式边界**（约定暂停暗号与独处配额） | 四问弹性放宽，共担 L1–L3 |

## 【动态升降级铁律】

* **升级极慢**：从 Class 0 → Class 1 → Class 2 必须经过数月乃至数年的“双向互惠、尊重边界、不踩红线”实测检验，绝不因一次聊得投机就跨级交心。
* **降级果断**：任何 Class 1/Class 2 对象一旦出现《红色预警信号》（单向索取、道德绑架、越界打探、翻旧账指责），无需争吵宣布，直接在内心将其权限静默下调一级。
