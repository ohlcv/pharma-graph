# 第三节 切换规则

## 【核心机制：管住模式 B 的“自动唤醒漏洞”】

你的大脑之所以在社交中极易倦怠，是因为旧习惯把模式 B 设成了“中断自启（Auto-Trigger）”——只要别人眉头一皱或语气一变，你根本没经过前额叶批准，后台就已经自动拉满功率开始跑深度心理分析了。

本节《切换规则》只有一条核心指令：**拔掉模式 B 的自动唤醒线，改成纯手动机械开关。**
* **平时开关永远焊死在模式 A**；
* **只有当你主动确认“人重要 + 事重要 + 环境静 + 我满电”四项全绿时**，才允许手动按下模式 B 启动键；
* **谈完正事的一秒钟后，立刻手动拉回模式 A**，绝不让重型推理引擎在后台空转。
