# 第二节 高精度深度推理模式

## 【核心定位：受控开启的重型推理引擎（Step 3B）】

当一场沟通通过了《关系分级（Class 2–4）》与《模式选择决策判断表（四问全 Yes）》后，你才正式手动合闸，启动**模式 B（高精度深度推理模式）**。
但即便在模式 B 下，你的算力依然受本节内置的**“四问串联校验 + L1–L3 分级输出 + 红色预警一票否决”**三道硬件限流器保护，绝不允许滑向无底线包办。

## 【模式 B 帮助请求处理全链路表】

| 处理阶段 | 调用子卡 | 核心执行标准 |
| :--- | :--- | :--- |
| **1. 红线安检** | 《红色预警信号》 | 先扫一眼对方是否有“催促立刻表态、道德绑架、完全不自救、历史上有赖账前科”？命中任一条 → **一票否决，直接退回模式 A 拒绝** |
| **2. 四问串联** | 《决策四问》（Q1–Q4） | 依次核验：Q1 我自愿不委屈？→ Q2 算力代价可控？→ Q3 对方已先尽力自救？→ Q4 办砸了不赖我？任一为 No → **最高只给 L1** |
| **3. 定级输出** | **L1 浅层共情** | 仅提供情绪接纳与鼓励（耗电 <5%，适用于绝大多数未过四问的倾诉） |
| **3. 定级输出** | **L2 客观信息指引（主力档）** | 指明方向、给公开参考资料或列出客观选项，**由对方自己动手执行、自己拍板担责**（耗电 15%，兼顾善意与边界的黄金档位） |
| **3. 定级输出** | **L3 动手实操代劳（特批档）** | 亲自替对方写方案、修东西、跑腿处理；仅限 Class 2–4 极少数核心场景，且必须预先声明交付边界与免责条款 |
