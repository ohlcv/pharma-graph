# 使用警示

## 【为什么要为“外部参考模块”专门加一道保险栓？】

第八节收录的《杰哥三要三不要》提炼自世俗人际与亲密关系博弈的实战经验，优点是极度清醒、止损快；但它的底层预设带有明显的**“人际博弈论”**色彩。
对于高算力、容易把规则执行到极致的大脑来说，如果不加限制地把博弈视角当成全书的总公理，很容易滑向“看谁都像在算计我、连挚友和伴侣都要拿框架去压制”的防御过载。因此，调用第八节任何节点前，必须先过本保险栓。

## 【五大误用陷阱与校准表】

| 外部原则 | ❌ 走火入魔的错误用法（主动博弈/冷暴力） | ✅ 符合本系统的正确用法（被动自保/守主线） |
| :--- | :--- | :--- |
| **三要① 提供情绪价值** | 违背本心去讨好、恭维不认可的人（沦为伪装过载） | 在不耗损主线的前提下，用温和语气包裹坚定边界（嘴甜心硬） |
| **三要② 建立稳定框架** | 强行要求伴侣或朋友事事服从自己的规矩 | 自己内部的作息、底线与算力配额清晰稳定，不随他人情绪摇摆 |
| **三不要① 不自证清白** | 伴侣正常询问事实经过时，冷脸甩一句“信不信由你” | 仅在对方怀揣恶意定罪、扣道德大帽（场景 1）时拒绝掉入自证陷阱 |
| **三不要② 不争辩输赢** | 带着轻蔑冷笑敷衍“行行行你全对”（被动攻击激化矛盾） | 平静温和地放下口舌胜负，把对话拉回具体可执行的下一步方案 |
| **三不要③ 不过度付出** | 拿秒表和计算器跟挚友/伴侣算每一顿饭谁多花了几块钱 | 在 3–6 个月宏观尺度上监控算力账本，防止单向供养导致的系统崩盘 |
