    【不同种类的镇静与催眠药剂量】
    镇静与催眠药随用药剂量增加依次呈现不同的药理作用。剂量由小到大，分别表现出抗焦虑、镇静催眠、抗惊厥、麻醉、肌松的药理作用，甚至引起呼吸麻痹而死亡，其中松弛肌肉的药理作用与剂量无关。

    【各类药物药理作用对比】

    | 类别 | 抗焦虑 | 镇静催眠 | 抗惊厥 | 麻醉 | 肌松作用 |
    |---|---|---|---|---|---|
    | 巴比妥类 | 无 | 有 | 有 | 有 | 无 |
    | 苯二氮䓬类 | 有 | 有 | 有 | 无 | 有 |
    | 佐匹克隆 | 有 | 有 | 无 | 无 | 无 |
    | 唑吡坦 | 无 | 有 | 无 | 无 | 无 |
