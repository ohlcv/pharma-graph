# 镇静催眠药、中枢肌松药

## 这一节在讲什么？

这一节讲的是用于镇静、催眠和缓解肌肉痉挛的药物。镇静催眠药主要通过增强GABA能神经抑制发挥作用：苯二氮卓类（如地西泮、氯硝西泮）效果全面但有成瘾风险；非苯二氮卓类Z药（如唑吡坦）入睡效果强而依赖性相对较低；褪黑素受体激动剂（如雷美替胺）模拟生理节律，适合昼夜节律失调性失眠。中枢肌松药（如巴氯芬）则通过抑制脊髓反射弧中的中间神经元来缓解肌肉痉挛。

## 为什么要理解它？

因为失眠是门诊最常见的睡眠主诉，镇静催眠药的使用非常普遍。但成瘾风险、宿醉效应、跌倒风险（老年人）、撤药反应和长期用药管理，都是临床用药安全必须高度关注的领域。掌握各类药物的特点，是在CNS用药中做好用药监护的基础。

## 它主要和什么有关？

它最容易和抗癫痫发作药物连起来理解——苯二氮卓类本身就是癫痫持续状态的首选急救药物，作用机制（增强GABA抑制）完全相通。同时，苯二氮卓类与阿片类联用时的呼吸抑制风险，也是围手术期镇痛和急救用药中需要特别警惕的药物相互作用。

## 它通常在什么阶段出现？

它出现在CNS用药学习的起点，是临床最常用的CNS药物类别之一。学到这里，已经开始接触到"增强神经递质抑制"这一核心药理学机制，以及"CNS药物都有成瘾风险"这条贯穿始终的安全主线。

## 它在整套框架里放在哪里？

它位于《药学专业知识二》第一章第一节，是整章中临床应用最广的入门节点。往上承接CNS用药总框架，往下可通向失眠管理、焦虑治疗和癫痫持续状态的急救处理。

## 镇静催眠药药理作用横向对比

| 药物类别 | 抗焦虑 | 镇静催眠 | 抗惊厥 | 抗癫痫 | 麻醉作用 | 肌肉松弛 |
|---|---|---|---|---|---|---|
| 巴比妥类 | 有 | 有 | 有 | 有 | 有 | 有 |
| 苯二氮䓬类 | 有 | 有 | 有 | 有 | 无 | 有 |
| 佐匹克隆 | 无 | 有 | 无 | 无 | 无 | 弱 |
| 唑吡坦 | 无 | 有 | 无 | 无 | 无 | 无 |

**剂量-效应核心规律**：镇静催眠药随剂量递增效应依次为——**镇静 → 催眠 → 抗惊厥 → 麻醉 → 呼吸麻痹死亡**；其中肌肉松弛作用与剂量无正相关。

## 镇静催眠药临床用药评价

### 巴比妥类

**作用特点**

- 起效速度由脂溶性决定：短效/超短效脂溶性高、起效快；长效类脂溶性低、起效慢
- 肝药酶诱导作用：加速自身及合用药物的代谢，降低其他药物药效
- 剂量依赖性效应：随剂量升高，依次呈现"镇静→催眠→抗惊厥→麻醉→呼吸麻痹死亡"
- 记忆口诀：**全心全意**

**典型不良反应**

- 宿醉效应：嗜睡、精神依赖、步履蹒跚、共济失调、肌无力
- 过敏反应：严重可诱发史蒂文斯-约翰逊综合征（SJS），一旦出现需立即停药
- 依赖与戒断：长期用药产生耐受性、依赖性；突然停药会出现失眠、焦虑、震颤、惊厥等戒断症状
- 心血管风险：大剂量抑制心肌收缩力、降低血压；与延长 Q-T 间期的药物合用，心脏毒性风险升高
- 呼吸风险：静脉快速给药易引发呼吸暂停、支气管痉挛
- 记忆口诀：**笨蛋儿子找不到妈妈**

**禁忌与注意**

- 禁用人群：严重肺功能不全、肝硬化、血卟啉病、未控制的糖尿病、严重贫血患者
- 特殊人群：肝功能不全者常规剂量即可诱发反常兴奋，老年患者必须减量

### 苯二氮䓬类

**作用特点**

- 起效速度由脂溶性决定：地西泮、氟西泮脂溶性高、起效快；氯氮䓬起效慢
- 肝脏代谢：多数经肝脏代谢，代谢产物仍有药理活性，半衰期会延长
- 药理谱广：同时具备抗焦虑、镇静催眠、抗惊厥、抗癫痫、中枢性肌松作用
- 药物相互作用：与其他中枢抑制药合用，中枢抑制效应叠加；与对乙酰氨基酚合用，会降低退热效果
- 记忆口诀：**爸比不焦急**

**典型不良反应**

- 宿醉效应：嗜睡、步履蹒跚、共济失调
- 依赖与戒断：长期用药产生依赖；突然停药出现反跳性失眠、焦虑、多汗、震颤、惊厥
- 静脉给药风险：低血压、心动过缓、呼吸抑制
- 老年风险：易诱发跌倒、认知功能障碍
- 可透过胎盘屏障、分泌入乳汁，妊娠期、哺乳期慎用

### 非苯二氮䓬类（新型催眠药）

**作用特点**

- 作用专一：镇静催眠作用强，抗焦虑、肌松、抗惊厥作用极弱
- 安全性高：起效快、半衰期短，次日宿醉效应轻，依赖性、戒断反应远低于苯二氮䓬类，无明显呼吸抑制
- 代表药特性：**唑吡坦仅具有镇静催眠作用**，无抗焦虑、肌松、抗惊厥功效
- 记忆口诀：
  - **克隆羊没有爹妈**（佐匹克隆无额外广谱药理作用）
  - **唑吡坦是孤儿，只能一个人睡**（唑吡坦仅单一催眠作用）

**典型不良反应**

- 常见嗜睡、头晕、乏力、记忆障碍
- 罕见睡眠相关异常行为（梦游、睡眠进食、睡眠驾驶）
- 长期用药突然停药，可出现轻度反跳性失眠

## 中枢肌松药临床用药评价

### 乙哌立松

**作用特点**

- 抑制 γ-运动神经元自发冲动
- 降低肌梭敏感性
- 兼具镇痛、改善局部循环作用
- 不影响神经肌肉接头传递

**临床应用**：缓解多种疾病导致的肌紧张、痉挛性麻痹。

**典型不良反应**：嗜睡、头晕、头痛；胃肠道不适；肝功能异常；血压下降。

### 巴氯芬

**作用特点**：选择性激动 GABA-B 受体；抑制脊髓突触反射。

**临床应用**：多发性硬化所致的骨骼肌痉挛；脊髓外伤、退行性病变、肿瘤引发的肌肉痉挛。

**典型不良反应**：嗜睡、头晕、乏力、恶心；突然停药可诱发幻觉、惊厥。

### 氯唑沙宗

**作用特点**：抑制脊髓和皮层下的多突触反射；发挥肌松效果。

**临床应用**：急慢性软组织扭伤；运动后肌肉酸痛；中枢病变导致的肌肉痉挛。

**典型不良反应**：以恶心等消化道症状为主；其次为头晕、嗜睡。
