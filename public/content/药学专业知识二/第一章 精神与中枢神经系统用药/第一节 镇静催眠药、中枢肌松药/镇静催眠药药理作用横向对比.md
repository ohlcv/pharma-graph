# 镇静催眠药药理作用横向对比

## 它在讲什么？

镇静催眠药药理作用横向对比的主题节点，通过表格化方式对比不同类别在抗焦虑、镇静催眠、抗惊厥、抗癫痫、麻醉、肌肉松弛作用上的异同。

## 对比表

| 药物类别 | 抗焦虑 | 镇静催眠 | 抗惊厥 | 抗癫痫 | 麻醉作用 | 肌肉松弛 |
|---|---|---|---|---|---|---|
| 巴比妥类 | 有 | 有 | 有 | 有 | 有 | 有 |
| 苯二氮䓬类 | 有 | 有 | 有 | 有 | 无 | 有 |
| 佐匹克隆 | 无 | 有 | 无 | 无 | 无 | 弱 |
| 唑吡坦 | 无 | 有 | 无 | 无 | 无 | 无 |

## 剂量-效应核心规律

镇静催眠药随剂量递增效应依次为：**镇静 → 催眠 → 抗惊厥 → 麻醉 → 呼吸麻痹死亡**；其中肌肉松弛作用与剂量无正相关。

## 它和节的关系？

它属于镇静催眠药、中枢肌松药节的总结对比主题节点，向上承接节节点，向下汇总 4 类典型代表。
