# 中枢神经系统作用（阿片类）

## 它是什么机制？

阿片类作用于中枢神经系统的综合效应集合。

## 六大子效应

| 子效应 | 机制要点 |
|---|---|
| 镇痛 | 强效镇痛，对慢性钝痛的效果优于急性锐痛 |
| 镇静、欣快 | 消除疼痛伴随的焦虑、恐惧情绪，欣快感是成瘾性的核心基础 |
| 镇咳 | 直接抑制延髓咳嗽中枢，镇咳作用强大 |
| 缩瞳 | 兴奋动眼神经副核，中毒时出现特征性针尖样瞳孔 |
| 催吐 | 兴奋延髓催吐化学感受区，用药初期易引发恶心呕吐 |
| 抑制呼吸 | 降低呼吸中枢对 CO₂ 的敏感性，是急性中毒致死的主要原因 |

## 在整套知识框架里放在哪里？

它位于中枢镇痛药节内，是阿片类作用机制按系统的维度节点之一，与心血管系统作用、平滑肌作用并列。
