# 拟多巴胺类药

## 它是什么分类？

抗帕金森病药下与中枢抗胆碱药并列的机制大类——通过增强多巴胺能通路功能改善症状。

## 五大亚类

| 亚类 | 代表药物 |
|---|---|
| 多巴胺前体+外周脱羧酶抑制剂 | 左旋多巴、卡比多巴、苄丝肼（多巴丝肼、卡左双多巴） |
| COMT 抑制剂 | 恩他卡朋、托卡朋 |
| 多巴胺受体激动剂 | 溴隐亭、培高利特、普拉克索、罗匹尼罗、吡贝地尔、罗替戈汀、阿扑吗啡 |
| MAO-B 抑制剂 | 司来吉兰、雷沙吉兰 |
| 其他类（促多巴胺释放药） | 金刚烷胺 |

## 它和节的关系？

它属于抗帕金森病药节下两大机制分类之一，与中枢抗胆碱药并列。
