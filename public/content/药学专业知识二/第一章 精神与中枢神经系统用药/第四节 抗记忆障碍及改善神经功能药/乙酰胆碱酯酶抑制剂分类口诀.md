# 乙酰胆碱酯酶抑制剂分类口诀

> **"多加点利是吧，胆子真大"**

- **多** → 多奈哌齐
- **加** → 加兰他敏
- **点** → （谐音"碘"，无实义，连接词）
- **利** → 利斯的明
- **是** → 石（石杉碱甲）
- 胆子真大 → 胆碱酯酶抑制剂
