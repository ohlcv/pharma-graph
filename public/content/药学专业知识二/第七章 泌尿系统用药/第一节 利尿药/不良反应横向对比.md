# 利尿剂不良反应横向对比

## 速记表

| 不良反应项目 | 强效利尿剂（袢利尿剂） | 中效利尿剂（噻嗪类） | 低效利尿剂（留钾类） | 碳酸酐酶抑制药 |
|---|---|---|---|---|
| **血钾变化** | 降低 | 降低 | 升高 | 降低 |
| **耳毒性** | 有 | 无 | 无 | 无 |
| **男性乳房女性化** | 无 | 无 | 有（螺内酯） | 无 |

## 关键速记口诀

| 利尿剂 | 不良反应口诀 |
|---|---|
| 袢利尿剂 | "那位假美女脸蛋黄，小心高糖高脂高尿酸；一只耳朵不过敏" |
| 噻嗪类 | "那位假美女脸蛋黄，小心高糖高脂高尿酸" |
| 留钾利尿剂 | "盖中盖，升血钾" |
| 碳酸酐酶抑制药 | "清官探案，走近看" |
| 渗透性利尿药 | "脱水了，得解压" |

## 临床意义

- **袢利尿剂独有**：耳毒性（依他尼酸最大、布美他尼最小）
- **噻嗪类独有**：升血钙（与袢利尿剂相反）
- **留钾类独有**：男性乳房女性化（仅螺内酯）、高钾血症
- **碳酸酐酶抑制药独有**：代谢性酸中毒（区别于其他利尿剂的"碱中毒"倾向）

## 它和节的关系？

不良反应横向对比表是利尿药章节的高频考点速记，是考试复习的精华。
