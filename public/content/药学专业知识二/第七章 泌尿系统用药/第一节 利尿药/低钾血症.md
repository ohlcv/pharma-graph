# 低钾血症

## 它是什么病？

低钾血症是指血清钾浓度低于3.5 mmol/L的病理状态。是利尿药治疗中最常见的电解质紊乱问题。

## 利尿药相关性低钾

| 利尿药类型 | 排钾风险 |
|---|---|
| 袢利尿药 | 高 |
| 噻嗪类利尿药 | 高 |
| 留钾利尿药 | 负（保钾） |
| 渗透性利尿药 | 较轻 |
| 碳酸酐酶抑制药 | 中等 |
| V2受体拮抗药 | 较轻 |
| SGLT2抑制药 | 较轻 |

## 临床危害

- 心律失常（最严重）
- 肌无力、麻痹
- 横纹肌溶解
- 糖耐量异常

## 预防策略

- 排钾利尿药 + 留钾利尿药联合
- 监测血钾浓度
- 必要时口服补钾

## 它在知识体系里的位置？

低钾血症是排钾利尿药的核心不良反应，是留钾利尿药的主要预防对象。
