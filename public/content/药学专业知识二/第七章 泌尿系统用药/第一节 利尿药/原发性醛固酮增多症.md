# 原发性醛固酮增多症

## 它是什么病？

原发性醛固酮增多症（Conn综合征）是肾上腺皮质球状带分泌过多醛固酮，导致高血压、低钾血症、代谢性碱中毒的疾病。

## 临床特点

- 高血压（常为首发）
- 低钾血症（肌无力、心律失常）
- 代谢性碱中毒
- 高醛固酮、低肾素活性
- 醛固酮/肾素比值（ARR）升高

## 治疗

| 方案 | 适用情况 |
|---|---|
| **手术治疗** | 单侧腺瘤患者首选 |
| 螺内酯 | 药物治疗首选 |
| 依普利酮 | 选择性高，不良反应少 |
| 氨苯蝶啶 | 严重男性不良反应时的备选 |
| 阿米洛利 | 备选 |

## 它在知识体系里的位置？

原发性醛固酮增多症是螺内酯（醛固酮受体拮抗药）的经典适应证。
