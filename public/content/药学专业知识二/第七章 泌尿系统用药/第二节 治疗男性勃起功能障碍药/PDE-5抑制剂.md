# 5型磷酸二酯酶（PDE-5）抑制剂

## 这类药是什么？

PDE-5抑制剂（5型磷酸二酯酶抑制剂）通过**选择性抑制阴茎海绵体内的5型磷酸二酯酶（PDE-5）**，升高细胞内cGMP水平，松弛海绵体平滑肌，促使血液涌入，发动并维持阴茎勃起。

**为勃起功能障碍的首选治疗药物**（一线口服）。

## 核心作用机制

```
性刺激 → 神经末梢释放NO → 激活鸟苷酸环化酶 → cGMP↑ → 平滑肌松弛 → 血液流入海绵体 → 勃起
                                                                       ↑
                                              PDE-5抑制剂抑制PDE-5降解cGMP ───┘
```

**关键前提**：**药物起效必须有性刺激触发**，无性刺激不会自发勃起。

## 分类代表药

| 药物 | 起效 | 维持 | 特点 |
|---|---|---|---|
| 西地那非 | 30-60min | 4-6h | 经典代表药，易致"蓝视" |
| 伐地那非 | 30-60min | 4-6h | 起效快，可致QT延长 |
| **他达拉非** | 30-60min | **36h** | 长效代表，**不受高脂饮食影响**，可改善BPH下尿路症状 |
| 阿伐那非 | 15-30min | 6h | **起效最快**，视觉不良反应少 |
| 爱地那非 | 30-60min | 4-6h | 中国国产新药 |

## 拓展适应症

- **西地那非、他达拉非**：获批用于治疗**肺动脉高压**，也可用于儿童重症肺动脉高压
- **他达拉非**：还可用于勃起功能障碍合并良性前列腺增生患者，改善尿频、尿急等下尿路症状

## 吸收与饮食影响

| 药物 | 饮食影响 |
|---|---|
| 西地那非 | 高脂餐延缓吸收，**建议餐前至少2小时服用** |
| 伐地那非 | 高脂餐延缓吸收，**建议餐前至少2小时服用** |
| 他达拉非 | **不受高脂饮食影响** |
| 伐地那非口腔崩解片 | **不受高脂膳食影响** |

## 典型不良反应

### 1. 血管扩张反应（最常见）

颜面潮红、反射性心动过速、鼻塞、头晕、体位性低血压。

**风险比较**：他达拉非、阿伐那非的相关风险**低于**西地那非、伐地那非。

### 2. 视觉异常

- **"蓝视"现象**（视物呈蓝绿色调、光敏感增强）：除他达拉非外均可能出现，大剂量/高血药浓度时更明显，多为一过性，停药后2-3小时自行消失
- 严重罕见：非动脉炎性缺血性视神经病变（NAION），高危因素为年龄>50岁、高血压、血脂异常、糖尿病
- 还可能诱发视网膜脱离、视网膜静脉阻塞

### 3. 肌肉骨骼反应

- 背痛、肌痛
- **他达拉非相对多见**

### 4. 胃肠道反应

- 食管下括约肌松弛引发胃反流、消化不良、恶心、呕吐

### 5. 心血管影响

- 伐地那非可轻度延长心电图Q-T间期

### 6. 严重风险

- **阴茎异常勃起**（勃起持续超过4小时），需紧急就医处理，避免海绵体组织永久损伤

## 禁忌

### 绝对禁忌

- 正在使用任何剂型硝酸酯类药物的患者（**联用可引发致命性低血压**）

### 严重心血管疾病

- 低血压（收缩压<90/60mmHg）
- 未控制的重度高血压（血压>170/100mmHg）
- 不稳定型心绞痛
- 充血性心力衰竭
- 近1个月内发生心肌梗死、脑卒中或致死性心律失常的患者

### 伐地那非特殊禁忌

- 禁止与Ⅰa类（奎尼丁、普鲁卡因胺）、Ⅲ类（胺碘酮）抗心律失常药物合用
- 先天性Q-T间期延长患者慎用

## 药物相互作用

### 1. 硝酸酯类药物（绝对禁忌）

- 联用可导致**严重顽固性低血压**
- 若服用PDE-5抑制剂后出现心绞痛，需延迟足够时间再使用硝酸酯类药物

### 2. 肝药酶相互作用

**CYP3A4抑制剂**（西咪替丁、红霉素、克拉霉素、伊曲康唑、利托那韦等）：
- 药物代谢减慢、半衰期延长、血药浓度升高
- **需降低本类药物的起始剂量**

**CYP3A4诱导剂**（如波生坦）：
- 药物代谢加速，血药浓度降低，药效减弱

### 3. α受体拮抗剂

- 联用降压作用叠加，可能引发症状性低血压
- 优先选择高选择性α₁A受体拮抗剂（坦索罗辛、赛洛多辛），低血压风险更低

### 4. 雄激素补充治疗

- 对睾酮水平偏低的ED患者，雄激素联合PDE-5抑制剂可增强疗效，改善单药治疗无应答患者的勃起功能

## 它和节的关系？

PDE-5抑制剂是ED治疗的首选口服药，是药物治疗ED的核心手段。
