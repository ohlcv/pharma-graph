# ED治疗核心考点速记

## 核心考点速记表

| 考点 | 关键内容 |
|---|---|
| **ED首选口服药** | PDE-5抑制剂，**必须有性刺激才能起效** |
| **绝对配伍禁忌** | 任何硝酸酯类药物均不可联用 |
| **长效代表** | 他达拉非，作用维持**36小时**，不受高脂饮食影响 |
| **特征不良反应** | 西地那非、伐地那非易致"蓝视"，**他达拉非少见** |
| **起效最快** | 阿伐那非（15-30分钟） |
| **独特心血管风险** | 伐地那非可致QT延长 |
| **ED合并BPH首选** | 他达拉非（兼具改善下尿路症状） |
| **国产新药** | 爱地那非 |

## 5个PDE-5抑制剂速记

| 药物 | 一句话记忆 |
|---|---|
| 西地那非 | "伟哥"、经典代表、易蓝视 |
| 伐地那非 | 易蓝视、**QT延长**、禁与抗心律失常药联用 |
| **他达拉非** | 长效36h、**不受饮食影响**、可治BPH |
| 阿伐那非 | **起效最快**（15-30min）、视觉不良反应少 |
| 爱地那非 | 中国国产新药 |

## 二线治疗速记

| 药物 | 机制 | 特点 |
|---|---|---|
| 前列地尔（PGE1） | 激活腺苷酸环化酶，cAMP↑ | 海绵体内注射 / 经尿道 |
| 酚妥拉明 | α受体阻滞剂 | 经典还有嗜铬细胞瘤 |
| 罂粟碱 | 非特异性PDE抑制剂 | **阴茎异常勃起风险较高** |
| **三联鸡尾酒** | 三药机制互补 | 单药剂量减少，副作用降低 |

## 临床用药评价要点

### 作用特点

- 选择性抑制PDE-5，升高cGMP，松平滑肌
- 关键前提：必须有性刺激触发，无性刺激不会自发勃起
- 拓展：西地那非、他达拉非可用于肺动脉高压；他达拉非可改善BPH下尿路症状

### 典型不良反应

1. **血管扩张反应**：颜面潮红、反射性心动过速、鼻塞、头晕、体位性低血压
2. **视觉异常**：蓝视（除他达拉非外）；罕见：NAION、视网膜脱离
3. **肌肉骨骼反应**：背痛、肌痛（他达拉非多见）
4. **胃肠道反应**：食管下括约肌松弛引发反流
5. **心血管影响**：伐地那非可致QT延长
6. **严重风险**：阴茎异常勃起

### 禁忌

- **绝对禁忌**：硝酸酯类
- 严重心血管疾病
- 伐地那非特殊禁忌：Ⅰa/Ⅲ类抗心律失常药

### 药物相互作用

- 硝酸酯类（绝对禁忌）
- CYP3A4抑制剂（需降低剂量）
- CYP3A4诱导剂（药效减弱）
- α受体拮抗剂（低血压风险）
- 雄激素（增强疗效）

## 它和节的关系？

核心考点速记是第二节药物复习的精华，是执业药师考试的常考内容。
