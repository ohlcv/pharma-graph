# 可待因

## 它是什么药？

属于**中枢性镇咳药**，是强效镇咳药，同时具有**镇痛（中重度疼痛）和镇静**作用。是**麻醉药品**，有成瘾性和耐受性。

## 它有什么独特之处？

- **前体药物**：约 15% 经 CYP2D6 代谢为吗啡发挥作用——CYP2D6 超快代谢者可致吗啡中毒，是最重要的安全警示
- **镇咳、镇痛、镇静**三重作用
- 镇咳作用强而迅速（约为吗啡的 1/4）
- 归属**中枢镇痛药章节**（第一章第五节）——麻醉性镇痛药中的弱阿片类代表

## 核心作用特点是什么？

| 特点 | 说明 |
|---|---|
| **受体机制** | 阿片 μ/κ/δ 受体激动（弱激动） |
| **代谢特点** | 前体药，约 15% 经 CYP2D6 → 吗啡 |
| **镇咳效力** | 强效（约为吗啡的 1/4） |
| **镇痛效力** | 中重度疼痛（约为吗啡的 1/4） |
| **成瘾性** | 麻醉药品，有成瘾和耐受风险 |

## 临床应用是什么？

**镇咳用途（第三章第一节）：**
- **各种原因的剧烈干咳**（首选，特别是伴随胸痛的干咳）
- 中重度疼痛（镇痛作用约为吗啡的 1/4）

**镇痛用途（第一章第五节）：**
- 中重度疼痛（阿片类镇痛药中的弱阿片代表）

## 典型不良反应是什么？

- **成瘾性**（麻醉药品，吗啡衍生物）
- 呼吸抑制（过量）
- 便秘
- 恶心、呕吐

## 禁忌人群是什么？

- **CYP2D6 超快代谢者**：禁用（吗啡代谢过度，可致中毒甚至死亡）
- **18 岁以下儿童**：禁用含可待因的感冒制剂
- **妊娠期、哺乳期妇女**：禁用（透过胎盘，致胎儿成瘾/呼吸抑制）
- **1 岁以下儿童**：禁用
- **痰多者**：不宜使用（抑制咳嗽反射，痰液无法咳出）

## 药物相互作用是什么？

- **CYP2D6 抑制剂**（奎尼丁、西咪替丁等）：抑制代谢，吗啡浓度升高，毒性↑
- 与中枢抑制药合用：呼吸抑制风险↑

## 它和节/章的关系？

- **镇咳药章节**（第三章第一节）：中枢性镇咳药代表，定位"强效镇咳，镇痛，成瘾性麻醉药品，CYP2D6 代谢，多种禁忌"
- **中枢镇痛药章节**（第一章第五节）：弱阿片类代表药，与吗啡（强阿片类）并列，属于阿片生物碱类
