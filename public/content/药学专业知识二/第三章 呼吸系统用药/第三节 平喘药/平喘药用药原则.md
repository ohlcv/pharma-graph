# 平喘药用药原则

## 哮喘的本质是什么？

哮喘的本质是**气道慢性炎症 + 支气管痉挛**双重病理——气道炎症是长期根本，痉挛是急性表现。因此平喘药分为两大类：**抗炎控制类**（长期维持，从根本上控制炎症）和**解痉缓解类**（急救按需，快速解除痉挛）。

## 按治疗目的怎么分类？

| 类别 | 定位 | 代表药物 |
|---|---|---|
| **控制症状药（长期维持）** | 每日规律使用，控制气道炎症，预防发作 | 吸入型糖皮质激素(ICS)、全身性激素、白三烯受体拮抗剂(LTRA)、长效β₂受体激动剂(LABA)、缓释茶碱、抗IgE单克隆抗体 |
| **缓解症状药（急救按需）** | 急性发作时使用，快速解除支气管痉挛 | 速效吸入/短效口服β₂受体激动剂(SABA)、ICS+福莫特罗复方制剂、吸入型抗胆碱能药物(SAMA)、短效茶碱、全身性激素 |

## 不同情况怎么选药？

| 场景 | 首选药物 |
|---|---|
| 轻至中度哮喘急性发作、COPD支气管痉挛 | 吸入**短效β₂受体激动剂**（沙丁胺醇、特布他林）；联合雾化异丙托溴铵+沙丁胺醇效果更好 |
| 轻中度哮喘稳定期控制 | **白三烯受体拮抗剂**（孟鲁司特） |
| 中重度持续哮喘长期治疗 | **吸入糖皮质激素 + 长效β₂受体激动剂**（ICS+LABA联合制剂，如布地奈德/福莫特罗） |
| 重度哮喘、COPD患者 | **三联复合制剂**（ICS+LABA+LAMA，如氟替美溴铵/维兰特罗/乌地溴铵） |
| IgE介导的中重度过敏性哮喘 | **奥马珠单抗**（抗IgE单克隆抗体） |

## 核心选药口诀是什么？

**"急布丁；轻中稳定选司特；奥巴马过敏要抗议"**

- **急布丁**：急性发作用沙**丁**胺醇、**特**布他林
- **轻中稳定选司特**：轻中度稳定期选**白三烯受体拮抗剂**（名字带"司特"：孟鲁司特、普仑司特）
- **奥巴马过敏要抗议**：IgE介导的过敏性哮喘用**奥马珠单抗**

## 它和章的关系？

它是第三节平喘药的临床应用指南，把所有平喘药按照治疗目的和哮喘严重程度整合为可操作的选药方案，是平喘药学习的最终归宿。
