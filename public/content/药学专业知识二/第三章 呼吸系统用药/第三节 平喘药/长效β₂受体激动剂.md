# 长效β₂受体激动剂（LABA）

## 它是什么？

属于**β₂受体激动剂**的长效亚类（LABA），通过激动气道平滑肌β₂受体松弛支气管，作用维持12~24 h，**不能单独用于哮喘**，必须与吸入糖皮质激素（ICS）联合使用。

## 代表药有哪些？

| 药物 | 特点 |
|---|---|
| **沙美特罗** | 经典LABA，昔萘酸沙美特罗吸入粉雾剂 |
| **福莫特罗** | 起效较快（1~3 min），是ICS+LABA复方制剂（如布地奈德/福莫特罗）中的LABA成分 |
| **茚达特罗** | 新型LABA，一日1次，使用方便 |
| **维兰特罗** | 一日1次，常与其他药物组成三联制剂 |
| **奥达特罗** | 一日1次，新型LABA |

## 为什么不能单独使用？

美国FDA对LABA发出**黑框警告**：单独使用LABA治疗哮喘可增加哮喘相关死亡风险。必须与ICS联用，且一旦症状控制应尽快降低剂量。

## 典型不良反应是什么？

- 骨骼肌震颤
- 心悸、心动过速
- 低钾血症

## 它和总论的关系？

它是β₂受体激动剂总论的下属节点，定位"LABA，不单独用于哮喘，需与ICS联用，是ICS+LABA联合制剂的核心成分"。
