# 黄嘌呤类口诀

## 口诀是什么？

**"二线茶碱有点黄，不良反应真够多"**

## 口诀怎么记？

| 口诀 | 含义 |
|---|---|
| **二线** | 黄嘌呤类是二线平喘药，非首选 |
| **茶碱** | 代表药都是"茶碱"类：茶碱、多索**茶碱**、氨**茶碱**、二羟丙**茶碱** |
| **有点黄** | 治疗浓度窗窄（10~20 μg/mL），安全范围小 |
| **不良反应真够多** | 不良反应多：心律失常、血压下降、中枢兴奋、胃肠道刺激；安全范围窄，需监测血药浓度 |

## 为什么要记口诀？

记住黄嘌呤类"二线地位"和"安全窗窄、副作用多"的特点，考试中常考其禁忌证和血药浓度监测要求。
