# 乙酰半胱氨酸

## 它是什么？

属于**黏痰溶解剂**，是祛痰药中作用最强的代表药。分子中含有**巯基（-SH）**，能裂解痰液中黏多糖/黏蛋白二硫键（S-S），使黏痰直接液化。

## 核心作用特点是什么？

1. **强效祛痰**：不仅溶解白色黏痰，还能溶解**脓性痰**；雾化吸入效果显著优于氨溴索、溴己新
2. **解毒用途**：注射剂可用于**对乙酰氨基酚中毒**解救（补充谷胱甘肽）；治疗环磷酰胺引起的出血性膀胱炎
3. **pH依赖性**：在pH 7.0时溶解黏痰作用最强；**酸性环境减弱疗效**，加服碳酸氢钠可增强效果
4. **抗菌药联用禁忌**：减弱青霉素、头孢菌素、四环素活性，**不宜直接合用**，必须间隔4 h或交替使用

## 典型不良反应是什么？

- 恶心、呕吐（口服给药）
- 呛咳、支气管痉挛（雾化吸入，哮喘患者慎用）
- 口腔异味

## 药物/理化相互作用是什么？

- **抗生素**：减弱青霉素、头孢、四环素抗菌活性 → 间隔4 h
- **金属/橡胶**：巯基化合物易被氧化 → 储存避免接触空气、金属、橡胶
- **硝酸甘油**：增强低血压效应 → 监测血压
- **pH**：酸性环境（pH低）减弱疗效

## 禁忌人群是什么？

- **消化道溃疡病史者**慎用
- **支气管哮喘患者**慎用（可能诱发支气管痉挛）
- 口服生物利用度低（6%~10%），首关效应明显

## 它和章的关系？

它是黏痰溶解剂的代表药，定位"黏痰溶解剂作用最强，兼具解毒，抗生素/金属禁忌，pH依赖"。

## 记忆口诀是什么？

**"半胱氨酸真优秀，祛痰解毒666，酸性环境定蛋咯，抗生素类不同用，巯基怕碰金属，溃疡哮喘要慎用"**

| 口诀 | 含义 |
|---|---|
| **祛痰解毒666** | 祛痰（裂解二硫键）和解毒（对乙酰氨基酚中毒、环磷酰胺膀胱炎）两大用途 |
| **酸性环境定蛋咯** | 在pH 7.0时作用最强，酸性环境定"蛋"（二硫键）效果差 |
| **抗生素类不同用** | 与青霉素、头孢、四环素同用减弱抗菌效果，须间隔4 h |
| **巯基怕碰金属** | 巯基化合物易被氧化，避免接触金属、橡胶 |
| **溃疡哮喘要慎用** | 消化道溃疡和支气管哮喘患者慎用 |
