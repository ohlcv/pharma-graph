# 乙酰半胱氨酸口诀

## 口诀是什么？

**"半胱氨酸真优秀，祛痰解毒666，酸性环境定蛋咯，抗生素类不同用，巯基怕碰金属，溃疡哮喘要慎用"**

## 口诀怎么记？

| 口诀 | 含义 |
|---|---|
| **祛痰解毒666** | 祛痰（裂解二硫键）和解毒（对乙酰氨基酚中毒、环磷酰胺膀胱炎）两大用途 |
| **酸性环境定蛋咯** | 在pH 7.0时作用最强，酸性环境定"蛋"（二硫键）效果差 |
| **抗生素类不同用** | 与青霉素、头孢、四环素同用减弱抗菌效果，须间隔4 h |
| **巯基怕碰金属** | 巯基化合物易被氧化，避免接触金属、橡胶 |
| **溃疡哮喘要慎用** | 消化道溃疡和支气管哮喘患者慎用 |

## 为什么要记口诀？

乙酰半胱氨酸是祛痰药中考点最多的药物（pH依赖、抗生素禁忌、金属禁忌、解毒用途、支气管痉挛），口诀把高频考点一网打尽。
