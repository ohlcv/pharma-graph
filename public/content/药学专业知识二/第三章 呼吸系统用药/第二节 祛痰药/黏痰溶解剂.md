# 黏痰溶解剂

## 它是什么药？

通过直接**裂解痰液中黏性成分（黏多糖、黏蛋白）的分子结构**，使黏痰液化、黏度降低，从而易于咳出。是祛痰药中作用最强的亚类。

## 代表药有哪些？

| 药物 | 特点 |
|---|---|
| **乙酰半胱氨酸** | 裂解二硫键，作用最强，兼具解毒作用 |
| **氨溴索** | 临床最常用，可增强抗菌药肺组织浓度 |
| **溴己新** | 经典黏痰溶解剂 |
| **桉柠蒎** | 兼具抗炎、扩张支气管 |
| **羧甲司坦** | 口服给药，使用方便 |
| **厄多司坦** | 口服给药 |
| **福多司坦** | 推荐餐后服用 |
| **糜蛋白酶** | 雾化吸入，溶解黏痰 |

## 和恶心性祛痰药的区别是什么？

- **恶心性祛痰药**：刺激胃黏膜 → 反射性增加分泌 → 痰液被稀释（间接作用）
- **黏痰溶解剂**：直接裂解黏痰分子结构 → 痰液液化（直接作用，作用更强）

## 典型不良反应是什么？

- 恶心、胃肠道不适
- 乙酰半胱氨酸：可能引起支气管痉挛（哮喘患者慎用）

## 它和章的关系？

它是祛痰药两大分类之一，定位"黏痰溶解剂，直接裂解黏痰分子，作用最强"。
