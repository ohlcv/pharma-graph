# NSAIDs 用药原则

## 核心选药原则是什么？

**按COX选择性选药**：
- **非选择性NSAIDs**：胃肠道风险高（阿司匹林、布洛芬、吲哚美辛等）
- **选择性COX-2抑制剂**：心血管风险高（塞来昔布、依托考昔等）

口诀：**"非胃心选"**——非选择性药物**胃**肠道风险高，选择性药物**心**血管风险高。

## 各类情况如何选药？

| 临床情况 | 推荐药物 | 原因 |
|---|---|---|
| 轻度疼痛/发热（无炎症） | **对乙酰氨基酚** | 无抗炎作用，安全性好 |
| 需抗炎镇痛（胃肠道正常） | **布洛芬**等芳基丙酸类 | 抗炎镇痛效果确切，胃肠道耐受 |
| 胃溃疡高危人群 | 选择性COX-2抑制剂或+ PPI | 减少胃肠道风险 |
| 心血管高危人群 | 避免选择性COX-2抑制剂 | 心血管风险 |
| 肾功能不全/老年人 | 慎用非选择性NSAIDs | 肾损伤风险 |
| 阿司匹林哮喘患者 | 避免所有NSAIDs | 可能诱发哮喘 |
| 儿童退热 | **对乙酰氨基酚**、**布洛芬** | 安全性好 |

## 用药注意事项是什么？

- **不联用两种NSAIDs**（胃肠道+肾毒性叠加，无额外获益）
- 定期监测肝肾功能
- 避免长期大剂量使用
- 餐后服用减轻胃肠道刺激
- 老年人、小剂量起始，逐渐加量
