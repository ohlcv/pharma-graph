# NSAIDs 致消化性溃疡

## 发病机制是什么？

NSAIDs抑制**胃黏膜COX-1**，导致：
1. 减少**黏液和碳酸氢盐分泌**（黏膜保护层削弱）
2. 减少**黏膜血流**（黏膜修复能力下降）
3. 直接损伤胃黏膜上皮细胞

结果：从上腹不适→黏膜糜烂→**消化性溃疡**→出血→穿孔

## 风险因素是什么？

| 因素 | 说明 |
|---|---|
| **非选择性COX抑制剂** | 风险最高 |
| 高剂量/长期使用 | 风险随剂量和疗程增加 |
| 老年人群 | 胃黏膜防御功能下降 |
| 既往溃疡病史 | 高危人群 |
| 联用糖皮质激素/抗凝药 | 风险叠加 |

## 如何预防？

- **高危人群**：联用**质子泵抑制剂（PPI）**或**米索前列醇**
- 选用**选择性COX-2抑制剂**（胃肠道风险低）
- **餐后服用**，避免空腹
- 避免联用糖皮质激素或抗凝药

## 它和章的关系？

它是NSAIDs最常见的胃肠道不良反应，理解机制有助于掌握预防和选药原则。
