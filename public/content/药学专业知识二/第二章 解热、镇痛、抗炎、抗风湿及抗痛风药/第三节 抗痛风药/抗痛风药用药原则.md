# 抗痛风药用药原则

## 核心治疗原则是什么？

**急性发作期**：抗炎镇痛为主，禁用新增降尿酸药。

**缓解期**：长期控制血尿酸为主，个体化选药。

## 急性期用药原则是什么？

- **首选秋水仙碱**（发病24小时内，超过48小时效果差）
- **NSAIDs一线**（布洛芬、双氯芬酸等，足量用至缓解）
- **激素备用**（NSAIDs/秋水仙碱无效或不耐受时）
- **禁止两种NSAIDs联用**
- 急性期**不新增降尿酸药**（会使尿酸波动加重炎症）
- 已长期服用降尿酸药者发作时**无需停药**，维持原剂量

## 缓解期选药原则是什么？

| 情况 | 首选药物 |
|---|---|
| 尿酸生成过多型 | 别嘌醇 / 非布司他（抑制生成） |
| 尿酸排泄减少型、肾功能正常、无肾结石 | 苯溴马隆 / 丙磺舒（促排泄） |
| 肾功能不全 | 非布司他（更安全） |
| 肾结石病史 | 别嘌醇 / 非布司他（不增加尿尿酸） |
| 有痛风石 | 目标血尿酸<300 μmol/L |

## 降尿酸治疗初期注意点是什么？

启动降尿酸治疗前**3~6个月**，联用**小剂量秋水仙碱**或**NSAIDs**预防急性发作。

## 通用生活管理原则是什么？

- **低嘌呤饮食**（限制海鲜、动物内脏、浓汤、啤酒）
- **多饮水**（每日尿量2000 mL以上）
- **限酒**
- **控制体重**
- **避免升高血尿酸的药物**（噻嗪类利尿剂、小剂量阿司匹林）

## 口诀总结是什么？

- 秋水仙碱："治疗窗很窄，胃肠道是中毒信号，24h不过6"
- 别嘌醇："别生成，不生成"（抑制尿酸生成）
- 苯溴马隆："笨马排黄尿"（促进尿酸排泄）
