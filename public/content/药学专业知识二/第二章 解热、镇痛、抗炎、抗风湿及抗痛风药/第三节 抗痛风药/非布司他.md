# 非布司他

## 它是什么？

属于**抑制尿酸生成药**（黄嘌呤氧化酶抑制剂），新型高选择性黄嘌呤氧化酶抑制剂。降尿酸强度和起效速度均优于别嘌醇。

## 临床应用是什么？

- **痛风和高尿酸血症的长期控制**
- 尤其适合别嘌醇不耐受或有使用禁忌的患者

## 和别嘌醇的区别是什么？

| 对比 | 别嘌醇 | 非布司他 |
|---|---|---|
| 类型 | 经典 | 新型 |
| 降尿酸强度 | 较强 | **更强** |
| 起效速度 | 较慢 | **更快** |
| 肝肾功能不全 | 需减量 | **无需调整**（轻中度） |
| 过敏风险 | **高**（HLA-B*5801需筛查） | **低**（无交叉过敏） |
| 嘌呤/嘧啶代谢干扰 | 有 | **无** |
| 心血管风险 | 无 | 需关注 |

## 典型不良反应是什么？

- 肝功能异常
- 恶心
- 关节痛
- 皮疹
- **心血管风险**：长期使用需关注心血管事件，有严重心脑血管基础病者慎用

## 临床注意是什么？

- 轻中度肝肾功能不全无需调整剂量
- 与别嘌醇无交叉过敏
- 不干扰正常嘌呤、嘧啶代谢

## 它和章的关系？

它是抑制尿酸生成药的代表药，定位"新型黄嘌呤氧化酶抑制剂，降尿酸作用更强，安全性更好，轻中度肝肾功能不全无需调整剂量"。
