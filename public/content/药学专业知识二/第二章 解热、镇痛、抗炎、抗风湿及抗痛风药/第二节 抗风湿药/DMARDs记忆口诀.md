# DMARDs记忆口诀

## 口诀是什么？

**"阿凡达的丈夫（得了肿瘤）他疯了"**

## 口诀如何拆解？

| 口诀片段 | 对应药物/分类 | 解释 |
|---|---|---|
| **阿** | 阿达木单抗 | TNF‑α抑制剂，单克隆抗体 |
| **的** | TNF‑α（肿瘤坏死因子） | 靶点 |
| **丈** | 依那西普 | TNF‑α抑制剂，融合蛋白 |
| **夫** | — | 连接词 |
| **得** | — | 连接词 |
| **肿** | — | 连接词 |
| **瘤** | 肿瘤坏死因子 | TNF‑α的全称 |
| **他** | 司库奇尤单抗、依奇珠单抗 | IL‑17抑制剂 |
| **疯** | 托法替布、巴瑞替尼 | JAK抑制剂（谐音"疯"） |

## 口诀对应哪个分类？

此口诀对应**生物制剂及靶向DMARDs**的分类记忆。

## 它和章的关系？

是bDMARDs/tsDMARDs分类的辅助记忆，定位"阿凡达的丈夫（得了肿瘤）他疯了 = TNF‑α抑制剂 + IL‑17抑制剂 + JAK抑制剂"。
