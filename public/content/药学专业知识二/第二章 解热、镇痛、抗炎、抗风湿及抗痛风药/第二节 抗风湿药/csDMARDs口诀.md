# csDMARDs 口诀

## 口诀是什么？

**"甲乙丙丁戊，红金双"**——甲（**甲氨蝶呤**）、乙（**来氟米特**）、丙（**柳氮磺吡啶**）、丁（金诺**芬**）、戊（羟氯**喹**）、红（金诺**芬**的"金"）、双（**双醋瑞因**）。

## 口诀怎么记？

| 口诀 | 代表药 | 临床定位 |
|---|---|---|
| **甲** | **甲氨蝶呤** | 类风湿锚定药、首选药 |
| **乙** | **来氟米特** | 类风湿、狼疮肾炎 |
| **丙** | **柳氮磺吡啶** | 强直、类风湿、溃疡性结肠炎 |
| **丁/红** | **金诺芬** | 活动性类风湿 |
| **戊** | **羟氯喹** | 系统性红斑狼疮基础用药 |
| **双** | **双醋瑞因** | 退行性骨关节炎 |

## 为什么要记口诀？

csDMARDs 是抗风湿药的核心，代表药众多，口诀帮助快速记忆六大传统合成DMARDs及其临床定位。
