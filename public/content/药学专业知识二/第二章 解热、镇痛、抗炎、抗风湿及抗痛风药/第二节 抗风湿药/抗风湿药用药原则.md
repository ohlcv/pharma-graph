# 抗风湿药用药原则

## 核心用药原则是什么？

**① 定位原则**：对症药（NSAIDs/糖皮质激素）**不延缓病程**，DMARDs才是核心治疗药物。

**② 联合原则**：对症药可与DMARDs联用（对症缓解 + 改善病情）；但**NSAIDs不宜与糖皮质激素联用**（胃肠道风险叠加）。

**③ csDMARDs是基础**：所有风湿免疫病患者一经确诊，应尽早启动csDMARDs治疗，甲氨蝶呤是类风湿关节炎锚定药。

**④ 阶梯原则**：
- 轻度/早期：NSAIDs + csDMARDs
- 中重度/传统药不耐受：csDMARDs + bDMARDs/tsDMARDs
- 重症急性发作：NSAIDs/糖皮质激素 + 桥接csDMARDs

**⑤ 生物制剂筛查原则**：使用bDMARDs/tsDMARDs前必须**筛查结核和乙肝**，阳性者先治疗感染。

## 各类药物的核心考点是什么？

| 药物 | 核心考点 |
|---|---|
| **甲氨蝶呤** | 每周1次，补充叶酸，骨髓抑制+致畸 |
| **来氟米特** | 长半衰期，强致畸，停药需洗脱 |
| **柳氮磺吡啶** | 磺胺过敏禁用，男性可逆不育 |
| **羟氯喹** | SLE基础用药，眼底检查防视网膜病变 |
| **双醋瑞因** | IL-1抑制剂，骨关节炎，腹泻+尿液变黄 |
| **TNF-α抑制剂** | 感染筛查是共性要求 |
| **JAK抑制剂** | 血栓风险是重要关注点 |
