# 生物制剂及靶向改善病情的抗风湿药

## 它是什么？

精准靶向炎症通路关键分子的抗风湿药，**起效快、疗效强**，用于传统DMARDs疗效不佳或不耐受的中重度患者。

## 按靶点分哪几类？

| 靶点 | 代表药 |
|---|---|
| **TNF‑α抑制剂** | 依那西普（融合蛋白）、阿达木单抗、英夫利昔单抗（单克隆抗体） |
| **IL‑17抑制剂** | 司库奇尤单抗、依奇珠单抗 |
| **JAK抑制剂** | 枸橼酸托法替布、巴瑞替尼 |
| **IL‑1拮抗剂** | 阿那白滞素 |
| **IL‑6拮抗剂** | 托珠单抗 |

## 记忆口诀是什么？

**"阿凡达的丈夫（得了肿瘤）他疯了"**——**阿**达**木**单抗、**的**（TNF‑α）、**丈**夫（**依那西**普）、**得**了**肿**瘤（TNF‑α抑制剂）、**他**（IL‑17：**司库奇尤单抗**、**依奇珠单抗**）、**疯**了（JAK激酶抑制剂）。

## 共性不良反应是什么？

1. **感染风险升高**：可激活潜伏结核、乙肝，用药前需常规筛查
2. 过敏/输注反应
3. 恶性肿瘤风险升高

## 它和章的关系？

是DMARDs的进阶分支，定位"靶向精准，起效快，感染风险升高是共性风险"。
