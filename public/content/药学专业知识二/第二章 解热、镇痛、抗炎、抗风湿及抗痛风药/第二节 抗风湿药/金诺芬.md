# 金诺芬

## 它是什么？

属于**csDMARDs**，是口服金制剂，通过抑制免疫细胞活性、减少炎症因子发挥作用。**起效慢**，用于活动性类风湿关节炎，延缓病情进展。

## 典型不良反应是什么？

| 系统 | 表现 |
|---|---|
| 胃肠道 | 腹泻、腹痛、恶心 |
| 黏膜 | 口腔炎、结膜炎 |
| 皮肤 | 皮疹、瘙痒、色素沉着 |
| 血液系统 | 粒细胞减少、血小板减少 |
| 肾脏 | 蛋白尿、血尿 |

## 它和章的关系？

它是csDMARDs代表药之一，定位"口服金制剂，起效慢，不良反应涉及多系统"。
