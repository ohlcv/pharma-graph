# 阿达木单抗口诀

## 口诀是什么？

**"阿达的丈夫得了肿瘤他疯了"**

## 口诀怎么记？

| 口诀 | 代表药 |
|---|---|
| **阿达** | **阿达木单抗**（TNF-α抑制剂） |
| **的丈夫** | **依那西普**（TNF-α抑制剂） |
| **得了肿瘤** | **TNF-α**抑制剂（肿瘤坏死因子-α抑制剂） |
| **他疯了** | **IL-17**抑制剂（**司库奇尤单抗**、**依奇珠单抗**） |

## 为什么要记口诀？

快速记住TNF-α抑制剂（阿达木单抗、依那西普、英夫利昔单抗）和IL-17抑制剂（司库奇尤单抗、依奇珠单抗），区分bDMARDs不同靶点类别。
