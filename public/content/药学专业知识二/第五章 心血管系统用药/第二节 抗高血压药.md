# 抗高血压药


## 这一节在讲什么？

这一节讲的是用于降低血压的药物，按六大类组织：①利尿药（氢氯噻嗪、吲达帕胺）；②钙通道阻滞剂CCB（硝苯地平、氨氯地平、维拉帕米、地尔硫䓬等）；③肾素-血管紧张素系统抑制药（ACEI普利类、ARB沙坦类、肾素抑制剂、ARNI沙库巴曲缬沙坦）；④交感神经抑制药（中枢性可乐定、α₁阻断剂哌唑嗪、β阻断剂美托洛尔、αβ联合阻断剂拉贝洛尔等）；⑤直接扩血管药（肼屈嗪、硝普钠）；⑥其他类（钾通道开放药米诺地尔、5-HT拮抗药酮色林、前列环素合成促进药西氯他宁）。

## 为什么要理解它？

因为高血压是全球心血管死亡最重要的可改变危险因素，降压治疗是临床最常见也最重要的公共卫生干预之一。理解六大类降压药的特点和个体化选药原则（糖尿病肾病选ACEI/ARB、老年选CCB、心衰选ACEI/ARB+β阻断剂+醛固酮拮抗剂、妊娠选拉贝洛尔+甲基多巴+硝苯地平），是临床药师参与高血压管理的核心能力。

## 它主要和什么有关？

它最容易和抗心力衰竭药连起来理解——ACE/ARB和β受体拮抗剂同时是高血压和心衰治疗的核心药物，高血压是心衰最重要的上游危险因素，降压治疗是心衰预防的关键环节。同时，高血压和高血脂常常共存，两者联合管理是心血管风险综合干预的重要组成部分。

## 它通常在什么阶段出现？

它出现在心血管系统用药学习的早期阶段，是临床处方量最大的药物类别之一。学到这里，已经开始理解"六大类降压药各有所长，个体化选药基于患者的具体合并症"这一核心判断原则。

## 它在整套框架里放在哪里？

它位于《药学专业知识二》第五章第二节，是整章中临床应用最广、与多系统关联最多的核心节点。往上承接心血管用药总框架，往下可通向高血压个体化治疗方案和联合用药策略。

## 血压调节机制是什么？

血压通过三条系统共同调控，所有降压药的作用靶点都对应这三条系统的不同环节：

**① 交感神经系统**
- 路径：中枢→神经节→神经末梢释放去甲肾上腺素→作用于 α、β 受体
- 效应：调控血管收缩与心率
- 对应降压药：中枢性降压药、神经节阻断药、α/β 受体阻断剂

**② 肾素-血管紧张素-醛固酮系统（RAAS）**
- 路径：血管紧张素原 →（肾素）→ AngⅠ →（ACE）→ AngⅡ → 作用于 AT₁ 受体
- 效应：血管收缩、醛固酮释放、水钠潴留、血压升高
- 对应降压药：ACEI（卡托普利等）、ARB（氯沙坦等）、肾素抑制剂（阿利吉仑）、ARNI（沙库巴曲缬沙坦）

**③ 血管舒张机制**
- 路径：钾通道开放、NO 释放等途径
- 效应：直接舒张血管、降低血压
- 对应降压药：CCB（二氢吡啶类）、直接扩血管药（肼屈嗪、硝普钠）、钾通道开放药（米诺地尔）

利尿药通过排钠利尿降低血容量，进而下调 RAAS 活性，与三条系统也有间接关系。

## β受体亚型与作用是什么？

β受体分为 β₁、β₂、β₃ 三种亚型，分布不同、效应不同：

| 亚型 | 主要分布 | 激动效应 | 阻断临床意义 |
|---|---|---|---|
| **β₁** | 心脏 | 加快心率、增强心肌收缩力、升高血压 | β₁ 阻断→降低心排血量、降低血压（β 阻断剂降压核心机制） |
| **β₂** | 支气管、血管平滑肌、骨骼肌 | 舒张支气管、扩张血管、升高血糖 | β₂ 阻断→支气管痉挛（哮喘患者禁用非选择性 β 阻断剂）、血管收缩 |
| **β₃** | 脂肪组织 | 促进脂肪分解 | β₃ 阻断→影响脂肪代谢、可能影响体重 |

β受体阻断剂的选择性梯度（非选择性→选择性 β₁）正是基于这三种亚型的分布和效应差异：非选择性 β 阻断剂在哮喘患者禁用，而选择性 β₁ 可以。

## 常用降压药的临床选择原则是什么？

六大类降压药各有其适应人群和禁忌，是临床安全选药的总则：

| 类别 | 适用 | 禁用/慎用 |
|---|---|---|
| **① 二氢吡啶类 CCB** | 老年高血压、单纯收缩期高血压、伴稳定型心绞痛、动脉粥样硬化、周围血管病 | 快速型心律失常、心力衰竭慎用 |
| **② 非二氢吡啶类 CCB** | 心绞痛、颈动脉粥样硬化、室上性心动过速 | 二至三度房室传导阻滞、心力衰竭禁用 |
| **③ ACEI/ARB** | 慢性心衰、心肌梗死后、左室肥厚、糖尿病肾病、代谢综合征 | 双侧肾动脉狭窄、高钾血症、妊娠禁用 |
| **④ 噻嗪类利尿药** | 老年高血压、单纯收缩期高血压、心力衰竭 | 痛风禁用 |
| **⑤ β受体阻断剂** | 冠心病心绞痛、心肌梗死后、慢性心衰、快速心律失常、交感活性增高 | 二至三度房室传导阻滞、哮喘、慢阻肺禁用 |
| **⑥ α受体阻断剂** | 高血压伴前列腺增生、难治性高血压 | 体位性低血压禁用；心力衰竭慎用 |

## 高血压合并症选药表是什么？

高血压合并不同疾病时首选/禁用药物不同，是抗高血压药学习的核心应用框架：

| 合并情况 | 首选/宜用药物 | 禁用/慎用 |
|---|---|---|
| 糖尿病肾病、蛋白尿 | ACEI、ARB、ARNI | - |
| 左心室肥厚 | ACEI、ARB、ARNI、CCB | - |
| 心力衰竭 | ACEI/ARB/ARNI、β受体阻断剂、醛固酮受体拮抗剂 | - |
| 冠心病、心绞痛 | β受体阻断剂、CCB、ACEI/ARB | - |
| 支气管哮喘、慢阻肺 | CCB | 非选择性β受体阻断剂禁用 |
| 痛风 | - | 噻嗪类利尿药禁用 |
| 前列腺增生 | α₁受体阻断剂 | 体位性低血压患者禁用 |
| 妊娠高血压 | 拉贝洛尔、甲基多巴、硝苯地平 | ACEI、ARB、肾素抑制剂禁用 |

口诀："比美专治心衰"——比索洛尔、美托洛尔是慢性心衰的 β 阻断剂基石。

## CCB与β受体阻断剂对比是什么？

CCB 与 β受体阻断剂是高血压和心绞痛治疗中最重要的两大类药物：

**相同点**：均可治疗心绞痛、降低血压、减少心肌耗氧量；两者联用可显著增强降压疗效，并互相抵消不良反应（CCB 致反射性心动过速，β 阻断剂抵消）。

**相反点**：

| 临床场景 | 首选 | 理由 |
|---|---|---|
| 伴雷诺综合征 | 二氢吡啶类 CCB | 扩血管、改善雷诺 |
| 下肢间歇性跛行 | 二氢吡啶类 CCB | β阻断剂可能加重外周血管收缩 |
| 变异型心绞痛 | 二氢吡啶类 CCB | 扩张冠脉、解除痉挛 |
| 支气管哮喘 | 二氢吡啶类 CCB | β阻断剂可能诱发支气管痉挛 |
| 交感神经兴奋 | β受体阻断剂 | 阻断交感活性 |
| 甲亢 | β受体阻断剂 | 控制甲亢所致心动过速 |
| 窦性心动过速 | β受体阻断剂 | 直接减慢心率 |

## 高频考点补充是什么？

五大最高频考点药物的特征总结：

**① 卡托普利**——唯一含巯基的 ACEI，可舌下含服，用于高血压急症。

**② 硝苯地平**——短效二氢吡啶类 CCB，降压快但血药浓度波动大，易致反射性心动过速、心悸、头痛；第二代控释片、第三代长效药可改善这些问题。

**③ 硝普钠**——高血压急症、高血压危象、手术控制性降压的首选；代谢产物为硫氰酸盐，肾功能不全或大剂量使用易蓄积；不良反应：氰化物中毒、硫氰酸盐蓄积、光敏、低血压。口诀："硝普钠是事儿妈，光敏中毒低血压，不是急事别找它"。

**④ 哌唑嗪**——α₁ 受体阻断剂，首剂现象明显（首次给药可致严重体位性低血压），睡前服用可减轻。

**⑤ 氢氯噻嗪**——基础降压药，小剂量使用，常与其他药物联用。
