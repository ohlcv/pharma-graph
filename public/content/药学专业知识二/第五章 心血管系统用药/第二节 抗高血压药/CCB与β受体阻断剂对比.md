# CCB与β受体阻断剂对比

## 这是什么？

这是抗高血压药学习的**核心对比框架**——CCB 与 β受体阻断剂是高血压和心绞痛治疗中最重要的两大类药物，临床选药时常常需要二者对比。

## 相同点是什么？

- **治疗心绞痛**：两者均可通过减少心肌耗氧量治疗心绞痛
- **降低血压**：两者均为一线降压药
- **减少心肌耗氧量**：β阻断剂通过降低心率和心肌收缩力，CCB 通过扩张冠脉和降低后负荷
- **可联合用药**：两者联用可显著增强降压疗效，并互相抵消不良反应（CCB致反射性心动过速，β阻断剂抵消）

## 相反点是什么？

| 临床场景 | 首选 | 理由 |
|---|---|---|
| 伴雷诺综合征 | 二氢吡啶类CCB | 扩血管、改善雷诺 |
| 下肢间歇性跛行 | 二氢吡啶类CCB | β阻断剂可能加重外周血管收缩 |
| 变异型心绞痛 | 二氢吡啶类CCB | 扩张冠脉、解除痉挛 |
| 支气管哮喘 | 二氢吡啶类CCB | β阻断剂可能诱发支气管痉挛 |
| 交感神经兴奋 | β受体阻断剂 | 阻断交感活性 |
| 甲亢 | β受体阻断剂 | 控制甲亢所致心动过速 |
| 窦性心动过速 | β受体阻断剂 | 直接减慢心率 |

## 为什么要理解它？

因为高血压合并不同心血管疾病时，**CCB 和 β阻断剂的选择常呈"反向"**——理解它们的对比，能快速做出临床选药决策。

## 它和什么有关？

它和CCB大类、β阻断剂大类都密切相关，是两类药物临床定位的对照参考。

## 它通常在什么阶段出现？

它出现在理解CCB和β阻断剂各自的作用特点之后，是把"两类药物对比→临床决策"落到实处的关键节点。
