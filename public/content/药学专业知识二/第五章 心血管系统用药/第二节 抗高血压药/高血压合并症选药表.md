# 高血压合并症选药表

## 这是什么？

这是抗高血压药学习的**核心应用框架**——高血压合并不同疾病时首选/禁用药物的速查表。

## 怎么选药？

| 合并情况 | 首选/宜用药物 | 禁用/慎用 |
|---|---|---|
| 糖尿病肾病、蛋白尿 | ACEI、ARB、ARNI | - |
| 左心室肥厚 | ACEI、ARB、ARNI、CCB | - |
| 心力衰竭 | ACEI/ARB/ARNI、β受体阻断剂、醛固酮受体拮抗剂 | - |
| 冠心病、心绞痛 | β受体阻断剂、CCB、ACEI/ARB | - |
| 支气管哮喘、慢阻肺 | CCB | 非选择性β受体阻断剂禁用 |
| 痛风 | - | 噻嗪类利尿药禁用 |
| 前列腺增生 | α₁受体阻断剂 | 体位性低血压患者禁用 |
| 妊娠高血压 | 拉贝洛尔、甲基多巴、硝苯地平 | ACEI、ARB、肾素抑制剂禁用 |

**口诀**："比美专治心衰"——比索洛尔、美托洛尔是慢性心衰的β阻断剂基石。

## 为什么要记住它？

因为高血压患者**几乎都合并其他疾病**——糖尿病、冠心病、心衰、肾病的患病率很高。掌握合并症选药是临床安全用药的核心。

## 它和什么有关？

它和六大类降压药的全部子模块都相关——每个合并症的首选/禁用都对应特定的药物类别。它是"药物分类→临床应用"的桥梁。

## 它通常在什么阶段出现？

它出现在理解六大类降压药的全部亚类之后，是把分类知识落到"具体患者群选药"的关键节点。

## 它在整套框架里放在哪里？

它位于《药学专业知识二》第五章第二节抗高血压药节下属的应用框架节点，是抗高血压药学习的"集大成"节点。
