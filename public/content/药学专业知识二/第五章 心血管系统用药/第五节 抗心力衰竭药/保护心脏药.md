# 保护心脏药（心衰）

## 它是什么药？

通过抑制RAAS、利尿、排糖等机制**延缓心室重构、改善心衰预后**的药物。

## 六大类

| 类别 | 代表药 | 核心作用 |
|---|---|---|
| **ACEI** | 卡托普利、依那普利等 | 抑制RAAS，延缓心室重构 |
| **ARB** | 缬沙坦、氯沙坦等 | 不能耐受ACEI干咳者 |
| **ARNI**（复方制剂） | 沙库巴曲缬沙坦 | 抑制RAAS+减少利钠肽降解 |
| **利尿剂** | 呋塞米、氢氯噻嗪、螺内酯等 | 缓解水钠潴留 |
| **SGLT-2抑制剂** | 达格列净、恩格列净等 | 促进肾脏排糖排钠 |
| **sGC激动剂** | 维立西呱 | 直接刺激sGC，改善心肌重构 |

## 核心要点

### ACEI/ARB

- 改善心室重构，降低HFrEF患者的心血管死亡与住院风险
- ARB用于不能耐受ACEI干咳的患者

### ARNI（沙库巴曲缬沙坦）

- 沙库巴曲抑制脑啡肽酶减少利钠肽降解
- 缬沙坦阻断AT₁受体抑制RAAS
- 适用于NYHA Ⅱ~Ⅳ级、LVEF≤40%的HFrEF
- **禁忌**：禁止与ACEI合用（需停ACEI至少36小时再换用ARNI）

### 盐皮质激素受体拮抗剂（螺内酯）

- 拮抗醛固酮，减少水钠潴留、降低血压
- 在ACEI/ARB+β受体拮抗剂基础上加用，可降低死亡率与心衰住院风险

### SGLT-2抑制剂

- 促进肾脏排糖、排钠，降低血糖与血压
- 降低心梗后心衰加重患者的心血管死亡与心衰住院风险

### sGC激动剂（维立西呱）

- 直接刺激可溶性鸟苷酸环化酶
- 改善心肌重构
- 降低心血管死亡与心衰住院风险

## 记忆口诀是什么？

**"心衰保护六罗汉：普利洛尔醛固酮，排糖维立沙库巴"**

| 口诀 | 代表药 |
|---|---|
| **普利** | ACEI（卡托普利、依那普利） |
| **洛尔** | ARB（缬沙坦、氯沙坦） |
| **醛固酮** | 螺内酯（盐皮质激素受体拮抗剂） |
| **排糖** | SGLT-2抑制剂（达格列净、恩格列净） |
| **维立** | 维立西呱（sGC激动剂） |
| **沙库巴** | 沙库巴曲缬沙坦（ARNI） |

**为什么要记？** 保护心脏六类药物是改善预后的核心框架，与正性肌力药、控制心率药共同构成心衰治疗全景。

## 它和章的关系？

保护心脏是心衰治疗改善预后的核心，定位"ACEI/ARB/ARNI+利尿剂+SGLT-2i+螺内酯+sGC激动剂，六类药物延缓心室重构、改善预后，是心衰治疗的基石"。
