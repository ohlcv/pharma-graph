# 抗心力衰竭药

## 总论

**慢性心功能不全**是多种病因所致的各种心脏疾病的终末阶段，既是一种超负荷心肌病，也是心功能异常状态下的病理生理反应，目前**药物治疗是主要治疗手段**。

## 治疗目标

| 目标 | 说明 |
|---|---|
| **缓解心衰症状** | 减轻呼吸困难、水肿等 |
| **延缓疾病进展** | 抑制心室重构 |
| **降低心血管死亡与住院风险** | 改善预后 |

## 一、分类与代表药品

### （一）正性肌力药

| 类别 | 代表药 |
|---|---|
| **强心苷类** | 地高辛、洋地黄毒苷、去乙酰毛花苷（西地兰D）、毒毛花苷K |
| **非强心苷类** | 米力农、多巴酚丁胺、氨力农 |

### （二）控制心率

| 类别 | 代表药 |
|---|---|
| **选择性β₁受体拮抗** | 美托洛尔、比索洛尔 |
| **α+β受体拮抗** | 卡维地洛 |
| **单纯降低心率** | 伊伐布雷定 |

### （三）保护心脏

| 类别 | 代表药 |
|---|---|
| **ACEI** | 卡托普利、依那普利等 |
| **ARB** | 缬沙坦、氯沙坦等 |
| **ARNI（沙库巴曲缬沙坦）** | 沙库巴曲+缬沙坦复方 |
| **利尿剂** | 呋塞米、氢氯噻嗪、螺内酯等 |
| **SGLT-2抑制剂** | 达格列净、恩格列净等 |
| **sGC激动剂** | 维立西呱 |

## 二、临床常用八类治疗药物

1. **利尿剂**
2. **ACEI / ARB / ARNI**
3. **β受体拮抗剂**
4. **盐皮质激素受体拮抗剂（螺内酯）**
5. **SGLT-2抑制剂**
6. **可溶性鸟苷酸环化酶激动剂（维立西呱）**
7. **伊伐布雷定**
8. **地高辛**

## 三、核心定位

| 药物 | 定位 |
|---|---|
| **伊伐布雷定** | 已使用ACEI/ARB/ARNI + β受体拮抗剂 + 醛固酮受体拮抗剂后，心率仍≥70次/分者；或β受体拮抗剂禁忌/不耐受者 |
| **地高辛** | 减轻心衰症状，改善心功能，用于HFrEF持续有症状者 |

## 记忆口诀是什么？

**"心衰治疗八罗汉：利尿普利和洛尔，醛固酮拮抗排糖王，维立西呱伊伐布雷定，地高辛来把症状清"**

| 口诀 | 代表药 |
|---|---|
| **利尿** | 利尿剂（呋塞米、螺内酯） |
| **普利** | ACEI/ARB/ARNI |
| **洛尔** | β受体拮抗剂 |
| **醛固酮拮抗** | 螺内酯 |
| **排糖王** | SGLT-2抑制剂（达格列净、恩格列净） |
| **维立西呱** | sGC激动剂 |
| **伊伐布雷定** | 单纯降低心率 |
| **地高辛** | 正性肌力 |

**为什么要记？** 心衰治疗八类药物是临床用药评价的核心框架，涵盖缓解症状、改善预后两大目标，口诀一网打尽。
