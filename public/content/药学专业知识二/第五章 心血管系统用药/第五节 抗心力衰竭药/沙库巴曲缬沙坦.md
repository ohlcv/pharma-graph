# 沙库巴曲缬沙坦（ARNI）

## 它是什么？

**复方制剂**，含脑啡肽酶抑制剂**沙库巴曲** + AT₁受体拮抗剂**缬沙坦**。

## 双重作用机制

| 组分 | 作用 |
|---|---|
| **沙库巴曲** | 抑制脑啡肽酶，减少利钠肽（ANP、BNP）降解 |
| **缬沙坦** | 阻断AT₁受体，抑制RAAS |

## 适应证

| 适应证 | 说明 |
|---|---|
| **HFrEF** | 射血分数降低的慢性心衰（NYHA Ⅱ~Ⅳ级，LVEF≤40%）成人患者，降低心血管死亡和心衰住院风险 |
| **原发性高血压** | 降压 |

## 用法用量

- 常规起始：**100mg/次，每日2次**
- 未使用过ACEI/ARB者起始：**50mg/次，每日2次**

## 典型不良反应

低血压、高钾血症、咳嗽、头晕、血管性水肿

## 禁忌

| 禁忌 | 原因 |
|---|---|
| **与ACEI合用** | 从ACEI转换需停药至少36小时 |
| **ACEI/ARB相关血管性水肿病史** | 再发风险 |
| **血钾>5.4mmol/L** | 加重高钾 |
| **重度肝功能损害** | 代谢障碍 |
| **胆汁性肝硬化、胆汁淤积** | 排泄障碍 |
| **妊娠中晚期** | 致畸风险 |

## 它和章的关系？

沙库巴曲缬沙坦是ARNI代表药，定位"脑啡肽酶抑制剂+ARB复方，HFrEF优选，ACEI换用需停36h，高钾血症禁用"。
