# 洋地黄毒苷

## 它是什么？

**长效强心苷**，经肝脏代谢，受肾功能影响小。

## 核心作用特点

| 特点 | 说明 |
|---|---|
| **效价** | 长效 |
| **起效** | 1~4小时 |
| **达峰** | 8~14小时 |
| **半衰期** | 7天以上 |
| **代谢** | 主要经**肝脏代谢** |
| **肾功能影响** | 受肾功能影响小 |
| **特点** | 消除缓慢，有蓄积性 |

## 临床应用

- 慢性心力衰竭（尤其适用于**肾功能不全**患者）
- 需长期控制心室率的房颤

## 典型不良反应

- **胃肠道**：恶心、呕吐、腹泻
- **心脏毒性**：心律失常

## 优势

不受肾功能影响——这是相对于地高辛（经肾排泄）的最大优势

## 它和章的关系？

洋地黄毒苷是强心苷类的长效代表药，定位"长效强心苷，半衰期7天以上，肝脏代谢为主，肾功能不全者可用"。
