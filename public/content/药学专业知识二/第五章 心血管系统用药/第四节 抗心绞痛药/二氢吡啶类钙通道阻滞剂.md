# 二氢吡啶类钙通道阻滞剂

## 它是什么？

二氢吡啶类钙通道阻滞剂选择性阻断血管平滑肌L型钙通道，**扩张血管**为主。

## 核心作用特点是什么？

| 特点 | 说明 |
|---|---|
| **主要作用** | 扩张外周动脉和冠状动脉 |
| **血流动力学** | 降低外周阻力（后负荷）和血压 |
| **心脏传导** | **不抑制**心脏传导 |
| **反射效应** | 反射性激活交感神经（可致心动过速） |

## 代表药有哪些？

| 药物 | 特点 |
|---|---|
| **氨氯地平** | 长效（每日1次），扩张冠脉作用强，用于稳定型心绞痛和高血压 |
| **非洛地平** | 长效，扩张外周血管，适合高血压伴心绞痛 |
| **硝苯地平** | 短效（普通片）；缓释/控释片可延长作用时间 |

## 临床应用是什么？

- **稳定型心绞痛**（尤其是冠状动脉痉挛性心绞痛）
- 高血压
- 变异性心绞痛

## 典型不良反应是什么？

- **头痛**（扩血管）
- **面部潮红**
- **踝部水肿**（毛细血管前扩张所致）
- **低血压**
- **反射性心动过速**

## 禁忌人群是什么？

- 严重主动脉瓣狭窄慎用
- 心源性休克禁用

## 它和章的关系？

二氢吡啶类CCB是钙通道阻滞剂的亚类，定位"扩张血管为主，反射性激活交感，不抑制心脏传导，用于心绞痛和高血压"。

## 记忆口诀是什么？

**"二氢吡啶扩血管，氨氯非洛和硝苯，反射心跳加快点"**

| 口诀 | 代表药 |
|---|---|
| **氨氯** | **氨氯地平**（长效，首选） |
| **非洛** | **非洛地平**（长效） |
| **硝苯** | **硝苯地平**（短效，缓/控释片可延长） |
| **扩血管** | 主要作用是选择性扩张外周动脉 |
| **反射心跳加快** | 扩张血管后反射性激活交感神经（心动过速） |

**为什么要记？** 快速记住二氢吡啶类CCB三大代表药（氨氯地平、非洛地平、硝苯地平），以及其扩张血管为主、反射性交感激活的作用特点，区分于非二氢吡啶类。
