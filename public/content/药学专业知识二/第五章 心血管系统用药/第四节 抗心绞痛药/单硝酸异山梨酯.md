# 单硝酸异山梨酯

## 它是什么？

**长效硝酸酯类**，无首关效应，生物利用度近100%。

## 核心作用特点是什么？

| 特点 | 说明 |
|---|---|
| **吸收特点** | 胃肠道吸收完全，**无首关效应** |
| **生物利用度** | **近100%** |
| **缓释片起效** | 60~90分钟起效；30~60分钟达峰；持续3~6小时 |
| **普通片起效** | 约60分钟起效；持续约12小时 |
| **半衰期** | 4~5小时 |
| **服药方式** | **每日晨起服药1次** |

## 用法用量是什么？

- **缓释片**：每日晨起服用1次
- **普通片**：约60分钟起效，持续约12小时，每日晨起服药1次

## 典型不良反应是什么？

- 扩血管反应：低血压、头痛、面部潮红
- 反射性心率加快
- 耐受性（连续使用24h可发生）

## 禁忌人群是什么？

- 青光眼患者禁用
- 严重低血压患者禁用
- 正在使用5型磷酸二酯酶抑制剂者禁用

## 它和章的关系？

单硝酸异山梨酯是硝酸酯类代表药，定位"长效硝酸酯类，无首关效应，生物利用度近100%，每日晨服1次"。

## 记忆口诀

**"每日一次缓缓晨读，单科100分"**

- **每日一次**：每日服药1次
- **缓缓**：缓释片
- **晨读**：晨起服用
- **单科100分**：单硝酸异山梨酯，生物利用度近100%
