# 抗心绞痛药

## 总论

**心绞痛**是缺血性心肌病的常见症状，是冠状动脉供血不足引起的心肌短暂缺血缺氧。冠心病是全球最常见的死亡原因之一，心绞痛是冠心病的典型表现。理解"减少耗氧+改善供氧"两条治疗路径，以及β受体阻滞剂作为一线首选的理由（降低心肌耗氧、减少心梗后死亡），是临床药师参与冠心病用药管理的核心能力。

## 治疗目标

慢性稳定型心绞痛的治疗主要有两个目标：

| 目标 | 药物类别 |
|---|---|
| **预防心肌梗死和猝死，改善预后** | 抗血小板药、抗凝药、他汀类、ACEI或ARB、β受体拮抗剂 |
| **减轻和缓解症状** | 硝酸酯类、β受体拮抗剂、钙通道阻滞剂 |

**核心要点**：β受体拮抗剂兼具改善缺血、减轻症状与预防心肌梗死、改善预后两方面作用。

## 一、缓解心肌缺血和减轻心绞痛症状

1. **硝酸酯类**
   代表：硝酸甘油、硝酸异山梨酯、单硝酸异山梨酯
2. **β受体拮抗剂**
   代表：美托洛尔、比索洛尔、卡维地洛、阿罗洛尔
3. **钙通道阻滞剂**
   - 二氢吡啶类：氨氯地平、非洛地平、硝苯地平
   - 非二氢吡啶类：维拉帕米、地尔硫卓

## 二、预防心肌梗死，改善预后

1. **抗血小板药**
   代表：阿司匹林、氯吡格雷、替格瑞洛
2. **抗凝药**
   代表：肝素、低分子肝素、华法林、达比加群酯
3. **他汀类药物**
   代表：洛伐他汀、辛伐他汀、普伐他汀等
4. **ACEI或ARB类药物**
   代表：雷米普利、培哚普利等
5. **β受体拮抗剂**
   代表：美托洛尔、比索洛尔、卡维地洛、阿罗洛尔

## 记忆口诀是什么？

**"心绞痛药分两类：症状缓解硝酸酯、β受体、CCB；预后改善阿司匹林、抗凝他汀和普利"**

| 口诀 | 代表药 |
|---|---|
| **硝酸酯** | 硝酸甘油（舌下含服首选）、硝酸异山梨酯、单硝酸异山梨酯 |
| **β受体** | 美托洛尔、比索洛尔、卡维地洛、阿罗洛尔 |
| **CCB** | 氨氯地平（二氢吡啶类）、维拉帕米/地尔硫卓（非二氢吡啶类） |
| **阿司匹林** | 抗血小板首选 |
| **抗凝** | 肝素、低分子肝素、华法林、达比加群酯 |
| **他汀** | 阿托伐他汀、瑞舒伐他汀等 |
| **普利** | ACEI/ARB（雷米普利、培哚普利等） |

**为什么要记？** 心绞痛药物分类是基础：两大类（症状缓解 vs 改善预后），β受体拮抗剂是唯一兼具双重作用的药物，口诀一网打尽。

## 它在整套框架里放在哪里？

它位于《药学专业知识二》第五章第四节，是整章中冠心病药物治疗的核心节点。往上承接心血管用药基础，往下可通向急性冠脉综合征的治疗和冠心病的长期二级预防方案。它最容易和抗高血压药连起来理解——β受体阻滞剂和 CCB 同时是高血压和心绞痛的核心药物，在高血压伴冠心病患者中具有双重治疗价值。同时，硝酸酯类与西地那非等 PDE5 抑制剂的禁忌（严重低血压）是临床上最重要的药物相互作用之一。
