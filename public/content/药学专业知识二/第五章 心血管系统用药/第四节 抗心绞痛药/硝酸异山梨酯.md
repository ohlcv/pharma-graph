# 硝酸异山梨酯

## 它是什么？

**中效硝酸酯类**，本身具有药理活性。

## 核心作用特点是什么？

| 特点 | 说明 |
|---|---|
| **作用强度** | 中效 |
| **持续时间** | **2~6小时** |
| **药理活性** | 本身有活性 |
| **代谢产物** | 主要活性代谢产物为**5-单硝酸异山梨酯** |
| **剂型** | 普通片剂、缓释片、注射剂等 |

## 典型不良反应是什么？

- 扩血管反应：低血压、头痛、面部潮红
- 反射性心率加快
- 耐受性（连续使用24h可发生）

## 禁忌人群是什么？

- 青光眼患者禁用
- 严重低血压患者禁用
- 正在使用5型磷酸二酯酶抑制剂者禁用

## 它和章的关系？

硝酸异山梨酯是硝酸酯类代表药，定位"中效硝酸酯类，作用持续2~6h，5-单硝酸异山梨酯是其主要活性代谢产物"。
