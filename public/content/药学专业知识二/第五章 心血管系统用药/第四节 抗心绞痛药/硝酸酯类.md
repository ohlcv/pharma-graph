# 硝酸酯类

## 它是什么药？

通过在血管平滑肌内释放**一氧化氮（NO）**，使细胞内cGMP增多、钙离子减少，直接松弛血管平滑肌，从而：
- **降低心肌耗氧量**（扩张静脉为主，降低前负荷，兼轻微扩张动脉）
- **增加缺血区血液供应**（选择性舒张心外膜下输送血管，开放侧支循环）
- **保护心肌细胞**，减轻缺血性损伤
- 适用于**各型心绞痛**，既可缓解急性发作，又可预防用药

## 代表药有哪些？

| 药物 | 作用特点 | 起效/持续 |
|---|---|---|
| **硝酸甘油** | 舌下含服急性发作首选；剂型多样（片剂、溶液、喷雾、透皮贴剂） | 2~3 min起效；持续20~30 min |
| **硝酸异山梨酯** | 中效；本身有活性；代谢产物为5-单硝酸异山梨酯 | 持续2~6 h |
| **单硝酸异山梨酯** | 口服吸收完全，无首关效应，生物利用度近100% | 缓释片60~90 min起效，持续3~6 h；普通片约60 min起效，持续约12 h |

## 硝酸甘油：急性发作首选

- **舌下含服**：吸收迅速完全，生物利用度达80%
- **2~3分钟起效**，5分钟达最大效应，作用持续20~30分钟
- 疼痛未缓解，每5分钟可重复1片
- **15分钟内总量达3片仍不缓解，应立即就医**
- **为避免耐药，长期用药者不应突然停药**

## 单硝酸异山梨酯：长效代表

- 无首关效应，生物利用度近100%
- **缓释片**：60~90分钟起效，30~60分钟达峰，持续3~6小时
- **普通片**：约60分钟起效，持续约12小时，半衰期4~5小时，每日晨起服药1次

## 典型不良反应是什么？

| 不良反应 | 表现 |
|---|---|
| **扩血管反应** | 体位性低血压（搏动性头痛）、面部潮红或烧灼感、反射性心率加快 |
| **耐受性** | 任何剂型连续使用24h均可发生 |

### 如何避免耐受性？

**偏心给药**：小剂量、间断使用，每日提供**8~12小时无药期**

## 禁忌人群是什么？

- **青光眼**患者禁用
- **严重低血压**患者禁用
- **正在使用5型磷酸二酯酶抑制剂**（如西地那非）的患者禁用（合用可引起显著性低血压）

## 它和章的关系？

硝酸酯类是缓解心绞痛症状的核心药物，定位"NO供体，降低心肌耗氧，增加缺血区供血，舌下含服硝酸甘油是急性发作首选，耐受性采用偏心给药避免"。

## 记忆口诀是什么？

**"硝酸酯类释放NO，cGMP增多钙减少，血管松弛耗氧降，缺血区血流增加好"**

| 口诀 | 含义 |
|---|---|
| **释放NO** | 在血管平滑肌内经谷胱甘肽转移酶催化释放一氧化氮（NO） |
| **cGMP增多** | NO与巯基作用生成亚硝基硫醇，使细胞内cGMP↑ |
| **钙减少** | cGMP激活蛋白激酶，Ca²⁺从细胞内释放 |
| **血管松弛** | 细胞内钙减少 → 平滑肌松弛 |
| **耗氧降** | 扩张静脉为主，降低前负荷，降低心肌耗氧量 |
| **缺血区血流增加** | 选择性舒张心外膜下输送血管，开放侧支循环 |

**不良反应与禁忌口诀："硝酸酯类扩血管，低压头痛脸红慌，连续使用耐药了，偏心给药来预防"**

| 口诀 | 含义 |
|---|---|
| **低压、脸红、头痛** | 扩血管反应：体位性低血压、面部潮红、搏动性头痛 |
| **心慌** | 反射性心率加快 |
| **耐药** | 连续使用24h可产生耐受性 |
| **偏心给药** | 小剂量、间断使用，每日8~12h无药期 |

**禁忌口诀："青光眼、低血压、伟哥绝对不能搭"**

| 禁忌 | 原因 |
|---|---|
| **青光眼** | 扩血管作用加重眼压 |
| **严重低血压** | 加重低血压风险 |
| **5型磷酸二酯酶抑制剂**（西地那非等） | 合用导致显著性低血压 |

**为什么要记？** 硝酸酯类药理作用机制（NO-cGMP-钙通路）和不良反应（扩血管三联+耐受性）是高频考点，口诀一网打尽。
