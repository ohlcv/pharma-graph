# 美托洛尔

## 它是什么？

**β₁选择性受体拮抗剂**，临床最常用的抗心绞痛β受体拮抗剂。

## 核心作用特点是什么？

| 特点 | 说明 |
|---|---|
| **受体选择性** | **β₁选择性**（对β₂影响较小） |
| **作用机制** | 减慢心率、降低心肌收缩力、降低血压 → 降低心肌耗氧量 |
| **心脏保护** | 改善心肌重构，保护心功能 |
| **双重作用** | 兼具缓解症状与改善预后 |

## 临床应用是什么？

- **稳定型心绞痛**（首选之一）
- 不稳定型心绞痛
- 高血压
- 心律失常
- 心力衰竭

## 典型不良反应是什么？

- 心动过缓
- 低血压
- 乏力
- 支气管痉挛（相对少见，哮喘患者仍需慎用）

## 禁忌人群是什么？

- 支气管哮喘重度发作禁用
- 重度心动过缓禁用
- 急性心力衰竭发作期禁用
- 心源性休克禁用

## 它和章的关系？

美托洛尔是β受体拮抗剂的代表药，定位"β₁选择性，临床最常用，兼具抗心绞痛与改善预后，是心绞痛治疗的核心药物"。
