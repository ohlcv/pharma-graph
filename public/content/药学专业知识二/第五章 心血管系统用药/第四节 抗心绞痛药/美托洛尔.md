# 美托洛尔

## 它是什么药？

**β₁受体高选择性拮抗剂**的临床最常用代表药，临床常用其酒石酸盐（普通片）和琥珀酸盐（缓释片）。通过选择性阻断心脏β₁受体减慢心率、降低心肌收缩力、抑制房室结传导，临床用于高血压、心绞痛、慢性心力衰竭和多种心律失常。

## 它有什么独特之处？

它的"独特"在于四点：
- **对β₁有高选择性**——对β₂受体阻断作用弱，因此对支气管平滑肌、糖代谢、脂代谢的干扰比普萘洛尔小，哮喘和 COPD 患者在边界情况下相对安全
- **临床应用面极广**——同一药同时是抗高血压、抗心绞痛、抗心衰、抗心律失常的核心药，并用于心肌梗死二级预防和甲亢辅助
- **缓释片剂型**——普通片与缓释片两种剂型并存，缓释片血药浓度平稳，每日一次给药，依从性好
- **口服首过效应显著**——是药剂学"剂型—过程—效果"逻辑的典型药物实例，受首过效应影响生物利用度

## 核心作用特点是什么？

| 特点 | 说明 |
|---|---|
| **受体选择性** | **β₁选择性**（对β₂影响较小） |
| **作用机制** | 减慢心率、降低心肌收缩力、降低血压 → 降低心肌耗氧量 |
| **心脏保护** | 改善心肌重构，保护心功能 |
| **双重作用** | 兼具缓解症状与改善预后 |
| **剂型设计** | 缓释片调控释放速度实现 24h 平稳降压 |
| **生物利用度** | 受首过效应影响显著，剂量设计需考虑剂型 |

## 临床应用是什么？

- **高血压**：尤其适用于伴冠心病、心绞痛、心衰或快速性心律失常的患者
- **稳定型心绞痛**：长期预防一线药（β受体阻断降心肌耗氧量）
- **不稳定型心绞痛**：可联用硝酸酯
- **慢性心力衰竭**：β受体阻滞剂是心衰治疗的基石之一，需从极小剂量起始、逐渐滴定
- **心律失常**：窦性心动过速、室上性心动过速、房颤心室率控制
- **心肌梗死后二级预防**：降低再梗死和猝死风险
- **甲状腺功能亢进症**：辅助控制心动过速和震颤

## 典型不良反应是什么？

- **心动过缓、房室传导阻滞**
- **低血压、头晕、疲乏**
- **心力衰竭加重**：起始剂量过大或加量过快可诱发，需小剂量起始
- **支气管痉挛**：高选择性不等于零风险，严重哮喘仍禁用
- **肢端发冷**
- **撤药综合征**：长期使用后突然停药可诱发心绞痛或心梗

## 禁忌人群是什么？

- 支气管哮喘重度发作禁用
- 重度心动过缓禁用
- 急性心力衰竭发作期禁用
- 心源性休克禁用

## 药剂学视角（口服制剂设计）

作为口服固体制剂的具体药物实例，美托洛尔缓释片把"剂型—过程—效果"逻辑真正落地：
- **释放特性**：缓释制剂调控药物释放速度，实现一天一次服药却能维持 24 小时平稳降压
- **吸收过程**：先释放、再吸收、再进入体循环
- **生物利用度**：首过效应影响显著，是为什么需要缓释剂型补偿的典型案例

它是Ⅱ类β受体拮抗剂亚类的**高选择性β₁代表药**，定位"心脏选择性β阻断，缓释片剂型，每日一次"。它在图中跨多个章节归属：
- **抗心律失常药节**（第五章第一节）：Ⅱ类代表药，与普萘洛尔、比索洛尔、卡维地洛形成选择性梯度对比
- **抗心绞痛药节**（第五章第四节）：稳定型心绞痛长期预防一线药
- **抗高血压药节**（第五章第二节）：高血压治疗核心药
- **抗心力衰竭药节**（第五章第五节）：心衰治疗的基石（与比索洛尔、卡维地洛并称"心衰三巨头"）
