# 利伐沙班

## 它是什么？

口服**直接Ⅹa因子抑制剂**，DOAC代表药。

## 核心特性

| 特性 | 说明 |
|---|---|
| **靶点** | **因子Ⅹa** |
| **给药** | **一日1次** |
| **食物** | **15mg、20mg需与食物同服** |
| **肝功能** | **禁忌** |
| **肾消除** | 33% |

## 相互作用

与CYP3A4和P-gp强效抑制剂合用，血药浓度升高

## 特异性解救药

暂无特异性口服解救药

## 它和章的关系？

利伐沙班是DOAC的Ⅹa抑制剂代表，定位"一日1次，15/20mg需与食物同服，肝功能不全禁忌，CYP3A4/P-gp相互作用显著"。
