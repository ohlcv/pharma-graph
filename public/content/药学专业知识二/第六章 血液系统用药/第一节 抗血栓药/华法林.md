# 华法林

## 它是什么？

**维生素K拮抗剂**，口服抗凝药。

## 作用机制

| 步骤 | 说明 |
|---|---|
| ① 抑制VKORC1 | 阻断维生素K的再生循环 |
| ② 抑制凝血因子合成 | 维生素K依赖的Ⅱ、Ⅶ、Ⅸ、Ⅹ因子合成减少 |
| ③ 对已合成的凝血因子无影响 | **起效慢、维持时间长**，仅体内抗凝 |
| ④ 对已形成的血栓无直接作用 | 用药目的是防止血栓**进一步扩大** |

## 药动学特性

| 特性 | 说明 |
|---|---|
| **结构** | 消旋混合物 |
| **S-对映体** | 抗凝作用是R-对映体的**3~5倍**；主要经**CYP2C9**代谢 |
| **R-对映体** | 经CYP1A2、CYP3A4代谢 |
| **影响药效主因** | CYP2C9 |
| **基因多态性** | **CYP2C9** 和 **VKORC1** 影响药效；**VKORC1是个体差异的决定性因素** |
| **代谢** | 几乎完全经肝脏代谢，**肾功能不全者无需调整剂量** |

## 用法用量

| 项目 | 说明 |
|---|---|
| **INR目标值** | 静脉血栓栓塞、非瓣膜性房颤、高风险心梗患者：**INR 2.5**（范围2.0~3.0） |
| **漏服处理** | 当天尽快补服，**不可次日加倍** |
| **饮食注意** | 维持维生素K稳定摄入，避免大量食用绿叶蔬菜 |

## 典型不良反应

**出血并发症**（INR高出目标范围时风险升高）：
- 皮下瘀斑
- 牙龈出血
- 消化道出血
- **颅内出血**（最严重）

## 禁忌

| 禁忌 | 说明 |
|---|---|
| **妊娠期** | 禁用（机械瓣膜高血栓风险妊娠期女性除外） |
| **出血倾向** | 禁用 |
| **近期/预期创伤性手术** | 禁用 |
| **恶性高血压** | 禁用 |

## 记忆口诀是什么？

**"二舅在林子里被KO了"**

| 口诀 | 含义 |
|---|---|
| **二舅** | 凝血因子**Ⅱ、Ⅸ** |
| **在林子里** | 凝血因子**Ⅶ、Ⅹ** |
| **被KO** | **VKORC1**被抑制 |

**合起来**：华法林抑制VKORC1，影响凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ合成。

**为什么要记？** 维生素K依赖凝血因子（Ⅱ、Ⅶ、Ⅸ、Ⅹ）和作用靶点VKORC1是华法林的核心知识点。

## 它和章的关系？

华法林是抗凝药的维生素K拮抗剂代表，定位"抑制VKORC1阻断凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ合成，起效慢维持时间长，需监测INR（目标2.5），VKORC1多态性决定个体差异，妊娠禁用"。
