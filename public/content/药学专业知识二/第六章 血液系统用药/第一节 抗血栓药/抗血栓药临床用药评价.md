# 抗血栓药临床用药评价与总结

## 一、华法林 vs 肝素类

| 项目 | 华法林 | 肝素类 |
|---|---|---|
| 给药 | 口服 | 注射 |
| 机制 | 抑制VKORC1，减少凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ合成 | 增强AT-Ⅲ活性，抑制Ⅱa、Ⅸa、Ⅹa、Ⅺa、Ⅻa |
| 起效 | 慢，维持时间长 | 快，体内体外均抗凝 |
| 监测 | **INR** | **APTT**（低分子肝素通常无需） |
| 妊娠期 | 禁用 | 肝素、低分子量肝素可用 |
| 肾功能不全 | 无需调整 | 肝素无需调整；低分子肝素需调整或避免 |
| 解救 | 维生素K | 鱼精蛋白 |

## 二、DOAC三大代表对比

| 项目 | 达比加群酯 | 利伐沙班 | 阿哌沙班 |
|---|---|---|---|
| 靶点 | **凝血酶（Ⅱa）** | 因子Ⅹa | 因子Ⅹa |
| 与食物同服 | 无需 | **15mg、20mg需要** | 无需 |
| 肝功能不全 | 轻中度无需调整 | **禁忌** | 无需 |
| 房颤给药频次 | **一日2次** | **一日1次** | **一日2次** |
| 肾脏消除活性比例 | **80%** | 33% | 25% |
| 特异性解救药 | **依达赛珠单抗** | 暂无特异性口服解救 | 国内在新药申请中 |
| 关键相互作用 | P-gp抑制剂→血药浓度↑ | CYP3A4+P-gp强效抑制剂→血药浓度↑ | 同左 |

## 三、P2Y₁₂三药对比

| 药品 | 结构类型 | 是否前药 | 对血小板的抑制 |
|---|---|---|---|
| 噻氯匹定 | 噻吩并吡啶类 | 是 | 不可逆 |
| **氯吡格雷** | 噻吩并吡啶类 | 是 | 不可逆，需停用7日以上再手术 |
| **替格瑞洛** | 环戊基三唑嘧啶类 | **否，直接拮抗受体** | **可逆，起效更快** |

## 四、溶栓药对比

| 药品 | 纤维蛋白特异性 | 纤维蛋白原消耗 | 半衰期 | 给药特点 |
|---|---|---|---|---|
| **尿激酶** | 无 | 明显 | ≤20min | — |
| **重组链激酶** | 无 | 明显 | 5~30min | — |
| **阿替普酶** | 有 | 轻度 | **4~5min（短）** | 持续静滴 |
| **瑞替普酶** | 有 | 中度 | **14~16min（略长）** | 分2次注射 |
| **替奈普酶** | 有 | 极小 | **20~24min（更长）** | **单次注射** |
| **重组人尿激酶原** | 有 | 极小 | 0.67h（50mg） | 推注+静滴 |

### 记忆口诀

**"阿替短，瑞替长，替奈更好且更长，重组酶原它最长"**

| 口诀 | 含义 |
|---|---|
| **阿替短** | 阿替普酶半衰期4~5min最短 |
| **瑞替长** | 瑞替普酶14~16min略长 |
| **替奈更好且更长** | 替奈普酶20~24min更长 |
| **重组酶原它最长** | 重组人尿激酶原半衰期0.67h最长 |

### 溶栓适应证时间窗汇总

| 适应证 | 时间窗 |
|---|---|
| 急性心梗（阿替普酶） | 发病12小时内 |
| 急性心梗（替奈普酶） | 发病6小时内 |
| 急性缺血性脑卒中（阿替普酶） | 发病**4.5小时内**（3小时内最佳） |
| 急性缺血性脑卒中（瑞替普酶） | 发病4.5小时内 |

## 五、临床监测要点汇总

| 药物 | 监测指标 | 频次 |
|---|---|---|
| 华法林 | **INR**（目标2.5，范围2.0~3.0） | 定期 |
| 普通肝素 | **APTT** | 频繁 |
| 低分子量肝素 | 一般无需 | — |
| 阿替普酶 | 出血征象、神经功能 | 急性期 |
| DOAC | 一般无需 | — |

## 六、核心临床定位

| 类别 | 临床定位 |
|---|---|
| **华法林** | 口服长期抗凝，监测INR，妊娠禁用 |
| **低分子量肝素** | 妊娠期抗凝首选，使用方便无须监测 |
| **DOAC** | 房颤、静脉血栓新一代首选，无须监测INR |
| **阿司匹林+氯吡格雷** | ACS、PCI术后DAPT方案基石 |
| **阿替普酶** | 急性心梗/脑卒中急救首选溶栓药 |
| **替奈普酶** | 急性心梗单次注射，给药最简便 |

## 记忆口诀是什么？

**"抗凝、抗板、溶栓——抗凝管纤维蛋白，抗板管血小板，溶栓把血栓溶"**

**"华法林监测INR，肝素监测APTT，低分子方便无须测，DOAC更是省心"**

**为什么要记？** 抗血栓药是临床最复杂领域之一，三大类药物各有监测重点，临床定位差异大。
