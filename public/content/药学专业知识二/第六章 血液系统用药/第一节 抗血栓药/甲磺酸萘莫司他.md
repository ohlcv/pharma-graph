# 甲磺酸萘莫司他

## 它是什么？

**丝氨酸蛋白酶抑制剂**，我国首个预防血液体外循环凝固的药物。

## 核心特性

| 特性 | 说明 |
|---|---|
| **机制** | 丝氨酸蛋白酶抑制剂 |
| **作用范围** | **仅在体外循环回路中**发挥抗凝作用 |
| **体内代谢** | **体内迅速失活** |
| **代谢产物** | 无活性 |
| **出血风险** | 低 |

## 适应证

预防血液体外循环时血液凝固（如血液透析）

## 禁忌

| 禁忌 | 说明 |
|---|---|
| 对本品过敏者 | 禁用 |
| 活动性出血/出血性疾病 | 禁用 |
| 严重出凝血功能障碍 | 禁用 |

## 药物相互作用

| 相互作用 | 说明 |
|---|---|
| **与水杨酸盐合用** | 萘莫司他血浆蛋白结合减少，甲氨蝶呤肾清除下降、血液毒性增加，合用时甲氨蝶呤需减量 |
| **与治疗窗窄的药物合用** | 可能影响阿司匹林的心血管保护作用 |

## 它和章的关系？

萘莫司他是抗凝药的丝氨酸蛋白酶抑制剂代表，定位"仅体外循环抗凝，体内迅速失活，出血风险低"。
