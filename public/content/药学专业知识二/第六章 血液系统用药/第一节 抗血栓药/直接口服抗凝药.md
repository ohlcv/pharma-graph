# 直接口服抗凝药（DOAC）

## 它是什么药？

**直接抑制凝血因子活性**的口服抗凝药，无须监测INR。

## 分类

### 1. 直接凝血酶（Ⅱa）抑制剂

| 药物 | 给药 |
|---|---|
| **达比加群酯** | 口服 |
| 比伐芦定 | 注射 |
| 阿加曲班 | 注射 |
| 水蛭素、重组水蛭素 | 注射 |

### 2. 直接Ⅹa因子抑制剂（口服）

| 药物 |
|---|
| **利伐沙班** |
| **阿哌沙班** |
| **艾多沙班** |

## 记忆口诀是什么？

**"水蛭加班比美"**（直接凝血酶抑制剂）

| 口诀 | 含义 |
|---|---|
| **水蛭** | 水蛭素、重组水蛭素 |
| **加** | 阿加曲班 |
| **班** | 比伐芦定（**biva**lirudin） |
| **比美** | **达比加群酯**（口服直接凝血酶抑制剂代表） |

**为什么要记？** 直接凝血酶抑制剂药物名易混淆，口诀帮助快速区分。

## 它和节的关系？

DOAC是抗凝药的新一代口服药物，定位"无须监测INR，包括Ⅱa抑制剂和Ⅹa抑制剂，P-gp/CYP3A4强抑制剂是主要相互作用"。
