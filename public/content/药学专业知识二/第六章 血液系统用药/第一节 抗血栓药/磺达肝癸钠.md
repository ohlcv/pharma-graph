# 磺达肝癸钠

## 它是什么？

**人工合成的戊糖类似物**，仅抑制Ⅹa因子。

## 核心特性

| 特性 | 说明 |
|---|---|
| **分子量** | 1728.08 |
| **作用** | **仅抑制Ⅹa** |
| **生物利用度** | **100%** |
| **给药** | 皮下注射 |

## 优势

- 不与血小板结合，**HIT风险极低**
- 100%生物利用度，预测性好

## 它和章的关系？

磺达肝癸钠是肝素类的人工合成代表，定位"仅抑制Ⅹa因子，皮下100%生物利用，HIT风险极低"。
