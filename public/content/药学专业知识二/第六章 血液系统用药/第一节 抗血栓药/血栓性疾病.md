# 血栓性疾病

## 它是什么病？

血栓性疾病是因血管内血栓形成引起血管阻塞、器官缺血所致的临床综合征。

## 分类

| 类型 | 常见疾病 |
|---|---|
| **动脉血栓** | 急性心肌梗死、缺血性脑卒中 |
| **静脉血栓** | 深静脉血栓形成（DVT）、肺栓塞（PE） |
| **心源性** | 非瓣膜性房颤血栓栓塞 |
| **外周动脉** | 慢性动脉闭塞症（间歇性跛行、肢痛） |

## 核心治疗策略

| 药物类别 | 适用情况 |
|---|---|
| **抗凝药** | 静脉血栓、房颤栓塞预防 |
| **抗血小板药** | 动脉血栓（冠心病、脑梗） |
| **溶栓药** | 急性心梗、急性脑梗、肺栓塞急救 |

## 它和节的关系？

血栓性疾病是抗血栓药节所治疗的核心疾病，位于第六章第一节。
