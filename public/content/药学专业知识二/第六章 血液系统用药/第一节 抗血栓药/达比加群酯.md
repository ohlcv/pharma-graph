# 达比加群酯

## 它是什么？

口服**直接凝血酶（Ⅱa）抑制剂**，DOAC代表药。

## 核心特性

| 特性 | 说明 |
|---|---|
| **作用靶点** | **凝血酶（Ⅱa）** |
| **给药** | 口服 |
| **房颤频次** | **一日2次** |
| **食物** | 无需与食物同服 |
| **肝功能** | 轻中度肝功能不全无需调整 |
| **肾脏消除** | **80%**（最高） |

## 关键相互作用

与**P-糖蛋白抑制剂**（胺碘酮、维拉帕米、克拉霉素等）合用，血药浓度升高

## 特异性解救药

**依达赛珠单抗**

## 它和章的关系？

达比加群酯是DOAC的Ⅱa抑制剂代表，定位"口服直接凝血酶抑制剂，80%经肾消除，P-gp抑制剂禁合用，特异性解救药为依达赛珠单抗"。
