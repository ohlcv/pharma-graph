# 阿哌沙班

## 它是什么？

口服**直接Ⅹa因子抑制剂**，DOAC代表药。

## 核心特性

| 特性 | 说明 |
|---|---|
| **靶点** | **因子Ⅹa** |
| **给药** | **一日2次** |
| **食物** | 无须 |
| **肝功能** | 无需调整 |
| **肾消除** | 25% |

## 房颤适应证

非瓣膜性房颤的卒中预防——常用一日2次给药方案

## 相互作用

与CYP3A4和P-gp强效抑制剂合用，血药浓度升高

## 特异性解救药

国内在新药申请中

## 它和章的关系？

阿哌沙班是DOAC的Ⅹa抑制剂代表，定位"一日2次，无须食物，肾消除比例25%，房颤常用"。
