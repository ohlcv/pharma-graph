# 阿替普酶（rt-PA）

## 它是什么？

**特异性纤溶酶原激活剂**，纤维蛋白特异性激活血栓处的纤溶酶原。

## 核心特性

| 特性 | 说明 |
|---|---|
| **纤维蛋白特异性** | 有 |
| **纤维蛋白原消耗** | 轻度 |
| **半衰期** | **4~5min（短）** |
| **给药** | **持续静滴** |

## 适应证与时间窗

| 适应证 | 时间窗 |
|---|---|
| **急性心肌梗死** | 发病**12小时内** |
| **血流不稳定大面积肺栓塞** | — |
| **急性缺血性脑卒中** | **发病4.5小时内**（3小时内最佳） |

## 用法用量

### 急性心肌梗死

**发病6小时内（体重≥65kg）—— 90分钟加速给药法**：

| 步骤 | 剂量 |
|---|---|
| 静推 | 15mg |
| 30分钟内静滴 | 50mg |
| 剩余60分钟内静滴 | 35mg |

**发病6~12小时 —— 3小时给药法**：

| 步骤 | 剂量 |
|---|---|
| 静推 | 10mg |
| 1小时静滴 | 50mg |
| 剩余每30分钟静滴 | 10mg（最大100mg） |

### 肺栓塞

| 步骤 | 剂量 |
|---|---|
| 总剂量 | 100mg |
| 静推 | 10mg |
| 剩余2小时内持续静滴 | 90mg |

### 急性缺血性脑卒中

| 步骤 | 剂量 |
|---|---|
| 总剂量 | **0.9mg/kg，最大90mg** |
| 静推（10%总剂量） | 首剂 |
| 剩余量 | **60分钟内静滴** |

## 禁忌

| 禁忌 | 说明 |
|---|---|
| 出血性脑卒中史 | 禁用 |
| 不明原因脑卒中史 | 禁用 |
| **18岁以下、80岁以上急性脑卒中** | **禁用阿替普酶** |
| 近期大手术/创伤 | 禁用 |

## 典型不良反应

**出血**——最常见并发症；溶栓时常联合肝素/低分子肝素与抗血小板药，多重用药会增加出血风险

## 它和章的关系？

阿替普酶是特异性溶栓药代表，定位"rt-PA半衰期4~5min需持续静滴，急性心梗12h内/肺栓塞/急性缺血性脑卒中4.5h内，18岁以下、80岁以上脑卒中禁用"。
