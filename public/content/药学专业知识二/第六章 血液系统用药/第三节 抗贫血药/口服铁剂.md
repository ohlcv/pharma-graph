# 口服铁剂

## 它是什么药？

**口服**补充铁元素的药物，是缺铁性贫血的一线首选。

## 五大代表药

| 药物 | 类型 | 特点 |
|---|---|---|
| **硫酸亚铁** | 无机铁 | 经典、便宜，但胃肠道反应较大 |
| **琥珀酸亚铁** | 有机铁 | 胃肠道反应较小 |
| **多糖铁复合物** | 有机铁 | 吸收率高、副作用少 |
| **葡萄糖酸亚铁** | 有机铁 | 温和、适合儿童 |
| **右旋糖酐铁**（口服剂型） | 有机铁 | 同时有口服和注射剂型 |

## 用法要点

- **餐后服用**减少胃肠道刺激
- **避免与牛奶、茶、钙片、抗酸药同服**（影响吸收）
- 与**维生素 C 同服**促进吸收
- **血红蛋白恢复正常后继续服用 3~6 个月**，补充储存铁

## 典型不良反应

- 恶心、呕吐、上腹疼痛
- 便秘（减少肠蠕动）
- **黑便**（正常现象）
- 牙齿染色（液体制剂）

## 记忆口诀是什么？

**"口服铁剂，餐后服；VC 促吸，茶抑制"**——**餐后**减少胃肠刺激；**维生素 C 促进**吸收；**茶抑制**吸收。

**为什么要记？** 临床用药交代和药师审核处方的核心要点。

## 它和节的关系？

属于抗贫血药下铁剂子伞形，定位"口服一线首选，餐后服、注意食物相互作用"。
