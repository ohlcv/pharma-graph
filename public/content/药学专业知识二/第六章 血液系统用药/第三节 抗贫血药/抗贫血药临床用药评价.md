# 抗贫血药临床用药评价

## 一、三大类对比总表

| 类别 | 适应证 | 优势 | 局限 |
|---|---|---|---|
| **铁剂** | 缺铁性贫血（小细胞低色素性贫血） | 补充造血原料、安全、便宜 | 胃肠反应、注射过敏风险 |
| **巨幼细胞贫血用药** | 巨幼细胞性贫血、恶性贫血 | 补充造血原料、起效快 | 恶性贫血需终身用药、亚叶酸钙用于拮抗剂 |
| **红细胞生成刺激剂** | 肾性贫血、外科围手术期红细胞动员 | 五大亚类可选择、半衰期延长降低频次 | 高血压、血栓、纯红再障风险 |

## 二、选药原则

### 1. 铁剂选药

| 场景 | 优选药 |
|---|---|
| 缺铁性贫血一线 | 口服铁剂（硫酸亚铁、琥珀酸亚铁等） |
| 不能耐受口服 / 急需补铁 | 注射铁剂（首选蔗糖铁） |
| 慢性肾病透析 | 新一代可单次大剂量铁剂（异麦芽糖酐铁、羧基麦芽糖铁） |
| 儿童缺铁 | 葡萄糖酸亚铁（温和） |
| 妊娠后期严重贫血 | 注射铁剂（蔗糖铁） |

### 2. 巨幼细胞贫血用药选药

| 贫血类型 | 缺乏物质 | 首选 |
|---|---|---|
| 营养性巨幼细胞贫血 | 叶酸 | **叶酸** |
| 恶性贫血（内因子缺乏） | 维生素B₁₂ | **维生素B₁₂**（终身肌注） |
| 叶酸拮抗剂（甲氨蝶呤等）所致 | 四氢叶酸合成障碍 | **亚叶酸钙**（不能单用叶酸） |
| 妊娠期预防神经管畸形 | 叶酸 | **叶酸 0.4 mg/日** |

### 3. 红细胞生成刺激剂选药

| 场景 | 优选 |
|---|---|
| 慢性肾病维持期（依从性优先） | **甲氧基聚乙二醇促红素β**（每 4 周 1 次） |
| 慢性肾病诱导期 | **重组人促红素**（每周 2~3 次） |
| 慢性肾病过渡期 | **达依泊汀α**（每 2 周 1 次） |
| 不能耐受注射 | **罗沙司他**等 HIF-PHI（口服） |
| ESA 失败的地中海贫血 | **罗特西普** |
| 再生障碍性贫血辅助 | **十一酸睾酮、司坦唑醇** |

## 三、ESA 给药频次对比

| 分类 | 代表药物 | 给药频次 |
|---|---|---|
| **人促红素类** | 重组人促红素 | 每周给药 2~3 次 |
| | 达依泊汀α | 每 2 周给药 1 次 |
| | 甲氧基聚乙二醇促红素β | 每 4 周给药 1 次 |
| **EPO 模拟肽** | 罗米司亭 | 每周口服 1 次 |
| **HIF-PHI** | 罗沙司他、伐度司他、恩那司他 | 每周口服 2~3 次 |
| **红细胞成熟剂** | 罗特西普 | 每 3 周皮下注射 1 次 |
| **蛋白同化激素** | 十一酸睾酮、司坦唑醇 | 分早晚 2 次，餐后口服 |

## 四、相互作用要点

1. **铁剂 + 维生素 C**：促进铁吸收。
2. **铁剂 + 浓茶、鞣酸、磷酸盐、四环素、喹诺酮类**：降低铁吸收或互相影响。
3. **铁剂 + 钙剂**：互相竞争吸收。
4. **叶酸 + 甲氨蝶呤**：甲氨蝶呤拮抗叶酸作用，需用亚叶酸钙解救。
5. **重组人促红素 + 铁剂**：促红素治疗有效后造血增强，需每日补充铁剂。
6. **重组人促红素 + 血压药**：促红素可升高血压，联用时加强血压监测。

## 五、监护要点

| 药物类别 | 监测指标 |
|---|---|
| 铁剂（口服） | 血红蛋白、网织红细胞计数、血清铁蛋白、血清铁；观察胃肠道反应、黑便 |
| 铁剂（注射） | 过敏反应（试敏）、血清铁蛋白、肝肾功能 |
| 叶酸 | 血红蛋白、网织红细胞计数；观察尿色（大剂量可致黄色） |
| 维生素B₁₂ | 血红蛋白、神经系统症状 |
| 亚叶酸钙 | 血药浓度（甲氨蝶呤解救时） |
| 红细胞生成刺激剂 | **血红蛋白**（避免超过 130 g/L）、**血压**、**红细胞比容**、**血栓症状**、纯红再障 |

## 六、特殊人群用药

- **新生儿**：维生素K₁（出生后肌注 0.5~1 mg，预防新生儿出血，与贫血无关）；缺铁性贫血用葡萄糖酸亚铁。
- **儿童**：首选葡萄糖酸亚铁（温和）。
- **孕妇**：**叶酸 0.4 mg/日**预防胎儿神经管畸形；妊娠后期严重贫血用蔗糖铁注射；**重组人促红素可用**（C 类）；司坦唑醇禁用（雄激素样作用）。
- **哺乳期**：铁剂、叶酸、B₁₂ 均可使用；司坦唑醇禁用。
- **老年人**：铁剂需评估胃肠耐受；ESAs 需监测血压、血栓。
- **慢性肾病患者**：首选 ESAs（rhEPO、达依泊汀α、甲氧基聚乙二醇促红素β），目标血红蛋白 100~120 g/L；新型铁剂可单次大剂量输注。
- **肝功能不全**：司坦唑醇、十一酸睾酮慎用（肝毒性）。
- **肿瘤患者**：ESAs 需谨慎，目标血红蛋白不应过高（可能促进肿瘤生长）。

## 记忆口诀是什么？

**"贫血三型选药：缺铁补铁、缺叶补叶、肾不够补 EPO"**——**对因选药**是核心原则。

**为什么要记？** 贫血不是单一疾病，分类选药是临床安全用药的关键。
