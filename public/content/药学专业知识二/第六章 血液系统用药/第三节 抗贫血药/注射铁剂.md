# 注射铁剂

## 它是什么药？

**静脉/肌内注射**补充铁元素的药物，用于口服不耐受或急需补铁者。

## 六大代表药

| 药物 | 类型 | 特点 |
|---|---|---|
| **蔗糖铁** | 三价铁 + 蔗糖 | **最常用**，过敏反应少 |
| **右旋糖酐铁**（注射剂型） | 三价铁 + 右旋糖酐 | 过敏反应风险较高 |
| **山梨醇铁** | 三价铁 + 山梨醇 | 肌内注射 |
| **异麦芽糖酐铁** | 三价铁 + 异麦芽糖酐 | 新一代，可单次大剂量 |
| **羟基麦芽糖铁** | 三价铁 + 麦芽糖 | 新一代，可单次大剂量 |
| **羧基麦芽糖铁** | 三价铁 + 麦芽糖 | 新一代，可单次大剂量 |

## 用法要点

- **必须先做过敏试验**（右旋糖酐铁尤其需要）
- **缓慢静脉滴注**，起始 5 分钟内密切观察
- 配备**肾上腺素和复苏设备**
- 计算总缺铁量分次给予或单次大剂量

## 典型不良反应

- **过敏反应**（最严重）：呼吸困难、面部潮红、低血压 → **过敏性休克**
- 注射部位疼痛、变色
- 头痛、肌肉酸痛

## 记忆口诀是什么？

**"注射铁剂，先试敏；肾上腺素常备旁"**——**过敏试验**是注射铁剂的核心用药安全步骤。

**为什么要记？** 注射铁剂的过敏反应风险远高于口服，记忆"先试敏"是临床安全用药关键。

## 它和节的关系？

属于抗贫血药下铁剂子伞形，定位"保留用药，必须试敏，警惕过敏性休克"。
