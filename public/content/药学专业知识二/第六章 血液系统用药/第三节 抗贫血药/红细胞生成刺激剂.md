# 红细胞生成刺激剂（ESAs）

## 它是什么药？

通过**刺激红细胞生成或促进红细胞成熟**纠正肾性贫血、外科围手术期红细胞动员等的药物。

## 五大亚类

| 亚类 | 代表药 | 给药频次 |
|---|---|---|
| **人促红素类** | 重组人促红素（rhEPO） | 每周 2~3 次 |
| | 达依泊汀α | 每 2 周 1 次 |
| | 甲氧基聚乙二醇促红素β | 每 4 周 1 次 |
| **EPO 模拟肽** | 罗米司亭 | 每周口服 1 次 |
| **HIF-PHI** | 罗沙司他 | 每周口服 2~3 次 |
| | 伐度司他 | 每周口服 2~3 次 |
| | 恩那司他 | 每周口服 2~3 次 |
| **红细胞成熟剂** | 罗特西普 | 每 3 周皮下注射 1 次 |
| **蛋白同化激素** | 十一酸睾酮 | 分早晚 2 次，餐后口服 |
| | 司坦唑醇 | 分早晚 2 次，餐后口服 |

## 适应证

1. **肾功能不全所致贫血**（包括透析及非透析患者）——所有 ESAs 共同核心适应证
2. **外科围手术期的红细胞动员**——适用于术前血红蛋白 100~130 g/L 的择期手术患者

## 典型不良反应

1. **血压升高**，可诱发高血压性脑病；未控制的重度高血压患者禁用。
2. **血栓形成风险升高**。
3. **过敏反应**；长期使用可诱发纯红细胞再生障碍性贫血。

## 临床应用注意

1. 用药期间定期检查**红细胞比容**，避免红细胞过度生成。
2. 治疗有效后造血增强，需**每日补充铁剂**。
3. 叶酸或维生素B₁₂不足会降低本品疗效，体内铝蓄积过多也会影响疗效。

## 记忆口诀是什么？

**"ESA 五类：人促红、模拟肽、HIF-PHI、成熟剂、同化激素"**——按作用机制五类速记：
- **人促红**：模拟 EPO 直接作用
- **模拟肽**：口服肽类模拟 EPO
- **HIF-PHI**：抑制降解，稳定内源性 EPO
- **成熟剂**：促进晚期红细胞成熟
- **同化激素**：通过刺激骨髓造血

**为什么要记？** 五类 ESA 给药频次差异大（每周 1 次到每 4 周 1 次），按"机制 + 频次"双维度记忆。

## 它和节的关系？

属于抗贫血的第三大类，定位"刺激红细胞生成或促进成熟，五类机制不同、按频次选择"。
