# 促凝血药临床用药评价

## 一、五大类对比总表

| 类别 | 适应证 | 优势 | 局限 |
|---|---|---|---|
| **促血小板生成药** | 免疫性血小板减少症、再生障碍性贫血、化疗后血小板减少 | 升血小板、靶向 TPO 受体 | 起效慢、需监测、可能血栓 |
| **抗纤维蛋白溶解药** | 纤溶亢进出血、手术出血、产后出血、月经过多 | 作用快、相对安全 | 警惕血栓风险、动脉出血无效 |
| **凝血因子** | 血友病、维生素K缺乏、严重肝病出血、DIC | 直接补充、起效快 | 血源 vs 重组成本差异、抑制物风险 |
| **维生素K类** | 维生素K缺乏性出血、新生儿出血、抗凝药过量 | 补充不足的辅酶 | 起效慢（需 12~24 小时合成凝血因子） |
| **其他类** | 手术出血、毛细血管出血、食管静脉曲张破裂出血、静脉曲张硬化 | 局部/靶向作用 | 个体化选用 |

## 二、选药原则

### 1. 促血小板生成药选药

| 场景 | 优选药 |
|---|---|
| 需快速升血小板、围术期 | 重组人血小板生成素（rhTPO） |
| 化疗后预防血小板减少 | 人白介素-11 或 rhTPO |
| 慢性 ITP 长期维持 | 口服 TPO 受体激动剂（艾曲泊帕、海曲泊帕） |
| 慢性肝病相关血小板减少 | 阿伐曲泊帕、芦曲泊帕（CLD 适应证） |
| 需与食物同服、用药方便 | 阿伐曲泊帕 |

### 2. 抗纤维蛋白溶解药选药

| 场景 | 优选药 |
|---|---|
| 月经过多、产后出血、口腔术后 | 氨甲环酸（TXA）—— 临床最常用 |
| 泌尿系统出血 | 氨甲环酸 |
| 仅纤溶亢进（无动脉出血） | 氨基己酸、氨甲苯酸、氨甲环酸任一 |

**禁忌**：不能阻止小动脉出血（这是氨基己酸的核心考点）；有血栓形成倾向者禁用。

### 3. 凝血因子选药

| 适应证 | 首选 |
|---|---|
| 甲型血友病 | 凝血因子Ⅷ（人源 / 重组） |
| 乙型血友病 | 凝血因子Ⅸ（人源 / 重组） |
| 维生素K缺乏严重出血 | 人凝血酶原复合物 + 维生素K |
| 严重肝病凝血因子缺乏 | 人凝血酶原复合物 |
| DIC 消耗性低凝期 | 人纤维蛋白原 + 人凝血酶原复合物 |
| 华法林过量紧急逆转 | 人凝血酶原复合物 + 维生素K₁ |

### 4. 维生素K类选药

| 场景 | 优选 |
|---|---|
| 严重出血（紧急） | 维生素K₁（注射） |
| 新生儿出血预防 | 维生素K₁（出生后肌注） |
| 轻症维持 | 维生素K₄（口服） |
| **新生儿禁用** | 甲萘醌（K₃）—— 可致核黄疸 |

### 5. 其他类促凝血药选药

| 适应证 | 优选 |
|---|---|
| 手术前后出血预防 | 蛇毒血凝酶 |
| 鼻出血、牙龈出血 | 卡络磺钠、酚磺乙胺 |
| 食管静脉曲张破裂出血 | 特利加压素（首选）/ 垂体后叶注射液 |
| 肺咯血 | 垂体后叶注射液、酚磺乙胺 |
| 痔出血 | 卡络磺钠 |
| 静脉曲张硬化治疗 | 聚桂醇 |

## 三、相互作用要点

1. **抗纤溶药 + 凝血因子**：协同增加血栓风险，但一般不同时使用。
2. **蛇毒血凝酶 + 抗凝药**：抗凝药可拮抗蛇毒血凝酶作用，避免同时使用。
3. **维生素K₁ + 华法林**：维生素K₁ 解救华法林过量，但**严重出血需用 PCC 而非单用维生素K₁**（维生素K₁ 起效慢，需 12~24 小时）。
4. **TPO 受体激动剂 + 含多价阳离子食物/药物**：生物利用度显著降低，需间隔 2 小时给药（阿伐曲泊帕除外）。
5. **垂体后叶注射液 + 缩宫素**：不同时使用，避免子宫过度收缩。

## 四、监护要点

| 药物类别 | 监测指标 |
|---|---|
| 促血小板生成药 | 血常规（血小板计数），用药期间及停药后至少 2 周定期监测 |
| 抗纤溶药 | 有无血栓症状（胸痛、呼吸困难、肢体肿胀） |
| 凝血因子 | 凝血因子活性、APTT、PT、纤维蛋白原；定期检测抑制物 |
| 维生素K类 | 凝血酶原时间（PT）、国际标准化比值（INR）、肝功能 |
| 蛇毒血凝酶 | 过敏反应、出血改善情况 |
| 收缩血管药 | 血压、心率、心电图、腹部症状 |
| 聚桂醇 | 注射部位情况、深静脉血栓症状 |

## 五、特殊人群用药

- **新生儿**：维生素K₁（出生后肌注 0.5~1 mg）；**甲萘醌（K₃）禁用**。
- **孕妇**：垂体后叶慎用（缩宫素作用）；聚桂醇孕妇禁用。
- **哺乳期**：大多数促凝血药可通过乳汁分泌，需谨慎。
- **儿童**：抗纤溶药 6 岁以下慎用；凝血因子按体重计算。
- **老年人**：收缩血管药需监测血压、心电图。
- **肝肾功能不全**：抗纤溶药慎用；凝血因子按残余肝肾功能调整。

## 记忆口诀是什么？

**"促凝五类：板、溶、因、K、杂；选药看机制、剂型、个体"**——**选药三原则**："机制匹配"（出血原因选大类）、"剂型匹配"（口服/注射/局部）、"个体匹配"（年龄、孕产、肝肾功能）。

**为什么要记？** 临床用药核心是"对因选药、对人给药"，三大原则贯穿促凝血药全章节。
