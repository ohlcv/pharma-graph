# 促凝血药概述与分类

## 五类促凝血药

促凝血药按作用机制分为五大类，覆盖凝血过程不同环节：

| 类别 | 作用机制 | 代表药 |
|---|---|---|
| **促血小板生成药** | 激活 TPO 受体，刺激巨核细胞增殖分化，提升血小板计数 | 重组人血小板生成素、人白介素-11、艾曲泊帕、海曲泊帕、阿伐曲泊帕、芦曲泊帕 |
| **抗纤维蛋白溶解药** | 赖氨酸类似物竞争性抑制纤溶酶原与纤维蛋白结合，阻止血块溶解 | 氨基己酸、氨甲环酸、氨甲苯酸 |
| **凝血因子** | 直接补充/替代缺乏的凝血因子，纠正凝血功能障碍 | 人凝血酶原复合物、人纤维蛋白原、凝血因子Ⅷ/Ⅸ |
| **维生素K类** | 肝脏γ-羧化酶辅酶，参与凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ合成 | 维生素K₁、维生素K₄、甲萘醌 |
| **其他类** | 蛇毒血凝酶促凝、毛细血管止血、收缩血管、血管硬化 | 矛头蝮蛇血凝酶、卡络磺钠、酚磺乙胺、垂体后叶注射液、特利加压素、聚桂醇 |

## 记忆口诀是什么？

**"五类促凝血：板、溶、因、K、杂"**——按作用机制五字速记：**板**（促血小板生成药）、**溶**（抗纤维蛋白溶解药）、**因**（凝血因子）、**K**（维生素K类）、**杂**（蛇毒血凝酶/毛细血管止血/收缩血管/血管硬化剂）。

**为什么要记？** 促凝血药分类是临床用药基础，考试和审方常需要根据出血机制选择对应类别。

## 它和节的关系？

本节介绍促凝血药的总论与五类分类，定位"止血机制 + 五大类药物作用靶点 + 代表药框架，是临床用药评价的基础"。
