# PPI 与氯吡格雷相互作用

## 它在讲什么？

氯吡格雷（抗血小板药）与 PPI（抑酸药）合用时因 CYP2C19 共同代谢而产生的相互作用及其临床规避。

## 机制是什么？

**氯吡格雷**是**前药**，需经 CYP2C19 代谢为活性代谢物才能发挥抗血小板作用（不可逆抑制血小板 P2Y₁₂ 受体）。

**奥美拉唑、艾司奥美拉唑**强效抑制 CYP2C19 → 显著降低氯吡格雷活化率 → **削弱抗血小板疗效**，增加心血管事件风险。

## CYP2C19 抑制强度怎么排？

**艾司奥美拉唑 > 奥美拉唑 > 兰索拉唑 > 泮托拉唑**

**雷贝拉唑 / 右兰索拉唑** 影响最小（部分非酶代谢）

## 临床推荐是什么？

| 联用选择 | 推荐度 |
|---|---|
| 奥美拉唑 / 艾司奥美拉唑 | ❌ **避免** |
| 泮托拉唑 | ⚠️ 可选（弱抑制）|
| 雷贝拉唑 / 右兰索拉唑 | ✅ **首选** |
| 法莫替丁（H₂RA） | ✅ 替代选择 |
| P-CAB（伏诺拉生等） | ✅ 替代选择 |

## 它和节的关系？

它是 PPI 临床评价的关键相互作用专题；是冠心病 / PCI 术后患者**联用氯吡格雷 + 抑酸药**的必考点；考点集中在"**奥美/艾司奥美避免 + 雷贝拉唑首选**"。
