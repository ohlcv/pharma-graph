# 抑酸剂用药原则

## 它在讲什么？

抑酸剂（PPI / P-CAB / H₂RA / 前列腺素类）4 大亚类在酸相关疾病（PU、GERD、卓-艾、HP 根除、NSAID 溃疡预防）中的选药与用药原则。

## 按抑酸强度怎么排？

**PPI ≈ P-CAB > H₂RA > 抗酸药**

- PPI（抑酸最强、不可逆）
- P-CAB（起效最快、可逆、抑酸强）
- H₂RA（中等、夜间酸突破）
- 抗酸药（仅即时中和）

## 按疾病怎么选？

| 疾病 | 首选 |
|---|---|
| 消化性溃疡（DU/GU） | **PPI**（4~8 周愈合 > 90%）|
| GERD / 反流性食管炎 | **PPI 或 P-CAB** |
| 卓-艾综合征 | **大剂量 PPI** |
| HP 根除 | **PPI 或 P-CAB + 抗生素 + 铋剂** 四联 |
| NSAID 溃疡预防 | **PPI 或米索前列醇** |
| 轻症 / OTC / 维持 | **H₂RA**（法莫替丁）|

## 服药时间怎么把握？

- **PPI**：餐前 30~60 min 整粒吞服（**肠溶不可破坏**）
- **P-CAB**：空腹/餐后均可（不受食物影响）
- **H₂RA**：餐后或睡前
- **米索前列醇**：餐中或餐后（与食物同服减少腹泻）

## 长期用药监测什么？

- **骨折风险**（影响钙吸收）
- **低镁血症**
- **维生素 B₁₂ 缺乏**
- **艰难梭菌感染**
- **急性间质性肾炎**

## 相互作用怎么管？

- 奥美/艾司奥美**避免与氯吡格雷合用**（强 CYP2C19 抑制）
- 需联用时选**雷贝拉唑、安奈拉唑**
- 强效抑酸影响铁剂、钙剂、Vit B₁₂ 吸收
- H₂RA 中**西咪替丁**多酶 CYP 抑制、抗雄激素（男性乳房发育）

## 它和节的关系？

它是第一节抑酸剂的临床用药总纲，统辖 4 大亚类与多个代表药；是 PPI 临床评价、PPI 与氯吡格雷相互作用等节点的总览。
