# 铋剂

## 它属于什么分类？

铋剂（Bismuth Agents）属于黏膜保护药的核心亚类（兼具黏膜保护 + 抗 HP 双重作用）。

## 它有什么独特之处？

**4 重机制**：

1. **物理保护膜**：在酸性环境下形成不溶性铋盐胶体，牢固覆盖溃疡/糜烂表面 → 隔绝胃酸、胃蛋白酶的侵蚀
2. **促 PGE₂ 合成**：增强黏液-碳酸氢盐屏障，改善黏膜血流
3. **吸附并灭活胃蛋白酶**
4. **抑制幽门螺杆菌**（HP）生长 → **HP 根除四联疗法核心组分**

代表药：

- **枸橼酸铋钾**（Bismuth Subcitrate Potassium）
- **胶体果胶铋**（Colloidal Bismuth Pectin）
- 复方铝酸铋、碱式碳酸铋等

## 临床应用是什么？

- **HP 根除四联疗法**（PPI + 铋剂 + 两种抗生素）核心组分
- 消化性溃疡（**辅助 PPI**）
- 慢性胃炎、胃黏膜糜烂
- NSAIDs 致黏膜损伤

## 服药注意是什么？

- **需酸性环境起效，餐前半小时服用**
- **不可与抗酸药、强效抑酸剂同服**（药效互相降低）
- 服药期间可出现**舌苔、大便灰黑色、口中带氨味** → 停药后自行消失（**正常现象**）

## 典型不良反应是什么？

- 常见：**恶心、便秘、食欲减退**
- 长期大量服用 → **铋蓄积中毒** → **铋性脑病**（严重）
- **禁忌**：严重肾功能不全者（铋蓄积）、妊娠期女性（铋透过胎盘）

## 它和节的关系？

它是黏膜保护药的核心亚类；HP 根除四联疗法的关键组分；考点集中在"**餐前服用 + 灰黑便 + 铋蓄积脑病**"。
