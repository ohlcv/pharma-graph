# 氟哌利多

## 它是什么药？

丁酰苯类多巴胺 D₂ 受体拮抗剂，**镇静+镇吐作用强**，常用于麻醉前给药、术后恶心呕吐（PONV）防治和难治性化疗呕吐。也是第一代抗精神病药（FGAs）丁酰苯类药物，与氟哌啶醇作用相近。

## 它有什么独特之处？

- 丁酰苯类**强效镇吐+镇静**（与氟哌啶醇同类，强效）
- **常用于麻醉前给药**（减少腺体分泌、预防呕吐）
- 与阿片类镇痛药联合用于**神经安定镇痛**
- 大剂量锥体外系反应明显
- **FDA 黑框警告**：QT 间期延长风险

## 核心作用特点是什么？

| 特点 | 说明 |
|---|---|
| **受体阻断** | 丁酰苯类中枢 D₂ 强效拮抗 |
| **镇吐效力** | 强效（与氟哌啶醇并列） |
| **镇静作用** | 强于多数同类 |
| **锥体外系** | EPS 明显 |
| **QT 风险** | FDA 黑框警告 | 

## 临床应用是什么？

**止吐用途（第四章第三节）：**
- 术后恶心呕吐（PONV）防治
- 麻醉前给药（减少腺体分泌、预防呕吐）
- 难治性化疗呕吐
- 与阿片类联合用于神经安定镇痛

**抗精神病用途（第一章第七节）：**
- 精神分裂症（丁酰苯类 FGAs）

## 典型不良反应是什么？

- **锥体外系反应**（急性肌张力障碍、帕金森样症状、静坐不能）
- **QT 间期延长**（FDA 黑框警告）
- 镇静、嗜睡
- 禁忌：帕金森病、嗜铬细胞瘤、长 QT 综合征
