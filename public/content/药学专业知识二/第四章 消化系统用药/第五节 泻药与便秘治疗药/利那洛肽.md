# 利那洛肽(Linaclotide)

## 它是什么药？

鸟苷酸环化酶 C（GC-C）激动剂促分泌药，口服后基本不吸收，在肠道内促进水和电解质类物质渗入粪便。

## 它有什么独特之处？

- 鸟苷酸环化酶 C 激动剂
- **口服后基本不吸收**
- 在肠道内促进水和电解质类物质渗入粪便
- 通过物理性刺激肠道排便，安全有效
- 适应症：**慢性功能性便秘**
- 用法用量：**成人推荐一日 290 μg**

## 临床应用是什么？

- 慢性功能性便秘
- 便秘型肠易激综合征（IBS-C）
- 阿片类顽固性便秘可尝试
- 妊娠期、糖尿病便秘可尝试

## 典型不良反应是什么？

腹泻为最常见；偶见腹胀、腹痛；罕见的严重腹泻需注意水电解质平衡。

## 它和节的关系？

4.5 节 7 大类第六类（促分泌药）核心代表；与同机制药物鲁比前列酮（氯通道激活剂）共为顽固便秘的可尝试选项。
