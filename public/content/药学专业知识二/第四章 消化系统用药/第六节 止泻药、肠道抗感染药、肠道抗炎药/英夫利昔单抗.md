# 英夫利昔单抗(IBD 用途, Infliximab)

## 它是什么药？

TNF-α 抑制剂生物制剂，IBD 一线肠道选择性生物制剂。

## 它有什么独特之处？

- TNF-α 单克隆抗体
- **目前 IBD 一线生物制剂**
- 通过抑制 TNF-α 的促炎作用发挥疗效
- 静脉输注给药
- 急性重度 UC 抢救常用
- 与 2.2 节抗风湿用途同药

## 临床应用是什么？

- 中重度 UC 诱导缓解与维持
- 中重度 CD 诱导缓解与维持
- 急性重度 UC 抢救
- 类风湿关节炎等（2.2 节用途）

## 典型不良反应是什么？

输液反应；感染易感（特别是结核、乙肝激活）；罕见肿瘤风险；自身免疫样反应。

## 它和节的关系？

4.6 节第三亚类第四大类（生物制剂）TNF-α 代表；与阿达木、戈利木、培塞利珠同属 TNF-α 抑制剂。
