# 慢性阻塞性肺疾病

## 它是什么病？

慢性阻塞性肺疾病（COPD，简称慢阻肺）是以持续气流受限为特征的可以预防和治疗的疾病，其气流受限多呈进行性发展，与气道和肺脏对有害颗粒或气体的慢性炎症反应有关。

## 它有什么临床特征？

- **慢性咳嗽**：晨起明显，间歇性至持续性
- **咳痰**：白色黏液或浆液性泡沫痰，急性加重时变脓性
- **进行性呼吸困难**：标志性症状，活动后加重
- **急性加重**：呼吸困难加重、痰量增多、脓痰、需改变治疗方案
- **肺功能诊断**：吸入支气管舒张剂后 FEV1/FVC < 0.70
- **危险因素**：吸烟（最主要）、职业粉尘、生物燃料烟雾

## 它怎么治疗？急性加重 + 稳定期

### 急性加重期（AECOPD）
- **短效支气管扩张剂**：沙丁胺醇 + 异丙托溴铵雾化吸入
- **全身糖皮质激素**：泼尼松 30-40 mg/d × 5-7 天
- **抗菌药**：仅在有脓痰、呼吸困难加重、痰量增加时使用（首选阿莫西林/克拉维酸、二代头孢、大环内酯）
- **氧疗**：低流量吸氧（目标 SpO₂ 88-92%）

### 稳定期（GOLD 阶梯治疗）
- **A 组**（低症状、低风险）：任一支气管扩张剂（SABA 或 LAMA）
- **B 组**（高症状、低风险）：LABA + LAMA 联合
- **C 组**（低症状、高风险）：LAMA 单药
- **D 组**（高症状、高风险）：LABA + LAMA + ICS（如果嗜酸性粒细胞 ≥300 或频繁加重）

## 它有什么用药监护关键点？

- **ICS 不用于单纯 COPD**：仅在哮喘-慢阻肺重叠综合征（ACO）或频繁急性加重时使用
- **戒烟**：戒烟是唯一能延缓肺功能下降的措施——不管吸了多少年，戒烟都有益
- **疫苗**：每年流感疫苗、每 5 年肺炎球菌疫苗
- **氧疗指征**：PaO₂ ≤ 55 mmHg 或 SaO₂ ≤ 88%——长期家庭氧疗（>15 小时/天）可降低死亡率
- **抗菌药选择**：根据当地耐药谱；阿莫西林/克拉维酸、二代头孢、大环内酯
- **吸入技术**：同哮喘，正确使用是关键——药师在吸入制剂教育中可以发挥重要作用
- **急性加重识别**：咳嗽加重、痰量增多、痰色变脓——要及时就医

## 它在知识体系里放在哪里？

它位于药学综合知识与技能第八章第二节慢性阻塞性肺疾病节，是该节的核心疾病。在药学专业知识二第三章呼吸系统用药章通过镇咳药和平喘药反向关联。COPD 是全球第三位死因，吸烟是其最重要的危险因素。它和哮喘有关——都是慢性气道疾病，吸入制剂是共同的治疗工具，但治疗策略不同（COPD 以 LAMA 为基础，哮喘以 ICS/LABA 为基础）。
